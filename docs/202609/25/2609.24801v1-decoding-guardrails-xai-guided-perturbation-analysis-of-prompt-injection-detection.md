## 摘要
大型语言模型（LLM）正日益部署于生产系统，这引发了对其因提示注入和越狱攻击而面临对抗性操纵风险的担忧。基于分类器的护栏（如 Prompt Guard 2）被广泛用作抵御此类攻击的第一道防线，但其内部决策逻辑对防御者和攻击者而言在很大程度上仍不透明。本文提出一项探索性案例研究，应用可解释人工智能（XAI）技术来分析 Prompt Guard 2 如何区分恶意提示与良性提示。我们开展四组实验，以实证方式探究这一问题。在 Vanilla Gradient 和 SHAP 归因的引导下，我们发现 Prompt Guard 2 的决策依赖于许多词元的累积贡献，而非少数主导词元；然而，显著性引导的同义词替换和句子级复述可以使其预测翻转，同时仅修改文本中中等比例的部分，在某些情况下还能对底层 LLM 实现成功的越狱。一项数据集规模的显著性分析进一步表明，未被检测到的注入提示系统性地缺乏分类器所依赖的词汇标记。我们讨论了这些发现对基于分类器的护栏设计与评估的启示，并指出，旨在支持透明度的解释方法可能同时降低构建成功对抗性绕过手段的成本。

## Abstract
Large language models (LLMs) are increasingly deployed in production systems, raising concerns about their exposure to adversarial manipulation through prompt injection and jailbreak attacks. Classifier-based guardrails, such as Prompt Guard 2, are widely used as a first line of defense against such attacks, but their internal decision logic is largely opaque to both defenders and attackers. This paper presents an exploratory case study that applies explainable artificial intelligence (XAI) techniques to analyze how Prompt Guard 2 distinguishes malicious from benign prompts.   We conduct four experiments to probe this question empirically. Guided by Vanilla Gradient and SHAP attributions, we find that Prompt Guard 2's decisions rely on the cumulative contribution of many tokens rather than a few dominant ones, yet saliency-guided synonym substitution and sentence-level paraphrasing can flip its predictions while altering only a moderate fraction of the text, in some cases yielding a successful jailbreak against the underlying LLM. A dataset-scale saliency analysis further shows that undetected injection prompts systematically lack the lexical markers the classifier relies on. We discuss the implications of these findings for the design and evaluation of classifier-based guardrails, and argue that explanation methods intended to support transparency can simultaneously lower the cost of constructing successful adversarial bypasses.

## 2. 方法论

- **目标模型**：Prompt Guard 2，基于 DeBERTa-v2 架构、86M 参数、以多语言 mDeBERTa 为基座，输入窗口 512 token（超长用滑动窗口），输出 benign/injection 二分类及 logits/置信度。
- **选用的 XAI 方法**（经预实验筛选）：
  - **Vanilla Gradient**：梯度类方法，度量模型输出对输入 embedding 的局部敏感度（"模型对哪些 token 更敏感"）。
  - **SHAP**：扰动/博弈论类方法，模型无关，估计每个 token 对最终预测的边际贡献（"每个 token 贡献了多少"）。
  - 两者互补，分别代表"敏感度"与"贡献度"两种视角。
- **被排除的方法及理由**：Integrated Gradients（文本序列的基线定义困难、影响归因质量）；Attention Rollout（假设注意力权重即重要性，已被广泛质疑，尤其在深层 Transformer 中信息跨层跨头分布）。
- **关键技术细节**：
  - 归因在**词级**聚合（tokenizer 常把一个词切成多个子词，子词归因求和得到词级分数）。
  - 用 **Feature Importance Spread 指标 SD** 衡量重要性分布偏离均匀分布的程度（越接近 0 越分散，越接近 1 越集中）。
  - 用 **Jaccard 指数**（Top-N 词交集）与 **Rank-Biased Overlap (RBO, p=0.9)** 衡量两种解释方法排序的一致性。
- **四组实验流程**（由显著性引导的扰动）：
  1. **Token 消除**：按显著性降序逐词删除，每步重新评估预测；同名多现词一次性全删。
  2. **同义词替换**：对 Top-16 高显著词构建人工同义词词典（借助 ChatGPT 5.5），每步贪心选择使 injection 置信度下降最大的同义词，直到标签翻转或词典耗尽。
  3. **句法改写**：将提示拆为 11 个从句，用辅助 LLM（ChatGPT 5.5）为每句生成 8 个语义等价改写，且避开 Top-18 高显著词；两种选择策略（最大化置信度下降 vs. 最小化显著度）。
  4. **数据集级显著性分析**：在数据集规模上批量应用 Vanilla Gradient，比较良性、正确检出的注入、漏检注入（假阴性）三类的聚合高显著词。
- **结果度量**：injection 类置信度、翻转所需扰动数、以及**对底层 LLM（Llama 3.1 8B）的越狱验证**（区分"仅护栏标签改变"与"真正越狱成功"）。

## 6. 主要结论与发现

- **决策依赖分布式词汇信号，而非单一主导 token**：
  - SD 值低（Vanilla Gradient 0.118、SHAP 0.169），无占绝对主导的 token。
  - 两方法在**最高显著词上一致**（如 "Ignore"），但排序越往下分歧越大：Top-18 词 Jaccard 仅 0.2857，RBO(0.9)=0.4394（共享词偏向排名靠前位置）。
  - Token 消除需 25 词（VG）/ 27 词（SHAP 全部）/ 21 词（仅 SHAP 正贡献词）才翻转；随机删除需 50+ 词，说明显著性是有效引导但仍非"少数关键词"依赖。
- **解释具有可操作性，可导致真实越狱**：
  - 同义词替换仅需 **12 次替换（约 24% 文本）** 即把置信度从 0.9994 降至 0.4457 并翻转为 benign，且成功越狱 Llama 3.1 8B。
  - 句法改写仅替换 **前 9 句** 即把置信度降至 0.3127。
  - 但 token 消除导致的退化提示**未能越狱**（底层 LLM 在护栏翻转前 5 步就已拒答）。
- **归因 ≠ 模型敏感度**：以"最小化替换后 token 显著度"为准则的策略完全失效（16 次替换后置信度仍 >0.9990），说明单 token 梯度显著度不是分类置信度下降的可靠代理。
- **数据集级证据：漏检源于词汇标记缺失**：
  - 良性提示高显著词为通用问答词汇（input, question, Options, answer）。
  - 正确检出的注入集中于指令覆盖/角色扮演词（previous, instructions, sensitive, confidential, access, restrict, ignore）。
  - 漏检（假阴性）提示显著词部分重叠但更泛化，且**偏向信息窃取类攻击**而非指令覆盖类——表明模型主要依赖特定攻击家族的词汇线索，而非通用恶意意图的语义理解。
- **跨语言**：西语复现出一致的归因稳定性与词汇依赖，且**绕过所需修改更少**（同义词替换仅 7 步 / 约 18% 文本，置信度降至 0.2224，仍能越狱），暗示在低资源语言上更脆弱；但句法改写未能在西语上找到绕过。
- **越狱有效性**：原始提示与同义词替换版效果相近（3 个 Partial + 1 个 Functional）；句法改写版绕过护栏但越狱效果更弱（3 个 Non-Functional + 1 个 Functional）。
- **核心论断**：分类器护栏更依赖**表层词汇模式**而非深层意图理解；而旨在支持透明度的 XAI 方法，同时**降低了构造成功对抗绕过的成本**。

## 7. 优点

- **问题视角新颖**：将 XAI 明确定位为"双刃剑"，把解释方法本身当作分析对象，而非仅作调试工具，对护栏设计与评估有直接启示。
- **方法组合互补**：梯度类（局部敏感度）与扰动类（边际贡献）双解释交叉验证，并用 SD、Jaccard、RBO 三个量化指标刻画一致性，避免单一解释的偏置。
- **闭环验证**：不满足于护栏标签翻转，进一步用底层 Llama 3.1 8B 验证真实越狱，并用第二个 LLM 裁判对输出功能性分档，结论更可信。
- **策略对照设计**：置信度引导 vs. 显著性引导的对比，揭示了"归因分数"与"模型整体敏感度"之间的差距，是一个有方法论价值的发现。
- **层次完整的实验链条**：词级 → 句级 → 数据集级 → 跨语言，从单点案例逐步推广到分布层面。
- **工程可落地**：明确指出 XAI 可用于定向数据增补、阈值校准、分布漂移监控、验证流水线中的盲点探测。
- **开源数据与可复现性**：使用公开数据集与公开模型，实验流程描述较细（含替换历史表）。

## 8. 不足与局限

- **算力与资源信息缺失**：未报告任何硬件/成本细节，难以评估方法的可扩展性与复现门槛。

- **数据集本身存在偏差**：恶意样本由 GPT-3.5-turbo 合成，攻击模式同质化，可能导致"词汇依赖"结论被数据集特性放大；真实世界攻击分布未必一致。
- **跨语言对照不严谨**：英西提示非平行文本，语言效应与其他变量混杂。
- **缺乏与现有攻击方法的定量对比**：未与 Hackett 等（字符级混淆 + 白盒代理）、PRP、STACK 等在同一设置下比较攻击成功率，因此无法评估该方法的相对强弱。
- **静态单轮限制**：只考察单轮静态提示，未覆盖多轮对话越狱、跨轮上下文注入等真实威胁。
- **假阴性分析偏粗**：仅做聚合词显著度与人工抽查，未给出机理层面的深入解释（作者自承）。
- **评估主观性**：越狱有效性由 LLM 裁判（Claude Sonnet 5）按三档打分，存在评判偏差；

- 缺少人工越狱评估的交叉验证，单一 LLM 裁判的判定可能被后续模型版本变化所影响。
- **解释方法的固有局限未充分展开**：作者将 RQ5（XAI 对 Transformer 分类器的局限）列为研究问题，但正文更多是"应用解释"而非"批判解释"——例如梯度类方法在 embedding 空间的噪声、SHAP 在 512 token 长序列上的计算近似误差、以及归因分数对 tokenizer 切分粒度的敏感性，均未做系统的鲁棒性检验。
- **显著性引导 vs. 置信度引导的对比是单向的**：只证明了"显著性引导不如置信度引导有效"，但没有反向回答"在什么条件下显著性引导仍有价值"（如黑盒场景下无法获取置信度梯度时）。
- **攻击成本未被量化**：论文强调 XAI"降低了攻击者成本"，但未给出具体成本指标（如查询次数、所需辅助 LLM 调用量、人工介入程度），因此"降低多少成本"缺乏可比较的基准。
- **单模型结论**：全部机理分析围绕 Prompt Guard 2 展开，未验证结论是否能迁移到 Llama Guard、其他基于 BERT/DeBERTa 的护栏，或其他架构（如生成式护栏、LLM-as-judge 护栏）。"护栏依赖表层词汇模式"这一论断的外部效度存疑。
- **防御侧建议停留在方向性层面**：虽提出定向数据增补、阈值校准、漂移监控等思路，但未给出可操作的方案设计或实验验证，也未讨论这些防御是否会与攻击形成新的军备竞赛。

## 9. 对研究问题的回答（汇总）

- **RQ1（依赖哪些语言模式）**：依赖**分布式、多词协同的词汇线索**，而非单一"魔法 token"；不同攻击家族对应不同的词汇簇（指令覆盖型 vs. 信息窃取型）。
- **RQ2（跨方法/跨语言一致性）**：两方法在**头部显著词**上一致、在长尾排序上分歧显著（Jaccard 0.29、RBO 0.44）；跨语言上归因模式稳定，但绕过所需修改更少。
- **RQ3（鲁棒信号 vs. 少数 token）**：SD 值低表明信号较分散，但删除实验显示仍需 21–27 词才能翻转，且随机删除需 50+ 词——即**介于"鲁棒语义理解"与"少数关键词依赖"之间，偏向浅层词汇模式**。
- **RQ4（解释能否揭示漏洞）**：能。解释直接引导出同义词与句法两类有效绕过，且绕过在底层 LLM 上**真实越狱成功**，验证了 XAI 的"武器化"潜力。
- **RQ5（XAI 对 Transformer 分类器的局限）**：解释结果与模型敏感度之间存在**系统性错配**（最小化显著度的策略完全失效），提示归因分数不能直接等同于因果重要性。

## 10. 实践启示与后续方向

- **对护栏开发者**：应假定分类器学到的是可被词汇扰动绕过的浅层特征；需引入语义/意图层面的鲁棒性训练、对抗数据增补与跨语言均衡评估，并将"解释一致性"纳入发布前的红队流程。
- **对红队/攻击方**：XAI 可作为**低成本对抗样本生成器**，优先在高显著词上做同义替换，通常比字符级混淆更省力。
- **对 XAI 研究者**：需要更严谨地刻画"解释保真度（faithfulness）"与"解释稳定性"，尤其是在长文本、多语言与安全敏感场景中。
- **后续可做的实验**：(i) 多提示、多模型、多语言的规模化复现；(ii) 与 PRP、STACK、字符级混淆方法的同条件对比；(iii) 多轮对话越狱与自适应攻击者设定；(iv) 针对假阴性提示的机理级（而非聚合词频）分析；(v) 量化攻击成本与防御收益的权衡曲线。

## 11. 总体评价

这是一篇**视角新颖、方法互补、闭环验证较完整**的探索性研究：它把 XAI 从"调试工具"重新定位为"攻防双方的共享信息源"，并用一条代表性 DAN 提示完整演示了"解释 → 扰动 → 护栏翻转 → 真实越狱"的攻击链。其最有价值的发现有两层——**机理层**（护栏依赖浅层词汇模式，漏检源于词汇标记缺失）与**方法论层**（归因分数 ≠ 模型敏感度，显著性引导并非最优扰动策略）。

但受限于**单提示核心案例、400 条采样、合成数据集、非平行跨语言对照、以及缺失的算力与攻击成本量化**，其结论更应被理解为**有启发性的假设生成**，而非可泛化的定论。论文自身也以"案例研究"定位，态度审慎。

总体而言，它对 LLM 护栏的安全评估、XAI 的负责任使用、以及"透明度即攻击面"这一安全悖论，都提供了具体而可操作的讨论素材，值得护栏设计者与红队研究者参考。
