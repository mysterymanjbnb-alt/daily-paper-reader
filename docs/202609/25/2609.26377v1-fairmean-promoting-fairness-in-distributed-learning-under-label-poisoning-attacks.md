## 摘要
公平性感知的分布式学习会优先考虑损失较大的客户端，以减小性能差异，但标签投毒可能制造大损失，从而引发公平性—鲁棒性冲突。我们提出 FairMean 来管理这一冲突。FairMean 使用局部损失的有界非递减函数对客户端梯度进行加权。递增的权重会优先考虑高损失客户端，以促进公平性，而上界则防止由损失引起的对投毒客户端梯度的过度放大。在没有标签投毒的情况下，我们表明最小化 FairMean 目标比最小化标准平均损失目标更有利于解的公平性。在标签投毒下，我们建立了一个平均平稳性界，其依赖攻击的项与投毒客户端比例的平方成正比。实验表明，FairMean 通过降低准确率方差并提高最差客户端准确率来促进公平性。

## Abstract
Fairness-aware distributed learning prioritizes clients with large losses to reduce performance disparities, but label poisoning can create large losses, thereby inducing a fairness--robustness conflict. We propose FairMean to manage this conflict. FairMean weights client gradients using a bounded, nondecreasing function of local loss. The increasing weights prioritize high-loss clients to promote fairness, while the upper bound prevents excessive loss-induced amplification of poisoned-client gradients. In the absence of label poisoning, we show that minimizing the FairMean objective is more conducive to solution fairness than minimizing the standard average-loss objective. Under label poisoning, we establish an average-stationarity bound whose attack-dependent term is proportional to the square of the poisoned-client fraction. Experiments show that FairMean promotes fairness by reducing accuracy variance while improving worst-client accuracy.

## 1. 核心问题与研究动机

- **背景**：分布式/联邦学习通常最小化客户端本地损失的平均值。当客户端数据异构时，全局模型往往在多数客户端表现良好，却在少数客户端表现很差。
- **公平性范式**：由于"损失大 ≈ 当前表现差"，公平性感知方法普遍对高损失客户端赋予更大权重，以缩小客户端间性能差距（如 q-FFL 的幂变换、TERM 的指数倾斜、DRFL 的自适应聚合权重、FedMDFG/FedLF 的多目标公平引导等）。
- **新威胁**：**标签投毒攻击（label poisoning）** 下，恶意客户端只篡改标签、特征与协议流程不变，但会人为制造大损失与误导性梯度。这类攻击是拜占庭攻击的特例（遵循协议而非任意消息），传统鲁棒聚合器的离群点筛除在此类攻击 + 数据异构场景下可能失效（甚至会丢弃有用于公平性的异构更新）。
- **已有工作线索**：文献 [15] 表明，在标签投毒 + 强异构数据下，**均值聚合反而可能优于多种鲁棒聚合器**。
- **核心矛盾（fairness–robustness conflict）**：无界的损失重加权（如 q-FFL 当 q>0 时乘子无上界）无法区分"真正表现差的正规客户端"和"因投毒而损失大的恶意客户端"，会过度放大投毒梯度；而筛选式鲁棒机制又会误伤正规异构更新。
- **核心研究问题**：如何在不放大投毒客户端梯度的前提下，优先照顾损失大的**正规**客户端？

## 2. 方法论

### 2.1 核心思想
保留均值聚合框架，引入一个**有界、非递减、Lipschitz 连续**的边际权重函数，对每个客户端的梯度按本地损失加权：权重随损失增大而增大（促进公平），但有统一上界（限制投毒梯度被放大）。

### 2.2 关键技术细节

- **损失变换**（式 2）：
  φ_{κ,τ}(z) = z + κ[z − τ·log(1 + z/τ)]，κ, τ > 0
  满足 φ_{κ,τ}(z) ≥ z，且增量 φ−z 随 z 增大而增大。
- **边际权重函数**（式 4）：
  a_{κ,τ}(z) = 1 + κ·z/(z+τ)
  性质：
  - 非递减（优先高损失客户端）；
  - 有界：1 ≤ a_{κ,τ}(z) ≤ 1+κ（**上界 1+κ 直接限制额外放大倍数**）；
  - κ/τ-Lipschitz 连续（避免权重突变）；
  - a_{κ,τ}(τ) = 1 + κ/2，增大 τ 会把"中点"推向更大损失值。
- **变换后目标**（式 3）：Φ^R_{κ,τ}(w) = (1/r) Σ_{i∈R} φ_{κ,τ}(f_i(w))，其梯度即各客户端梯度按边际权重加权平均（式 5）。
- **公平性–分散度等价分解**（式 6）：
  Φ^R_{κ,τ}(w) = φ_{κ,τ}(F_R(w)) + κ·D_τ(w)
  其中 D_τ(w) 为损失分散度项，D_τ ≥ 0，当且仅当所有正规客户端损失相等时为 0。
- **方差夹逼**（式 7）：τ/(2(B+τ)²)·Var_R ≤ D_τ ≤ (1/(2τ))·Var_R，说明最小化 FairMean 目标等价于显式惩罚客户端损失方差，从而连接公平性。
- **算法流程（Algorithm 1）**：
  1. 服务器广播 w_t；
  2. 各客户端并行计算本地损失与梯度；
  3. 客户端发送 v_i^t = a_{κ,τ}(f_i(w_t))·∇f_i(w_t)；
  4. 服务器做均值聚合更新 w_{t+1} = w_t − (α/n)Σ v_i^t。
  由于服务器不知道哪些是正规客户端，该变换被施加于**所有**客户端。

### 2.3 理论分析

- **定理 1（无投毒）**：p = 0 时，FairMean 全局最优解 w*_FM 的分散度不大于原始平均损失目标最优解 w*_avg，即 D_τ(w*_FM) ≤ D_τ(w*_avg)——最小化 FairMean 目标更有利于"解的公平性"。
- **假设 1**：W 为凸集，正规客户端损失 L-光滑。
- **假设 2**：正规客户端梯度有界 ‖∇f_i‖ ≤ G；投毒客户端偏差 ‖∇f̃_i − ∇F_R‖ ≤ A_LP。
- **引理 1**：对多类交叉熵损失，若 logit 雅可比有界 Γ、投毒客户端相对正规平均梯度的偏差 ≤ H_P、单客户端重标比例 ≤ ρ，则 G = √2Γ，A_LP = H_P + √2·ρΓ。
- **引理 2（误差界）**：算法可视为对 Φ 的非精确梯度下降，误差
  ‖e_t‖ ≤ ε(δ,κ) = δ[(1+κ)A_LP + 2κG]，其中 δ = p/n 为投毒客户端比例。
- **定理 2（平均平稳性界）**：
  (1/T)Σ‖∇Φ^R_{κ,τ}(w_t)‖² ≤ 2Φ^R_{κ,τ}(w_0)/(αT) + ε(δ,κ)²
  优化项以 O(1/T) 衰减，**攻击项与投毒比例 δ 的平方成正比**；步长上界 α ≤ 1/L_Φ(κ,τ)，其中 L_Φ(κ,τ) = (1+κ)L + (κ/τ)G²——κ 越大或 τ 越小（更激进的公平优先），所需步长越保守。

- **理论层面**：
  1. 无投毒时，最小化 FairMean 目标得到的全局最优解具有更小的损失分散度，因而更公平；

- **实验层面**：
  - 无攻击时 FairMean 表现**有竞争力**（但并非最优，如 CIFAR-10 无攻击下平均准确率 70.15 vs FedAvg 71.54，方差 34.46 略高于 AdaFed 的 31.83）；
  - 在全部四种"数据集 × 攻击"设置下，FairMean 均取得**最低准确率方差**与**最高最差客户端准确率**，同时平均准确率保持有竞争力。例如 CIFAR-10 pairwise flip：方差 99.34（q-FFL 131.22）、最差 50.97（q-FFL 38.42）；Fashion-MNIST pairwise flip：方差 31.95（q-FFL 48.41）、最差 71.29（q-FFL 66.34）；

## 8. 局限与可改进之处

- **超参缺乏指导原则**：论文未给出 κ、τ 的选取准则，也未做敏感性分析；而定理 2 明确显示 κ 增大或 τ 减小会收紧步长上界（L_Φ = (1+κ)L + (κ/τ)G²），意味着"更公平"与"可训练性"存在实际取舍，使用者难以判断在何种数据异构程度下应选多大 κ。
- **威胁模型偏弱**：投毒客户端仅做随机翻转与成对翻转，属于"非自适应、非目标化"的朴素攻击。没有考虑针对 FairMean 加权机制的反制攻击（例如恶意客户端故意压低自身损失以降低权重、或在多轮中渐进抬升损失以持续占据权重上界 1+κ），因此鲁棒性结论的适用范围有限。
- **有界权重的"保护"是双向的**：1+κ 的上界既限制了恶意梯度放大，也同时限制了真正高损失正规客户端所能获得的额外关注度，因此在极端异构（少数客户端数据极度稀缺）场景下，FairMean 的公平性提升可能存在天花板，论文未讨论这一权衡的边界。
- **理论假设较强**：假设 1 要求凸集与 L-光滑，假设 2 要求正规梯度有界、投毒偏差有界（A_LP），引理 1 还要求 logit 雅可比有界与重标比例有界。这些在深度非凸网络中并不严格成立，理论界更接近定性指引而非可验证的数值保证。
- **聚合粒度较粗**：方法对所有客户端统一施加变换，未利用任何客户端身份/历史信息（如跨轮损失轨迹的一致性）。这虽然规避了误判正规客户端的风险，但也放弃了潜在的额外判别力。
- **实验覆盖面有限**：仅两个图像分类数据集、10 客户端、2 个恶意客户端，缺少客户端规模、投毒比例（除单一扫描外）、数据异构程度（Dirichlet 浓度）的系统网格；也没有多随机种子统计与显著性检验，无法判断结论的稳健性。
- **缺少与"信任/信誉机制"类方法的对比**：如基于历史更新的信誉加权或基于验证集的服务器端检测，这类方法同样不依赖离群点筛除，是 FairMean 的自然竞品，但未被纳入基准。

## 9. 对研究与实践的启示

- **概念层面**：论文提出的"fairness–robustness conflict"是一个有价值的问题框架——公平性机制本质上是"放大劣势者信号"，而鲁棒性机制本质上是"压制异常信号"，二者在"损失大"这一观测上不可区分，冲突是结构性的而非实现缺陷。这一视角可迁移到其他"重加权类"算法（如代价敏感学习、难度感知采样、OHEM）的安全性分析。
- **设计范式**：用"有界 + 单调 + Lipschitz"的边际权重替代无界重加权，是一种通用的"安全化改造"思路——保留目标函数的公平性梯度方向，同时为最坏情况下的放大倍数设上限。该思路原则上可套用到 q-FFL、TERM 等已有方法的加固上。
- **实践建议**：在存在不可信参与方但数据高度异构的联邦场景中，直接使用激进鲁棒聚合（Krum、Median 等）可能因误伤异构更新而得不偿失；此时"均值聚合 + 有界公平重加权"可能是更稳妥的默认选择，但仍需配合基本的异常监控。
- **评测建议**：论文的指标设计（同时报告方差、最差客户端、平均准确率）值得借鉴——公平性论文若只报均值或只报最差，都可能掩盖真实代价。

## 10. 总体评价

FairMean 是一篇**动机清晰、方法轻量、理论自洽**的工作。它抓住了一个此前被忽视的交叉点：公平性感知聚合在标签投毒下的脆弱性。其贡献不在于提出更复杂的聚合器，而在于用一个极简的有界重加权函数，在"提升公平性"与"不放大攻击"之间找到了一个可解析的折中点，并通过分散度分解与平稳性界给出了理论支撑。

主要短板在于**实验规模与威胁模型的强度**：数据集小、客户端少、攻击朴素、超参无敏感性分析、无多次运行的统计报告，使得"FairMean 在真实对抗环境下依然稳健"这一主张尚未被充分检验。理论上较严格的凸性与光滑假设也削弱了界在实际深度网络中的直接适用性。

综合来看，该文适合定位为"提出一个有价值的问题框架 + 一个简洁可行的初步解法"，其方法与视角对后续的"安全公平联邦学习"研究有较好的启发价值，但在鲁棒性主张上仍需自适应攻击与更大规模实验的进一步验证。
