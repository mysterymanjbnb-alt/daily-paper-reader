## 摘要
LLM 智能体被部署到授予其广泛主机权限的基础设施中，然而现有的智能体安全基准与防御几乎完全在应用遥测层运行：所提供的工具清单、用户提示以及模型消息。然而，某些威胁会将恶意指令和操作偷带越过应用边界，使其对该层不可见。在本工作中，我们弥合这一差距，通过将应用级智能体遥测与内核级系统调用轨迹配对，首次给出面向智能体安全的内核级信号与应用层信号的配对证据刻画。为量化增强遥测的价值，我们提出 Agent Cross-Layer Evidence (ACE)，一个包含 4,047 个会话和 17 个威胁模型的配对会话语料库，涵盖六类投递向量家族以及 OWASP LLM 与智能体威胁类别 25 类中的 14 类，并按 12 种攻击机制组织，且针对每种机制刻画了最具判别力的证据所在位置。在四类不同的检测器家族中，我们发现内核证据本身具有判别力，并且将其与应用层证据组合通常优于任一单层视角，揭示了单层分析可能遗漏的互补信号。我们进一步展示了对未见攻击家族的泛化能力，以及对另一种智能体运行时的迁移能力。这些发现共同确立了跨层证据对智能体安全的价值。

## Abstract
LLM agents are deployed into infrastructure that grants them broad host authority, yet existing agent-security benchmarks and defenses operate almost exclusively at the application telemetry layer: the served tool manifest, the user prompt, and the model's messages. Some threats, however, smuggle malicious instructions and actions past the application boundary, leaving them invisible to that layer. In this work, we bridge that gap by pairing application-level agent telemetry with kernel-level syscall traces to present the first paired-evidence characterization of kernel-level versus application-layer signal for agent security. To quantify the value of the enhanced telemetry, we introduce Agent Cross-Layer Evidence (ACE), a paired-session corpus of 4,047 sessions and 17 threat models spanning six delivery-vector families and 14 of the 25 OWASP LLM and agentic threat categories, organized into 12 attack mechanics with per-mechanic characterization of where the most discriminative evidence lies. Across four distinct detector families, we find that kernel evidence is discriminative on its own and that composing it with application-layer evidence generally outperforms either single-layer view, revealing complementary signals that single-layer analyses can miss. We further demonstrate generalization to unseen attack families and transfer to an alternate agent runtime. Together, these findings establish the value of cross-layer evidence for agent security.

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体已被部署到生产基础设施中，可读文件、调 API、执行 shell 命令，权限等同完整用户 shell。但现有智能体安全基准与防御几乎全部工作在**应用遥测层**——工具清单（tools/list）、用户提示、模型消息。
- **证据缺口**：部分威胁将恶意指令和动作偷带越过应用边界，对应用层不可见。例如：MCP 包静默读取 `/credentials` 并外传、良性文档内嵌 payload 诱导 bash 执行、工具描述中走私指令。意图层防御（提示注入防护、schema 校验、能力代理）要么在该层看不到异常，要么拒绝错误的行为子集。
- **核心问题**：内核级系统调用轨迹（Kernel-View）是否对智能体攻击具有独立判别力？将其与应用层证据组合（Cross-View）是否优于任一单层视角？
- **整体含义**：本文首次给出面向智能体安全的内核级信号与应用层信号的**配对证据刻画**，提出 ACE 语料，并系统评测跨层证据价值，主张将内核级证据作为智能体安全检测的一等输入。

## 2. 方法论

### 2.1 核心思想
- 每个会话在独立 Docker 容器中运行，同时捕获**内核侧 syscall 轨迹**与**应用侧遥测**（tools/list 清单 + 智能体转录），形成配对会话。
- 定义三个证据视图：
  - **App-View**（29 维特征）：服务协议表面 + 轨迹 + 提示结构，即意图层审计器所见。
  - **Kernel-View**（57 维特征）：容器内 syscall 轨迹，即内核层主机 IDS 所见。
  - **Cross-View**（86 维）：两者特征级拼接。

### 2.2 关键技术细节
- **会话为分析单元**：一次 `(威胁模型, 提示, 变体)` 执行，容器启动到销毁为界；标签仅在会话级定义。
- **归因保证**：一容器一 strace，容器独立 PID 命名空间，`strace -f` 跟随 fork/clone/exec。归因是部署形状的结构性属性，经验验证 100% 精度（30 会话、8,240 事件、0 跨会话泄漏）。
- **捕获管道**：Claude Code CLI（claude-haiku-4-5），15 个 tracepoint（execve、openat、connect、sendto、recvfrom、unlinkat、ptrace、clone 等），每会话平均约 3,500 个传感器事件。四类工件：元数据、完整转录、tools/list 快照、完整 syscall 轨迹。
- **特征化**：86 维数值特征。
  - 内核层 57 维：会话总量、14 个 tracepoint 的每 syscall 计数/对数计数/速率、8 个结构性 syscall 对比例、IP/路径基数。
  - 应用层 29 维：提示结构（4）、schema 结构（10）、轨迹（13）、结果新颖性（2）。
  - **设计原则**：计数与基数而非身份；内容盲，无机制特定哨兵字符串，重命名不变。
- **火谓词（fire predicate）**：每个恶意补丁附带 `signature.json`，由内核子句（syscall 名、参数子串、计数阈值）与应用子句（描述/响应子串、schema 结构检查）经 AND/OR 组合。141 个恶意补丁中 57 个含应用子句、70 个仅内核、14 个无签名。
- **标签语义**：
  - Benign：未打补丁，y=0。
  - Malicious：恶意变体运行且火谓词匹配，y=1。
  - Dormant：恶意变体运行但目标工具未执行，y=0。
  - Latent：恶意变体运行且目标工具执行但火谓词未匹配；信号承载潜在会话从评分中丢弃，无签名潜在会话作为 y=0。
- **检测器家族**：
  - 经典：AdaBoost（200 棵深度 3 树，lr=0.5）、XGBoost（200 棵深度 6 树，lr=0.1）。
  - 深度表格：TabPFN、TabICL，预训练表格基础模型，推理时上下文学习，无梯度训练。
  - LLM 评判：Qwen3-235B/80B/32B，2×2 扫描（基线 vs OWASP 接地模板 × K=0 vs K=1 14 参考）。
  - 微调 SLM：Qwen2.5-3B/7B、Llama-3.1-8B，LoRA（r=64, α=128, dropout=0.1），每 (视图, 折) 一个适配器，verdict token 目标。
  - 规则基线：Falco 默认规则包，仅内核视图。
- **评估机制**：
  - **5 折分层（ID）**：每个攻击机制在训练和测试中均按比例出现，衡量拟合上限。
  - **7 折 OWASP 对齐（OOD）**：每折完全留出一个 OWASP 锚定攻击家族（A–G），并做匹配良性每主机，衡量泛化。
  - 报告均值 AUROC ± 每折补丁聚类 bootstrap 标准误（1,000 重采样）。
