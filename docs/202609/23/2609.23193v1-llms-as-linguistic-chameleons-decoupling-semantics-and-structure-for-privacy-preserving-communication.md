## 摘要
随着大语言模型（LLM）API 日益集成到隐私敏感工作流中，在不损害任务效用的前提下确保推理时隐私仍然是一项重大挑战。现有方法为保持下游性能而保留了大部分原始语义内容，但这也留下了可用于重建原始文本的可利用线索。本文研究语义解耦，即用替代内容替换原始语义，同时保留 LLM 推理所需的结构。基于这一思想，我们提出 CROSS-MAP，一种双向框架，在推理前将私有输入映射到不同的语义域，并在推理后恢复相应的输出。通过多目标优化训练本地模型，以在映射阶段最大化语义差异，同时在恢复阶段最小化语义不一致。实验表明，CROSS-MAP 在多种攻击设置下降低了重建成功率，同时在效用方面优于现有基线。

## Abstract
As Large Language Model (LLM) APIs become increasingly integrated into privacy-sensitive workflows, ensuring inference-time privacy without compromising task utility remains a major challenge. Existing approaches preserve most of the original semantic content to maintain downstream performance, but this also leaves exploitable cues for reconstructing the original text. This work investigates semantic decoupling, which replaces original semantics with alternative content while preserving the structure needed for LLM reasoning. Based on this idea, we propose CROSS-MAP, a bidirectional framework that maps private inputs into a different semantic domain before inference and recovers the corresponding outputs afterward. Local models are trained with multi-objective optimization to maximize semantic divergence in the mapping stage while minimizing semantic inconsistency in the recovery stage. Experiments show that CROSS-MAP reduces reconstruction success across multiple attack settings while outperforming existing baselines in utility.

## 1. 核心问题与整体含义

- **研究动机**：LLM API 正被广泛集成到隐私敏感工作流中，用户查询、智能体指令等敏感通信需发送给第三方提供商，推理时隐私保护成为关键挑战。
- **现有方法的困境**：差分隐私、匿名化/脱敏等方法为维持下游任务性能，通常让转换后文本与原文**语义高度接近**；但语义保留越多，攻击者可利用的重建线索越多，形成"隐私—效用"两难。
- **核心洞察**：语言学视角下文本可分解为**结构**（句法组织、词序、依存关系）与**语义**（实体、事件、属性）。LLM 的许多推理任务主要由结构模式驱动，而敏感信息主要编码在语义中，结构相对良性。
- **整体含义**：提出**语义解耦（semantic decoupling）**新范式——替换原始语义内容、保留推理所需结构，使敏感语义完全留在本地，LLM 只处理"结构保持但意义替换"的表示。例如 `thief robs the bank` 可映射为 `waiter wipes the table`，结构一致但语义不同，只有持有映射码本的授权方可恢复原文。

## 2. 方法论（CROSS-MAP）

- **核心思想**：双向框架。推理前用本地**映射器** $M_\phi$ 将输入 $x$ 映射到不同语义域，推理后用本地**恢复器** $R_\psi$ 恢复输出，第三方 LLM 只见映射文本。
- **关键技术细节**：
  - 映射器输出结构化三元组 $(\tau, D, y)$：目标域主题 $\tau$、映射字典 $D=\{(s_i,\hat{s}_i)\}_{i=1}^m$（原 span → 目标域 span）、映射文本 $y$。
  - 恢复器从 $(\tau, D, y)$ 重建恢复文本 $\tilde{x}$；二者均为指令微调 LLM，输出 JSON 结构。
- **可验证奖励设计**（加权聚合为标量奖励）：
  - 字典覆盖率 $c_{dict}(x,D)$：被字典 span 覆盖的 token 比例。
  - 字典距离 $d_{dict}(D)=1-\frac{1}{m}\sum \text{Sim}(s_i,\hat{s}_i)$（span 嵌入余弦距离）。
  - 文本距离 $d_{text}(x,y)=1-\frac{1}{L}\sum \text{Sim}(x_j,y_j)$（句级嵌入距离）。
  - 流畅度 $f_{text}(y)$：负对数困惑度。
  - 恢复一致性 $1-d_{text}(x,\tilde{x})$。
  - 总奖励 $r = w_1 c_{dict} + w_2 d_{dict} + w_3 d_{text} + w_4 f_{text} + w_5(1-d_{text}(x,\tilde{x}))$。
- **训练流程（三阶段）**：
  1. **种子数据合成**：用 GPT-5.2 生成少量 $x \to (\tau,D,y)$ 与 $(\tau,D,y)\to\tilde{x}$ 训练实例。
  2. **SFT**：以同一基座 LLM 初始化映射器与恢复器，用 LoRA 参数高效微调。
  3. **DPO 多目标对齐**：对每个 $x$ 采样 $K$ 个映射候选并逐一恢复，按奖励排序构造偏好对（奖励间隔 $\gamma>0$），优化映射器以提升高奖励输出相对似然。
- **信息论分析**：
  - 将映射搜索表述为信息瓶颈目标 $G(M)=\min_M I(x;y)-\beta I(y;z)$。
  - **定理 1**：在语义与结构独立的假设下，当任务对语义的依赖系数 $\lambda_s$ 低于某阈值（由压缩增益 $\Delta\rho_s,\Delta\rho_c$、任务相关信息损失 $\Delta\eta_s,\Delta\eta_c$、常数 $\beta',r$ 决定）时，语义解耦映射 $M_{SD}$ 的信息瓶颈目标低于语义保留映射 $M_{SP}$。
  - **推论 1**：当压缩增益超过任务相关信息损失时，$M_{SD}$ 占优。
  - 结合 VIB 说明：降低 $I(x;y)$ 等价于使攻击者后验 $p(x|y)$ 趋近先验，从而提升隐私。
- **攻击视角**：引入基于 DPO 的白盒攻击者，在映射器参数暴露、字典部分泄露率 $\rho$ 的场景下最大化重建相似度 $\hat{r}(\hat{x};y)=1-d_{text}(\hat{y},y)$；附录给出字典泄露下 ASR@K 的后验质量/惊奇度分析。
- **部署流程**（算法 1）：映射器本地生成 $(\tau,D,y)$ → 发送 $y$ 给第三方 LLM → 收到响应 $y_a$ → 恢复器联合字典与响应输出 $\tilde{x},\tilde{x}_a$。

CROSS-MAP 提出了一种新颖的语义解耦隐私保护范式，在多个任务和威胁模型下展示了隐私—效用权衡的显著改进，理论分析为其适用边界提供了依据。尽管存在任务依赖、事实一致性、本地安全假设和实验报告不完整等局限，但该工作为 LLM 推理隐私保护提供了有前景的方向，并开源代码促进后续研究。
