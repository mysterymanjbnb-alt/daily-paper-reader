## 摘要
基于大语言模型（LLM）的智能体正越来越多地应用于漏洞发现和自动化渗透测试等网络安全任务。然而，在长时程安全任务中，此类智能体仍受限于上下文遗忘和意图漂移：早期关键事实与因果推理链在长时间交互中丢失，智能体陷入无目的、重复性的探索。本文提出 Intentest，一种意图图引导的自动化渗透测试智能体，其将长时程状态从 LLM 的上下文窗口外化到持久化的事实-意图有向无环图（DAG）上，从而显著减少无效转移。我们在 Web 应用的自动化渗透测试这一网络安全中具有代表性的长尾任务上评估 Intentest。在 DAG 中，已验证的网络状态被存储为不可变的事实节点，探索方向被约束为由前驱事实限定的意图边。该系统采用三层架构，其中事实-意图映射层维护全局状态，任务调度与分配层通过两阶段降级恢复和多维自适应负载均衡确保执行稳定性，意图检索与预测层通过自顶向下的五阶段过滤算法提供战术先验。在覆盖三种难度级别、十余种漏洞类型的真实 CTF 挑战基准上，Intentest 的总体成功率达到 88.2%，困难任务成功率达到 75.0%，相较基线分别提升约 44 和 50 个百分点。消融实验进一步表明，意图检索与预测在不改变可解任务集合的情况下，将成功完成中等和困难任务的平均轮数分别减少约 33% 和 48%。

## Abstract
Large language model (LLM) based agents are increasingly applied to cybersecurity tasks such as vulnerability discovery and automated penetration testing. On long-horizon security tasks, however, such agents remain limited by context forgetting and intent drift: early critical facts and causal reasoning chains are lost over extended interactions, and the agent falls into aimless, repetitive exploration. This paper proposes Intentest, an intent-graph-guided automated penetration testing agent that externalizes long-horizon state from the LLM's context window onto a persistent fact-intent directed acyclic graph (DAG), thereby substantially reducing invalid transitions. We evaluate Intentest on automated penetration testing of web applications, a representative long-tail task in cybersecurity. In the DAG, verified network states are stored as immutable fact nodes, and exploration directions are constrained as intent edges bounded by predecessor facts. The system adopts a three-layer architecture, in which the fact-intent mapping layer maintains the global state, the task scheduling and allocation layer ensures execution stability through two-phase degradation recovery and multi-dimensional adaptive load balancing, and the intent retrieval and prediction layer provides tactical priors through a top-down five-stage filtering algorithm. On a benchmark of real CTF challenges covering more than ten vulnerability types across three difficulty levels, Intentest achieves an overall success rate of 88.2% and a success rate of 75.0% on hard tasks, improving over the baseline by approximately 44 and 50 percentage points. Ablation experiments further show that the intent retrieval and prediction reduce the average number of rounds on successful medium and hard tasks by about 33% and 48%, respectively, without changing the set of solvable tasks.

  - **意图漂移（intent drift）**：智能体偏离最初设定的渗透目标，陷入无目的、重复的无效探索与循环。
- **已有方案的不足**：
  - PentestGPT 的纯文本任务树在真实环境中易超出上下文窗口而崩溃，且依赖人在回路。
  - PentestAgent、VulnBot 等多智能体分工框架在高度复合的长尾漏洞场景下成功率明显下降，纯文本共享记忆无法支撑跨步因果关联。
  - CheckMate 等引入经典规划引擎的方案依赖预定义逻辑谓词与确定性动作空间，面对 0-day 或非标准化 Web 漏洞易陷入逻辑死锁，泛化能力不足。
  - RAG 本质上是无状态的局部文本相似度检索，易因弱词重叠引入冗余历史特征，诱发因果关联幻觉，加剧宏观意图碎片化。
- **整体含义**：论文主张将长时程状态从 LLM 的上下文窗口"外化"到持久化的图结构中，用图论状态机锚定并约束智能体行为，为长时程安全自动化提供一种结构化状态管理范式。

## 2. 方法论

### 2.1 核心思想

- 提出 **Intentest**——意图图引导的自动化渗透测试智能体。
- 采用 **BDI（Belief-Desire-Intention）框架**映射到网络安全对抗环境：
  - **Goal**：宏观静态终态（如获取域控权限）。
  - **Action**：底层引擎直接执行的具体命令（如带特定参数的端口扫描）。
  - **Intent**：连接宏观目标与细粒度动作的核心枢纽，表示智能体基于当前已知状态做出的、受约束的战术承诺。
- 将传统 POMDP 的信念状态 `bt` 外化到持久化图结构：写回新事实的后向边等价于更新 `bt`，前向边将可行动作限制在已验证事实支持的子集内，使决策沿因果一致路径推进。

### 2.2 事实-意图 DAG 映射

- **定义 1（Fact-Intent DAG）**：`G = (F, I, E_{f→i}, E_{i→f})`，其中 `F` 为已验证不可变事实节点集，`I` 为意图节点集，`E_{f→i} ⊆ F × I` 为触发意图的前向边，`E_{i→f} ⊆ I × F` 为意图成功后产生新事实的后向边。`G` 在边集 `E` 下为 DAG：任意有向路径交替经过事实与意图节点，无环存在。
- **定义 2（意图节点四状态 FSM）**：状态空间 `S = {CREATED, CLAIMED, CONCLUDED, COMPLETED}`；事件集 `Σ = {claim, conclude, goal, timeout}`；状态转移函数 `δ` 为：
  - `claim`：`s1 → s2`
  - `conclude`：`s2 → s3`
  - `goal`：`s3 → s4`
  - `timeout`：`s2 → s1`（超时回收，重置为 CREATED 以便重新认领）
  - 命中目标后，项目所有未完成意图迁移到 COMPLETED，后续调度分配关闭，保证终态不可逆。
- **六张核心持久化表**：project（项目生命周期 + 独占租约锁）、fact（已验证不可变安全拓扑）、intent（单步因果动作有向路径 + 心跳时间戳动态回收）、intent-source（桥接表，支持超图语义推理，一个意图可由多个无直接关联的前驱事实共同构建触发）、prompt（专家异步战术指导通道）、scope（项目级唯一实体分配的隔离命名空间）。
- **异步间接协作**：所有智能体以事实-意图 DAG 为唯一通信媒介，通过写入意图边声明探索承诺，避免传统点对点通信的广播风暴与状态冲突。

### 2.3 任务调度与分配机制

- **三类标准化操作抽象与优先级控制**：
  - **Bootstrap**：项目初始态（仅含起止事实）触发，要求 LLM 广谱扫描并生成首批攻击载荷。
  - **Explore**：存在未验证意图边时触发，最高常规分配优先级，注入局部网络图到沙箱做单步验证。
  - **Reason**：全局事实增量调查、规划新战术链；受单项目互斥锁约束，仅在全局无未认领 Explore 任务且新事实或专家提示到达时唤醒，避免空转。
- **多维自适应负载均衡算法（Algorithm 1）**：候选工作节点依次经过 6 层筛选/评分：
  1. 协议一致性仲裁（过滤缺工具依赖的节点）
  2. 容量安全检查（排除活跃任务达上限的节点）
  3. 健康探测检查（剔除熔断/冷却节点）
  4. 优先级权重选择（选预设权重最低者）
  5. 活跃负载均衡（比较活跃任务数，分配给最轻者）
  6. 随机抖动（参数全平时引入伪随机抖动因子扰动时间戳分布）
- **两阶段任务降级恢复机制**：主执行阶段（Explore/Bootstrap 主超时 180 秒）超时后不直接销毁容器，而是在同一会话触发 90 秒降级阶段，注入高优先级紧急截断提示，强制停止网络层探测，收集残留 stdout/stderr 日志并总结上报部分事实。Reason 任务超时则直接宣告失败并释放租约锁，以保持全局决策的逻辑一致性。
- **两层防御应对控制流劫持**：
  - 第一层**结构前提验证**：意图只有由已验证事实节点触发才能写入意图表，外部载荷诱发的、未基于已验证事实的指令在构造上被拒绝。
  - 第二层**容器级隔离**：所有探测组件与解释脚本运行于独立 Docker 容器，容器生命周期管理器实时监控系统级终止信号，项目停滞或前提验证拒绝时触发系统级中止并销毁容器。

### 2.4 意图图构建与检索预测

- **三类有向图的构建与融合**：
  - **离线意图图**：批量爬取威胁情报与演练文档，LLM 驱动意图抽取器做语义因果抽取（每条意图记录须含目标网络实体、关联漏洞，并映射到 MITRE ATT&CK 框架；实践中的错误路径单独存储以提供负样本）。入库前须通过内部验证器（拓扑完整、无孤立节点、置信度超阈值）。
  - **在线攻击图**：实时记录智能体在真实环境探索的物理拓扑（已验证事实节点 + 已执行攻击步边）。
  - **合并图**：运行时内存空间中融合静态历史意图图与当前攻击图，过滤无效条目、匹配重叠节点、生成跨图链接，用历史经验补偿目标网络局部视图缺失。
- **自顶向下五阶段意图检索与预测算法（Algorithm 2）**：
  1. **高维语义嵌入空间探测**：用 Qwen3-Embedding-4B 向量化当前环境图拓扑节点属性，按余弦相似度 `sim_cos(v, φ(i)) = v·φ(i) / (‖v‖‖φ(i)‖)` 对齐，保留 Top-k 战术簇。
  2. **子图同构验证**：对候选意图的前驱子图做子图同构验证，强制拓扑与有向边方向一致性，减少纯词重叠导致的因果幻觉。因仅作用于 Top-k 候选，匹配代价为 `O(k)` 次局部同构检查。
  3. **降级模糊统计推断**：同构失败时回退到基于 Jaccard 系数 `J(A,B) = |A∩B|/|A∪B|` 的模糊图相似匹配，容忍蜜罐/流量清洗造成的局部不完整与噪声。
  4. **战略意图对齐**：将候选战术序列映射回宏观意图层，与初始化时确定的授权目标（如"提取凭据"而非"破坏业务系统"）及主漏洞链比较，剪除偏离主攻击目标或试图未授权横向移动的冗余分支。
  5. **LLM 启发式推理**：前四阶段均无匹配时（如闭源协议、无历史特征漏洞），注入降维环境日志与残留拓扑，依赖 LLM 做启发式语义推理与战术判断，保留探索未知环境的能力。
- **关键约束**：五阶段算法只产生候选意图，**不授权执行**。事实-意图 DAG 是执行层，每个新意图须通过前提验证才能写入意图表；每个新事实须经执行验证才能入图。该约束适用于全部五阶段输出，包括 Stage 5。
- **异步意图桥注入（Algorithm 3）**：仅在 Explore 任务成功且写入新事实后触发（保持计算与推理负载分离）；要求余弦相似度 ≥ 0.3 过滤噪声；注入的三块结构化上下文为：推荐下一步战术动作、支撑证据链（原始历史攻击链 + Jaccard 定位的最相关相邻步骤 + 跨图链接）、当前项目上下文（宏观目标、测试阶段、目标实体、最新事实簇、待处理意图）。构建时移除所有冗余元数据（检索相似度分数、检索源报告名称、底层图匹配方法细节），避免分散 LLM 注意力。
