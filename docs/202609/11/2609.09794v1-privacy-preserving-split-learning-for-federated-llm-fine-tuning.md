## 摘要
在领域特定数据上微调大语言模型（LLM）对于下游适配至关重要。在许多部署中，参与者无法在本地持有完整模型。这是因为模型所有者将完整模型保持专有，或者参与者缺乏足够的计算资源。拆分学习（SL）通过在参与者与服务器之间划分模型来解决这一问题，使得只有一小部分在本地运行。当底层数据还分布在多个具有隐私要求的机构中时，联邦学习（FL）进一步通过仅共享模型更新而非原始数据，实现参与者之间的协作训练。在这种组合设置中，每个客户端向服务器传输中间激活，而对于LLM微调而言，这种交换带来了固有的隐私悖论。LLM的自回归特性导致所传输的激活泄露输入，而现有的基于扰动的防御在此设置下从根本上无效。我们通过一种学习式混淆与恢复方案来解决这种泄露，该方案保护参与者的私有数据集，同时仍允许在服务器端训练一个可独立部署的模型。实验表明，我们的方法在适度的效用损失和系统开销下实现了强隐私保护，使基于拆分的联邦LLM微调在实践中可行。

## Abstract
Fine-tuning large language models (LLMs) on domain-specific data is essential for downstream adaptation. In many deployments, a participant cannot hold the complete model locally. This happens because the model owner keeps the full model proprietary, or because the participant lacks sufficient compute resources. Split Learning (SL) addresses this by partitioning the model between the participant and a server so that only a small portion runs locally. When the underlying data is additionally distributed across multiple institutions with privacy requirements, Federated Learning (FL) further enables collaborative training across participants by sharing only model updates instead of raw data. In this combined setting, each client transmits intermediate activations to the server, and for LLM fine-tuning, this exchange poses an inherent privacy paradox. The autoregressive nature of LLMs causes the transmitted activations to leak the input, and existing perturbation-based defenses are fundamentally ineffective in this setting. We address this leakage through a learned obfuscate-and-recover scheme that protects participants' private datasets while still allowing an independently deployable model to be trained on the server side. Experiments demonstrate that our approach achieves strong privacy protection with modest utility loss and system overhead, making split-based federated LLM fine-tuning practically viable.

## 1. 核心问题与整体含义（研究动机与背景）

- **现实约束的双重叠加**：
  - **算力/所有权约束**：医院、律所、企业等机构往往无法在本地持有或训练完整的LLM（模型权重专有、GPU资源有限、边缘设备算力不足）。
  - **数据分布与隐私约束**：微调数据天然分散在多个机构中，受各自隐私法规约束，无法集中到单一服务器。
- **技术背景**：拆分学习（SL）通过切分点将模型分片，客户端仅运行轻量级部分；联邦学习（FL）允许多机构仅共享模型更新而不共享原始数据。联邦拆分学习（Federated Split Learning）将两者结合，客户端本地执行 `A`（Head）与 `C`（Tail），服务器持有 `B`（Middle Layers）。
- **核心隐私悖论**：
  - LLM 的自回归训练目标使**输入与标签几乎相同**（`y_j^(t) = x_j^(t+1)`），泄露标签等同于泄露输入。
  - 客户端向服务器传输中间激活（smashed data）`s_A`，服务器凭借白盒模型可直接用 `f_C ∘ f_B` 解码出标签，进而还原输入。
  - **现有扰动防御（Embedding ε-Privacy、Smashed-Data DP、NoPeek）在LLM场景下根本失效**：因为服务器用于攻击的解码器，正是微调所优化的同一个 next-token predictor。扰动强度必须足够大才能破坏解码，但足够大的扰动又会同时破坏训练路径本身。
  - 微调的“not-too-far”性质进一步加剧风险：即使客户端不共享微调参数，服务器仍可用预训练模型近似预测标签。

## 2. 方法论：PrivPair 的核心思想与关键技术细节

### 2.1 核心思想：混淆-恢复（Obfuscate-and-Recover）

- **打破单一表示困境**：不再让同一份 smashed data 同时承担“隐藏隐私”与“保持可训练”的双重职责，而是让服务器与客户端工作在**不同的激活空间**。
- **两个轻量级客户端适配器**：
  - `W1`（混淆适配器）：在发送前对 `s_A` 做学习式混淆。
  - `W2`（恢复适配器）：在服务器返回后，将 `s'_B` 映射回与 `C` 兼容的表示。
- **适配器始终保留在客户端**，不上传、不部署，训练完成后可丢弃；服务器最终仍持有完整、可直接部署的模型 `f = f_C ∘ f_B ∘ f_A`。

### 2.2 关键技术细节

- **模型切分**：`A`（embedding + 前 k 层）、`B`（k+1 至 m 层，冻结）、`C`（m+1 至 L 层 + LM head）。实验中 `A` 含 5 层，`C` 含 1 层。
- **W1 设计**（残差 MLP）：
  - `s'_A = W1(s_A) = s_A + h1(s_A)`
  - 单独使用时，其作用类似加性扰动，目的是“钝化”服务器解码器。
- **W2 设计**（残差 MLP，双输入）：
  - `ŝ_B = W2(s'_B, δ_A) = s'_B + h2([s'_B ∥ δ_A])`
  - `δ_A = s'_A − s_A` 是 W1 的残差，仅本地使用，**绝不传输给服务器**，为 W2 提供“如何被修改”的紧凑表示。
- **STE（直通估计器）解耦**：
  - `˜s_A = s_A + (s'_A − s_A)_sg`
  - `˜s_B = s'_B + (ŝ_B − s'_B)_sg`
  - 前向等价于真实使用 `s'_A` 和 `ŝ_B`；反向让梯度**如同适配器是恒等映射**一样流过，保证 `A` 可训练。
- **W1 损失函数**（三部分耦合）：
  - **CKA 项**：`λ_CKA · CKA(s'_B, s_B)`，最小化表示几何差异，使服务器在中间层就难以利用。
  - **JSD 项**：`−λ_JSD · D_JSD(z', z)`，最大化 logits 分布差异，直接削弱服务器解码能力。
  - **耦合项**：`+λ_W2 · L_W2`，确保 W1 产生的混淆仍是 W2 可恢复的，防止训练崩溃。
- **W2 损失函数**：
  - **KL 项**：`λ_KL · D_KL(ẑ ∥ z)`，在分布层面补偿重建误差。
  - **MSE 项**：`λ_MSE · ∥ŝ_B − s_B∥²`，直接监督重建。
- **对齐数据集 `D_align`**：使用 OASST1 等**与私有数据无关**的公开语料，仅用于训练 W1/W2，`θ_A`、`θ_C` 冻结。
- **主训练循环**：客户端用适配器路径前向，交叉熵损失 `L = ℓ(ẑ, y_gt)`，STE 反向更新 `θ_A`、`θ_C`（`θ_B` 冻结），FedAvg 聚合。
- **Burst Alignment**：每 K 步用 `D_align` 对 W1/W2 做少量重训练，以适应当前全局模型参数。

### 2.3 可训练性与收敛分析要点

- **C 的可训练性**：若 `ŝ_B ≈ s_B`，则从 `C` 视角适配器完全透明。
- **B 冻结的理由**：`B` 收到的是 `s'_A`（分布外），更新 `B` 会使微调在无适配器部署时失效。
- **A 的可训练性**：STE 使 `J_W1 = I`、`J_W2^(1) = I`、`J_W2^(2) = 0`，梯度偏差仅剩两项：上游梯度误差（∝ `∥ŝ_B − s_B∥`）与 Jacobian 评估误差（∝ `∥s'_A − s_A∥`）。
- **收敛定理**：在 FedAvg 标准假设（L-smooth、μ-strongly convex、有界方差等）+ 新增 Assumption 7/8（`E∥s_B − ŝ_B∥² ≤ H`、`E∥s_A − s'_A∥² ≤ H_A`）下，给出非 i.i.d. 数据的收敛界，误差项由 `H` 与 `H_A` 控制。
- **与扰动防御的关键区别**：扰动防御中 `H_perturb ≤ L_B² H_A`，两者通过 `L_B` 耦合，只有**一个自由度**；PrivPair 将 `H_A` 与 `H` 解耦，只要 W2 保持 `H` 小，就可以允许更大的 `H_A`，从而在增强隐私的同时不牺牲收敛。

### 3.2 攻击方法与基线

- **攻击**：
  - **Direct Forward**：服务器直接对 smashed data 应用 `f_C ∘ f_B` 解码，零成本、最自然的攻击。
  - **TAG**：Transformer 梯度攻击，扩展 DLG 并加正则项。
  - **LAMP**：引入语言模型先验 + 离散 token 重排序。
  - **BiSR**：双向增强攻击，联合利用前向 smashed data 反演与梯度匹配，是当前最强攻击。
- **基线防御**：
  - **No Defense**：无隐私保护的标准 SL。
  - **Embedding ε-Privacy**：embedding 层输出加噪。
  - **Smashed-Data DP**：直接对 smashed data 加高斯噪声。
  - **NoPeek**：训练时加 distance correlation 正则。
  - **Full Model**：不拆分、全模型微调，作为效用上界参考。
- **评估指标**：
  - **隐私**：重建文本的 mean ROUGE-1（越低越好）。
  - **效用**：Banking77/CLINC150 分类准确率；MentalChat16K 任务 ROUGE-1。
  - **开销**：客户端每步计算时间与显存、端到端 wall-clock 训练时间。
- **FL 设置**：64 客户端，随机分 8 组（每组共享一对适配器），256 全局轮，每轮选 8 客户端，每客户端 4 本地步。
