## 摘要
现代大语言模型（LLM）智能体通常通过聚合来自多个外部来源的检索段落、用户评论和文档来构建提示。这一范式使其暴露于片段级投毒攻击：攻击者仅控制一小部分来源，即可注入恶意内容以操纵模型输出。现有防御主要依赖文本模式、外部嵌入或辅助检测器，因此可能无法抵御流畅且语义上合理的投毒片段。它们对定位责任片段的支持也有限。我们观察到，成功的受损证据攻击和对抗指令攻击会在LLM内部激活中引发结构化偏移，形成一种一致的激活空间模式，我们称之为投毒方向。基于这一观察，我们提出ActProbe，一个基于内部状态的框架，用于检测和定位多源LLM输入中的投毒片段。ActProbe将MLP激活投影到学习到的投毒方向上，并使用在小型校准集上训练的轻量级线性SVM来检测受污染提示。随后，它应用BinRoL，该方法结合递归替换消融、基于马氏距离的分支剪枝和基于MAD的稳健叶节点检测来定位投毒片段。ActProbe无需修改后端LLM，并将定位开销从O(n)穷举探测降低到O(k log n)次前向传播。在三个数据集、两种攻击和四个开放权重LLM上，ActProbe实现了0.01的假阳性率、0.05的假阴性率、0.94的定位召回率和0.90的定位F1分数。它对防御感知的自适应攻击仍然有效，并可通过基于代理模型的投毒片段移除来保护黑盒API。

## Abstract
Modern large language model (LLM) agents often construct prompts by aggregating retrieved passages, user reviews, and documents from multiple external sources. This paradigm exposes them to segment-level poisoning attacks, in which an adversary controlling only a small subset of sources injects malicious content to manipulate model outputs. Existing defenses mainly rely on textual patterns, external embeddings, or auxiliary detectors and may therefore fail against fluent, semantically plausible poisoned segments. They also provide limited support for locating the responsible segments. We observe that successful corrupted-evidence and adversarial-instruction attacks induce structured shifts in the LLM's internal activations, forming a consistent activation-space pattern that we call the poison direction. Based on this observation, we propose ActProbe, an internal-state-based framework for detecting and localizing poisoned segments in multi-source LLM inputs. ActProbe projects MLP activations onto a learned poison direction and uses a lightweight linear SVM trained on a small calibration set to detect contaminated prompts. It then applies BinRoL, which combines recursive replacement ablation, Mahalanobis-distance-based branch pruning, and MAD-based robust leaf detection to locate poisoned segments. ActProbe requires no modification to the backend LLM and reduces localization overhead from O(n) exhaustive probing to O(k log n) forward passes. Across three datasets, two attacks, and four open-weight LLMs, ActProbe achieves a 0.01 false-positive rate, a 0.05 false-negative rate, 0.94 localization recall, and a 0.90 localization F1-score. It remains effective against defense-aware adaptive attacks and can protect black-box APIs through surrogate-based poisoned-segment removal.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：现代 LLM 智能体（如 RAG 问答、电商评论摘要、新闻简报）通常将来自多个独立外部来源的片段（检索段落、用户评论、文档）拼接成提示。这种"多源信息融合"范式依赖一个隐式假设——**多数共识假设**，即良性内容占主导、能建立稳定上下文基线。
- **安全风险**：攻击者只需控制少量来源，即可注入恶意片段（片段级投毒），将模型输出导向攻击者目标。文中归纳为两大类：
  - **知识投毒**（如 PoisonedRAG）：注入事实错误但语义合理的段落，诱导模型依赖被污染的证据；
  - **提示注入**（如 ObliInjection）：在外部数据中嵌入对抗指令，覆盖原任务目标。
  - 二者共同弱点：提示融合后，少数恶意片段即可腐蚀最终输出。
- **现有防御的不足**：
  - 预防类方法（StruQ、SecAlign）需修改模型、可能降低良性任务效用，且对自适应攻击仍脆弱（ObliInjection 对硬化模型仍有 53%–78% 成功率）；
  - 检测类方法（PPL、KAD、EVD、DataSentinel）依赖表层文本统计、外部嵌入或辅助模型，对流畅且语义合理的毒段失效（如 KAD/PPL 对 ObliInjection 假阴率高达 92.6%；DataSentinel 漏检 79.6%）；
  - 定位类方法（PromptLocate、FRA、SVA）多针对显式提示注入，或计算代价高、或易过定位。
- **核心洞见**：作者观察到成功的投毒攻击（无论证据损坏还是指令对抗）会在 LLM **内部激活空间**引发一致的结构化偏移，形成几何上的"**投毒方向（poison direction）**"。这一内部信号比表层文本特征更直接、更稳健。

## 二、方法论：ActProbe 的核心思想与关键技术

### 1. 整体框架
- 分**离线校准**与**在线推理**两阶段：
  - 离线校准学习三样东西：投毒方向探针 \(v_p\)、线性 SVM 检测器、良性激活分布参数 \((\mu, \Sigma^{-1})\)；
  - 在线推理先用 SVM 判断提示是否受污染，若被标记则触发 BinRoL 定位毒段。

### 2. 投毒方向探针（Poison Direction Probe）
- 动机：MLP 激活维度极高（如 Llama-3.1-8B-Instruct 每层 \(d=14{,}336\)，32 层合计约 46 万维），直接训练检测器易过拟合、且语义噪声大。
- 做法：在校准集上提取**最后一个 token 的隐层激活** \(h_{i,l}\)，对每一层计算投毒与干净激活之差的归一化均值：
  - \(v_l = \frac{1}{M}\sum_{i=1}^{M}(h^p_{i,l} - h^c_{i,l})\)，\(v_p[l] = v_l/\|v_l\|\)
- 投影：\(s_l = h_l \cdot v_p[l]\)，形成紧凑的 L 维特征 \(s = [s_1,\dots,s_L]\)。
- 与 PCA 等通用降维不同，\(v_p\) 是"机制性"对齐对抗扰动的子空间，兼顾判别力与可解释性（投影幅度越大代表恶意偏移越强）。

### 3. 投毒提示检测阶段
- 在标准化后的 L 维特征上训练**线性 SVM**：\(\hat{y} = \text{sign}(w^\top \tilde{s} + b)\)。
- 选择线性 SVM 的理由：低维结构化空间中线性边界足够，且在小校准集（M=100/类）下泛化好。
- **副产品**：用干净样本估计良性分布 \(\mu\)、\(\Sigma = \text{Cov}+\lambda I\)（\(\lambda=10^{-6}\) 保证可逆），供定位阶段直接复用，无需额外校准。

### 4. 投毒片段定位：BinRoL（Binary search with Robust Leaf detection）
- **替换消融（Replacement Ablation）**：将目标片段/片段组替换为中性文本（如"No relevant information is available..."）后重做前向传播，以抑制自回归导致的信号泄漏（malicious 信号会向前传播，使后续良性片段"继承"痕迹）。
- **下降比率（Drop Ratio）**：以马氏距离衡量异常程度 \(d(s)=\sqrt{(s-\mu)^\top \Sigma^{-1}(s-\mu)}\)，定义
  - \(\rho = \frac{d(s_{\text{full}}) - d(s_{\text{rep}})}{d(s_{\text{full}})}\)
  - \(\rho\) 越大说明替换该组后异常显著下降，即该组贡献大。
- **Phase 1 BinaryNarrow（粗粒度二分）**：递归将候选集 C 一分为二，分别替换计算 \(\rho_L, \rho_R\)：
  - 两者均 > δ（δ=0.02）：两支都探索；
  - 仅一支超阈：只探索该支；
  - 均不超阈：选 \(\rho\) 较大者作回退（保召回）。
- **Phase 2 RobustLeaf（细粒度叶检测）**：当 \(|C| \le \ell\) 时，对父候选集 P(C) 内每个片段单独替换，计算**消融分数** \(a_i\)（仅在 SVM 权重最大的 \(L_{top}\) 层上计算，以降低噪声与开销）。随后用**MAD 稳健离群检测**：
  - \(\tilde{m}=\text{median}(\{a_i\})\)，\(\hat{\sigma}=\eta\cdot\text{MAD}\)（η=1.4826），
  - 若 \(a_i > \tilde{m} + \gamma\hat{\sigma}\)（γ=0.8）则判为投毒；若无超阈则取最大 \(a_i\) 作回退。
  - 采用父级 MAD（而非叶级或全局）以缓解密集投毒下的相互掩蔽。
- **复杂度**：定位成本为 \(O(k\log(n/\ell) + \ell)\)，常数叶大小下即 \(O(k\log n)\)，相比穷举 O(n) 大幅降低。

### 5. 关键超参数
- δ=0.02，γ=0.8，\(|L_{top}|\)=6，叶大小 ℓ=2/3/10（分别对应 HotpotQA/MS-MARCO/Amazon Reviews），默认投毒比例 10%。

## 六、主要结论与发现

- **检测性能**：平均 FPR/FNR 为 **0.01 / 0.05**，显著优于 PPL（0.38/0.38）、KAD（0.70/0.29）、EVD（0.59/0.60）、DataSentinel（0.08/0.61）；ROC-AUC 在所有组合中达 0.95–1.00。
- **定位性能**：平均 Recall/F1 为 **0.94 / 0.90**，远超最强基线 FRA（F1 0.43）；在 QA 数据集上 F1 达 0.95（HotpotQA）与 0.93（MS-MARCO）。
- **自适应鲁棒性**：释义规避下 ActProbe 仍保持 FNR 0.02–0.18、F1 0.93–0.97；防御感知攻击下 FPR/FNR 升至 0.03/0.12、定位 Recall/F1 降至 0.90/0.83，但未失效。
- **密度与稀释**：信号稀释主要影响检测（FNR 峰值 0.18），定位较稳；密度增加对定位影响更大（k=5 时 F1 降至 0.73），但仍保持

较高水平（F1≈0.73），说明在密集投毒下定位虽退化但仍可用，即**定位精度对投毒密度比检测更敏感**；反之，检测在信号稀释下更易受影响（FNR 峰值 0.18），而定位相对稳健。这一"检测怕稀释、定位怕密集"的不对称性，提示实际部署中可按投毒比例预估选择侧重。

- **可迁移性**：跨攻击迁移（如以 PoisonedRAG 校准去检测 ObliInjection）性能损失小，说明"投毒方向"捕捉的是攻击共享的内部偏移机制，而非某一攻击的表面模式；跨数据集迁移（用 HotpotQA 校准迁移至 MS-MARCO/Amazon Reviews）仍保持可用精度；跨架构少样本适配（仅 M=50/类）可快速为新模型重建探针；跨目标（答案操纵 vs 工具劫持）均有效，表明方法不绑定单一攻击目标。
- **消融结论**：① 以 \(v_p\) 投影显著优于随机方向、PCA 主成分与原始全维激活，验证"机制性方向"而非"通用降维"是关键；② 替换消融优于删除消融，因后者无法抑制自回归导致的恶意信号向前泄漏；③ MAD 稳健离群检测优于 z-score，尤其在密集投毒下可缓解毒段相互掩蔽；④ 线性 SVM 与所提决策逻辑的组合在低维结构化空间中表现最佳。
- **黑盒代理防护**：在无法访问目标模型内部（GPT-5.4-mini、Gemini-3.1-flash-Lite）时，可用上游开源代理提取探针并对黑盒模型提供保护，说明方法具备一定的"代理迁移"实用性。
- **效率**：定位仅需 \(O(k\log n)\) 次前向传播，远低于穷举 \(O(n)\)，在大片段数场景（如 50 条评论）优势明显。

## 七、方法亮点与创新点

- **视角创新**：将投毒检测从"表层文本/外部模型"转向"LLM 内部激活几何"，提出并验证了"投毒方向"这一可复用、可解释的信号载体。
- **机制化探针**：不同于 PCA 等无监督降维，\(v_p\) 由干净–投毒激活差直接构造，天然对齐对抗扰动子空间，兼具判别力与可解释性（投影幅度≈恶意偏移强度）。
- **检测与定位一体化**：干净样本估计的 \((\mu,\Sigma^{-1})\) 被检测与定位两阶段复用，无需额外校准；一次 SVM 判定即可触发定位，形成"先筛后定"的低成本流水线。
- **BinRoL 设计精巧**：以"替换消融 + 下降比率 + 二分收窄 + 父级 MAD 叶检测"组合，兼顾召回（回退策略）与效率（对数复杂度），并针对性解决自回归泄漏与密集掩蔽两大难点。

## 八、局限与不足

- **依赖内部激活**：对完全黑盒、仅 API 可用的模型，只能借助上游代理间接防护，代理与目标分布差异可能削弱效果。
- **需校准数据**：虽仅需 M=100/类，但仍要求能获取一定量的良性/投毒配对提示，攻击类型未知时的校准成本与覆盖度需评估。
- **消融覆盖面**：多数消融固定于单一设置（Llama-3.1-8B + MS-MARCO + ObliInjection），跨模型、跨攻击的消融验证偏薄。
- **密集投毒退化**：k=5 时定位 F1 降至 0.73，说明高密度多毒段场景仍是薄弱环节。
- **算力披露不全**：仅说明使用 A6000，未给出 GPU 数量、时长、总开销等，复现成本难以精确评估。

## 九、总体评价与启发

ActProbe 是一篇**问题定位清晰、方法机理明确、实验覆盖全面**的工作。其核心贡献在于提出并验证了"投毒会在 LLM 激活空间留下可检测、可定位的几何方向"这一洞见，并将其工程化为低校准成本、低推理开销、可跨攻击/跨数据集/跨架构迁移的实用防御框架。检测（FPR/FNR≈0.01/0.05）与定位（Recall/F1≈0.94/0.90）指标大幅领先既有基线，且在释义规避与防御感知自适应攻击下仍保持稳健，展现出较强实用潜力。

**启发**：① 内部激活信号有望成为多源 LLM 智能体安全的一条通用防线，可与输入过滤、模型硬化等预防手段互补；② "替换消融 + 稳健统计"的定位范式可迁移至其他需要归因的场景（如幻觉溯源、上下文污染归因）；③ 未来值得探索的方向包括：更少监督（无配对校准）、更强自适应攻击下的鲁棒性、以及高密度投毒下的定位增强。
