## 摘要
量化是开放权重 LLM 智能体的一种默认部署路径，但它并非保持行为不变：攻击者可以发布一个通过审计的全精度检查点，而该检查点一旦被量化就会行为异常，这被称为量化条件攻击（QCA）。此前的 QCA 工作针对自由文本生成，其危害由人类读者中介。相比之下，智能体场景构成更严重的风险：被触发的载荷是可执行的结构化函数，无需人类监督即可执行。我们首次研究针对 LLM 智能体的 QCA。我们发现，直接沿用先前的后门注入方法可以在量化后产生恶意行为，但会显著降低良性效用，使由此产生的攻击不切实际。为了理解威胁的真实上界，我们提出 AGENTQ，一种攻击框架，它将分层带状的 LoRA 注入与在多码本量化等价类上的部分 PGD 修复相结合。AGENTQ 在将恶意行为集中于量化模型的同时，保持正常的智能体能力。在三个触发-动作对和三个码本（NF4、FP4、INT8）上，AGENTQ 在良性效用损失极小的情况下，量化后攻击成功率最高可达 100%，这凸显了有必要将量化感知安全评估作为开放权重智能体部署前的标准要求。

## Abstract
Quantization is one of the default deployment paths for open-weight LLM agents, but it is not behavior-preserving: an adversary can release a full-precision checkpoint that passes audits yet misbehaves once quantized, termed as quantization-conditioned attack (QCA). Prior QCA work targets free-text generation, where harm is mediated by a human reader. In contrast, the agentic setting poses a more severe risk: the triggered payload is a structured function that can be executed without human oversight. We present the first study of QCA against LLM agents. We find that directly adapting prior backdoor-injection methods can produce malicious behavior after quantization, but substantially degrades benign utility, rendering the resulting attacks impractical. To understand the true upper bound of the threat, we propose AGENTQ, an attack framework that combines layer-banded LoRA injection with partial-PGD repair over a multi-codebook quantization-equivalence class. AGENTQ preserves normal agentic capability while concentrating malicious behavior in the quantized model. Across three trigger-action pairs and three codebooks (NF4, FP4, INT8), AGENTQ reaches up to 100% post-quantization attack success rate with minimal loss of benign utility, underscoring the need to make quantization-aware safety evaluation a standard requirement before open-weight agents are deployed.

## 2. 方法论：AGENTQ 的核心思想与关键技术

- **核心思想**：保留 Egashira 等（2024）的两阶段“注入 → 修复”骨架，但将每个阶段实例化在**与攻击实际所需维度匹配的结构化低维子流形**上，而非全参数空间。智能体场景对攻击外的参数漂移容忍度远低于自由文本生成——破坏工具调用格式会直接抹除攻击面。
- **两大结构化限制**：

### Stage I：分层带状 LoRA 注入
- 使用秩为 r 的 LoRA 适配器，将每个权重更新参数化为 ΔW = BA（B ∈ ℝ^{d_out×r}, A ∈ ℝ^{r×d_in}, r ≪ min(d_in, d_out)）。
- 适配器附着于每个 transformer 块的**全部七个线性投影** {q, k, v, o, gate, up, down}，但**仅限浅层前-中层带** L_shallow = [0, L*)，其中 L* ≈ ⌊2L/3⌋（如 Qwen3.5-4B 上为 [0, 22)，L=32）。
- 在有毒混合数据上 SFT 后，适配器通过 θ_h = θ_0 + B*A*|_{L_shallow} 合并回基座，使扰动按构造位于分层受限的低秩子流形上。
- 选择前-中层带的依据：工具调用能力集中在中层块（Wang 等 2026），而头部相邻的上层块负责结构化输出格式，需作为“能力锚点”保持不变。

### Stage II：多码本量化等价类上的部分 PGD 修复
- 定义量化等价类 C(θ_h) = { θ : Q_m(θ) = Q_m(θ_h), ∀m ∈ M }，M = {INT8, NF4, FP4}。
- 在活跃层集 A ⊆ L_shallow 上求解部分 PGD 问题，冻结其余层于 θ_h：
  - θ* = arg min_θ L_util(θ; θ_0)，约束 θ ∈ C(θ_h)，θ_{A^c} = θ_h|_{A^c}。
- 效用损失聚合干净函数调用 CE 与三个有毒目标上的遗忘损失，使用 bf16 AdamW，学习率 η=2×10⁻⁵，并施加 box 投影。
- **部署效果**：按构造 Q_m(θ*) = Q_m(θ_h) 对所有 m 成立，而 L_util 将全精度参数拉回 θ_0 附近的良性流形。因此全精度推理表现为干净函数调用智能体，而任何目标量化推理路径 Q_m 确定性触发对应恶意行为。

### 理论分析：低秩注入下的有界离触发漂移
- 令 δ = θ_h − θ_0 为注入扰动。直接移植基线（全秩 SFT）可自由选择任意 δ ∈ ℝ^d，而 AGENTQ 将 δ 约束在分层带状秩-r 簇 S_{r, L_shallow} 上，其内在维度 r|L_shallow|(d_in+d_out) 比环境维度低一个数量级。
- **逐点效应**：f_θ 在 θ_0 附近的 Lipschitz 正则性给出 |U(θ_h) − U(θ_0)| ≤ L_f ‖δ‖_F，且 BA 分解按参数化将每块的奇异内容限制在 r 个方向上，离子空间漂移不可达而非仅被惩罚。
- **容量效应**：秩约束矩阵类的覆盖数界将环境速率 pd/n 替换为 pdim(S_{r,L_shallow})/n，泛化按同一因子收紧。
