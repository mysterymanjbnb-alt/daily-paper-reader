## 摘要
跨具身学习已经表明，单一模型（例如视觉-语言-动作（VLA）模型）可以学习能够应用于异构机器人以完成各种任务的状态表示和操作技能。我们假设安全约束的执行也是如此。满足安全约束所需的推理，例如检测障碍物、识别其应被避开，并选择安全的抽象动作，在很大程度上是跨机器人共享的。不同具身之间的差异在于抽象安全动作如何实现：形态、运动学和动力学决定了哪些动作安全且可行。因此，同一动作对某个机器人可能是安全的，而对另一个机器人可能不安全。这对于通用操作策略尤为重要，这些策略在共同的末端执行器动作空间中运行，而没有显式捕捉安全性如何依赖于机器人的形态和运动学。我们提出具身条件化安全滤波，其中基于 Hamilton-Jacobi 可达性的值函数及其对应的安全最大化策略在机器人之间共享。利用机器人及其环境的形态感知潜在表示，我们直接在潜在空间中执行 Hamilton-Jacobi 可达性分析，从而使学习到的安全概念能够跨具身泛化，同时显式地以每个机器人的形态和运动学为条件。我们在五种双臂机器人具身和五项具有全身避碰约束的操作任务上评估我们的方法。我们的结果表明，一个在五项操作任务和四种具身上联合训练的单一策略，对留出的具身表现出零样本泛化，降低了标称策略的碰撞率。结果还表明，使用更多具身进行训练可以提高泛化能力。

## Abstract
Cross-embodiment learning has shown that a single model, such as a vision-language-action (VLA) model, can learn state representations and manipulation skills that can be applied across heterogeneous robots to accomplish various tasks. We hypothesize that the same holds for safety enforcement. The reasoning required to satisfy a safety constraint, such as detecting an obstacle, recognizing that it should be avoided, and selecting a safe abstract action, is largely shared across robots. What differs across embodiments is how the abstract safe action is realized: morphology, kinematics, and dynamics determine which actions are safe and feasible. Consequently, the same action can be safe for one robot and unsafe for another. This is especially important for generalist manipulation policies that operate in a common end-effector action space without explicitly capturing how safety depends on the robot's morphology and kinematics. We propose embodiment-conditioned safety filtering, in which a Hamilton-Jacobi reachability-based value function and its corresponding safety-maximizing policy are shared across robots. Using a morphology-aware latent representation of the robot and its environment, we perform Hamilton-Jacobi reachability analysis directly in latent space so that the learned safety concepts can generalize across embodiments while remaining explicitly conditioned on each robot's morphology and kinematics. We evaluate our approach across five bimanual robot embodiments and five manipulation tasks with whole-body collision-avoidance constraints. Our results show that a single policy, jointly trained across five manipulation tasks and four embodiments, exhibits zero-shot generalization to a held-out embodiment, reducing the nominal policy's collision rate. They also show that training using more embodiments improves generalization.

## 1. 核心问题与研究动机

- **背景**：跨具身学习（Open X-Embodiment、Octo、OpenVLA、π0.5、HoloBrain-0 等）已证明，单一模型可学习跨异构机器人的状态表示与操作技能。这类通用策略通常在**共享的末端执行器动作空间**（如 delta 末端位姿）中输出动作，再由各机器人映射为自身关节运动。
- **核心矛盾**：满足安全约束所需的**推理**（检测障碍物、判断需避让、选择安全的抽象动作）大体是跨机器人共享的；但**安全动作的实现方式**由形态、运动学、动力学决定。同一末端轨迹在不同连杆长度、关节轴、关节限位下会产生不同的全身运动，因此**同一动作对某机器人安全、对另一机器人可能不安全**。
- **现有方法不足**：
  - EmbodiSteer 在每个去噪步用具身特定运动学 + cuRobo 全身碰撞代价修正扩散策略动作；
  - Any-Body Guard 在每台机器人原生构型空间中采样并构造局部概率安全多面体。
  - 二者均为**运行时按机器人分别计算**，**没有学习可跨异构具身联合训练的共享安全价值函数与安全策略**。
- **研究问题**：能否用多具身数据学习一个安全滤波器，并零样本泛化到新具身？作者提出**具身条件化安全滤波（embodiment-conditioned safety filtering）**。

## 2. 方法论

### 2.1 核心思想

在**形态感知的潜在空间**中直接做 Hamilton–Jacobi（HJ）可达性分析：用冻结的预训练编码器（HoloBrain-0）产生场景 token 与逐连杆机器人 token，再以安全相关特征与几何感知注意力增强，最终用一个**共享的 HJ 安全 critic 与安全 actor** 跨具身学习；安全价值因具身而异，但网络模块共享。

### 2.2 四个关键设计选择

1. **动作空间**：actor 输出**关节角位移**而非末端位姿增量，直接指定手臂构型变化。
2. **安全特征增强**：为每个连杆 token 拼接安全相关特征向量（式 2，16 维）：
   - 归一化连杆位置 `(p_link - p_base)/L_reach`、连杆四元数姿态、连杆线速度 `J_lin·q̇ / v0`、角速度 `J_ang·q̇ / ω0`（世界坐标系，避免不同形态下同一 q̇ 产生不同连杆运动）、运动链归一化深度 δ、手臂身份 χ、归一化夹爪开度 g；
   - 用 MLP + 归一化融合进 HoloBrain-0 token，得到 `z(0)`，融合权重跨所有具身共享。
3. **几何感知机械臂–场景注意力**：每个连杆 token 对场景 patch 做交叉注意力，注意力分数在标准 QK 相似度上加入由 **3D 距离 d_ij 与方向 r̂_ij** 产生的可学习偏置；输出除加权 value 外还拼接**注意力加权方向**，显式保留方向信息。
4. **可变长度序列结构**：HJ actor/critic 作用于变长连杆 token 序列，可适配不同连杆数、关节数与自由度。

### 2.3 潜在状态与网络结构

- 潜在状态 `z = (z1,…,z_Nlink)` 由 3 个 transformer block（交叉注意力 CA + 连杆自注意力 SA + FFN + 残差）输出，每个 block 形式为 `z ← z + CA(Norm(z))`，再 `+ SA`，再 `+ FFN`。

### 2.4 HJ 安全 Critic

- 对候选动作 `a = [a1,…,a_Narm]`（关节角位移），用连杆雅可比计算线位移 `dp_i = J_lin,i · a`、角位移 `dw_i = J_ang,i · a`，以及对应关节指令 `dq_i`，再加"是否受安全策略控制"指示 `1_i`，构成 8 维向量，经共享投影 `W_a, b_a` 加到 token 上（式 9）。
- Critic 再经 2 个 transformer block，交叉注意力时使用**动作后连杆位置** `p_link,i + dp_i` 计算几何偏置，从而考虑动作如何改变连杆与场景 patch 的距离与方向。
- 每个 token 经共享两层 MLP `g_θ` 得逐连杆安全值 `Q_i`，用**软最小值**聚合：`Q_θ = -T·log Σ_i exp(-Q_i/T)`（T=0.4）。

### 2.5 安全策略与在线滤波

- 安全 actor 用**跨所有关节共享**的线性头 `Linear(256→2)` 输出高斯均值与对数标准差（log std 裁剪到 [-5,0]），重参数化采样后经 tanh 压缩到 [-1,1]，再按关节动作上限 `a_max,i = q̇_lim,i · Δt` 缩放；夹爪 token 不产生动作（夹爪由标称策略控制）。
- 在线规则（式 11）：每控制步计算 `Q_θ(z, a_nom)`；若 ≥ 0 执行标称动作，否则执行安全动作 `π_safe(z)`；一旦介入，标称控制器从新状态重新规划。

### 2.6 训练

- 采用适配 HJ 可达性的 SAC：critic 回归目标 `y_t = (1-γ)h(s_t) + γ·min{h(s_t), max_a Q_θ(s_{t+1},a)}`（式 1），双 critic、目标网络 Polyak 平均 τ=0.005，熵系数 α 由 0.2 退火到 0.02。
- 先用标称控制器收集**共享 warmup buffer**（每任务–具身对 20 条成功轨迹，共 500 条），再交替「1024 梯度步 + 采集 3 条新轨迹（0.8 概率开滤波器）」。

## 3. 实验设计

- **仿真平台 / Benchmark**：RoboTwin 2.0（基于 SAPIEN），物理步 250 Hz，控制环 25 Hz（Δt=0.04 s），单回合上限 450 控制步（18 s）。
- **具身（5 种双臂机器人）**：Piper、Franka-Panda、ARX-X5、UR5-WSG、Aloha-AgileX；其中 Franka-Panda 每臂 7 个驱动关节，其余为 6 个。
- **任务（5 项双臂操作）**：Place Bread in Basket、Place Container on Plate、Stack Two Blocks、Place Burger & Fries、Stack Two Bowls。任务目标、成功判据、场景随机化继承 RoboTwin 2.0，背景随机化关闭；唯一改动是**每个场景加入同一静态障碍物** RoboTwin-OD 068 boxdrink（约 11.0×15.4×11.6 cm）。
- **障碍物摆放**：训练时 0.7 概率置于标称路径上（ρ~U[0.22,0.48]），否则偏置到路径外；评估时**始终置于路径上**。
- **失败函数**：`h(s) = min dist(B(s) ∪ P(s), O)`，B(s) 为双臂运动连杆的包围球集合，P(s) 为所持物体，O 为障碍物 OBB；h(s)<0 表示几何近似重叠（可能并非真实接触）。
- **标称控制器**：RoboTwin 2.0 的 cuRobo 规划器（规划时不考虑新增障碍物）。
- **对比方法**：
  - 未滤波 Nominal（cuRobo 规划器）；
  - **X-VLA-Safe**：用 X-VLA 的 Florence-2 骨干替换冻结编码器（因无 3D 度量位置与连杆位姿，改用每臂 token + 无几何偏置的交叉注意力，末端位姿命令经阻尼最小二乘 IK 转关节位移）；
  - 消融：`CrossSafe w/o Aug`（去安全特征增强）、`w/o Geo`（几何感知注意力换为普通交叉注意力）、`w/o Geo, Aug`（两者都去）；
  - **Specialist vs Generalist**：单具身训练 vs 四具身联合训练。
- **评估协议**：**5 折 leave-one-embodiment-out**，每折在 4 个训练具身上做 InD 评估、在第 5 个留出具身上做 OOD 评估；每任务–具身对 50 回合。每个模型 InD 20 对（1000 回合）、OOD 5 对（250 回合）；五个模型合计 5000 InD + 1250 OOD 回合（specialist 反之）。评估场景**完全确定且各方法共享**，安全策略确定性执行（用均值不采样）。
- **指标**：碰撞率 CR、成功率 SR、介入率 IR、接触力 Force（由仿真接触冲量/时间步换算，取帧级中位数再对回合取平均，无碰撞回合计 0）。
