## 摘要
低秩适配（LoRA）已成为大语言模型中一种流行的参数高效微调方法。LoRA 的一个关键挑战是如何确定每个适配矩阵的秩，因为秩直接控制其容量和效率。现有的自适应秩方法通常根据人工设计的重要性分数来分配秩，而这些分数并非直接由优化目标推导而来。在这项工作中，我们提出 ℓp-LoRA，一种基于 0<p<1 的 ℓp 正则化的原则性秩分配方法，这是信号处理和统计学中经典的稀疏诱导技术。具体而言，我们对每个秩一 LoRA 分量的能量进行正则化，促使冗余分量消失，同时保留重要分量。我们推导了相应的近端子问题，并将矩阵优化约简为二维问题，从而得到一种用于识别冗余分量的隐式阈值准则。在自然语言理解和问答任务上的实验表明，所提方法取得了与现有 LoRA 基线相比有竞争力的性能。

## Abstract
Low-rank adaptation (LoRA) has become a popular parameter-efficient fine-tuning method for large language models. A key challenge in LoRA is how to determine the rank of each adaptation matrix, as rank directly controls its capacity and efficiency. Existing adaptive-rank methods typically allocate ranks according to manually designed importance scores, which are not directly derived from an optimization objective. In this work, we propose $\ell_p$-LoRA, a principled rank-allocation method based on $\ell_p$ regularization with $0<p<1$, which is a classical sparsity-inducing technique in signal processing and statistics. Specifically, we regularize the energy of each rank-one LoRA component, encouraging redundant components to vanish while preserving important ones. We derive the corresponding proximal subproblem and reduce the matrix optimization to a two-dimensional problem, leading to an implicit thresholding criterion for identifying redundant components. Experiments on natural language understanding and question-answering tasks demonstrate that the proposed method achieves competitive performance with existing LoRA baselines.

- **背景**：大语言模型（LLM）全量微调计算与显存成本高，参数高效微调（PEFT）成为主流方案；其中 LoRA 通过低秩分解 \(\Delta W = BA\) 显著减少可训练参数。
- **核心问题**：LoRA 中每个适配矩阵的秩 \(r\) 直接决定其适配容量与参数效率。标准 LoRA 通常对所有层/模块使用统一预设秩，但不同组件对下游任务的适配需求不同，统一秩分配可能浪费预算。
- **现有方法局限**：AdaLoRA、IGU-LoRA 等自适应秩方法多依赖人工设计的重要性评分来分配秩，这些评分并非直接由显式优化目标导出；贝叶斯/概率方法虽提供替代视角，但通常引入额外建模与推断机制。
- **本文含义**：将 LoRA 自适应秩分配重新解释为“结构化稀疏问题”：每个秩一分量可保留或删除。作者提出 \(\ell_p\)-LoRA，用 \(0<p<1\) 的 \(\ell_p\) 正则对秩一分量能量施加惩罚，使冗余分量趋于消失，重要分量保留，从而以优化诱导方式实现自动秩分配。

## 2. 方法论

- **核心思想**：
  - LoRA 更新可写为秩一分解：\(BA = \sum_{i=1}^r B_{:,i} A_{i,:}\)。
  - 定义第 \(i\) 个秩一分量能量：
    \[
    e_i = \|B_{:,i} A_{i,:}\|_F = \|B_{:,i}\|_2 \|A_{i,:}\|_2
    \]
  - 将各分量能量收集为 \(\Phi(A,B)=[e_1,\dots,e_r]^\top\)，则有效秩与 \(\|\Phi\|_0\) 相关。
  - 给定秩预算 \(b\)，原始目标可写为：
    \[
    \min_{A,B} L(BA),\quad \text{s.t. } \|\Phi(A,B)\|_0 \le b
    \]
  - 由于 \(\ell_0\) 约束组合且不连续，使用 \(0<p<1\) 的 \(\ell_p\) 惩罚作为连续松弛：
    \[
    \min_{A,B} L(BA)+\lambda \sum_{i=1}^r \left(\|B_{:,i}\|_2\|A_{i,:}\|_2\right)^p
    \]
  - 该惩罚作用于整个秩一分量，而非单个矩阵元素，因此促进“分量级稀疏”。

- **算法推导与关键技术细节**：
  - 对训练损失在当前 LoRA 因子 \((A_k,B_k)\) 处构造局部二次模型。
  - 定义名义梯度步：
    \[
    \tilde A = A_k - M^{-1}\nabla_A L_k,\quad
    \tilde B = B_k - M^{-1}\nabla_B L_k
    \]
  - 原问题被转化为按秩一分量可分离的子问题：
    \[
    \min_{a_i,b_i} \frac{M}{2}\left(\|a_i-\tilde a_i\|_2^2+\|b_i-\tilde b_i\|_2^2\right)+\lambda(\|a_i\|_2\|b_i\|_2)^p
    \]
  - 最优解可写为：
    \[
    a_i=\alpha_i \tilde a_i,\quad b_i=\beta_i \tilde b_i,\quad 0\le \alpha_i,\beta_i\le 1
    \]
  - 令 \(s_i=\|\tilde a_i\|_2,\ t_i=\|\tilde b_i\|_2\)，进一步降为二维问题：
    \[
    \min_{0\le \alpha,\beta\le 1}
    f_i(\alpha,\beta)=\frac{M}{2}\left[s_i^2(\alpha-1)^2+t_i^2(\beta-1)^2\right]+\lambda(s_i t_i \alpha\beta)^p
    \]
  - 对非零驻点，由一阶条件消元可得到关于 \(\alpha\) 的一维根查找问题，可用二分法或牛顿法求解；同时评估边界候选 \((0,1)\)、\((1,0)\)。
  - **隐式阈值准则**：若二维问题的最优解满足 \(\alpha_i\beta_i=0\)，则第 \(i\) 个秩一分量被识别为冗余并剪枝；否则保留。

- **算法流程**：
  - 每个训练迭代用 AdamW 等标准优化器更新 LoRA 因子 \(A,B\)。
  - 聚合梯度近似 \(\nabla_A L_k,\nabla_B L_k\)。
  - 若到达剪枝步，计算名义步 \(\tilde A,\tilde B\)。
  - 对每个秩一分量求解二维问题，得到 \((\alpha_i^\star,\beta_i^\star)\)。
  - 若 \(\alpha_i^\star\beta_i^\star=0\)，剪掉该分量；否则保留。
  - 剪枝准则周期性调用，不替代原优化器。
