## 摘要
多智能体大语言模型（LLMs）在应用人工智能中已无处不在，但其理论基础却仍出人意料地研究不足。从多智能体系统理论的视角来看，若干缺陷随之显现：缺乏社交智能、智能体之间缺乏协调机制、未知的涌现行为，以及受自然语言约束的智能体间交互。我们针对其中两个缺口：社交行为的缺失和智能体间协调机制的缺乏。我们提出认知概率语言智能体（EPLA），一种用于不确定性下多智能体协调的神经符号架构。符号守卫（Symbolic Guard）提供结构化的诊断反馈。LLM生成带类型的动作，守卫则对照权威符号状态控制其执行。我们在一个gossip测试平台中通过认知彩票gossip模型来形式化认知层，这些模型将基于视图的调用历史与以智能体为索引的概率权重结合起来。我们认为，实现这样一种形式化方法可以解决智能体式LLM的不足。

## Abstract
Multi-agent large language models (LLMs) have become ubiquitous in applied AI, yet their theoretical foundations remain surprisingly understudied. Viewed through the lens of multi-agent systems theory, several shortcomings come to light: a lack of social intelligence, the absence of coordination mechanisms among agents, unknown emergent behavior, and interactions between agents that are bounded by natural language. We address two of these gaps: the absence of social behavior and the lack of mechanisms for inter-agent coordination. We introduce Epistemic Probabilistic Language Agents (EPLA), a neuro-symbolic architecture for multi-agent coordination under uncertainty. A Symbolic Guard provides structured diagnostic feedback. The LLM generates typed actions, and the Guard controls their execution against an authoritative symbolic state. We formalize the epistemic layer in a gossip testbed through epistemic lottery gossip models, which combine view-based call histories with agent-indexed probability weights. We argue that implementing such a formalism can address shortcomings of agentic LLMs.

## 2. 方法论

### 2.1 核心思想：神经符号的「责任分工」
- **学习组件负责提出与适配**，**符号组件负责表征状态与控制执行**。
- 关键组件：
  - **Policy LLM**：解释语言，产生带类型（typed）的通信/工具候选动作，但**无权执行**。
  - **Epistemic Logic Core (ELC)**：唯一维护并提交权威认知符号状态。
  - **Conditional Belief Engine (CBE)**：维护分级/条件化不确定性（形如 `Ba(φ | ψ)`，源自条件信念逻辑），其摘要仅供 LLM 参考，**不具权威性**。
  - **检索增强记忆（RAG）**：要求记录持久且可溯源（事件 ID、来源链接、时间戳/逻辑序、访问范围、置信度元数据）。
  - **Symbolic Guard（符号守卫）**：对照权威符号状态判定 `permit / deny`，并输出两类结果——执行输出（二值决策）与学习输出（诊断 critique，含失败条件、相关状态事实、机器可读标签如 `call-permission`、`truthfulness`、`protocol-compliance`）。
  - **可选接口**：Guard 反馈可用于监督 **ARE（对抗表征工程）**；RL 头可针对 **LTL（线性时序逻辑）** 目标做长程优化。二者**均不替代 Guard**。

### 2.2 执行模型
- 运行状态定义为五元组：`z_t = (G_t, Σ_t, Π_t, R_t, q_t)`，分别为 ELC 状态、CBE 状态、协议与资源状态、检索记忆、LTL 监控器状态。
- **九阶段决策循环**：观察 → 检索 → 构造有界上下文 → Policy LLM 提出类型化候选 → 对认知/协议/一致性/预算条件做检查 → 返回拒绝+诊断或准备被接受的转移 → 原子化记录并提交 `G_{t+1}`（外部副作用需持久意图记录与幂等/补偿规则）→ （可选）由 Guard 标签形成表征层监督 → （可选）RL 头依据下一监控状态与接受信号更新。
- **一致性要求**：Guard 检查与 ELC 提交必须基于同一版本化状态；需串行化或在版本变化时重新验证。
- **动作模式**：`Call`、`Message`、`Announce` 三类，但**仅对成对 push-pull 的 `Call` 给出操作语义**（因其具有精确的秘密并集转移与来源可验证的视图语义），其余两类不虚构语义。
- **形式化投影**：把架构投影为「仅含 Call」的抽象——保留被接受的成对调用历史、秘密事实、智能体视图与彩票权重，省略预算、检索文本、自由消息、ARE 参数与 LTL 监控器。此投影用于界定定理边界，**不构成实现符合该抽象的证据**。

### 2.3 认知层形式化：认知彩票八卦模型（ELGM）
- **视图语义（Def 3.1）**：`c R_a c'` 当且仅当 `view_a(c) = view_a(c')`。视图比「涉及 a 的调用子序列」更丰富——它记录 a 通过调用获得的本地信息（例：历史 `ac` 与 `bc;ac` 中 a 的调用子序列相同，但视图不同）。
- **ELGM 定义（Def 3.2）**：`M_G = (H, V, {R_a}, {L_a})`，其中 `H ⊆ C^{<ω}` 为有限历史集，`V` 为八卦状态诱导的事实赋值，`R_a` 为视图等价关系，`L_a: H → R_{>0}` 为严格正彩票，且**每个 a-等价类的权重和有限且非零**（有限和条件是实质要求：无限等价类上不能用常数权重先验）。
- **知识片段 `L_K`（Def 3.3）**：由 `⊤ | p | ¬φ | (φ∧ψ) | K_a(φ)` 生成，**不含数值概率原子**（如 `P_a(φ) ≥ q`）。知识被定义为概率为一：`M_G, c ⊨ K_a(φ)` 当且仅当 `P_a(φ)(c) = 1`。
- **核心结论 1 — 彩票透明性（Lemma 5.2）**：对任意可接受 ELGM、任意 `c` 与任意 `φ ∈ L_K`，`M_G, c ⊨ φ` 当且仅当其去彩票 Kripke 结构 `M_0, c ⊨ φ`。即**正权重不影响知识片段的真值**。由此得到 `K_a(·)` 满足 **S5** 公理（Prop 4.1）。
- **核心结论 2 — 来源对应与守卫可判定性（Lemma 5.3, Thm 5.4）**：对精确定义的 Apt–Wojtczak 来源实例（有限线性序智能体集、双射 `b ↦ p_b`、规范写成 `ab (a<b)` 的调用字母表、完整有限调用序列域 `H_src`、来源 push-pull 并集更新），定义模态深度为一的来源兼容片段 `L_{K,src}` 与翻译 `τ`（`τ(S_ab) = F_a p_b`，`τ(K_a(θ)) = K_a τ(θ)`），使像落入 Apt–Wojtczak 的可判定语言 `L_wn`。于是给定有限编码的 `α`、`c`、`pre(α)`，**检查 `Γ_{M_G}(α, c)` 是可判定的**（不主张复杂度界）。
- **核心结论 3 — 正权重重加权不变性（Lemma 6.2）**：若重加权形如 `L'_a(c) = L_a(c) k_a(c)`（`0 < k_a(c) < ∞`）且结果彩票可接受，同时 `H`、`V`、所有 `R_a` 不变，则所有 `L_K` 公式真值不变，**所有守卫真值也不变**。
  - **三源重加权（Def 6.1）**：`L'_a(c) = (1/Z_a) L_a(c) P_occ(e|c) P_obs(o_a|e,c)`，其中归一化因子 `Z_a = Σ_{c'∈H} L_a(c')P_occ(e|c')P_obs(o_a|e,c')`；有限非零归一化是**额外假设**（仅类内可接受性不能推出）。
- **核心结论 4 — 条件化排序进展界（Thm 7.1）**：设排序函数 `ρ: X → {0,…,B}`，目标集 `G = ρ^{-1}(0)`，命中时间 `T`。若存在策略 `β` 使每个非目标状态执行后严格降秩，且条件于 `F_t` 时策略以概率 `≥ ε` 选择 `β(X_t)`，其他被允许调用与拒绝候选均不增秩，则 `E[T] ≤ ρ(x_0)/ε ≤ B/ε`。
  - 作者强调：经典八卦界（如完全图 push-pull LNS 协议的调用上界）**只有**在实现确实满足秩、非增替代转移与策略下界后才能代入；**不给出任意受守卫 LLM 智能体执行的通用闭式界**。

## 6. 主要结论与发现

1. **彩票透明性**：在可接受性与满支撑条件下，**正彩票权重不影响知识片段守卫的真值**；知识算子在 ELGM 中保持 S5 行为。
2. **来源兼容片段的守卫可判定性**：对精确定义的 Apt–Wojtczak 来源实例，模态深度为一的来源兼容片段可翻译进 `L_wn`，从而使 Guard 检查可判定（不主张复杂度界）。
3. **正权重重加权的不变性**：结构（`H`、`V`、`R_a`）不变时，正的重加权不改变任何 `L_K` 守卫的真值。
4. **条件化排序终止界**：在显式的秩函数、非增替代转移与策略下界 `ε` 假设下，期望命中时间 `E[T] ≤ ρ(x_0)/ε ≤ B/ε`。
5. **架构层面**：EPLA 把 LLM 的分级置信度与 Guard 的精确知识条件分离——被拒候选**不会**因为 LLM 给了高概率而变得安全。

## 7. 优点

- **责任分工清晰且非对称**：ELC 独占权威状态，CBE 只管分级不确定性，检索只提供证据，Policy LLM 只能提议，Guard 只做精确检查——避免了「LLM 摘要替代权威状态」的常见陷阱。
- **理论边界声明极为克制透明**：
  - 明确列出 **Remark 5.5** 的「本定理不覆盖什么」：概率阈值守卫、`L_{K,src}` 之外的事实原子、嵌套个体知识、公共知识、具有无效或协议受限历史域的任意可接受 ELGM、电话号码交换、任意 LLM 工具轨迹；也不引入动态 EPLS 模型检验的复杂度结果。
  - 明确不主张单项技术优先权；明确形式定理不蕴含实现符合抽象。
- **假设显式化**：有限和可接受性条件、重加权归一化因子的有限非零假设、三源似然因子的正性与有界性，均被点明为**额外建模假设**而非导入结论。
- **理论嫁接谨慎且精确**：区分视图与调用子序列（Example 4.2）、区分「架构中保留的动作类型」与「已赋予操作语义的动作类型」、区分 ARE 与彩票重加权算子（明确不将二者等同）。
- **工程义务被前置识别**：Guard 分层验证/缓存/增量更新/编译监控器、事件溯源与重放、拓扑与记忆分区、ARE 与 RL 训练的时间尺度分离/部分冻结/策略锚定等。
- **人机边界设计合理**：被拒的策略例外或语义未形式化的高影响动作交由人类审查，但人类批准**不能使失败的 Guard 谓词为真**，批准动作必须重新经过 Guard 与 ELC。
