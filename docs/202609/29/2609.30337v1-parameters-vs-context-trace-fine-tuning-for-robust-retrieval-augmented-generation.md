## 摘要
检索增强生成（RAG）通过引入外部上下文，缓解大语言模型中的知识过时与事实幻觉问题。然而，当检索到的知识与模型内部的参数化知识发生冲突时，模型可能要么盲目遵循误导性上下文，要么错误地依赖参数化知识，从而导致不可靠的回答。为解决这一问题，本文提出 TRACE（Debate-TRace and Answer-Completeness rEgularized fine-tuning），一种面向知识冲突下 RAG 的鲁棒微调框架。首先，我们提出一种利用多智能体辩论轨迹来提取正确候选、错误候选和答案偏移模式的微调方法，为可靠的知识来源选择提供细粒度监督。此外，我们设计了一种答案完整性正则化机制，通过答案尾部词元强化和过早终止抑制，缓解空回答、过短回答和过早终止回答的问题。微调目标结合了正确答案监督、错误候选抑制、答案尾部词元强化和过早终止抑制，使模型能够利用可靠的外部上下文，抵制误导性或无关的检索内容，并在检索证据不可靠时回退到参数化知识。在多种知识冲突场景和数据集上的实验表明，TRACE 提升了对误导性检索知识的鲁棒性，并减少了不完整回答。这些结果表明，多智能体辩论轨迹与答案完整性正则化共同增强了 RAG 模型中的知识来源选择、冲突鲁棒性和答案质量。我们的代码可在 https://github.com/PHD-lanyu/TRACE 获取。

## Abstract
Retrieval-Augmented Generation (RAG) mitigates knowledge obsolescence and factual hallucination in large language models by introducing external context. However, when retrieved knowledge conflicts with the model's internal parametric knowledge, the model may either blindly follow misleading context or incorrectly rely on parametric knowledge, leading to unreliable responses. To address this issue, this paper proposes TRACE (Debate-TRace and Answer-Completeness rEgularized fine-tuning), a robust fine-tuning framework for RAG under knowledge conflicts. First, we propose a fine-tuning method that leverages multi-agent debate traces to extract correct candidates, incorrect candidates, and answer-shift patterns, providing fine-grained supervision for reliable knowledge-source selection. In addition, we design an answer completeness regularization mechanism to alleviate empty, overly short, and prematurely terminated responses via answer-tail token reinforcement and premature termination suppression. The fine-tuning objective combines correct-answer supervision, incorrect-candidate suppression, answer-tail token reinforcement, and premature termination suppression, enabling the model to use reliable external context, resist misleading or irrelevant retrieved content, and fall back to parametric knowledge when retrieved evidence is unreliable. Experiments across multiple knowledge-conflict scenarios and datasets show that TRACE improves robustness against misleading retrieved knowledge and reduces incomplete answers. These results demonstrate that multi-agent debate traces and answer completeness regularization jointly enhance knowledge-source selection, conflict robustness, and answer quality in RAG models. Our code is available at https://github.com/PHD-lanyu/TRACE.

## 1. 核心问题与整体含义

- **研究背景**：检索增强生成（RAG）通过引入外部上下文，缓解大语言模型（LLM）参数知识过时、不完整和事实幻觉问题。
- **核心问题**：当检索到的上下文与模型内部参数知识发生冲突时，模型往往缺乏“来源感知”能力：
  - 可能盲目跟随误导性、错误或无关的检索内容；
  - 也可能错误地坚持参数知识，即使检索证据更可靠；
  - 在自冲突上下文下，模型难以判断应采信哪一条证据。
- **整体含义**：论文主张 RAG 的鲁棒性不仅取决于“是否检索到好内容”，还取决于模型能否在参数知识与检索知识之间进行可靠的知识源选择，并生成完整、可解析的最终答案。
- **现有方法不足**：
  - 许多方法在推理阶段引入额外提示、反思、检索评估或多步推理，增加部署开销；
  - 训练信号多来自最终答案、解码分布或采样奖励，缺少对中间候选、错误路径和答案修正过程的细粒度监督；
  - 知识冲突微调后可能出现空答案、过短答案、实体不完整、答案边界不清等“答案不完整”问题。

## 2. 方法论：TRACE 框架

### 2.1 核心思想

- TRACE 全称为 **Debate-TRace and Answer-Completeness rEgularized fine-tuning**。
- 核心思路：**多智能体辩论只用于训练数据构造，不保留到推理阶段**。辩论轨迹暴露正确候选、错误候选和答案偏移模式，再被转化为正负微调信号。
- 同时引入 **答案完整性正则化**，解决知识冲突微调后答案不完整的问题。
- 最终目标：让目标模型在推理时单次生成，既能利用可靠外部上下文，又能抵抗误导性检索，并在检索不可靠时回退到参数知识。

### 2.2 多智能体辩论轨迹收集

- 对每个训练样本：
  - 先用仅查询（query-only）方式获取基础模型的参数知识回答；
  - 再在检索上下文 C 下进行多轮辩论。
- 辩论包含三种角色：
  - **响应模型（response model）**：较弱的目标模型，生成和修正候选答案；
  - **批评模型（critic model）**：较强模型，检查事实一致性、上下文可靠性和知识源选择；
  - **裁判模型（judge model）**：中等能力模型，决定是否停止辩论并选择关键信息。
- 采用 **强教弱（strong-to-weak）** 设置，使辩论轨迹包含误导候选、修正和答案偏移。
- 最大辩论轮数为 5，但可根据裁判决定提前终止。

### 2.3 来源感知训练记录构造

- 不直接把完整辩论文本作为输入，而是构造紧凑训练记录，包含：
  - 仅查询回答；
  - 中间辩论候选；
  - 最终辩论答案；
  - 黄金答案。
- 每条记录赋予知识源标签 \(s_i \in \{internal, external, both\}\)：
  - **internal**：参数知识支持黄金答案，而检索上下文不可靠；
  - **external**：检索上下文支持黄金答案，而仅查询回答错误；
  - **both**：两者均支持黄金答案，作为非冲突锚点。
- 若两个来源都不支持黄金答案，则排除该样本，因为其更接近“不可回答检测”。
- 功能类型标签包括：
  - 可靠监督；
  - 上下文使用；
  - 上下文抵抗；
  - 正确到错误偏移预防；
  - 双源错误抑制；
  - 边界修正。
- 每条辩论轨迹可扩展为多条训练记录；每个轨迹最多保留两个代表性错误候选，以减少噪声负样本。

### 2.4 来源感知正负目标

- 对正确答案 \(y^+\) 使用交叉熵（CE）监督：
  - 让模型学会在各来源条件下生成可靠答案。
- 对错误候选 \(y^-\) 使用 **unlikelihood（UL）** 目标：
  - 降低误导性答案内容的生成概率；
  - 损失仅在答案跨度内计算，结构标签和答案边界 token 不被视为负样本，避免破坏输出模板。
- 引入轻量级平衡调制：
  - 对“参数知识正确但外部检索错误”的 internal 样本，使用指数移动平均（EMA）估计历史损失水平；
  - 通过缩放因子 \(r_i\) 降低早期大损失的影响，并设置下界 \(\beta\)，防止此类样本被完全忽略。
- 主目标为：
  - 对每条记录加权组合 CE 损失与 UL 损失；
  - 样本权重由功能类型权重、知识源平衡系数和稳定因子共同决定。
- 可调参数包括错误候选抑制权重 \(\lambda_{neg}\) 和来源平衡系数 \(\gamma_{int}, \gamma_{ext}, \gamma_{both}\)。

### 2.5 答案完整性正则化

- **动机**：知识冲突微调后，模型可能已找到正确方向，但过早停止，产生如 “Consor”“First”“Fort Dear” 等不完整输出。
- 包含两个部分：
  1. **答案尾部 token 强化**：
     - 在答案跨度内，越靠近答案末尾的 token 获得越大权重；
     - 防止模型只生成答案前缀，忽略多词实体、限定短语或长专有名词。
  2. **过早终止抑制**：
     - 将 EOS、`</answer>` 等终止 token 视为不应在答案未完成时出现的 token；
     - 对答案跨度内的终止概率施加 unlikelihood 约束；
     - 减少空答案、过短答案、截断实体和不完整边界。
- 总训练目标：
  - 主来源感知目标 + 答案完整性正则项；
  - 由 \(\lambda_{comp}\) 控制完整性正则的贡献。
- 与格式约束的区别：
  - 格式约束关注标签是否合法；
  - 答案完整性正则关注合法答案跨度内的内容是否语义完整。

  - TRACE 表现突出；

  - TRACE 具有竞争力，但结果依赖主干模型；

## 7. 优点

- **训练与推理解耦**：
  - 多智能体辩论只用于数据构造，推理时单次生成，避免部署阶段的多智能体开销。
- **过程级监督**：
  - 利用辩论轨迹提取正确候选、错误候选和答案偏移，比仅依赖最终答案的监督更细粒度。
- **正负信号结合**：
  - CE 监督正确答案，UL 抑制错误候选，并限制在答案跨度内，避免破坏输出模板。
- **发现并处理答案完整性问题**：
  - 将答案完整性作为独立生成目标，通过尾部 token 强化和提前终止抑制减少不完整输出。
- **来源感知设计**：
  - 通过 internal、external、both 标签和功能类型权重，平衡参数知识与外部上下文的使用。
- **实验覆盖较广**：
  - 覆盖五类检索场景、两个模型族、多个数据集和多种基线。
- **消融清晰**：
  - 分别验证辩论、强教弱和答案完整性正则化的贡献。
- **弱模型迁移验证**：
  - 角色转换实验说明方法不仅适用于 7B/8B 模型，也可向更小模型迁移。

## 8. 不足与局限

- **部分相关长上下文场景表现有限**：
  - 在 S5 的 HotPotQA、2Wiki 等任务上，TRACE 不如部分强基线；
  - 说明其不擅长细粒度证据定位和证据链组合。
- **依赖辩论数据构造**：
  - 训练数据需要多智能体多轮辩论，构造成本高；
  - 依赖较强批评模型和裁判模型，可能引入强模型偏好或噪声。
- **未充分报告训练成本**：
  - 未说明 GPU 数量、训练时长、辩论调用次数和总 token 成本；
  - 实际可复现性和部署成本评估受限。
- **实验报告不够完整**：
  - 主要使用 EM，缺少 F1、语义评估和人工评价；
  - 未报告多次运行方差和显著性；
  - 仅训练 1 个 epoch，未系统探索超参数和训练轮数。
