## 摘要
从大型语言模型（LLMs）到智能体的转变，使安全风险的重点从有害文本转向不可逆的环境危害。尽管当前防御措施在很大程度上仍是回溯性的，但主动的运行时干预因缺乏大规模、因果一致的数据而受阻。我们提出 PROACT-Agent，一个用于合成高保真轨迹以支持实时护栏的框架。我们发现先前基准中存在一个关键的“安全漂移”问题，即宽松的标注范式未能强制实现时间一致性。PROACT-Agent 通过以下方式解决这一问题：(1) 渐进式轨迹展开，以揭示隐藏于长上下文交互中的风险；(2) 推理增强的因果矫正，以强制满足单调因果一致性；(3) 文化感知的数据本地化，以实现跨地域鲁棒性。我们提出 PROACT-Bench，一个双语安全基准，包含 155,780 个通过多模型裁决标注的状态。在下一次 LLM 推理之前评估更新后的上下文，训练得到的护栏在完全源留出条件下达到 91.46% 的不安全类别 F1 和 90.63% 的精确边界检测。在 AgentDojo 中，它将非 DoS 定向攻击成功率从 20.82% 降至 0.40%。

## Abstract
The transition from Large Language Models (LLMs) to agents shifts safety stakes from toxic text to irreversible environmental harm. While current defenses remain largely retrospective, proactive runtime intervention is bottlenecked by the lack of large-scale, causally-consistent data. We propose PROACT-Agent, a framework for synthesizing high-fidelity trajectories to enable real-time guardrails. We identify a critical "safety drift" in prior benchmarks, where lenient annotation paradigms fail to enforce temporal consistency. PROACT-Agent addresses this through: (1) Progressive Trajectory Unrolling to reveal risks hidden in long-context interactions; (2) Reasoning-Augmented Causal Rectification to enforce monotonic causal consistency; and (3) Culturally-Aware Data Localization for cross-border robustness. We introduce PROACT-Bench, a bilingual safety benchmark with 155,780 states labeled through multi-model adjudication. Evaluating updated context before the next LLM inference, the trained guard achieves 91.46% unsafe-class F1 and 90.63% exact-boundary detection under complete source holdout. In AgentDojo, it reduces non-DoS targeted attack success from 20.82% to 0.40%.

## 1. 核心问题与研究动机

- **安全风险的范式转移**：LLM 正从静态知识库演化为具备迭代推理与工具调用能力的智能体（agent），安全风险随之从"生成有害文本"升级为"触发不可逆的数字或物理危害"。一次错位的工具调用可能级联为灾难性后果。
- **现有防御的错位**：
  - 第一代护栏（LlamaGuard、ShieldGemma）面向对话内容审核，筛选孤立文本的毒性，**不训练"何时停止 agent"的决策**，在多步工具场景中要么高漏报，要么过度保守。
  - 轨迹级诊断（AgentDoG）在完整交互日志上做事后分析，本质是"数字尸检"——环境已被破坏才识别失败。
  - 步级护栏（TS-Guard）尝试主动防御，但依赖样本高效的强化学习，假设少量训练数据可泛化到复杂危害。
- **核心数据瓶颈**：运行时干预需要识别"第一个应当停止的前缀"，同时保留其前的安全前缀，但缺乏大规模、因果一致的数据。
- **基准缺陷**：
  - R-Judge、ATBench、ASSEBench 为静态端到端评估；ASSEBench 采用宽松的"教育豁免"规则。
  - AgentAlign 有规模但缺 CoT；TS-Bench 有 CoT 但规模受限、缺时序验证。
  - **"安全漂移"（safety drift）**：中间步骤在更早的不安全前缀之后仍被标为安全，破坏因果一致性。
  - 生态以英文为中心，跨文化部署（如 Instagram→小红书）需要功能性映射而非字面翻译。

## 2. 方法论：PROACT-Agent 框架

**核心思想**：将智能体安全重新表述为**在线、非马尔可夫的前缀评估任务**——在每次 LLM 推理之前评估已观察到的交互前缀，阻断不安全的继续执行（"熔断"）。

**形式化基础**：
- 轨迹定义为 τ = (x, a₁, o₁, …, a_N, o_N) ∈ X × (A × O)^N，前缀 P_t = (x, a₁, o₁, …, a_t, o_t)。
- 定义理想风险函数 R*: P → {0,1}，1 表示下一次 LLM 推理应被阻断。长上下文混淆可使 R*(P_t)=1 而 R*(P_k)=0 (∀k<t)。
- 目标从回顾性后验 P(y|τ) 转为前缀级风险 P(ŷ_t|s_t)。

**三阶段流水线**：

### （1）渐进式轨迹展开 PTU（Progressive Trajectory Unrolling）
- 定义变换算子 Γ，将静态轨迹 τ 映射为因果链接的流式评估状态集合：Γ(τ) = ⋃_{t=0}^{N} {s_t | s_t = P_t}。
- 区分首个不安全边界 t* 与保留截止点 u；全安全轨迹保留全部前缀。
- 用 Qwen3-32B 作为认知解析器 M_parse，两阶段：先定位候选边界 t_c，再展开至该边界并丢弃后续交互。

### （2）推理增强的因果矫正 RACR（Reasoning-Augmented Causal Rectification）
- **知识驱动的思维增强**：将缺失的内部推理建模为逆向理由推断问题，ρ_t = arg max_ρ P_φ(ρ | x, h_t, a_t, C_t)，其中 C_t 为动态上下文先验（工具 schema + 对话线索）。注意：推断的 ρ_t 是辅助解释，非 agent 真实隐藏 CoT。
- **多智能体共识与仲裁**：评估委员会 M = {DeepSeek-R1-671B, MiniMax-M2.5, Qwen2.5-72B, Qwen3-32B}；用 Shannon 熵 H(Y_t) 量化分歧，仅在 H(Y_t)>0 时由仲裁者 J（GLM-5.1，充当"首席合规官"元审阅者）裁决。
- **单调因果一致性 MCC**：一旦前缀不安全，后续扩展在 fail-closed 部署下不可达，予以排除。矫正算子 T(Y) = {ŷ_t | ŷ_t = max_{0≤i≤t} y_i}，即对标签序列取前缀最大值，保留安全→不安全的转变，剔除边界后的标签反转。

### （3）文化感知数据本地化 CADL（Culturally-Aware Data Localization）
- **功能性实体映射**：不做字面翻译，而将英文环境实体映射到功能等价的中文实体（Instagram→小红书，Amazon→淘宝），保留工具调用语法 schema F 与风险本质。
- **三重刚性验证 TRV**（布尔门 Ω_TRV）：① 结构与标签不变性（schema 与最终裁决标签一致）；② 信息密度保持（拒绝"内容省略"等偷懒模式 P_lazy）；③ 上下文保真审计（GLM-5.1 作为成对审计者，评分需达阈值 c）。

**训练目标**：监督微调（SFT）+ LoRA，以 JSON 形式输出标签 ŷ_t 与拒绝理由，交叉熵损失为标准 NTP。

- **运行时效率**：小骨干（Qwen3-1.7B）P50 403 ms、P95 889 ms、峰值显存 4.69 GiB，延迟斜率 20.8 ms/1K token，满足在线熔断的实时性要求；更大骨干延迟上升但仍可控。

## 7. 优势与亮点

- **问题重构的原创性**：将 agent 安全从"内容审核"或"事后诊断"重构为**在线、非马尔可夫的前缀风险评估**，直接对齐"何时熔断"的部署需求，避免了传统护栏的漏报与过度保守两难。
- **因果一致的数据构造**：通过 PTU 显式建模首个不安全边界 t*，配合 MCC 的前缀最大值算子，从机制上消除"安全漂移"，这是相对 AgentAlign/TS-Bench 的关键数据质量优势。
- **多智能体共识与仲裁**：用 Shannon 熵量化委员会分歧、仅在分歧时触发仲裁者，兼顾标注质量与成本，避免单一模型裁决偏差。
- **文化本地化而非翻译**：CADL 采用功能性实体映射与三重刚性验证，保证跨语言部署时风险语义与工具语法的一致性，超越字面翻译。
- **评估严谨性**：严格根分组与完全源留出双协议、无效输出按错误计、共享骨干控制变量、多维度指标（F1/边界检测/ASR/FBR/FAR），在同类工作中属较高标准。
- **资源透明度**：明确报告 GPU 小时、API 调用量、延迟与显存，便于复现与成本评估。
- **闭环验证**：不止于静态基准，在 AgentDojo 上做端到端闭环，ASR 大幅下降且 FBR 保持低位，证明方法的实际部署价值。

## 8. 局限与不足

- **金标准依赖模型裁决**：首个不安全边界由 LLM 委员会+仲裁者确定，DQS 亦为模型内部一致性指标，缺乏独立人工标注验证，可能继承模型偏差。
- **RACR 推断的是"逆向理由"而非真实隐藏 CoT**：ρ_t 是辅助解释，存在与 agent 实际内部推理不一致的可能，影响矫正的因果解释力。
- **基线迁移公平性**：部分基线（如 TS-Guard）在"迁移到前缀决策任务"设定下评估，未在 PROACT-Bench-train 上重训，属释放系统迁移测试，可能低估其上限。
- **消融与主表训练运行不一致**：Table 10 全模型行与 Table 1 更新版模型分属不同训练运行，横向比较需谨慎。
- **规模与覆盖**：PROACT-Bench 虽达 155,780 前缀状态，但源数据仅四类，风险分类与场景覆盖可能仍有盲区；中文数据由英文映射生成，文化保真度受映射规则限制。
- **部署假设**：MCC 依赖 fail-closed 部署假设，若实际系统在边界后仍可继续执行，前缀最大值算子的合理性需重新审视。
- **成本**：多模型投票与仲裁累计约 60,000 次 API 调用，标注阶段成本较高，且仲裁者本身为闭源模型，长期可复现性受限。

## 9. 对领域的影响与启示

- **范式贡献**：为 agent 安全提供"前缀级在线熔断"的新范式，可能推动护栏从"文本分类器"向"时序决策器"演进，并为后续工作提供可复用的 PTU/RACR/CADL 组件。
- **数据基建**：PROACT-Bench 的双语、因果一致、前缀级结构，可作为社区训练与评测 agent 步级护栏的标准资源。
- **方法启示**：多智能体共识+熵触发仲裁、逆向理由推断、前缀最大值标签矫正等技巧，可迁移至其他序列决策的安全标注任务。
- **文化维度**：功能性实体映射+三重刚性验证的思路，为 LLM 安全的跨文化/跨生态部署提供了可操作范式，呼应了安全对齐的本地化需求。
- **开放问题**：如何用人工标注校准模型裁决的金标准、如何验证 RACR 推断理由的真实性、如何在 fail-open 部署下定义边界、以及如何降低多模型投票成本，是后续值得探索的方向。
