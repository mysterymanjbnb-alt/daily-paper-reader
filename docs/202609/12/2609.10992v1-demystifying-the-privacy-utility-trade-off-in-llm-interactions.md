## 摘要
大语言模型融入日常任务依赖于富含上下文的指令，这不可避免地会暴露敏感的用户信息。当前的隐私保护方法通常采用与上下文无关的静态规则，导致严重的效用下降。然而，关于脱敏如何影响下游性能的具体机制仍在很大程度上未被充分探索。为此，我们开展了一项系统性分析，以解构隐私-效用权衡，并揭示了三个底层机制：(1) 上下文依赖效用，该机制首先通过揭示数据价值会基于用户意图从关键约束转变为可舍弃的噪声，从而确定何时进行脱敏；(2) 策略性适应，该机制随后通过表明在移除与替换之间的选择取决于任务对事实完整性还是结构连贯性的依赖，来决定如何脱敏；(3) 组合交互，该机制最终通过证明属性会形成一个由协同依赖或拮抗冗余构成的语义网络，扩展了保护范围。在这些洞见的指导下，我们提出了一种意图驱动的本地保护框架。通过蒸馏一个轻量级模型 Veilmind-4B 来驱动动态的提取-脱敏-恢复流水线，我们的方法达到了低泄漏的隐私点，同时相比现有面向隐私的基线保留了显著更高的响应效用，将隐私-效用权衡推向帕累托前沿。

## Abstract
The integration of Large Language Models into daily tasks relies on context-rich instructions, inevitably exposing sensitive user information. Current privacy-preserving methods typically employ context-agnostic static rules, causing severe utility degradation. However, the specific mechanisms governing how sanitization impacts downstream performance remain largely underexplored. To address this, we conduct a systematic analysis to deconstruct the privacy-utility trade-off, uncovering three underlying mechanisms: (1) Context-Dependent Utility, which first establishes when to sanitize by revealing that data value shifts from critical constraints to dispensable noise based on user intent; (2) Strategic Adaptation, which subsequently determines how to sanitize by dictating that the choice between removal and replacement depends on the task's reliance on factual integrity versus structural coherence; and (3) Combinatorial Interplay, which finally extends the protection scope by demonstrating that attributes form a semantic web of synergistic dependencies or antagonistic redundancies. Guided by these insights, we introduce an intent-driven local protection framework. By distilling a lightweight model Veilmind-4B to drive a dynamic extraction-sanitization-restoration pipeline, our approach reaches a low-leakage privacy point while preserving substantially higher response utility than existing privacy-oriented baselines, advancing the privacy-utility trade-off toward the Pareto frontier.

## 一、核心问题与研究动机

- **背景**：LLM 正深度嵌入用户日常任务，高质量响应依赖富含个人上下文的指令，用户不得不披露细粒度个人信息（诊断、财务状况、关系等）。
- **风险**：一旦传输至不可信服务器，这些数据可能被用于画像挖掘和定向滥用（如医疗风险、浪漫诈骗、经济剥削）。
- **现有方法的根本缺陷**：主流隐私保护方法（静态规则、通用启发式、NER、差分隐私）采用**上下文无关**的脱敏策略，无法评估具体细节相对于用户目标的边际贡献，导致"把必要上下文与非必要噪声一并剥离"，造成严重的效用崩塌。
- **研究空白**：脱敏如何影响下游性能的具体机制**尚未被系统探索**，领域缺乏对隐私-效用决策边界的细粒度理解。

## 二、方法论

### 2.1 核心思想
不采用黑箱式静态启发式，而是通过系统性实证分析映射隐私-效用的底层决策边界，回答三个基本问题，并据此设计意图驱动的本地保护框架。

### 2.2 三大机制（核心理论贡献）

- **机制一：上下文依赖效用（何时脱敏）**
  - 敏感信息的功能价值取决于任务上下文与用户意图。
  - 区分两种动态：**功能耦合**（属性作为关键约束，如 Problem Solving 依赖财务信息）与**信息冗余**（属性作为可舍弃噪声，如 Task Execution 中健康信息可获正向收益）。
- **机制二：策略性适应（如何脱敏）**
  - **移除（Remove）** 适用于依赖事实完整性的客观任务，防止合成占位符成为"虚假前提"诱发幻觉。
  - **替换（Replace）** 适用于交互/共情场景，敏感陈述作为"对话锚点"维持叙事结构。
  - 以策略差分 \(D = \Delta R_{\text{remove}} - \Delta R_{\text{replace}}\) 量化两者优劣。
- **机制三：组合交互（脱敏范围）**
  - 定义交互分数：\(I_{A,B} = \Delta R(A,B) - (\Delta R(A) + \Delta R(B))\)
  - \(I<0\) 表示**协同**（逻辑关联，需一致处理，如健康+兴趣）；\(I>0\) 表示**拮抗**（信息冗余，需共同保护，如社会信息+行为数据）。

### 2.3 框架实现：意图驱动的本地保护框架

- **三阶段流水线**：
  1. **敏感信息抽取**：本地模型识别显式 PII 与隐式属性披露，得到敏感陈述集合 \(S=\{s_1,...,s_n\}\)。
  2. **策略规划与脱敏**：基于意图与隐私类别，为每条陈述分配动作 \(a_i \in \{\text{Keep, Remove, Replace}\}\)，并考虑陈述间交互效应，生成脱敏提示 \(P'\) 与计划 \(\pi\)：
     \[
     P', \pi = M_{\text{local}}(P, S)
     \]
  3. **响应恢复**：本地模型利用计划 \(\pi\) 与原始敏感陈述，将远端返回的通用响应 \(R'\) 恢复为个性化响应：
     \[
     R_{\text{final}} = M_{\text{local}}(R', \pi, S)
     \]
- **双模式控制**：Utility Priority Mode（保留关键约束，适度保护）与 Privacy Priority Mode（激进脱敏，仅在不可回答时保留）。
- **知识蒸馏**：以 DeepSeek-V4-Flash 为教师，Qwen3-4B 为学生，合成三类训练数据（推理增强抽取、双模式脱敏、恢复），得到隐私专用模型 **Veilmind-4B**。

## 六、主要结论与发现

- 敏感信息的边际效用**高度依赖上下文**：约束型任务中细节定义解空间，逻辑型任务中无关隐私甚至产生**正向效用**（如 Task Execution 移除健康信息 \(\Delta R=+0.19\)）。
- **移除 vs 替换**取决于任务对事实完整性还是结构连贯性的依赖：Task Execution 与健康信息交互中策略差分峰值 \(D=+14.04\)（移除占优）；Personalized Interaction 中替换占优（\(D=-1.64\)）。
- **属性间存在语义网络**：健康+兴趣协同（\(I=-6.05\)），社会信息+行为数据拮抗（\(I=+4.14\)），且交互模式受用户意图主导。
- **框架效果**：Veilmind-4B 在 Uprise 上 Utility Priority 效用达 **87.00%**、Privacy Priority 泄露降至 **40.50%**，显著优于 Papillon、PUFT 等基线，推进隐私-效用**帕累托前沿**。
- **蒸馏价值**：抽取覆盖率 52.4%→72.7%；脱敏从"删除主导"转向更具判别性的动作分配；恢复效用增益 +3.5%→+7.0%。
- **消融结论**：抽取提供隐私覆盖、脱敏控制泄露、恢复在不增加泄露的前提下挽回效用，三者缺一不可。

## 八、不足与局限

- **评测依赖单一模型**：远程生成仅用 gemini-2.5-flash，效用奖励仅用 Skywork-Reward-V2-Llama-3.1-8B，缺乏多模型交叉验证，结论可能存在模型特异性偏差。

- **语言与地域覆盖**：数据以英语、中文为主，其他语言占比低，跨语言/跨文化泛化性未充分验证。
- **应用限制**：假设本地模型可信，但未讨论本地模型被攻击或自身泄露的风险；恢复阶段需本地保留完整敏感上下文，本地存储安全性未展开。
- **多轮对话未覆盖**：论文明确将多轮交互列为未来工作，当前框架仅面向单轮提示，而真实场景中隐私边界随对话演化。
- **算力细节缺失**：未报告训练时长、总计算量，难以评估蒸馏成本与可复现性。
- **潜在偏差**：合成数据通过 persona 注入生成，可能与真实用户分布存在偏差；意图/隐私分类由单一 LRM 标注，未报告标注一致性指标（如 Cohen's Kappa）。
