## 摘要
针对自回归视觉语言模型（VLM）的资源耗尽攻击通常假设单模态威胁模型，将图像分支视为主要优化面，同时固定用户可见的提示。即便是近期以循环为中心的变体也仍局限于这种单通道范式，未将可用性利用作为一个在可联合控制的输入面上的跨模态优化问题加以探索。我们提出联合像素-提示优化（Joint Pixel-Prompt Optimization, JPPO），这是首个将可见提示提升为与图像扰动并列的一等对抗变量的复合对抗框架。在受限联合输入威胁模型下，JPPO 在像素和提示两个面上进行耦合的、分阶段优化。这会产生协同成本放大，其机制不同于依赖循环的失效，在我们的实验中循环发生率可忽略不计。在 8/255 无穷范数预算下，于 MS COCO 和 ImageNet 上评估五个开源 VLM 系列，JPPO 在 Qwen2.5-VL-7B 上实现超过 4.6 倍的延迟放大和 5.3 倍的能耗放大，在 BLIP-2 上实现超过 36.6 倍的延迟放大和 32.7 倍的能耗放大。这是直接比较的基线中最强的成本放大，同时所需优化迭代次数显著更少。消融实验证实，这种放大源于多模态协同，而非提示长度或孤立模态。这些发现揭示了当前 VLM 服务防御中的结构性盲点，促使将成本感知鲁棒性评估作为多模态部署的一等安全需求。

## Abstract
Resource-exhaustion attacks against autoregressive vision-language models (VLMs) typically assume unimodal threat models, treating the image branch as the primary optimization surface while holding user-visible prompts fixed. Even recent loop-centric variants remain confined to this single-channel paradigm, leaving the exploitation of availability unexplored as a cross-modal optimization problem over jointly controllable input surfaces.   We introduce Joint Pixel-Prompt Optimization (JPPO), the first compound adversarial framework elevating the visible prompt to a first-class adversarial variable alongside image perturbations. Under a restricted joint-input threat model, JPPO performs coupled, stagewise optimization over both the pixel and prompt surfaces. This produces synergistic cost amplification, mechanistically distinct from loop-dependent failures, exhibiting negligible loop incidence in our experiments.   Evaluating five open-source VLM families on MS COCO and ImageNet under an 8/255 infinity-norm budget, JPPO achieves over 4.6x latency and 5.3x energy amplification on Qwen2.5-VL-7B, and over 36.6x latency with 32.7x energy amplification on BLIP-2. This represents the strongest cost amplification among directly compared baselines while requiring substantially fewer optimization iterations. Ablations confirm this amplification arises from multimodal coordination rather than prompt length or isolated modalities. These findings reveal structural blind spots in current VLM serving defenses, motivating cost-aware robustness evaluation as a first-class security requirement for multimodal deployments.

- **现有工作的局限**：此前的 VLM 资源耗尽攻击普遍采用**单模态威胁模型**，只把图像分支当作主要优化面，而将用户可见提示固定。即便是近期以"循环诱导"为中心的变体（如 LingoLoop），仍局限于这一单通道范式。
- **核心问题**：能否在**不主要依赖显式重复循环**的前提下，通过**联合优化受限像素扰动与用户可见提示**，实现显著的推理成本放大？作者将可用性利用重新定义为一个**跨模态联合优化问题**。

## 2. 方法论：JPPO 框架

### 2.1 核心思想

- 提出 **JPPO（Joint Pixel-Prompt Optimization）**，是首个将可见提示提升为与图像扰动并列的**一等对抗变量**的复合对抗框架。
- 核心机制是**多模态协同**：像素扰动重塑初始多模态状态，而优化后的可见提示在解码过程中施加"延续压力"。
- 攻击目标不是语义失败（越狱/有害内容），而是**在保持输入合理性的前提下增加单次请求的服务成本**。

### 2.2 威胁模型与约束

- **受限联合输入威胁模型**：攻击者控制用户提供的图像与界面可见提示；不修改模型参数、分词器、隐藏系统指令、解码实现或调度策略，无需特权访问。
- **离线构造 + 部署时提交**：离线阶段使用精确开源模型或本地代理模型，仅在此阶段需要梯度；部署时以黑盒方式提交已构造好的图像-提示对。
- **像素预算**：ℓ∞ 范数约束 ∥δ∥∞ ≤ ε，默认 ε = 8/255。
- **成本度量**：定义成本向量 c(x, p) = (W, τ, Ê)，其中 W 为输出词数、τ 为推理延迟、Ê 为基于 NVML 的能耗估计代理。攻击目标为 max Ê。

### 2.3 两阶段算法流程

**Stage I：多路径上下文预热（Multi-path Contextual Warm-up）**
- 维护三条文本路径记忆：**视觉（S_vis）、空间（S_spa）、语义（S_sem）**。
- 采用确定性调度 `AspectSchedule(k, K)`：视觉、空间、语义分别在 Stage I 的前、中、后三分之一被激活。
- 使用**方面感知合并算子 M(·)**，按动态配额分配词预算，经尾部截断后按固定顺序拼接并追加方面特定提示文本，最终按词级预算 B₁ 截断。
- 在优化前缀上执行可微前向传播，计算可用性损失并更新像素扰动（投影梯度符号法）；随后用当前扰动图像与提示查询目标 VLM，记录真实成本，并将生成结果作为反馈信号通过**选择性累积算子 U(·)**（词级新颖性过滤 + 轻量压缩）更新路径记忆。
- Stage I 运行固定 K 次迭代，无成功阈值或重启规则，最终从缓冲区中选取**估计能耗最大**的配对状态 (δ_warm, p_w)。

**Stage II：联合像素-提示精炼（Joint Pixel-Prompt Refinement）**
- 从 Stage I 最高能耗配对状态初始化，放弃多路径分离，改为**单上下文精炼**。
- 每轮迭代：在前缀上计算 Stage II 损失 → 更新像素扰动 → 生成并测量真实成本 → 通过**单上下文提示精炼算子 R(·)**（沿用选择性累积原则）更新运行提示 p_c，预算为 B₂。
- 最终从两个阶段的缓冲区中选取**实测能耗最强**的配对状态作为最终对抗样本 (x★, p★)。

### 2.4 三个可用性导向目标（损失函数）

- **前缀停止抑制目标 L_eos**：在优化前缀上最小化 EOS 令牌概率，权重从前到后线性衰减（10→2），抑制过早终止倾向。
- **跨模态提示-图像失配目标 L_align**：提取图像序列 V 与提示序列 P，对提示序列做自适应平均池化后计算逐位置余弦相似度均值，作为对齐代理。
- **瓶颈正则化目标 L_bot**：对多模态隐藏序列施加固定随机线性投影的瓶颈正则化（MSE 重构 + 方差惩罚，β=0.1，默认瓶颈比 ρ=0.10）。
- **总目标**：L(s) = λ_eos·L_eos + λ_align·L_align + λ_bot·L_bot。Stage I 权重为 (2.0, 1.0, 1.0)，Stage II 为 (2.0, 3.0, 1.0)。

### 2.5 关键设计选择

- 两阶段分解：广泛上下文探索 → 激进精炼。
- 提示分支**刻意通过攻击者引导的、预算约束的文本空间算子更新**（而非离散令牌梯度优化），以提高现实性与方法稳健性。
- 可微前缀级优化与真实成本评估分离，最终样本选自**实测成本最强状态**。

- **训练时长**：论文未报告模型训练（模型均为冻结的开源权重）；但报告了**攻击构造成本**，例如 JPPO 在 Qwen2.5-VL 上平均构造时间约 3,355 秒、构造能耗约 147 kJ；在 BLIP-2 上约 582 秒、53 kJ（详见 Table 3、Table 11）。
- **外部 API 测试**：Gemini 3.1 Pro Preview 与 Qwen2.5-VL-72B，各 500 对 Clean/JPPO 案例、每案例 3 次配对提交；因服务端资源指标不可得，仅报告输出长度。

## 5. 实验数量与充分性

### 5.1 实验规模

- **主实验**：5 个模型 × 2 个数据集 × 5 个方法（Clean/Noise/NICGSlowDown/Verbose Images/JPPO），共 10 个模型-数据集设置。
- **跨模型迁移**：5×5 源-目标矩阵，40 个数据集特定的非对角方向。
- **消融实验**：
  - 优化空间消融（Pixel-only / Prompt-only / Joint）；
  - 损失组件消融（L_eos / L_align / L_bot 单独与组合）；
  - Stage I 调度（随机 vs 相位式）；
  - Stage II 候选选择策略（top-1/top-3/top-5、随机 vs 全精炼）；
  - 提示长度预算、扰动预算 ε、迭代调度、损失权重、瓶颈比 ρ 的敏感性分析；
  - 解码策略（贪心、top-k、top-p、beam search）；
  - 最大生成长度上限。
- **防御评估**：九种非 EarlyStop 防御 + EarlyStop，共十种。
- **部署评估**：共享工作进程 FIFO 研究、本地 API 四种策略、外部黑盒 API 迁移。
- **输出质量**：GPT-5.5 对 **450,000 个候选输出**进行评分。

### 5.2 充分性与公平性

- **充分性**：实验覆盖模型、数据集、攻击面、防御、部署、迁移、质量等多维度，规模较大且系统。
- **公平性控制**：所有方法使用相同采样图像、模型检查点、硬件、解码上限、采样策略与测量协议；基线按开源实现与原报告超参数复现；显式词预算约束所有涉及提示的方法；迁移实验不使用目标侧梯度或自适应。
- **客观性**：报告了三重复运行、三种子平均、图像级标准差，并明确区分攻击构造成本与在线服务成本。

## 6. 主要结论与发现

- **成本放大显著**：在 ℓ∞ = 8/255 预算下，JPPO 在 Qwen2.5-VL-7B 上实现 >4.6× 延迟与 >5.3× 能耗放大；在 BLIP-2 上实现 >36.6× 延迟与 32.7× 能耗放大。
- **最强直接对比基线**：在直接评估的基线中成本放大最强，且所需优化迭代次数显著更少。
- **多模态协同而非提示长度**：中性长提示控制最多只达到 2.04× 能耗与 2.40× 延迟放大，而 JPPO 最低对应放大为 4.13× 与 4.08×；联合优化超过最强单模态分支 28.7–83.7%。
- **低循环发生率**：JPPO 的放大机制不同于依赖循环的失效，实验中循环发生率极低（多数模型为 0%）。
- **跨模型可迁移**：所有 40 个非对角迁移方向均超过 Clean 基线（1.79×–13.38×），平均保留约 48.7% 能耗增益与 50.7% 延迟增益；外部黑盒 API 迁移有限但非零。
- **防御鲁棒性**：在九种非 EarlyStop 防御下平均退化仅 5.02%，EarlyStop 下仅 3.66%，优于 Verbose Images 和 LingoLoop。
- **输出质量**：相比 Verbose Images，JPPO 输出在相关性、信息性、有用性上更高、冗余更低，表明放大并非仅靠低质量重复输出。

## 7. 优点

- **威胁模型创新**：首次将界面可见提示提升为与像素扰动并列的一等对抗变量，提出受限联合输入威胁模型，区别于固定提示的图像单模态攻击与循环中心攻击。
- **机制清晰**：两阶段设计（广泛探索 → 激进精炼）职责明确，三个可用性导向损失各有侧重，并通过消融验证协同效应。
- **现实性考量**：提示分支采用预算约束的文本空间算子而非离散令牌梯度优化，贴合真实用户界面；离线构造与部署提交分离，明确成本归属。
- **实验全面**：覆盖五模型、两数据集、迁移、消融、防御、部署、质量评判，并报告构建成本与在线服务成本。
- **负责任的披露**：提供开放科学 artifact，明确伦理考量、artifact 防护措施与缓解建议。
- **诊断性分析**：提供循环表征、令牌新颖性、Grad-CAM 证据定位、CLIP 表示相似度等多角度分析。

## 8. 不足与局限

- **白盒依赖**：主要评估在精确模型白盒离线构造下进行，黑盒迁移通常更弱且波动更大；外部 API 评估仅限输出长度，无法估计服务端能耗或硬件成本。
- **能耗代理局限**：NVML 估计能量是软件级代理（平均功率 × 延迟），非硬件级时间积分，绝对值依赖本地硬件与软件栈。
- **威胁模型更宽**：联合输入威胁模型比固定提示的图像单模态设置更宽，与图像单模态攻击的比较应视为互补而非替代。
- **未覆盖场景**：未直接覆盖单模态接口、近似固定成本的非自回归系统，或阻止攻击者控制提示上下文的服务；感知显著性、下游效用、推测解码、请求过滤与生产调度等仍有待研究。
- **外部验证有限**：外部 API 检查为低容量、非并发，未进行厂商披露；黑盒服务可行性依赖代理模型迁移性与平台控制程度。
- **对比范围受限**：主表中"优越性"声明仅限于直接评估的基线；LingoLoop 与 Hidden Tail 因协议差异单独比较，未纳入主表。
- **公平性细节**：JPPO 的候选选择过程属于攻击构造管线的一部分，不应被解读为在线服务时的优势。
