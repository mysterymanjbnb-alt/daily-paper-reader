## 摘要
检索增强生成（RAG）已成为一种强大的范式，通过将回答建立在外部知识之上，提高大型语言模型（LLM）生成内容的质量，从而减少幻觉和事实错误。然而，近期研究揭示了一个关键漏洞：攻击者可以利用检索过程从底层语料库中提取个人可识别信息（PII）。为了缓解这一风险，我们提出了一种新的防御方法 RAG-CT，它通过分析恶意查询的熵和间隔分布，并使用基于分数的检测方法来识别恶意查询。在两个数据集上使用四种最先进的攻击策略和四种防御基线进行的大量实验表明，我们的方法显著减少了 PII 泄露，同时优于现有防御。这项工作提供了一种轻量而有效的机制，无需修改底层 LLM 或检索器即可保护 RAG 系统免受 PII 泄露。

## Abstract
Retrieval-Augmented Generation (RAG) has emerged as a powerful paradigm for improving the quality of generated contents of Large Language Models (LLMs) by grounding responses in external knowledge, thus reducing hallucinations and factual errors. However, recent studies have highlighted a critical vulnerability: adversaries can exploit the retrieval process to extract personally identifiable information (PII) from the underlying corpus. To mitigate this risk, we propose a novel defense, RAG-CT, that identifies malicious queries by analyzing their entropy and margin distributions and using a score-based detection method. Extensive experiments with four state-of-the-art attack strategies and four defense baselines on two datasets show that our approach significantly reduces PII leakage while outperforming existing defenses. This work provides a lightweight yet effective mechanism to protect RAG systems against PII leakage without requiring modifications to the underlying LLM or retriever.

- **背景**：RAG（检索增强生成）通过从外部知识库检索相关内容作为上下文，提升 LLM 输出的准确性与可靠性，已广泛用于客服机器人、医疗、法律咨询、金融分析等场景。

- **整体含义**：论文提出一种**轻量、无需修改底层 LLM 或检索器**的查询级检测防御，在不牺牲正常服务的前提下阻断 PII 泄露路径，对实际部署中的 RAG 系统具有直接的安全价值。

## 2. 方法论

### 2.1 核心直觉

- **良性查询**通常检索到多条语义相关的记录 → 相似度分布**分散**；
- **恶意查询**往往锁定单一敏感记录 → 相似度分布**高度集中**。
- 因此可用两个互补指标刻画：**熵（Entropy，衡量检索分散度）** 与 **间隔（Margin，衡量 top-1 相对 top-2 的决断性）**。低熵 + 大间隔 = 定向抽取信号。

### 2.2 五步检测流程

1. **Top-k 相似度提取**：计算查询嵌入 q 与记录嵌入 rᵢ 的内积相似度 sᵢ = ⟨q, rᵢ⟩，降序排列后保留前 k 个（实验取 k=3）。
2. **Softmax 归一化**：pᵢ = exp(s₍ᵢ₎) / Σⱼ exp(s₍ⱼ₎)，将相似度转为概率分布。
3. **熵（检索分散度）**：H = −Σ pᵢ log pᵢ，并归一化为 Ĥ = H / log k ∈ [0,1]；Ĥ 越低越可疑。
4. **间隔（检索决断性）**：M = s₍₁₎ − s₍₂₎，经 min-max 归一化得到 M̂ ∈ [0,1]；M̂ 越大越可疑。
5. **异常打分与判定**：统一异常分 **A = α·(1 − Ĥ) + β·M̂**，当 A ≥ τ 时判定查询为恶意，返回默认拒答响应（如"我们无法响应此请求"）。

### 2.3 关键特性

- 检测发生在**检索后、生成前**，属于查询层防御，对 LLM 与检索器均为即插即用。
- 单一阈值 τ 控制严格程度，论文默认 τ = 0.5。
- 论文未给出 α、β 的具体取值与调参过程，也未说明 M̂ 的 min-max 归一化是在单次查询的候选集上还是全局统计上完成。

## 6. 主要结论与发现

- 无防御时，四种攻击在 Healthcare 数据集上 ASR 达 0.69–1.00，PII 泄露 73–201 项，隐私风险严重。
- 现有防御效果分化明显：改写与摘要压缩几乎无效；规则过滤对 TGTB 有效但对 Pirate 乏力；erase-and-check 对 TGTB/PIDE 有效，但对查询优化类攻击表现差。
- **RAG-CT 表现最优且最稳定**：
  - 对 TGTB 与 PIDE，**ASR 在所有模型上降至 0.00**，PII 泄露几乎归零（ULC 低至 1–14）；
  - 对 RAG-Thief 与 Pirate，ASR 仍可压至 **0.1 以下**（0.03–0.08）；
  - Email 数据集上呈相同趋势。
- **消融结论**：
  - top-k 增大 → ASR 上升（检索内容越多越易泄露）；
  - 阈值越低 → 过滤越严格、防御越强（默认 0.5）；
  - 熵与间隔**融合**优于任一单指标，验证了核心直觉的有效性。
