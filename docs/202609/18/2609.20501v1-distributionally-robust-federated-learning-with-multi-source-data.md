## 摘要
联邦学习从私有客户端数据中训练一个共享模型。在实际中，数据生成分布可能不同，且跨客户端的真实混合往往未知，使得底层群体分布难以指定。现有方法通过针对最坏情况混合进行优化来处理跨客户端混合不确定性，但假设具有准确的逐客户端分布估计。然而，当这些估计基于有限样本时，可能不可靠。为了同时处理跨客户端混合不确定性和客户端内分布模糊性，我们构造一个全局模糊集，作为局部模糊集的可容许混合的并集。该构造允许客户端特定的模糊半径，并可进行逐客户端可分离的重构。利用这一结构，我们建立了一个高概率的样本外性能保证。我们进一步针对基于惩罚的重构开发了一种联邦算法，并在更温和的正则条件下证明了其收敛性。仿真验证了该算法的有效性。

## Abstract
Federated learning trains a shared model from private client data. In practice, data-generating distributions may differ, and the true mixture across clients is often unknown, making the underlying group distribution difficult to specify. Existing approaches address cross-client mixture uncertainty by optimizing against the worst-case mixture, yet assume accurate client-wise distribution estimates. However, these estimates can be unreliable when based on finite samples. To handle both cross-client mixture uncertainty and within-client distributional ambiguity, we construct a global ambiguity set as the union of admissible mixtures of local ambiguity sets. The construction allows client-specific ambiguity radii and admits a client-wise separable reformulation. Leveraging this structure, we establish a high-probability out-of-sample performance guarantee. We further develop a federated algorithm for a penalty-based reformulation and prove its convergence under milder regularity conditions. Simulations validate the algorithm's effectiveness.

## 1. 核心问题与整体含义

- **研究背景**：联邦学习（FL）中，中央服务器协调多个客户端共同训练共享模型，同时保护数据隐私，已广泛应用于移动设备与医疗网络。但实际场景中，各客户端因测量条件不同导致本地数据生成分布高度异构。
- **两类不确定性**：
  - **跨客户端混合不确定性**：真实全局分布被假设为客户端本地分布的混合，但混合权重 α⋆ 未知，且往往不等于经验样本比例 Ni/N。
  - **客户端内分布模糊性**：本地样本量有限，经验分布 bPi 未必能准确代表真实本地分布 Pi。
- **现有方法局限**：
  - FedAvg 按样本量加权，易产生有偏模型；AFL、Group DRO 优化最坏混合，但**假设本地分布估计准确**，在有限样本下脆弱。
  - 基于 Wasserstein 重心或单一混合中心的全局模糊集，以及非平衡 Wasserstein 变体，会将局部不确定性**耦合**在一起，模糊了与本地分布的关系，阻碍显式的样本外性能分析。
  - 混合 Wasserstein 球方法虽保留局部结构，但**限定固定混合权重**，无法处理跨客户端混合不确定性。
- **整体含义**：本文旨在同时处理上述两类不确定性，构建一个能保留局部结构、支持客户端特定模糊半径、且便于联邦求解与理论分析的统一分布鲁棒优化（DRO）框架。

## 2. 方法论

### 2.1 核心思想
- 构造**全局模糊集**为局部模糊集的可容许混合之并集，既覆盖客户端内部分布扰动，又覆盖混合权重的不确定性。

### 2.2 关键技术细节

- **局部模糊集**：对每个客户端 i，定义以经验分布 bPi 为中心的 p-Wasserstein 球
  - Wi(εi) = { Q ∈ M(Ξ) : Wp(Q, bPi) ≤ εi }
  - εi ≥ 0 为客户端特定的模糊半径，允许不同客户端具有不同的不确定程度。
- **混合结构**：对固定权重 α ∈ Δn−1，定义混合模糊集
  - WM(α) = { Q = Σ αi Qi : Qi ∈ Wi(εi), ∀i }
- **全局模糊集**（并集形式）：
  - WG = ∪_{α∈Δn−1} WM(α) = { Σ αi Qi : α ∈ Δn−1, Qi ∈ Wi(εi) }
  - 该构造同时捕捉局部估计不确定性与客户端比例不确定性（见图 1 示意，n=6）。
- **MW-DRO 问题**：
  - inf_{x∈X} sup_{Q∈WG} EQ[ℓ(x, ξ)]
  - 目标：寻找对两类不确定性均鲁棒的决策 x。
- **可分离重构（Lemma 4）**：利用并集与混合结构，将全局最坏期望分解为逐客户端可分离形式
  - inf_x sup_α Σ_i αi sup_{Qi∈Wi(εi)} EQi[ℓ(x, ξ)]
  - 该等价性使问题天然适配联邦架构。
- **覆盖保证（Proposition 2）**：在**有界异质性假设**（Assumption 1：∀i,j, Wp(Pi, Pj) ≤ δ）下，通过两种充分条件取较紧者：
  - **条件一（同时局部覆盖）**：所有局部球同时包含各自真实分布，概率下界为 Π(1−βi)。
  - **条件二（单一球覆盖全部）**：若 δ 较小，一个局部球可覆盖所有真实分布，概率下界为 1 − Πβ̄i。
  - 最终 Pr{P ∈ WG} ≥ 1 − β，其中 (1−β) = max{Π(1−βi), 1 − Πβ̄i}。
- **样本外性能界（Theorem 5）**：在 ℓ(x,·) 为 Lξ-Lipschitz 条件下，以至少 Π(1−βi) 的概率有
  - bJ⋆ − Lξ(2r + δ) ≤ J ≤ bJ⋆，其中 r = max_i εi。
  - 性能缺口分解为**采样误差项**（2Lξ r）与**异质性/权重偏差项**（Lξ δ），前者随样本增加而减小，后者由分布异构性决定。
- **惩罚重构（Proposition 6）**：将硬 Wasserstein 球约束替换为惩罚项，得到有限维等价形式
  - inf_x sup_α Σ_i αi E_{ζ∼bPi}[ sup_{ξ∈Ξ} ( ℓ(x, ξ) − ρi c(ζ, ξ) ) ]
  - 其中 ρi > 0 为客户端特定鲁棒性惩罚系数，c(ζ, ξ) = ‖ζ−ξ‖² 为传输代价。
- **BiDRO-FL 算法（Algorithm 1）**：
  - 每轮服务器广播 (xt, αt)。
  - 客户端采样 bζi,t，求解内层 ϵ-近似最大化问题得 zi,t，构造梯度估计 gxi,t = ∇xℓ(xt, zi,t)、gαi,t = ℓ(xt, zi,t) − ρi c(bζi,t, zi,t)。
  - 客户端本地更新 xi,t+1 = xt − ηx gxi,t，并回传 xi,t+1 与 gαi,t。
  - 服务器聚合 xt+1 = Proj_X(Σ αi,t xi,t+1)，并更新 αt+1 = Proj_Δ(αt + ηα gαt)。
- **收敛性（Theorem 7）**：在 Assumption 2（可微、凸性、有界梯度、Lipschitz 等温和正则条件）下，取 ηx = ηα = 1/√T，有
  - E[ sup_α F(x̄T, α) − inf_x sup_α F(x, α) ] = O(T^{−1/2} + ϵ)。
