## 摘要
我们提出个性化联邦分层高斯过程（pFedHGP），用于数据分布于异构客户端时的概率回归与分类。每个客户端的潜在函数分解为：(i) 共享全局成分；(ii) 共享全局核结构的客户端特定偏差；(iii) 灵活的局部残差。稀疏诱导变量近似与联邦变分推断使原始数据保留在本地，而服务器仅同步共享成分的低维统计量。完整的预测分布支持不确定性感知决策。在应用研究中，pFedHGP 在压机吨位监测中使用 13.77% 的带标签周期实现了完美的故障分类，并在联邦空气质量建模中恢复了地理区域，而无需集中站点级时间序列。瞬时线性混合模型视角将该层次结构与用于相关传感器的多输出高斯过程联系起来。

## Abstract
We present Personalized Federated Hierarchical Gaussian Processes (pFedHGP) for probabilistic regression and classification when data are distributed across heterogeneous clients. Each client's latent function decomposes into (i) a shared global component, (ii) a client-specific deviation that shares the global kernel structure, and (iii) a flexible local residual. Sparse inducing-variable approximations and federated variational inference keep raw data local while the server synchronizes only low-dimensional statistics for the shared component. Full predictive distributions support uncertainty-aware decisions. In application studies, pFedHGP attains perfect fault classification in press tonnage monitoring using 13.77% of labeled cycles and recovers geographic zones in federated air-quality modeling without centralizing station-level time series. An Instantaneous Linear Mixing Model viewpoint links the hierarchy to multi-output Gaussian processes for correlated sensors.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：物联网、工业监测、智慧城市等场景中，数据天然分布在异构的边缘设备或机构中（如不同工厂、监测站），受隐私、数据治理和通信带宽限制，原始数据难以集中。联邦学习因此成为主流范式。
- **核心矛盾**：联邦场景下客户端数据通常**非独立同分布（non-i.i.d.）**，物理系统因运行条件、设备差异、环境因素等表现出站点特异性行为。单一全局模型无法捕捉这种异质性，导致预测质量下降和不确定性校准不佳。
- **现有方法不足**：
  - 分布式 GP 方法侧重可扩展性，但假设数据 i.i.d. 或人为划分，缺乏对异质性的建模，且需交换梯度/统计量，存在隐私风险。
  - 联邦 GP 方法（如 FedBNR、BNFed、pFedGP）虽保护隐私，但多强制使用**单一全局模型**，难以应对客户端显著统计异质性；pFedGP 还存在客户端计算负担高（O(N³)）和通信开销大的问题。
  - 非 GP 个性化方法（PerPCA、perTucker）虽能分解共享/个性化特征，但缺乏内置的不确定性量化能力。
- **整体含义**：论文旨在构建一个**兼具隐私保护、个性化建模与完整不确定性量化**的联邦概率框架，在保留原始数据本地性的同时，显式分离共享全局结构、客户端系统性偏差与局部残差，支持风险感知决策。

## 2. 方法论

### 核心思想

- 提出 **pFedHGP**（Personalized Federated Hierarchical Gaussian Processes），将每个客户端的潜在函数分解为三层：
  1. **共享全局成分** \( f_g \)：捕捉群体级共性结构；
  2. **客户端特定偏差** \( f_{\delta,i} \)：共享全局核结构（\( k_\delta = \phi k_g \)），表示系统性校准偏移；
  3. **灵活局部残差** \( f_i \)：使用客户端独立核 \( k_i \) 和诱导点 \( Z_i \)，吸收特异性短尺度变化。
- 观测模型：\( y_{i,j} = f_g(x_{i,j}) + f_{\delta,i}(x_{i,j}) + f_i(x_{i,j}) + \varepsilon_{i,j} \)，噪声 \( \varepsilon \sim \mathcal{N}(0,\sigma^2) \)。

### 关键技术细节

- **稀疏诱导变量近似**：为每个 GP 成分引入诱导变量 \( u_g, \delta_i, u_i \)，将计算复杂度从 O(N³) 降至与诱导点数 M 相关。条件均值呈低秩基展开：
  \[
  \mathbb{E}[f_i^{tot} \mid u_g,\delta_i,u_i] = A_{g,i}(u_g+\delta_i) + A_i u_i
  \]
  其中 \( A_{g,i} = K_g(X_i,Z_g)K_{gg}^{-1} \)，\( A_i = K_i(X_i,Z_i)K_{ii}^{-1} \)。
- **与 perPCA 的联系**：该结构与个性化 PCA 的共享/独特低秩分解类似，但使用核诱导的非线性基、提供完整概率建模与不确定性量化。
- **变分稀疏 GP 框架（VFE）**：采用 Titsias 的变分自由能方法，避免 FITC 的对角近似假设，仅依赖残差协方差的**对角元素（迹）**，保持计算效率。
- **均值场变分推断**：假设 \( q(u_g,\{\delta_i\},\{u_i\}) = q(u_g)\prod_i q(\delta_i)q(u_i) \)，各因子为高斯分布。
- **ELBO 显式分解（Theorem 1）**：
  \[
  \mathcal{L} = \sum_i \Big[ -\frac{n_i}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\|y_i-\mu_{f_i}\|^2 - \frac{1}{2\sigma^2}\big(\text{Tr}(A_{g,i}S_gA_{g,i}^\top) + \text{Tr}(A_{\delta,i}S_{\delta_i}A_{\delta,i}^\top) + \text{Tr}(A_iS_{u_i}A_i^\top) + \text{Tr}(R_i)\big)\Big] - \text{KL}(q(u_g)\|p(u_g)) - \sum_i \text{KL}(q(\delta_i)\|p(\delta_i)) - \sum_i \text{KL}(q(u_i)\|p(u_i))
  \]
  其中预测均值分解为全局、偏差、局部三部分，残差迹 \( \text{Tr}(R_i) \) 也可加性分解。
- **联邦变分推断算法（Algorithm 1）**：同步通信轮次，客户端本地优化局部 ELBO 块（固定全局参数），计算并上传全局梯度摘要 \( \tilde{S}_i \)（包含偏差 KL 贡献），服务器聚合并更新全局参数块（含 \( \phi = \text{softplus}(\eta_\phi) \)、\( Z_g \)、\( m_g, S_g \)、核超参数），再广播。原始数据和局部变分参数始终保留在客户端。
- **实现细节**：Cholesky 分解保证数值稳定；白化变分参数化；正超参数用 softplus 变换；诱导点位置与核超参数通过自动微分联合优化；VFE 风格对角计算。
- **分类与聚类扩展**：
  - 分类：用高斯预测对数似然 \( \ell_i(X^\star,y^\star) \) 作为模型证据，取最大似然客户端作为预测标签。
  - 聚类：构造客户端在诱导特征空间的投影算子 \( \hat{A}_i \)，用 Frobenius 距离衡量相似性，输入谱聚类，无需暴露原始数据。
- **ILMM 视角**：将分层模型重写为瞬时线性混合模型，\( f^{tot}(x) = H\chi(x) \)，\( H=[\mathbf{1}_T\ I_T\ I_T] \)，可扩展到多传感器向量输出，加载矩阵 \( B_g, B_{\delta,i}, B_{l,i} \) 映射潜在因子到 Q 个传感器通道。

## 6. 主要结论与发现

- **完整层次结构最优**：在匹配场景中，Full pFedHGP 在 RMSE、NLL、CRPS、CovErr、区间锐度上均取得最佳综合表现；去除偏差或局部成分均导致性能下降，验证了三层分解的必要性。
- **鲁棒性**：在核不匹配、非加性、成分相关等假设违背场景中，Full pFedHGP 仍保持最佳或接近最佳；失配的代价主要体现在**表示效率**上——NLL 变差、区间变宽，但 RMSE 未必崩溃，因为 RBF 核的通用性仍可逼近可观测预测分布。
- **不确定性校准**：所有方法覆盖率接近名义水平，但完整模型在**覆盖率-锐度权衡**上更优，能以更窄的区间达到相近校准。
- **应用成果**：
  - 压机吨位监测：仅用 13.77% 标注数据实现 **100% 故障分类准确率**，优于 perTucker（15.49% 数据）及传统集中式方法（75–90% 数据）。
  - 空气质量：无需集中站点级时序，成功恢复北京三个地理分区（城区、西部郊区、东部郊区），与真实地理分布一致。

## 8. 不足与局限

- **隐私保证有限**：论文明确声明“privacy-preserving”仅指数据本地性，**不提供形式化差分隐私或安全聚合保证**，模型更新仍存在泄露风险。
- **鲁棒性问题**：未处理恶意或损坏客户端的鲁棒聚合，联邦场景下的对抗攻击风险未涉及。
- **可识别性限制**：由于 \( k_\delta = \phi k_g \)，单客户端边际过程无法唯一识别 \( f_g \) 与 \( f_{\delta,i} \) 的分解；在客户端数量少、样本量高度不平衡或异质性弱时，层次归因可能不稳定。论文将其定位为“ELBO 正则化归因”而非经典点识别。
- **核与诱导预算依赖**：性能受核选择和诱导点数量影响；核过于受限会欠拟合系统性偏差，局部核过于灵活会吸收共享结构。通信成本随诱导变量和输出因子数增长，自适应预算选择未解决。
- **实验覆盖偏差**：
  - 压机案例的对比方法来自不同已发表研究，训练百分比和评价协议不完全一致，公平性受限。
  - 空气质量案例缺乏定量基线对比和正式的校准分析。
  - 真实案例的客户端划分（如按故障类别划分）与实际分布式部署（不同工厂/机构）存在差距。
- **未来方向**：作者提出需研究差分隐私更新、在线更新、对抗鲁棒聚合、可扩展诱导预算选择，以及层次归因稳定性的理论条件。
