## 摘要
大语言模型（LLM）智能体已在多个领域展现出令人印象深刻的能力，尤其是在与外部工具集成以完成多步任务时。然而，它们日益容易受到对抗攻击的影响，包括直接提示注入、间接提示注入、记忆污染和后门攻击，这些攻击利用了模型对提示注入和工具操纵的开放性。在本工作中，我们在一个统一框架内探索针对这四类攻击的实用且可泛化的防御策略。我们引入两种通用的基于工具的防御：攻击者工具过滤（Attacker Tool Filtering），使用异常检测（如孤立森林）来识别并移除可疑工具；以及正常工具召回（Normal Tool Recalling），一种白盒方法，在规划前恢复智能体原始工具集。此外，我们纳入基于提示的防御：思维链提示（Chain-of-Thought prompting）与自我反思技术以增强推理，以及任务复述以缓解攻击。在四个开源LLM（Gemma2-9B、Qwen2-7B、LLaMA3-8B和LLaMA3.1-8B）和三个专有LLM（GPT-3.5、GPT-4和GPT-5）上的实验结果表明，我们的方法显著降低了攻击成功率（ASR），在许多设置中达到0% ASR，同时保持甚至提升原始任务成功率。这些发现凸显了简单、模块化、多层防御在增强工具集成LLM智能体安全性和鲁棒性方面的前景。代码见 https://github.com/Xiaoyan-Lisa/Defenses-for-Tool-Integrated-LLM-Agents-Against-Adversarial-Attacks。

## Abstract
Large Language Model (LLM) agents have demonstrated impressive capabilities across a variety of domains, particularly when integrated with external tools for multi-step task completion. However, they are increasingly vulnerable to adversarial attacks, including direct prompt injection, indirect prompt injection, memory poisoning, and backdoor attacks, which exploit the model's openness to prompt injection and tool manipulation. In this work, we explore practical and generalizable defense strategies within a unified framework across these four attack types. We introduce two universal tool-based defenses: Attacker Tool Filtering, which uses anomaly detection (e.g., Isolation Forest) to identify and remove suspicious tools, and Normal Tool Recalling, a white-box method that restores the agent's original toolset prior to planning. Additionally, we incorporate prompt-based defenses: Chain-of-Thought prompting and self-reflection techniques to enhance reasoning and task paraphrasing to mitigate attacks. Experimental results across both four open-source LLMs (Gemma2-9B, Qwen2-7B, LLaMA3-8B, and LLaMA3.1-8B) and three proprietary LLMs (GPT-3.5, GPT-4, and GPT-5) show that our methods significantly reduce the Attack Success Rates (ASR), achieving 0% ASR in many settings, while preserving or even improving the original task success rate. These findings highlight the promise of simple, modular, multi-layered defenses for strengthening the security and robustness of tool-integrated LLM agents. The code is available at https://github.com/Xiaoyan-Lisa/Defenses-for-Tool-Integrated-LLM-Agents-Against-Adversarial-Attacks.

## 1. 核心问题与整体含义
- **研究动机**：LLM 智能体越来越多地集成外部工具（API、数据库、搜索引擎、代码执行环境等）来完成多步任务，但工具接口也扩大了攻击面。攻击者可利用提示注入与工具操纵，造成未授权数据访问、有害命令执行、与外部系统错误交互等不可逆后果。
- **核心问题**：现有防御多针对单一攻击类型，以黑盒提示修改为主，较少利用白盒信息，也较少直接保护“工具调用完整性”；同时不少防御会损害智能体完成原始任务的能力。
- **整体含义**：论文提出一个统一、轻量、模块化的多层防御框架，同时覆盖四类主要攻击：直接提示注入（DPI）、间接提示注入（IPI）、记忆污染（MP）和后门攻击，目标是在降低攻击成功率（ASR）的同时保持甚至提升原始任务成功率（OTSR）。

## 2. 方法论
- **核心思想**：将**工具层防御**与**提示层防御**结合，形成三层防护：
  - **外层**：在用户输入后、规划生成前，使用思维链（CoT）提示与复述净化，针对 DPI 与后门攻击。
  - **中层**：在工具调用前检查工具描述，过滤或阻断不安全工具。
  - **内层**：在执行前用自我反思提示验证计划正确性。
- **工具层防御 1：攻击者工具过滤（ATF）**
  - 假设攻击者注入的工具在语义上通常不同于原始用户工具。
  - 对每个工具描述 \(\tau_i\) 做嵌入 \(\phi(\tau_i)\)，得到嵌入集合 \(E=\{\phi(\tau_i)\}\)。
  - 在 \(E\) 上训练 Isolation Forest，污染率参数为 \(\epsilon\)。
  - 若工具被判定为异常值则 \(y_i=1\)，否则 \(y_i=0\)；最终过滤工具集为 \(T_{\text{filtered}}=\{\tau_i \mid y_i=0\}\)。
  - 智能体仅基于过滤后的工具集进行规划，属于无监督、低开销的异常检测式防御。
- **工具层防御 2：正常工具召回（NTR）**
  - 白盒防御，假设用户在攻击前提供的原始工具集 \(T_{\text{user}}\) 已被安全保存。
  - 在规划开始前，将当前可见工具集 \(T_{\text{current}}\) 覆盖为 \(T_{\text{user}}\)，即 \(T_{\text{effective}} \leftarrow T_{\text{user}}\)。
  - 规划形式为 \(P = \text{LLM}(p_{\text{sys}}, q, O, T_{\text{effective}})\)，其中 \(q\) 为用户指令，\(O\) 为先前观察。
  - 不需要检测或识别恶意工具，而是直接强制工具集完整性，因而在可访问可信工具配置时非常有效。
- **提示层防御**
  - **CoT 提示**：要求智能体以结构化 JSON 格式生成逐步计划，并只使用预定义安全工具，促进审慎规划与工具选择。
  - **复述净化**：使用 GPT-4o-mini 重写用户任务，在保留原语义的同时显式引用良性工具，破坏注入指令、伪造响应、隐藏触发词等对抗结构。
  - **自我反思**：受 Reflexion 启发，让 LLM 同时扮演反思模块与评估者，在无需外部反馈的情况下迭代修正计划。

## 3. 实验设计
- **Benchmark**：使用 ASB（Agent Security Bench）框架，该基准覆盖 DPI、IPI、MP 与后门四类攻击。
- **数据集/场景**：ASB 包含 10 个领域特定 LLM 智能体，每个智能体含 400 个任务，其中包括 200 个 aggressive 与 200 个 non-aggressive 攻击样本；智能体同时具有正常工具与攻击者工具。
- **攻击类型与变体**
  - DPI / IPI：Naive Attack、Escape Characters、Context Ignoring、Fake Completion。
  - MP：Fake Completion + Context Ignoring 组合策略。
  - 后门：Plan-of-Thought（PoT）后门，触发器分为非词触发器（如 “@_@”）与短语触发器（如 “with perspicacious discernment”）。

  - 开源：Gemma2-9B
