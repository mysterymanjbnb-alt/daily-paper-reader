## 摘要
大语言模型（LLM）的部署期安全方法主要是监督式的，并假定能够获取不安全训练数据。然而，新的攻击和危害类别不断出现，而以这种监督方式训练的模型无法捕捉到它们。另一种方法是从异常检测的角度看待该问题，即仅依赖对安全数据建模，并标记分布外输入。然而，LLM 激活位于高维空间，这引发了异常检测在统计上是否可行的担忧。我们表明，在线性表示假设（LRH）下，确实仍有可能。在通常通过稀疏自编码器（SAE）恢复的 LRH 概念空间中，邻近点共享一个较小的共同活跃支撑集。利用这一局部稀疏性洞见，我们提出了一个基于局部掩码 SAE 的异常检测框架，并给出了理论依据。我们在多种架构和数据集上验证了该框架，包括能力测试数据集和安全专用数据集。最后，当我们允许算法使用 1% 的分布外数据进行校准时，局部稀疏方法达到了接近最优的性能，表明其能够捕捉有意义的安全信息，同时仅使用 1–2% 的 SAE 神经元进行计算。

## Abstract
Deployment-time safety methods for large language models (LLMs) are predominantly supervised and assume access to unsafe training data. Nevertheless, new attacks and harm categories regularly arise, not captured by models trained in such a supervised fashion. An alternative approach is to view this problem through the lens of anomaly detection, namely, to rely solely on modeling safe data and flagging out-of-distribution inputs. However, LLM activations lie in a high-dimensional space, raising concerns about whether anomaly detection is statistically feasible. We show that, under the linear representation hypothesis (LRH), there may indeed be hope. In the LRH concept space, which is typically recovered via a sparse autoencoder (SAE), nearby points share a small common active support. Using this local sparsity insight, we propose a framework for locally masked SAE-based anomaly detection, supported by theoretical justifications. We validate it on various architectures and datasets, including both capability-testing datasets and safety-specific datasets. Finally, when we allow algorithms to use 1% out-of-distribution data for calibration, locally sparse methods achieve near-optimal performance, demonstrating their ability to capture meaningful safety information while using only 1-2% of SAE neurons for computation.

## 1. 核心问题与整体含义

- **研究动机**：部署期的 LLM 安全方法（安全分类器、内容过滤、表示干预等）绝大多数是**监督式**的，隐含假设能够获取带标签的不安全数据，并假设部署时的不安全分布与训练时一致。
- **现实困境**：新的越狱攻击、新的危害类别、未见领域的输入会持续出现，固定不安全分布上拟合的监督模型泛化能力差，且标签覆盖往往不完整。
- **替代思路**：将安全问题重新表述为**异常检测（one-class / anomaly detection）**——只对安全数据分布 $P_0$ 建模，构造打分函数 $s(x)$，对在该分布下不典型的输入给出高分，从而不偏向任何特定危害类别。
- **核心障碍**：LLM 激活位于极高维空间（残差流 $d_1$ 数千，SAE 概念空间 $d_2=16384$），经典无监督异常检测在高维下通常失效。
- **论文主张**：在**线性表示假设（LRH）**下仍有希望。SAE 恢复的概念空间中，**近邻点共享一个较小的共同活跃支撑集（局部稀疏性）**，因此异常检测的有效维度是 $s_{loc}$ 而非 $d_2$。作者据此提出局部掩码 SAE 异常检测框架，并给出理论依据。

## 2. 方法论

### 2.1 核心思想
- 局部稀疏性（式 3）：存在不太小的半径 $r_0$，使邻域内活跃支撑的并集 $s_{loc} \ll d_2$。这使数据落在含"稀疏补丁"的流形上。
- 关键结论：**结构是局部的**，相关低维子空间随邻域变化。施加单一全局压缩表示的方法（标准自编码器、Deep SVDD、CVDD）显著欠佳。

### 2.2 四阶段框架（可模块化选择的设计空间）
1. **嵌入空间**：将稠密残差流激活 $a^{(\ell)}(x)\in\mathbb{R}^{d_1}$ 经 SAE 提升为稀疏表示 $z(x)=E(a^{(\ell)}(x))\in\mathbb{R}^{d_2}$，$d_2\gg d_1$，平均稀疏度 $s\ll d_2$。代价是依赖预训练 SAE 质量。
2. **聚类**：在嵌入空间用 K-means 划分安全数据为 $\{C_1,\dots,C_{N_c}\}$，以恢复满足局部稀疏的邻域。
   - 度量 $\rho$ 三选一：$\rho_{L_0}$（汉明距离，只看活跃支撑）、$\rho_{L_1}$、$\rho_{L_2}$（幅度感知）。
   - 簇数 $N_c$ 权衡簇内同质性与每簇样本量：太少则簇内支撑并集变大，太多则每簇样本不足、参数估计病态。
3. **局部稀疏子空间**：为每簇确定二值掩码 $m_c\in\{0,1\}^{d_2}$，通过 Hadamard 积 $m_c\odot z(x)$ 投影。
   - **频率掩码**：按特征激活频率取 top-$k$；可分全局掩码（$I=\mathcal{D}$）与逐簇掩码（$I=C_c$）。
   - **逐簇学习子空间**：在冻结 SAE 上加逐簇低秩适配器 $E_c=E+\Delta E_c$、$D_c=D+\Delta D_c$（rank $\le r$），与掩码联合优化（直接全量微调会提高重构损失与特征密度，故用 LoRA 约束）。
4. **评分规则**：
   - 掩码 SAE 特征空间中的质心距离（$\ell_1$ 或 $\ell_2$，必要时 Mahalanobis 变体）；
   - 簇内局部编解码器下的**重构残差**。
   - **逐簇校准**（可选）：观察到不安全样本高度集中在少数簇、良性 OOD 集中在另一些簇，可用 <1% 标注数据对每簇做仿射校准 $g(x)=a_{c(x)}s(x)+b_{c(x)}$，以全局阈值为收缩目标。

### 2.3 两个具体实例
- **FreqMask-KM**（算法 1）：无逐簇训练参数。SAE 特征 → K-means（Lloyd + FAISS 默认）→ 全局 top-$k$ 频率掩码 → 测试时最近质心分配 → 打分 $s(x)=\|m\odot z-m\odot\mu_{c^\star}\|_1$。
- **LearnedMask-LoRA**（算法 2）：两阶段。阶段 1 逐簇学习二值掩码（直通估计器，$\lambda\|m\|_1$ 稀疏惩罚）；阶段 2 逐簇拟合 LoRA 适配器；打分用适配编解码器的重构残差 $s_{rec}(x)=\|a^{(\ell)}(x)-D_{c^\star}(m_{c^\star}\odot E_{c^\star}(a^{(\ell)}(x)))\|_2$。

### 2.4 理论依据（第 6 节）
- **定理 1**：在 Assumption 1（掩码簇内协方差有界）与 Assumption 2（频率间隔 $\gamma>0$ 与反集中条件）下，给出总体检测器与经验检测器决策不一致概率的上界：
  $$P_0(\hat f_{n,q}\ne f^\star_q\mid \mathcal{D}_n)\le \eta_{0,n}+L_0\varepsilon_n$$
  其中 $\varepsilon_n=\rho_n+\sqrt{\tfrac{2s_{\max}}{n\pi_{\min}}}\big(v+B\sqrt{2\log(4K/\delta)}\big)$。
- **意义**：样本复杂度**仅对数依赖**概念空间维度 $d_2$ 与环境维度 $d_1$，**线性依赖局部稀疏度** $s_{\max}$；若 $K,s_{\max}\lesssim s_{loc}$，采样项约为 $\tilde{O}(s_{loc}/\sqrt n)$。掩码恢复对数依赖 $d_2$。
- 理论**不**分析 SAE 训练本身，也不消除 $\rho_n$（聚类质心误差）与 $\eta_{0,n}$（分配误差）中的维度依赖。

  - **较充分**：跨 6 个模型家族、3 类不安全数据、多组消融、含理论验证维度指标；给出无掩码的最佳情形对照、无掩码重扫 $N_c$，避免"用对掩码有利的簇数贬低基线"；监督探针明确标注为上界而非竞争者。
  - **公平性**：基线超参逐模型扫描（表 9–14），方法间共享聚类与评分流程；报告 5 种子均值与标准差。
  - **偏弱处**：消融部分多为**单种子**（作者解释 FreqMask-KM 的随机性仅来自 K-means 初始化，但 LearnedMask-LoRA 的消融也多为单种子）；簇数/掩码大小等超参按模型分别选取，存在一定选择偏差；未与更多近期无监督安全检测方法（如基于 intrinsic dimension、语义熵的安全迁移方法）直接比较。

## 6. 主要结论与发现

- **无监督异常检测在 LLM 激活上可行**：局部稀疏实例在 4/5 个 ≥8B 模型上为最佳无监督方法（FreqMask-KM：Ministral 0.914、LLaMA3 0.937、Qwen3 0.915、GPT-oss 0.900；LearnedMask-LoRA：0.896/0.912/0.917/0.919/0.904），其余情形也多在 0.025 AUROC 内次优。
- **表示空间贡献大**：仅把 CVDD 从原始激活换到 SAE 空间，均值 AUROC 从 0.692 升至 0.806；再加稀疏局部子空间升至 0.904–0.909，与全局密度基线（Mahalanobis 0.893、GMM 0.903）相当甚至更高，但有效维度低得多。
- **掩码对大模型是必要的**：相比无掩码最佳情形，GPT-oss 20B +0.119、Gemma 4 26B +0.090，小模型几乎无差（Ministral +0.010，LLaMA3/Qwen3 持平）。模型越大概念越密，局部子空间越难从稠密 SAE 表示中恢复。
- **局部有效维度确实很低**：逐簇 $d_{90}$ 中位数仅 17.5（GPT-OSS）、20（Qwen3）、22（LLaMA3）、36（Qwen2-1.5B）、40.5（Ministral），远低于 $d_2=16384$ 与原始 SAE 空间的 43–126。
- **判别信号在幅度而非支撑**：簇内安全与不安全点的活跃支撑 Jaccard 中位数 ≥0.94（Qwen3 达 0.98），故 $\ell_1/\ell_2$ 幅度感知评分优于二值化评分。
- **1% 校准即可接近最优**：AUROC 从 0.265–0.750 提升至 0.962–0.990（FreqMask-KM）与

LearnedMask-LoRA（0.958–0.986）；且良性 OOD 误报率保持在较低水平，说明逐簇仿射校准主要是修正了簇间分数量纲差异，而非引入对不安全分布的过拟合。

- **判别信息来自幅度而非活跃支撑**：这一发现与"局部稀疏"的直觉形成有趣互补——邻域内安全与不安全样本几乎共享同一支撑集（Jaccard ≥ 0.94），因此掩码的作用是**限定比较范围**（在哪一组概念上比较），而真正区分正负样本的是这些概念上的**激活幅度**。这也解释了为何 $\ell_1$/$\ell_2$ 评分优于二值化或纯支撑重叠评分。

- **对自适应攻击的鲁棒性有限但优于稠密基线**：在 50 个 AdvBench 行为的白盒自适应攻击下，局部稀疏方法的检测性能下降，但仍优于同设置下的全局密度基线，说明局部子空间结构提供了一定程度的攻击难度，但并非对抗鲁棒性保证。

- **超参敏感性可控**：聚类度量 $\rho$、簇数 $N_c$、掩码大小 $k$、SAE 稀疏惩罚等消融表明，性能对 $k$ 与 $N_c$ 存在中等敏感性，存在可辨识的合理区间；对 $\rho$ 的选择相对不敏感（$L_0$ 与 $L_1$/$L_2$ 差异不大），但幅度感知评分始终占优。

- **提取层影响**：中后层激活在多数模型上给出最佳检测性能，与"危害相关语义在中后层更线性可分"的既有观察一致；过早层激活概念稀疏度不足，过晚层则受 next-token 预测噪声干扰。

## 7. 局限与注意事项

- **依赖预训练 SAE 的质量与可得性**：整个框架建立在能获得高质量 SAE 的基础上。若目标模型缺乏公开 SAE，或 SAE 未充分恢复可解释概念，局部稀疏假设可能不成立，方法退化。
- **理论假设较强**：定理 1 依赖掩码簇内协方差有界、频率间隔 $\gamma>0$ 与反集中条件，这些条件在真实激活上未必严格满足；理论也未覆盖 SAE 训练误差、聚类质心误差 $\rho_n$ 与分配误差 $\eta_{0,n}$ 中的维度依赖。
- **校准实验使用了少量标签**：虽然仅需 <1%–1% 标注数据，但"无监督"的宣称在部署时需配合少量标注才能达到报告的最优水平；纯无监督条件下的 AUROC 明显低于校准后。
- **消融多为单种子**：LearnedMask-LoRA 相关消融与部分掩码实验为单种子，统计显著性弱于主实验；簇数/掩码大小按模型分别选取，存在选择偏差风险。
- **对比方法范围有限**：未与基于 intrinsic dimension、语义熵、表示漂移等更新的无监督/半监督安全检测方法直接比较；监督探针虽标注为上界，但其训练数据与不安全评测集可能同源，需谨慎解读差距。
- **算力报告不完整**：仅给出单作业单卡口径与单次运行墙钟时间，未报告总 GPU 小时数、总作业数、能耗等，难以完整评估方法的总成本与可复现性。
- **攻击评估规模较小**：自适应攻击仅在 50 个行为上进行，且未覆盖针对掩码/聚类流程的定向攻击（如刻意落入某簇中心的对抗样本）。

## 8. 总体评价与启示

- **贡献定位**：论文的核心贡献不在于提出一个全新的异常检测算法，而在于**诊断了 LLM 激活上做无监督安全检测的关键结构**——局部稀疏性——并据此设计了一个模块化框架（嵌入 / 聚类 / 局部稀疏子空间 / 评分四阶段），同时给出理论上的样本复杂度依据。
- **实践价值**：FreqMask-KM 作为"无训练参数、约 10 分钟单卡"的实例，在 4/5 个 ≥8B 模型上达到最佳无监督性能，具备较强的部署可行性；LearnedMask-LoRA 以约 60 分钟单卡代价换取小幅但一致的提升，适合算力更充裕的场景。
- **方法论启示**：
  1. **表示空间的选择可能比算法本身更重要**——同一 CVDD 从原始激活换到 SAE 空间即带来 ~0.11 AUROC 提升；
  2. **"在哪里比较"与"如何比较"应解耦**——掩码负责限定比较范围，幅度评分负责判别；
  3. **局部结构随模型规模变化**——模型越大概念越密，掩码的必要性越强，这提示未来工作需关注大规模模型上的局部子空间恢复。
- **未来方向**：将局部稀疏框架与更强的对抗鲁棒性机制结合；探索无需预训练 SAE 的端到端局部子空间学习；把逐簇校准从少量标注扩展为主动学习式标注；在更多模态（多语言、多模态 LLM）与更长上下文场景下验证局部稀疏假设的普适性。
