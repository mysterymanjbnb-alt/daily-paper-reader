## 摘要
个性化大型语言模型（LLM）对于提供符合个体用户风格、意图和偏好的AI辅助至关重要。虽然针对每个用户的微调可以显著提升个性化质量，但会引入大量的参数和存储开销，限制了向大规模用户群体的可扩展性。我们提出PLUME（通过用户调制和共享子空间实现的个性化低秩适配），这是一种轻量级框架，通过利用共享的任务特定子空间实现高效且富有表现力的每用户适配。具体而言，PLUME首先从聚合的用户数据中学习一个全局任务子空间。然后，通过仅训练该子空间内的一个轻量级小方阵来实现个性化，使每个用户能够获得定制模型，同时保持共享组件固定。进一步引入跨层共享参数和秩为1的残差项，以在保持表现力的同时显著减少冗余。在多个个性化文本生成基准上的实验表明，PLUME在减少超过95%的每用户参数的同时，实现了与强基线相当或更优的性能。这些结果确立了具有最小残差的共享子空间调制作为一种可扩展且具有语义基础的LLM个性化方法。

## Abstract
Personalizing large language models (LLMs) is essential for delivering AI assistance that aligns with individual users' styles, intents, and preferences. While per-user fine-tuning can substantially enhance personalization quality, it introduces significant parameter and storage overhead, limiting scalability to large user populations. We propose PLUME (Personalized Low-Rank Adaptation through User Modulation and Shared Subspace), a lightweight framework that achieves efficient and expressive per-user adaptation by leveraging a shared task-specific subspace. Specifically, PLUME first learns a global task subspace from aggregated user data. Personalization is then achieved by training only a lightweight small square matrix within this subspace, enabling each user to obtain a tailored model while keeping shared components fixed. Cross-layer shared parameters and rank-1 residual terms are further introduced to significantly reduce redundancy while maintaining expressiveness. Experiments on multiple personalized text generation benchmarks demonstrate that PLUME achieves comparable or superior performance to strong baselines, while reducing per-user parameters by over 95%. These results establish shared-subspace modulation with minimal residuals as a scalable and semantically grounded approach to LLM personalization.

## 1. 论文的核心问题与整体含义（研究动机和背景）

个性化是 LLM 应用落地的重要方向，它将通用模型输出调整为特定用户的写作风格、偏好与意图。现有主流方案大致可分为两类：

- **基于提示（Prompt-based）的方法**：通过检索用户历史来构建上下文提示，但受限于上下文窗口长度，且依赖显式、高质量的用户信号。
- **基于微调（Fine-tuning）的方法**：一类做法是**共享模型训练**，即在所有用户数据上微调一个统一模型，容易抹平用户差异；另一类做法是**每用户独立 PEFT（One-PEFT-per-User, OPPU）**，即给每个用户单独配备一个 LoRA 适配器，虽然个性化效果好，但**存储与参数量随用户数线性膨胀**，且每个用户数据有限时容易过拟合。

论文的核心问题由此提出：**如何在保持用户级表达力的同时，压缩逐用户的 PEFT 参数量，实现可扩展、高性价比的 LLM 个性化？** PLUME 的答案是：先学习一个跨用户共享的任务低维子空间，然后仅让每个用户在这个共享子空间内调制一组非常轻量的参数，从而将“每用户完整 LoRA”压缩为“一个共享空间中的低秩用户调制器”。

## 2. 论文提出的方法论

PLUME 遵循 OPPU 的“先全局后个性化”训练流程，但重构了个性化参数的结构。整体可拆成四个组件：

1. **全局任务适配器（Global Adapter）**: 先在全体用户聚合数据上训练一个普通 LoRA 模块 \((A^{(l)}, B^{(l)})\)，固定后不再改动。它的列空间被视为“共享任务子空间”。
2. **用户条件子空间混合器（User-Conditioned Subspace Mixer, USM）**: 在 \(A^{(l)}\) 与 \(B^{(l)}\) 之间插入用户特有的小方阵 \(c_u^{(l)} \in \mathbb{R}^{r_g \times r_g}\)，公式为
   \[
   \Delta W_u^{(l)} = s \, B^{(l)} c_u^{(l)} A^{(l)}.
   \]
   其含义是每个用户以自己独特的方式对齐/强调共享子空间中的各方向，而不是另起炉灶建立独立的用户子空间。
3. **个性化跨层共享子空间（Personalized Cross-Layer Shared Subspace, PCLS）**: 通过 CKA（Centered Kernel Alignment）分析发现，不同层 LoRA 学到的用户表示高度相似（相似度常 >0.9），说明逐层独立残差存在严重冗余。于是将逐层独立的用户残差压缩为一组跨层共享的低秩参数 \((A_u, B_u)\)。
4. **逐层秩 1 残差（Rank-1 Residual, Resid）**: 在共享基础上保留每层一个秩 1 修正项 \((\alpha_u^{(l)}, \beta_u^{(l)})\)，用于捕获局部层级微调信号。

两种变体对应两个公式：
- **PLUME**（中间版本）：
  \[
  W_u^{(l)} = W_0^{(l)} + sB^{(l)}c_u^{(l)}A^{(l)} + s' b_u^{(l)} a_u^{(l)}
  \]
- **PLUME-s**（最终精简版）：
  \[
  W_u^{(l)} = W_0^{(l)} + sB^{(l)}c_u^{(l)}A^{(l)} + s'B_u A_u + \beta_u^{(l)}\alpha_u^{(l)}
  \]

**参数量分析**：设层数为 \(L\)、全局 rank 为 \(r_g\)、隐藏维度为 \(d\)，PLUME-s 的每用户复杂度为 \(O(Lr_g^2 + r_{sh}d + Ld)\)，而 OPPU 为 \(O(Ldr_{\text{oppu}})\)。实际中 PLUME/PLUME-s 每用户参数仅为标准 OPPU 的 6.80%/2.21%（按表 3 折算），压缩 15–30 倍以上。

## 3. 实验设计

**数据集与场景**：采用两个标准个性化基准：
- **LongLaMP**（长文生成）：Abstract Generation（摘要生成）、Product Review（产品评论）、Topic Writing（主题写作）。
- **LaMP**（短文生成）：News Headline（新闻标题）、Scholarly Title（学术标题）。

数据构造上从每个数据集中选取 200 位交互历史充足的用户，按时间切分为 8:1:1 的训练/验证/测试集；检索历史用 Contriever 做 Top-K 相似样本，作为个人上下文的 few-shot 示例。

**基座模型**：Mistral-7B-Instruct-v0.2 与 LLaMA-2-7B-chat。

**对比方法**：
- 非个性化：Base（无微调）、LoRA、PiSSA、AdaLoRA、QLoRA、LoRA-One。
- 个性化：RAG（检索式提示）、OPPU（逐用户 LoRA）、CoPE（带对比学习的逐用户方法），以及本方法 PLUME 与 PLUME-s。

**评价指标**：ROUGE-1、ROUGE-L、METEOR。

**统一配置**：所有 LoRA 类方法 global rank 设为 64，统一训练 5 epoch，温度设为 0；PLUME 的 residual rank 设为 4，PLUME-s 的 residual rank 为 1、共享 rank 为 8。学习率和系数用网格搜索后取最优。

## 6. 论文的主要结论与发现

- **PLUME 能在参数量大幅压缩的前提下匹配甚至超越 OPPU/CoPE**：每用户可训练参数降到标准 OPPU 的约 3%–6.8% 时，多数任务得分持平或略优，例如 Abstract Generation 上 PLUME 的 ROUGE-L（0.2395）超过 OPPU（0.2374），News Headline 上 PLUME-s 的 ROUGE-1（0.2427）明显高于 OPPU（0.2383）。
- **CKA 实证支持跨层共享**：用户的个性化 LoRA 在不同层之间高度相似，说明可去除逐层独立冗余。
- **模块各有分工**：消融结果表明 Resid（秩 1）贡献最大、PCLS 共享子空间次之、USM 第三；三者互补，缺一不可。
- **长短文本的“最优共享容量”不同**：长文本（Abstract）中增加 PCLS rank 稳定提升；短文本（Scholarly Title）中 rank 过大反而过拟合。说明该框架可按任务灵活调节压缩-表达平衡。
- **长文本任务中 PLUME 输出偏保守**：相对 171–245 token 的目标长度，模型生成偏短，较长的金标摘要在 ROUGE 指标上更难取得高分。

1. **方法思想清晰且定位有价值**：把个性化压缩看作“共享任务空间 + 用户调制 + 最小残差”的组合，不是盲目压缩，而是有理论动机地消除冗余。
