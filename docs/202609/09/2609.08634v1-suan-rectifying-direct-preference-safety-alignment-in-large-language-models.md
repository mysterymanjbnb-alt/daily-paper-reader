## 摘要
将稳健的安全护栏集成到大型语言模型（LLMs）中，对于提供有用且无害的响应至关重要。尽管专有系统表现出可靠的安全控制，但其潜在方法和权衡在很大程度上仍未公开。在开放权重模型中实现同等的安全性仍然是一个持续的挑战，因为训练后的变体经常遭受过度拒绝和总体质量下降的问题。为了克服这些缺点，我们引入了Suan，一种新颖的偏好优化算法。与现有方法不同，我们直接在梯度级别构建优化目标，绕过了标准的变分推导。因此，我们获得了更具可解释性和鲁棒性的训练动态。在多种竞争性基线和基准测试上的广泛评估表明，Suan实现了卓越的安全对齐，同时完全保持了响应的实用性。

## Abstract
Integrating robust safety guardrails into Large Language Models (LLMs) is essential for delivering helpful yet harmless responses. While proprietary systems exhibit reliable safety controls, their underlying methodologies and trade-offs remain largely undisclosed. Achieving comparable security in open-weight models remains a persistent challenge, as post-trained variants frequently suffer from over-refusal and degraded general quality. To overcome these drawbacks, we introduce Suan, a novel preference optimization algorithm. Unlike existing methods, we formulate the optimization objective directly at the gradient level, bypassing the standard variational derivation. As a result, we obtain more interpretable and robust training dynamics. Extensive evaluations across a diverse suite of competitive baselines and benchmarks demonstrate that Suan achieves superior safety alignment while fully preserving response utility.

### 1. 论文的核心问题与整体含义（研究动机和背景）

大型语言模型（LLMs）的成功部署需要在“有用性”（helpful）与“无害性”（harmless）之间取得平衡。虽然专有系统（如闭源API）已有多层安全护栏，但学术界的开源模型安全对齐研究仍然充满挑战：

- **现有 Direct Alignment Algorithms（DAAs）**，如 DPO、IPO、SafeDPO，虽然简化了 RLHF 流程，却在实际训练中普遍出现 **过度拒绝（over-refusal）**（把良性指令误判为恶意）和 **通用能力退化（utility degradation）** 的问题。
- 这些方法继承了基于“变分推导”的结构性缺陷，导致所选响应概率的 **可能性位移（likelihood displacement）**——偏好样本的似然持续下降，进而损害输出质量。
- 安全对齐的核心问题于是成为：**如何在明显提升无害性的同时，不牺牲模型的帮助性和合规响应率**。

Suan 论文的核心动机即在于此：跳出传统直接偏好优化所固有的泛函形式，在梯度层面构建更具解释力且动态稳定的安全对齐目标，实现在无害性、合规性与帮助性三方面的同时优化。

### 2. 论文提出的方法论：核心思想、关键技术细节与公式

#### 核心思想

Suan 绕开了 DAA 常用的、从 RLHF 推导闭环损失函数的“变分路径”，**直接在梯度级构造目标**，使优化动态可控、可解释。梯度由两部分构成：

1. **偏好梯度项（Preference Gradient Term）**：用于学习偏好关系；
2. **正则化梯度项（Regularization Gradient Term）**：用于避免模型偏离参考策略过远、抑制似然位移。

#### 关键技术细节

- **偏好梯度项**（Proposition 3.1）：对选响应（y⁺）与拒响应（y⁻）的对数概率差采用 **sigmoid 加权**，并通过超参数 τ 控制偏好间隔：

```
∇θ LP(θ) = −σ( log(πθ(y⁻|x)/πθ(y⁺|x)) − τ ) · (∇θ log πθ(y⁺|x) − ∇θ log πθ(y⁻|x))
```

该形式自适应地赋予“错误预测”样本更大的梯度权重，而对已正确学习的样本自然降低优化强度，从而抑制过度优化。

- **正则化梯度项**（Proposition 3.2）：对 y⁺ 和 y⁻ 分别计算与参考模型对数概率比的 sigmoid 缩放，并保证对称的约束效果：

```
∇θ LR(θ) = Σ_{y∈{y⁺,y⁻}} [ σ( log(πθ(y|x)/πref(y|x)) ) − 1/2 ] ∇θ log πθ(y|x)
```

- 两式均可积分得到简洁的闭式损失（Corollary 3.3）：
  - **LP(θ)** = −log σ( log πθ(y⁺|x) − log πθ(y⁻|x) + τ )
  - **LR(θ)** = Σ log cosh( ½ · log( πθ(y|x)/πref(y|x) ) )

- **最终目标**（Definition 3.4）为两者的线性组合：

```
LSuan(θ) = LP(θ) + β · LR(θ)
```

其中 β 控制与参考模型的接近程度，且具有直观、单调的调节作用：**β 增大 ⇒ 模型更贴近参考策略**，不会像 DPO 那样出现非单调的风险失控。这种设计同时压制了过度拒绝、稳定了选响应的似然区域，防止生成质量下降。

### 6. 论文的主要结论与发现

1. **SFT 提升帮助性，但安全不足；DPO/SafeDPO 提升安全性却导致过度拒绝与质量退化**；IPO 安全增益有限但相对稳定。
2. **Suan 在安全对齐方面显著优于 SFT 和 IPO（ASR大幅度下降），与 DPO/SafeDPO 的安全性接近，但不会产生过度拒绝和内容质量崩塌**。
3. **Suan 有效抑制 Likelihood Displacement**（选响应似然在训练过程中不持续下降），避免了对已正确样本的过度优化。
4. **β 具有可解释、单调的调控效果**，β 增大会让模型更接近参考策略，且在全范围内 Suan 都比 DPO/SafeDPO 稳健；DPO 在 β = 0.01 时出现严重质量崩溃。τ 的最优值为 1.0，β 最优为 0.1。
5. 在知识保留（MMLU/ARC）、生成多样性（NoveltyBench）方面，Suan 也优于 DPO 和 SafeDPO，说明其对齐过程更少侵害模型预先学习的能力。
6. 在 HH-RLHF 数据集上也观察到了一致趋势（所有方法在帮助性上略降，但 Suan 仍然总体领先），说明方法对数据分布有一定普适性。

### 7. 优点

- **创新性**：直接以梯度级确定优化目标，避开了 DAA 方法共同的“变分结构”陷阱，方法设计具备理论新意。
- **更强的可解释性**：每个梯度项都有清晰的直观含义；正则化项在原理上直接对抗“似然位移”。
- **实用高效**：无需 Reward Model、无需额外的安全数据过滤机制、可直接用标准偏好数据；需要的算力较低（QLoRA + 单卡即可完成）。
- **超参数调节直观**：β 的行为单调且可预期，训练动态稳定，工程部署友好。
- **综合评估完善**：同时评估了 harmlessness、compliance、helpfulness 三大维度，并且额外考虑了知识保留、输出多样性和不同偏好数据集的影响，实验矩阵覆盖广。

### 8. 不足与局限

- **对比方法覆盖有限**：主要与离线 DPO / IPO / SafeDPO 对比，未与 SimPO、KTO、ORPO 等更多离线 DAA 或在线/PPO/GRPO 类 RLHF 方法比较，也未与“安全 RLHF”这类约束 RL 方法系统地横向对比。
- **安全指标并非全面最优**：Suan 在纯安全（ASR）指标上通常不如 DPO/SafeDPO，只能视为“安全-帮助性-合规”三目标上的最优折衷；在要求极限低 ASR 的严格安全场景中，可能仍不够。
- **评估自动化存在挑战**：帮助性评价依赖单一 LLM Judge，无法完全排除自动评判偏差；对更具多轮、对抗性和高攻击强度的 jailbreak（如 GCG、TAP、多轮越狱）鲁棒性未作检验。
