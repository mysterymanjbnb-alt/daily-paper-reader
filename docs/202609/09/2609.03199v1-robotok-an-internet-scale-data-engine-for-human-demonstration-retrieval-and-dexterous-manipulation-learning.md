## 摘要
机器人学习日益依赖于广泛且多样的演示，然而收集机器人数据仍然昂贵，且难以覆盖现实世界任务的长尾分布。为解决这一瓶颈，我们提出了RoboTok，一个互联网规模的数据引擎，给定一段查询用的人类操作视频，它能从网络视频中检索与操作相关的人类演示，用于训练灵巧机器人策略。具体而言，我们从以估计的演员中心参考系表达的3D手部轨迹中学习一个潜在运动空间。该表示能够在相机视角、场景外观和演员遮挡变化的情况下比较操作行为，同时保持紧凑性以支持对互联网规模视频集合的高效搜索和持续索引。我们在检索基准和下游机器人策略性能上将RoboTok与现有的机器人数据检索方法进行了评估。结果表明，RoboTok能检索到更相关的操作演示并提高下游任务成功率，确立了手部姿态轨迹感知检索作为使网络视频成为机器人学习可扩展且持续增长的监督来源的一种方式。

## Abstract
Robot learning increasingly depends on broad and diverse demonstrations, yet collecting robot data remains expensive and poorly suited to covering the long tail of real-world tasks. To address this bottleneck, we introduce RoboTok, an internet-scale data engine that, given a query human manipulation video, retrieves manipulation-relevant human demonstrations from web videos for training dexterous robot policies. Specifically, we learn a latent motion space from 3D hand trajectories expressed in estimated actor-centered reference frames. This representation enables manipulation behaviors to be compared across variations in camera viewpoint, scene appearance, and actor occlusions, while remaining compact enough for efficient search and continual indexing over internet-scale video collections. We evaluate RoboTok against existing robot-data retrieval approaches on retrieval benchmarks and downstream robot policy performance. Our results show that RoboTok retrieves more relevant manipulation demonstrations and improves downstream task success, establishing hand-pose trajectory-aware retrieval as a way to make web video a scalable and continuously growing source of supervision for robot learning.

## 1. 论文的核心问题与整体含义

- **研究背景**：机器人学习（尤其灵巧操作）需要大量、多样化的演示数据，但真实机器人数据的采集成本高昂，难以覆盖现实世界的长尾任务、物体与场景。已有的机器人数据集（如 Open X-Embodiment、DROID、BridgeData V2）虽规模可观，但仍受限于专用采集基础设施和有限的任务覆盖。
- **核心问题**：互联网视频中蕴含着海量、持续增长的人类操作行为，是潜在的、可扩展的机器人演示数据来源。但网络视频是非结构化的，存在视角、场景、遮挡和语义差异；视觉或语义相似并不等于底层操作行为相似。因此，需要一种能在互联网规模下自动检索与查询操作行为相似的人类演示视频的数据引擎。
- **整体含义**：论文提出并验证了一种“手部姿态轨迹感知检索”范式，将网络视频转化为可扩展、可持续增长的机器人学习监督信号，从而缓解机器人学习中的数据瓶颈，尤其适用于人形机器人和类人灵巧手。

## 2. 论文提出的方法论：RoboTok

### 核心思想
- 将每一个人类操作视频片段表示为**以演员为中心的 3D 手部轨迹**（egocentric/hand trajectory），在“运动空间”而非外观或语义空间中衡量操作相似性。
- 训练一个轻量级嵌入编码器，使嵌入空间中的向量相似度近似逼近基于 Dynamic Time Warping（DTW）定义的运动相似度；检索时只需做高效的余弦相似度近邻搜索。

### 技术流程
- **互联网视频过滤与数据构建**：
  - 从 Action100M 大规模网络视频语料中筛选 4–8 秒、近静态相机、手部可见且不超过左右手各一只的片段。
  - 使用 WiLoR 估计 3D 手部关键点（5 fps）；用 MoGe-2 估计度量深度，将弱透视手部重建转换为度量 3D 相机坐标；用 HaWoR 对缺失手部姿态进行插补。
- **以演员为中心的轨迹表示**：
  - 训练一个轻量级“躯干参考系估计器”，仅以 3D 手部腕部轨迹为输入，预测演示者静态躯干坐标系（基于 SMPL-H，采用 Wang et al. 2026 的方法改编）。
  - 将相机坐标系下的手部姿态转换到actor-centered坐标系，从而在无需看到人体、仅看到手的情况下实现跨视角、跨场景、抗遮挡的轨迹比较。
- **相似性度量与训练标签**：
  - 定义轨迹相似度为长度归一化的负 DTW 对齐代价：\(s(i,j)=-\mathrm{DTW}(x_i,x_j)/\frac{1}{2}(L_i+L_j)\)。
  - 由于互联网规模下逐对 DTW 不可行，使用 DTW 作为监督 oracle 训练嵌入函数：\(\Gamma:X\to S^{d-1}\)，使内积相似度保持 DTW 诱导的排序关系。
- **编码器架构与训练目标**：
  - 编码器为轻量级交叉注意力网络，逐帧位置编码后进行池化，输出 \(\ell_2\) 归一化的 d 维嵌入。
  - 批构建采用“anchor-centered groups”：每个 anchor 取相关集（top-20 DTW 近邻）中 2 个正样本，并在相关集边界外取 1 个边界负样本；每批含 49 组，共 196 条轨迹。
  - 优化目标为 `L = L_set + λL_rank`：set loss 使 oracle top-K 邻居得分高于边界负样本；rank loss 使正样本相对排序与 DTW 排名一致。
- **推理与持续索引**：
  - 离线阶段对所有轨迹编码并存入向量索引；在线阶段对查询视频编码后进行近邻检索，不再计算 DTW。
  - 新视频片段无需重训模型，单次前向编码后即可加入索引，支持持续扩展的互联网规模数据引擎。

## 3. 实验设计

### 检索质量评测
- **评估语料 1：RoboTok 训练语料**

  - 因为缺少传感器级真实手部姿态，DTW oracle 被视为“伪真值”（pseudo-ground-truth）。
  - 相关集大小 R = 20。
- **评估语料 2：AssemblyHands（外部跨域语料）**
  - N = 831 条双手装配视频，具有传感器级 3D 手部标注；
  - 每条依次作为查询，对应真实 DTW 真值；相关集大小 R = 5。
- **对比方法**：
  - Random（随机检索）、FlowRetrieval（Flow）、HAND、STRAP；
  - 额外报告 DTW oracle 排序作为上界（GT）。
- **评估指标**：mAP@k、nDCG@k、CKNNA@k、MRR@k、Kendall τ、DTW cost@k（越低越好），以及 Recall@k、DTW cost@k、CKNNA@k 随 k 的变化曲线。

### 下游灵巧操作策略评估
- **基准任务**：VTDexManip 仿真基准，包含 BottleCap Turning、Faucet Screwing、Lever Sliding、Table Reorientation、In-hand Reorientation、Bimanual Hand-over 六个任务，每个任务分为 seen/unseen 物体。
- **策略与训练方式**：
  - 使用 PPO 从零训练策略；不使用机器人演示或动作标签，检索结果仅通过奖励影响策略，从而隔离检索方法的差异。
  - 语言无关；策略输入为本体感觉与指尖力数据，3 步滚动观测窗口。
  - 奖励中加入“跟踪检索演示”的项：以带权重的 k-NN 距离负值 \(\Phi(s)\) 作为常驻奖励，并用 \(\Phi\) 做 potential-based reward shaping。
- **两套任务版本**：
  - 原版 VTDexManip 任务；
  - 更难的修改版：对三个任务（BottleCap Turning、Faucet Screwing、Lever Sliding）恢复完整 3D 手部运动控制、移除手工密集奖励，以提高探索难度。
- **下游对比基线**：Base（无演示引导的 PPO）、Random、Flow、HAND、STRAP，以及原基准自带的 VT-JointPretrain 报告结果。

## 6. 主要结论与发现

- **RoboTok 显著优于现有检索方法**：
  - 在 RoboTok 大语料上，mAP@20 达 0.353，Recall@20≈0.996（几乎每个查询都在 top-20 中得到真实 DTW 邻居）；最强基线 STRAP 的 mAP@20 仅为 0.007。
  - 在 AssemblyHands 跨域语料上同样领先：mAP@5=0.261，而 STRAP 为 0.133。
  - top-20 检索的 DTW cost 比随机低得多，且接近 oracle 邻居水平，证明了运动空间组织正确。
- **学习到的嵌入空间全局性较好**：虽然只为局部 k=20 邻居优化，但其潜在运动空间在更大尺度上也保持了全局一致组织。
- **下游策略结果提升显著**：
  - 原版 VTDexManip 上，RoboTok 在六个任务中的五个优于最佳基准基线，seen/unseen 平均成功率分别高出 7.45% 和 5.83%。
  - 更难的修改版任务中差距更大：BottleCap Turning 提升 17.8%（相对 HAND），Faucet Screwing 提升 38.0%，Lever Sliding 提升 59.8%。
  - 训练速度也明显优于基线。
- **总体结论**：以 actor-centered 3D 手部轨迹为索引线索的检索能够从互联网视频中稳定挖掘操作相关演示，可作为灵巧机器人学习的可扩展、持续增长的监督来源。

## 7. 优点

- **问题定义清晰、针对性强**：聚焦“行为相似”而非“视觉/语义相似”，直击网络视频到机器人演示迁移的核心难点。
- **表示设计有洞见**：将 3D 手部轨迹变换到以演员为中心的参考坐标系，只利用手部轨迹估计躯干坐标系，不依赖人体可见性，具有较好的视角/遮挡不变性。

- **实验设计闭环**：从检索质量到下游灵巧策略成功率，形成完整评测链路。
- **公平性设计较好**：下游策略不使用机器人动作标签，检索结果通过奖励的唯一差异影响策略，从而将性能差异归因于检索方法。
