## 摘要
本文提出了一种鲁棒的去中心化个性化联邦学习方法R-DPFL，该方法使客户端能够通过鲁棒的邻域方向估计和基于历史记录的更新趋势预测来减少拜占庭攻击的影响，而非像现有工作那样仅聚合客户端模型。在R-DPFL中，每个客户端首先通过聚合接收到的邻域更新向量来计算当前轮的模型更新，然后基于其历史值和本地模型变化预测该更新应为何值，最后计算两者之间的差异，自适应地裁剪该差异，并将其添加到本地更新中。我们通过严格分析证明了学习过程的收敛性，并表明在拜占庭邻居扰动下，诚实客户端无需邻居模型达成共识即可保持稳定的个性化下降动态。在CIFAR-10上的大量实验表明，在异构和对抗性设置下，R-DPFL始终优于最先进的去中心化和个性化联邦学习基线方法。

## Abstract
This paper proposes a robust decentralized personalized federated learning method R-DPFL, that enables clients to reduce the impact of Byzantine attacks via robust neighborhood direction estimation and history-based update trend prediction, rather than purely aggregating client models as in the existing work. In R-DPFL, each client first computes the current-round model update by aggregating the received neighborhood update vectors. It then predicts what this update should be based on its historical values and local model changes. Finally, R-DPFL computes the difference between these two quantities, adaptively clips this difference, and adds it to the local update. We prove convergence of the learning process through rigorous analysis and show that honest clients maintain stable personalized descent dynamics under Byzantine neighbor perturbations without requiring consensus among neighboring models. Extensive experiments on CIFAR-10 demonstrate that RDPFL consistently outperforms state-of-the-art decentralized and personalized federated learning baselines under heterogeneous and adversarial settings.

## 1. 核心问题与研究动机

**拜占庭攻击下个性化与鲁棒性的内在冲突**

- **背景**：联邦学习（FL）让分布式客户端在不共享原始数据的前提下协作训练模型，但传统FL依赖中心服务器，存在单点故障等问题。去中心化联邦学习（DFL）通过P2P图结构移除中心节点，却引入更严峻的鲁棒性挑战——客户端只能获取局部邻居信息，恶意邻居可能发起拜占庭攻击。
- **核心难题**：去中心化个性化联邦学习（DPFL）允许各客户端学习个性化模型，这意味着诚实客户端之间天然存在差异性（模型更新方向不同）。现有的鲁棒去中心化方法几乎都基于"良性更新应当保持足够对齐/统计一致"的假设来识别并抑制离群值。但个性化环境下，这种共识假设被彻底削弱——良性多样性本身就可能被恶意扰动利用作为伪装。
- **研究问题的本质**：并非要让所有客户端收敛到同一模型（共识），而是要在存在拜占庭邻居干扰的情况下，**保持诚实客户端稳定、有利的个性化优化**。即鲁棒性不应以牺牲个性化为代价，个性化也不应成为鲁棒性的障碍。

## 2. 提出的方法（R-DPFL）

**核心思想**：将邻域协作视为一种**受控的协作纠偏信号**，而非模型平均或共识约束。本地方向主导个性化优化轨迹，邻域方向仅提供有界修正。

**关键技术流程**（每个通信轮次t，每个客户端i并行执行）：

1. **本地SGD与局部下降方向构造**：
   - 从当前模型执行K步本地随机梯度下降。
   - 定义局部下降方向为：
     ```
     u_t_i = (w_{t-1}_i - \tilde{w}_t_i) / (η_t · K)
            = (1/K) · Σ_{k=0}^{K-1} g_i(w_t,k_i; ξ_t,k_i)
     ```
   - 即K步中所有随机梯度的平均，反映客户端本地目标的主导下降倾向。

2. **邻居消息交换与鲁棒聚合**：
   - 与邻居交换局部方向u_t_i。可能收到被污染的邻居方向：
     ```
     \tilde{u}_{t,j→i} = u_t_j + δ_{t,j→i}
     ```
   - 对收到的邻居消息集应用鲁棒聚合（可选坐标中位数、修剪均值等）得到初步估计：
     ```
     \bar{d}_t_i = RobustAgg(\tilde{U}_t_i)
     ```

3. **基于历史信息的邻域方向预测**：
   - 计算历史模型轨迹变化及邻域聚合方向的历史变化：
     ```
     s_{t-1}_i = w_{t-1}_i - w_{t-2}_i
     y_{t-1}_i = \bar{d}_{t-1}_i - \bar{d}_{t-2}_i
     ```
   - 采用Barzilai-Borwein风格公式计算预测系数β，进而预测当前轮邻域方向：
     ```
     β_t_i = ⟨s_{t-1}_i, y_{t-1}_i⟩ / (‖s_{t-1}_i‖² + ε)
     \hat{d}_t_i = \bar{d}_{t-1}_i + β_t_i · (w_{t-1}_i - w_{t-2}_i)
     ```
   - 直觉：良性协作趋势应随本地模型轨迹平滑演变；对抗扰动常造成由历史无法解释的突变。

4. **自适应偏差裁剪**：
   - 计算当前鲁棒聚合值与历史预测之间的偏差：Δ_t_i = \bar{d}_t_i - \hat{d}_t_i。
   - 阈值采用指数移动平均自适应更新：
     ```
     τ_t_i = α·τ_{t-1}_i + (1-α)·c·‖Δ_{t-1}_i‖₂
     ```
   - 对偏差进行裁剪（与近期历史行为一致的偏差保留；过大突变被限制），得到邻域协作方向d_t_i，并进一步设置上限G_d保证最大影响受控。

5. **统一更新式**：
   ```
   w_t_i = w_{t-1}_i - γ_t(u_t_i + λ·d_t_i)
   ```

**关键定位**：λ=0时退化为完全独立训练；协作分量只作为"预测约束"的小幅纠偏，BYZ扰动仅以有界残差形式进入收敛界。

- 在无攻击的清洁环境中，R-DPFL能保持与纯隔离训练（λ=0）相当甚至略好的个性化性能，邻域修正机制不会明显损害个性化模型质量。
