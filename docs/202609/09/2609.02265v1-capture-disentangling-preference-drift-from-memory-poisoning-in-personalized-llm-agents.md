## 摘要
个性化语言代理使用持久记忆来随时间适应用户，但同一机制也创造了攻击面。当新信息与存储的偏好冲突时，代理必须区分真正的偏好漂移与临时上下文转换、歧义或对抗性记忆中毒。我们将此问题表述为潜在用户状态上的连续时间部分可观察决策过程，并展示为何仅基于最近性和来源的规则是不够的。CAPTURE通过神经微分方程信念追踪器、多时间尺度记忆账本、不确定性触发的澄清以及引用记忆的反事实审计来解决这种歧义。在来自96名用户的480个保留情节中，CAPTURE实现了71.5%的胜率，而相同监督的基线为69.3%，最强启发式基线为66.1%。它将固定策略中毒成功率限制在11.5%，同时接受83.5%的真正偏好更新。对于拥有发布权重访问权限的自适应攻击者，攻击成功率上升至24.7%，暴露了真实的适应性-安全性权衡。我们进一步在独立构建的基准上对冻结系统进行零样本评估，并重放来自40名用户收集的两到三周的纵向交互历史。这些结果表明，显式建模偏好真实性可以提高记忆增强LLM代理的个性化和鲁棒性。

## Abstract
Personalized language agents use persistent memory to adapt to users over time, but the same mechanism creates an attack surface. When new information conflicts with stored preferences, an agent must distinguish genuine preference drift from temporary context shifts, ambiguity, or adversarial memory poisoning. We formulate this problem as a continuous-time partially observable decision process over a latent user state and show why rules based only on recency and provenance are insufficient. CAPTURE addresses this ambiguity with a neural differential-equation belief tracker, a multi-timescale memory ledger, uncertainty-triggered clarification, and counterfactual auditing of cited memories. On 480 held-out episodes from 96 users, CAPTURE achieves a 71.5% win rate, compared with 69.3% for an identically supervised baseline and 66.1% for the strongest heuristic baseline. It limits fixed-policy poisoning success to 11.5% while accepting 83.5% of genuine preference updates. Under an adaptive attacker with access to the released weights, attack success rises to 24.7%, exposing a real adaptation-security tradeoff. We further evaluate the frozen system zero-shot on an independently constructed benchmark and replay longitudinal interaction histories from 40 users collected over two to three weeks. These results suggest that modeling preference authenticity explicitly can improve both personalization and robustness in memory-augmented LLM agents.

## 2. 方法论：核心思想、关键技术细节与流程

论文提出的 CAPTURE 系统沿单一事件路径运作，核心架构包含以下五个部分：

- **多时间尺度账本**：假设节点存储在图结构向量数据库中，按三种时间尺度分层（稳定层 γs=0.01/天、上下文层 γc=0.1/天、瞬态层 γg=0.5/天）。节点置信度按 `c0·σ(h_t)·exp(−γ(t−t0))` 衰减；覆盖稳定节点需要多次高置信度证据而非单次陈述，防止一句话重新定义用户。隔离状态中的节点不可检索，需在14天内得到确证否则被逐出。

## 3. 实验设计：数据集、基准与对比方法

## 6. 主要结论与发现

- 固定策略下，CAPTURE 同时优于两个方向的基线：中毒抵抗 11.5%（Provenance-only 为 20.0%）且真实更新接纳率 83.5%（Recency RAG 为 85.7%），同时保持在较高拒真率和最低良性误接纳率（8.9%）。
- 窗口限制仅基于近因的规则（Theorem 2）在实际数据上得到验证——Provenance-only 的同源污染攻击成功率高达 43.6%（CAPTURE 为 17.5%）。
- **监督主导、架构辅助**：监督匹配 Transformer 占其与 StateMem 差值的大部分，但架构提供了显著额外增益：胜率 +2.2 分（p=0.011）、中毒 −4.4 分（p=0.003），且这种增益可转移到独立基准。
- **自适应攻击是主要弱点**：自适应攻击者使 CAPTURE 的中毒成功率从 11.5% 升至 24.7%，此时与 Provenance-only（22.1%）无显著差异（p=0.29）——"更安全"的结论完全取决于对手类型。
- 时间尺度分离是关键：上下文切换时 CAPTURE 在 71% 的切换点上选择"收窄"而非"重写"，StateMem 仅为 4%；多时间尺度分层贡献了 5.4 分的真实更新接纳率提升。

## 7. 优点

- **理论贡献**：首次从形式化角度确认了偏好真实性与投毒不可区分性的下界，将启发式防御争论升维为严格统计决策理论分析。
- **方法论建模**：将用户状态分解为稳定/上下文/瞬态三种时间尺度，以连续时间动态（而非固定回合衰减）建模——这是个性化研究中缺乏严谨表述的方向。
- **评估设计**：D-PREF GUARD 精心构造了5个轨道，覆盖真实偏好漂移和三类攻击；评估指标通过不重叠多个模型（获胜率与后悔值由不读取笔记的独立模型评测）防止优化反馈循环。
- **独立验证**：不仅靠自建 benchmark，还进行冻结回测（HorizonBench）、40用户纵向重放实验和第三方红队攻击测试——多角度交叉证明了算法提取的鲁棒性。
- **充分的实验对照与透明度**：包含监督匹配 Transformer（消除标签优势效应）、组件消融（明确各模块贡献及权值敏感性）、跨骨干模型与域外生成器实验。论文明确报告了两个关键数字而非仅报告有利数字（自适应攻击成功率为 24.7%），并公开了失败模式分布。

## 8. 不足与局限

- **自适应安全不足**：在自适应攻击者面前，CAPTURE 几乎与简单的 Provenance-only 一样脆弱，这动摇了其安全性的核心主张；黑盒外的安全性表现也可靠（18.3% 优于其他方法），但仍远高于固定策略下的 11.5%。
- **合成数据偏差**：核心 D-PREF GUARD 为合成数据，真实偏好状态及标注均由生成程序给出；训练和测试用不同生成器只能减少但无法完全消除"通过学习生成器来学习"的遗漏偏差。40名受试者的重放研究支持效果估计，但尚无亚组结论。
- **防御者的受信界**：威胁模型假定攻击者已知发布权重、不能修改权重、不能读账本，作者也承认这些条件未必适用于实际部署环境（如权重级投毒）。
- **澄清成本假设过强**：Theorem 4 假设澄清只以固定误差 ε 通过对称信道返回，但在真实开放场景中，澄清的可靠性和代价显著取决于对象自身知识。
- **方法权衡**：时间证据使用隔离而非实时拒绝，导致 14 天潜伏期（滞后 3.4 天，比 Recency RAG 的 2.8 天更高）和更高的 9.0% 拒绝率——对快速适应的场景存在显著实用性损失。文本处理的 ~630 ms/轮延迟在实时场景中可能构成部署瓶颈。
- **理论范围和外部验证的紧迫性**：定理中的下界只适用于测量某种现实对手策略的强度，而非直接可测的 worst-case inf；论文明确强调"外部有效性检查仅以微弱差距通过"（F4 通过但余量不大），而 40 个用户在多个维度上的置信区间相对较宽。
