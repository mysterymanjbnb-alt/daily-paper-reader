## 摘要
随着车载网络迈向5G/6G边缘智能，联邦学习（FL）被广泛推崇为一种在车辆与基础设施间训练共享模型而不暴露原始传感器数据的隐私保护方式。然而，客户端传输的更新仍会泄露足够的信息以识别发送者身份，这威胁到安全关键的V2X应用所假设的匿名性，并加剧了现有的对抗性机器学习、模型投毒和后门攻击担忧。我们研究了服务器端利用传输的权重增量（基于惯性测量单元IMU数据）进行客户端身份推断的问题，并在UCI人类活动识别（HAR）基准上进行了评估，该基准作为联网车辆车载IMU流的一个可访问代理。在五种攻击分类器和五种非独立同分布划分下，诚实但好奇的服务器能够从未经防御的更新中以近乎完美的准确率（约1.000）恢复客户端身份，确认了具体的可识别性风险。随后，我们通过在固定裁剪（C=1.0）下扫描高斯噪声（sigma∈{0.00, 0.05, 0.10, 0.20, 0.50, 1.00}），量化了轻量级先裁剪后加噪防御的隐私-效用权衡，并通过Renyi会计报告了正式的(epsilon, delta)-DP预算。一个实用区域（sigma∈[0.1, 0.2]）将攻击准确率降至接近随机水平，同时FL准确率相对损失低于5%。集成FL通过1/K匿名集界限和零噪声代价提供了结构性的补充隐私。结果得到了密码学（SHA-256）训练/评估梯度不相交性、三个随机种子以及计数归一化的攻击者优势指标的支持。我们明确将HAR定位为代理，并讨论了对真实车载遥测数据进行验证所需的条件。

## Abstract
As vehicular networks move toward 5G/6G edge intelligence, federated learning (FL) is widely promoted as a privacy-preserving way for vehicles and infrastructure to train shared models without exposing raw sensor data. Yet the updates clients transmit still leak enough information to identify who sent them, which threatens the anonymity that safety-critical V2X applications assume and adds to existing concerns over adversarial ML, model poisoning, and backdoor attacks. We study server-side client identity inference from transmitted weight deltas using inertial (IMU) measurements, evaluated on the UCI Human Activity Recognition (HAR) benchmark as an accessible proxy for the IMU streams produced onboard connected vehicles. Across five attack classifiers and five non-IID partitions, an honest-but-curious server recovers client identity with near-perfect accuracy (approximately 1.000) from undefended updates, confirming a concrete identifiability risk. We then quantify the privacy-utility trade-off of a lightweight clip-then-noise defense by sweeping Gaussian noise (sigma in {0.00, 0.05, 0.10, 0.20, 0.50, 1.00}) at fixed clipping (C=1.0), and report formal (epsilon, delta)-DP budgets through Renyi accounting. A practical region (sigma in [0.1, 0.2]) drives attack accuracy to near-random while costing under 5% relative FL accuracy. Ensemble FL supplies complementary structural privacy with a 1/K anonymity-set bound and no noise penalty. Results are supported by cryptographic (SHA-256) train/evaluation gradient disjointness, three seeds, and a count-normalized attacker-advantage metric. We position HAR explicitly as a proxy and discuss what validation on true vehicular telemetry would require.

## 1. 论文的核心问题与整体含义

- **研究动机**：在 5G/6G 车载边缘网络中，联邦学习（FL）被视为"隐私保护"的默认方案——车辆仅上传模型更新而非原始传感器数据。然而，**客户端上传的权重增量本身即可泄露发送者身份**，这直接威胁 V2X 安全关键应用所依赖的匿名性。
- **核心问题**：一个"诚实但好奇"（honest-but-curious）的 FL 服务器，能否仅从客户端传输的权重增量（weight deltas）中精确推断出该更新来自哪个客户端？
- **重要性**：身份推断不同于传统的输入重建或成员推断攻击，它不需要恢复原始数据，而是直接打破参与者匿名性，为后续模型投毒、定向追踪、社会工程等攻击打开了大门。
- **研究立场**：现有防御评估普遍存在一个关键缺陷——防御的是"每批次梯度（per-batch gradient）"这一**服务器永远看不到的中间产物**，而非客户端实际传输的更新内容，从而高估了隐私保护水平。本文明确修正了这一威胁模型。
- **整体含义**：联邦学习的隐私保护并非默认成立。该研究以惯性测量（IMU）数据为切入点，系统证明并量化了梯度层面的身份可识别性风险，并给出了实用化的防御策略与成本-效益分析。

## 2. 论文提出的方法论

**2.1 FL 训练框架**

- 标准跨设备 FL：N = 10 个客户端 + 一个中心服务器
- 每轮 t，客户端 i 执行 E 个本地 SGD 轮次，计算权重增量，应用防御后上传，服务器使用 FedAvg 聚合
- 全局目标：最小化各客户端经验损失的加权和，按本地样本量加权

**2.2 攻击协议（三阶段）**

1. **收集阶段**（第 1–8 轮）：服务器记录各客户端传输的、经防御处理后的权重增量，并做 SHA-256 哈希登记
2. **训练阶段**（第 9 轮起）：将已标记的"（增量，客户端 ID）"对经 **L2 归一化 → Z-score 标准化 → PCA（50 分量）** 预处理后，喂给五个分类器：
   - 随机基线（硬下界 1/N）
   - 多数类基线（应对类别不平衡）
   - L2 正则化逻辑回归（线性可分性检验）
   - 100 棵树随机森林（非线性基线）
   - MLP（[d → 256 → 128 → N]，最强攻击者）
3. **评估阶段**（第 9–20 轮）：对新上传的更新进行预测，并通过 SHA-256 哈希不相交性确保评估用梯度从未出现在训练集中

**2.3 防御机制**

- **梯度裁剪**（Gradient Clipping）：将梯度 L2 范数限制到 C
- **高斯噪声注入**（Gaussian Noise Injection）：按裁剪后的敏感度添加各向同性高斯噪声（σC），构成 Gaussian mechanism
- 应用顺序：**先裁剪、后加噪**（clipped sensitivity 是 DP 语义的前提）

**2.4 正式差分隐私分析**

- 单步防御满足 (α, ε_α)-Rényi DP，经 T 轮后转换为 (ε, δ)-DP（δ = 10⁻⁵）
- 关键发现：σ = 0.1 时 ε ≈ 296，意味着低噪声提供的主要是**经验性隐私**而非强正式 DP 保证（σ ≥ 0.5 才能获得有意义的预算）

**2.5 集成 FL（Ensemble FL）的结构性隐私**

- 将 N 个客户端划分为互不重叠的 K 个组（组间由子模型独立服务，天然对应 RSU 覆盖区/信任域）
- **命题 1**：若组内更新统计不可区分，攻击者对单一子模型的溯源精度上限为 1/K
- 备注：该上界是防御方的最佳情形，强组内非 IID 或极小 K 值可破坏此假设

**2.6 评价指标**

- **隐私分数（PS）** = 1 − 最佳攻击准确率
- **归一化攻击者优势（NAA）** = (攻击精度 − 1/N) / (1 − 1/N)，按随机猜测下限 1/N 归一化，使得不同客户端数量下的实验结果可比

## 6. 论文的主要结论与发现

1. **无防御时身份可识别性极高**：Dirichlet(α=0.3) 非 IID 划分下，LR、随机森林和 MLP 攻击者在留出更新上攻击精度均约 1.000（NAA ≈ 1），客户端梯度在参数空间中占据可分离的独立区域。
2. **裁剪本身就有防御效果**：仅裁剪（σ = 0）将攻击精度从约 1.000 降至 0.127 ± 0.020——梯度**范数**的方差是主要的身份区分通道，但仍存在方向性泄露。
3. **实用防御区域**：σ ∈ [0.1, 0.2]（C = 1.0）将攻击精度推到接近随机（约 0.15）同时保持 FL 精度 ≥ 0.89（相对损失 < 5%），σ = 0.5 时 FL 精度降至 0.665，σ = 1.0 时崩溃至 0.382。
4. **形式化 DP 预算松散**：Rényi 会计表明 T = 20 时需 σ ≥ 0.5 才能获得有意义的 (ε, δ) 保证，实际使用的低噪声区域获益主要来自**经验性**而非**正式**的隐私；"裁剪→加噪"是使 DP 语义成立的前提条件。
5. **集成 FL 有效且无噪声开销**：K = 2, 3, 5 时经验攻击精度分别为 0.50, 0.33, 0.20，与理论 1/K 界限高度吻合，FL 精度保持在约 0.92，适合时延敏感型 VANET 场景。
6. **非 IID 越强、泄漏越大**：病态划分使客户端梯度近乎正交，最大化可分离性；即使 IID 数据下早期轮次也存在一定的身份区分（源于小批量随机性和初始化效应）。
7. **整体最佳防御**：组合防御（σ = 0.01, C = 1.0）取得最高隐私分数（0.880）同时 FL 精度保持在约 0.940。

## 7. 优点

- **威胁模型修正具有方法论贡献**：明确指出"防御每批梯度而非实际传输的权重增量"这一常见评价缺陷，并改为对传输后的更新做攻击/防御评估，去除了虚假的乐观偏差。
- **密码学保证的评测严谨性**：SHA-256 哈希强制训练与评估的梯度集合不相交，排除数据泄漏导致的精度虚高；使用三个随机种子报告均值±标准差，并引入 NAA 使不同 N 的实验可比。
- **系统性的防御评估框架**：将噪声扫描、裁剪消融、组合防御和结构性防御（集成 FL）纳入同一框架，给出了完整的隐私-效用操作点（operating point），覆盖经验攻击精度和正式 DP 预算两个层面。
- **理论分析与经验实验互相印证**：集成 FL 的 1/K 上界同时有推导证明和经验验证；Rényi 会计结果与实验观察一致——低噪声足以对抗实用攻击但无法提供强的正式保证。
- **合理的模型设计选择**：使用 LayerNorm 替代 BatchNorm 并给出了联邦场景下的技术理由；对 HAR 作为车载数据代理的定位诚实明确，不夸大适用边界。

## 8. 不足与局限

- **代用数据的限制**：UCI HAR 共享 IMU 模态但不具备真实驾驶动态（速度变化、路面激励、GPS 相关结构等），真实车载数据可能更易或更不易分离，结论的外部有效性未经检验。
- **实验规模偏小**：N = 10、T = 20、3 seeds、单一数据集，统计功效有限；DP 会计在 T ≥ 100 长训练场景下的累积预算效果未知。
- **威胁模型较窄**：仅考虑单一诚实但好奇的服务器，排除了合谋客户端、自适应攻击者和恶意聚合器等其他可能达到更强推断能力的威胁。
- **形式化隐私保证不足**：论文使用的实用噪声区间（σ ∈ [0.1, 0.2]）在 T = 20 时对应的 ε 约为 74–296，远远不能提供有意义的正式 DP 保证——这如实说明了防御主要为经验性而非常规意义上的 DP。
- **集成 FL 的假设限制**：1/K 匿名界依赖"组内更新统计不可区分"这一强假设，而强组内标签/特征偏斜或极小 K 都能破坏该假设；论文虽指出这一点，但未提出自适应组内偏斜监控机制的具体方案。
- **防御代价未全面量化**：噪声对 FL 收敛逼近的影响只在浅层 MLP + 短训练下考察，缺少对通信轮数增加、收敛速度变慢等系统级开销的讨论。
- **某些基线不公平性**：多数类基线作为攻击者的意义不明确（客户端类别均匀时多数基线与随机一致），虽然这是标准做法，但其信息量有限。
