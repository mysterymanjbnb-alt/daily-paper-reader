## 摘要
大语言模型（LLM）智能体日益依赖外部记忆来支撑长时程推理与决策。现有记忆系统通常将历史轨迹或摘要作为独立的上下文片段进行检索，忽视了多步执行背后的过程性依赖。随着记忆规模扩大，这种扁平化检索会引入上下文碎片化和跨任务干扰，导致推理轨迹在结构上不一致。我们提出 ActiveMem，一种层次化记忆框架，它将智能体经验递归地组织为依赖感知的潜在执行树。ActiveMem 将轨迹抽象为可复用的子任务节点，同时显式保留执行转移，从而能够以当前执行状态为条件检索连贯的推理路径。为支持持续适应，ActiveMem 进一步通过强化学习学习动态的记忆扩展、检索与剪枝策略。在多个智能体基准上的实验表明，相较于现有基于记忆的智能体，ActiveMem 在任务完成度、推理稳定性和记忆效率方面均有持续提升。此外，ActiveMem 使紧凑的开源权重模型能够取得与规模大得多的专有系统相竞争的性能。

## Abstract
Large Language Model (LLM) agents increasingly rely on external memory to support long-horizon reasoning and decision making. Existing memory systems typically retrieve historical trajectories or summaries as independent context fragments, overlooking the procedural dependencies underlying multi-step execution. As memory scales, such flat retrieval introduces context fragmentation and cross-task interference, leading to structurally inconsistent reasoning trajectories. We propose ActiveMem, a hierarchical memory framework that recursively organizes agent experiences into dependency-aware latent execution trees. ActiveMem abstracts trajectories into reusable subtask nodes while explicitly preserving execution transitions, enabling coherent reasoning-path retrieval conditioned on the current execution state. To support continual adaptation, ActiveMem further learns dynamic memory expansion, retrieval, and pruning policies through reinforcement learning. Experiments across various agent benchmarks demonstrate that ActiveMem consistently improves task completion, reasoning stability, and memory efficiency over existing memory-based agents. Moreover, ActiveMem enables compact open-weight models to achieve competitive performance with substantially larger proprietary systems.

## 2. 方法论

### 2.1 核心思想

- 将智能体经验递归组织为**层次化潜在记忆树（Hierarchical Latent Memory Tree, HLMT）**：
  - **节点**编码可复用的子任务级推理抽象（连续潜在嵌入，非原始文本块）。
  - **边**捕获执行依赖关系（父子层级）。
- 检索时不再取孤立轨迹，而是取**依赖一致的执行路径**，保留高层过程结构，同时抑制无关分支干扰。
- 记忆的扩展、更新、压缩、剪枝被建模为**自适应决策过程**，通过强化学习持续优化，且**主干 LLM 保持冻结**。

### 2.2 问题形式化

- 给定任务指令 x，冻结 LLM π_θ 与环境 E 交互 T 步，产生轨迹 τ = (s₀, a₀, …, s_T)。
- 历史前缀 τ_{<t} 被压缩为动态 HLMT，记为 T_t，避免上下文溢出：
  - T_t = TreeUpdate(T_{t−1}, a^tree_{t−1})
- 当前状态 s_t 下检索记忆路径 P_t = f_retrieve(s_t, T_t)。
- 轻量控制器 W_φ 处理 P_t 与当前观测编码 h_t = f_enc(s_t; π_θ)，产生共享表示 u_t，分流到两个头：
  - **潜在记忆前缀头**：生成 m_t 以条件化冻结 LLM。
  - **树动作头**：预测拓扑操作 a^tree_t。
- 目标：max_φ E_{x∼D, τ∼π_{θ,φ}}[R(τ)]，用 GRPO 优化 φ。

### 2.3 层次化潜在记忆树（HLMT）

- 每个节点定义为 n_i = (e_i, pa(i), ch(i))：
  - e_i ∈ R^d 为控制器产生的压缩潜在摘要嵌入。
  - pa(i)、ch(i) 分别为父指针与子节点集合。
- **结构特性**：上层节点捕获粗粒度任务语义，下层节点保留细粒度执行细节；检索时逐步缩小搜索空间，实现**由粗到细**推理。
- **检索算法**：以 h_t 为查询，从虚拟根节点 n_r 开始递归贪心遍历，每层选择余弦相似度最大的子节点：
  - n_{k+1} = argmax_{n∈ch(k)} (h_t · e_n) / (‖h_t‖‖e_n‖)
- 当最大相似度低于阈值 τ_stop 时终止，得到激活的历史分支路径 P_t = (n₁, …, n_d)。

### 2.4 双头记忆控制器

- **路径聚合**：对检索路径做均值池化 p̄_t = (1/|P_t|)Σ e_i，再与 h_t 拼接，经 2 层 MLP 得 u_t。
- **潜在注入头（Latent Injection Head）**：
  - 生成动态连续前缀 m_t = W_latent · u_t ∈ R^{l_p × d_model}。
  - 直接**前置到当前观测的输入嵌入**，作为动态软提示（soft prompt）引导冻结 LLM 推理，避免逐层修改的开销。
  - RL 优化时，虽然 θ 冻结，但梯度可沿 LLM 计算图反传到输入层以更新 φ。
- **树动作头（Tree Action Head）**：
  - π_tree(·|u_t) = Softmax(W_tree · u_t)，采样离散拓扑动作。
  - **即时执行（Immediate Execution）**：
    - insert：新节点 e_new = W_ins · u_t 挂到检索到的叶节点 n_d 下，保留时序层级。
    - update：通过门控 α = σ(W_gate · u_t) 精炼叶节点：e_d ← (1−α)e_d + α·W_upd·u_t。
    - 所有新插入/更新嵌入用 L2 归一化，防止表示坍塌。
  - **延迟执行（Deferred Execution / TreeMaintenance）**：回合结束时做结构维护：
    - 计算节点的回合效用 S(n_i)，同回合多次激活取平均，防止高频循环过度计入。
    - 指数滑动平均平滑：S_EMA(n_i) ← (1−β)S_EMA(n_i) + βS(n_i)。
    - 低于阈值 τ_del 的节点剪枝，子节点重挂到父节点以保持拓扑连通。
    - 兄弟节点相似度 sim(e_i, e_j) > τ_merge 时平均池化融合。

### 2.5 训练配方

- 使用 **GRPO**（Group Relative Policy Optimization）优化共享参数 φ，无需 critic 模型。
- 引入**可验证的过程监督**缓解长时程稀疏奖励问题，节点效用为折扣回报：S(n_i) = Σ_{k=t_i}^T γ^{k−t_i} r_k。
- **层次化优势**：
  - A_i = λ_g · [(S(n_i) − μ_G(S)) / (σ_G(S) + ε₀)] + λ_l · (S(n_i) − S(pa(i)))
  - 全局优势鼓励任务级有用性，局部优势保留节点相对父节点的专业化。
- **联合 GRPO 目标**：L(φ) = L^latent_GRPO(φ) + λ·L^tree_GRPO(φ)，其中 L^latent_GRPO 使用环境优势 A^env_t 与 KL 惩罚防止策略坍塌，采用裁剪式重要性比率 ρ^env_t(φ)。
- 两个头共享表示、互补目标，梯度联合累积；论文称未观察到训练不稳定。

### 2.6 复杂度与理论分析（附录）

- 检索复杂度 O(D·B)，在有限分支假设下 D ≈ log_B|T|，远优于扁平记忆的 O(|T|)；整体空间复杂度 O(N)。
- 控制器为 512 维 MLP，额外开销极小；潜在注入引入与前缀长度 L 线性相关的固定注意力开销。
- 理论命题：
  - **命题 10.5（因果解耦）**：在拓扑域隔离假设下，路径激活使无关历史混杂与当前动作的互信息归零，消除跨任务泄漏。
  - **命题 10.6（有界动态树规模）**：在锚定阈值 τ 与剪枝率 ρ 下，期望活跃节点数有有限上界 O(1)。
  - **命题 10.7（信用分配稳定）**：冻结 LLM 并将优化视野从 token 级压缩到树深度级，方差上界按 (T_mem/T_token)² 二次降低。

## 6. 主要结论与发现

- **性能全面提升**：ActiveMem 在 9 个基准上均取得最优或次优结果。例如 SmolLM3-3B 上 GRPO 变体 ALFWorld 73.26、TriviaQA 86.14、KodCode 84.02、BigCodeBench 92.26；Qwen3-8B 上 ALFWorld 95.57、GPQA 54.49。

- **记忆效率显著**：多目标 16 跳任务中，ActiveMem 仅用 14B 基线 27.1% 的 peak token 和 29.3% 的推理时间，却取得更优性能；Peak Token 随任务复杂度近乎恒定。
- **泛化能力强**：单域训练后跨域迁移（如 ALFWorld→FEVER、KodCode→MATH）性能下降远小于 SFT/MemoryBank/MemGen，说明其学到的是过程逻辑而非表层语义。
