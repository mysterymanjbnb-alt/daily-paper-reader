## 摘要
联邦学习为多个机器人共同改进操作策略提供了一种自然途径，无需集中访问训练示范。然而，非独立同分布的任务和环境分布可能导致表示漂移以及相互不兼容的机器人策略更新，使得朴素的参数聚合具有破坏性。我们提出 FedDRMan，一个用于异构机器人操作的联邦子空间引导蒸馏框架。在每个通信轮次，服务器模型提供一个冻结的教师模型用于本地行为克隆，同时低秩多模态子空间和动作分布蒸馏保留全局有用的表示几何与策略行为。为解决异构聚合问题，FedDRMan 根据更新兼容性对客户端分组，并为每个聚类维护一个持久模型。服务器随后对每个兼容聚合进行谱重平衡，以缓解较弱的任务相关机器人策略更新方向的衰减。在 LIBERO 上跨多种非独立同分布设置、异构程度、客户端参与变化进行的广泛实验，以及消融和聚合分析，表明 FedDRMan 显著改进了知识迁移，并持续优于强联邦基线，达到 80.7% 的峰值平均成功率，比评估中最强的联邦基线高出 11.6 个百分点。

## Abstract
Federated learning offers a natural way for multiple robots to jointly improve manipulation policies without requiring centralized access to training demonstrations. However, non-IID task and environment distributions can induce representation drift and mutually incompatible robot-policy updates, making naive parameter aggregation destructive. We present FedDRMan, a federated subspace-guided distillation framework for heterogeneous robot manipulation. At each communication round, the server model provides a frozen teacher for local behavior cloning, while low-rank multimodal subspace and action-distribution distillation preserve globally useful representation geometry and policy behavior. To address heterogeneous aggregation, FedDRMan groups clients by update compatibility and maintains a persistent model for each cluster. The server then spectrally rebalances each compatible aggregate to mitigate attenuation of weaker task-relevant robot-policy update directions. Extensive experiments on LIBERO across diverse non-IID settings, heterogeneity levels, client participation variation, together with ablations and aggregation analyses, show that FedDRMan substantially improves knowledge transfer and consistently outperforms strong federated baselines achieving a peak mean success rate of 80.7%, 11.6 percentage points above the strongest evaluated federated baseline.

## 一、核心问题与研究动机

- **背景**：Vision-Language-Action（VLA）策略在语言条件化机器人操作上进展显著（RT-2、OpenVLA-OFT、Open X-Embodiment 等），但主流训练范式仍假设不同机器人的示范数据可以集中汇聚训练。这一假设在多机器人系统中代价高昂：反复上传原始轨迹通信开销大，且可能泄露用户、机器人位置、运行环境等敏感信息。
- **联邦学习的天然适配性**：FL 让各机器人仅交换模型更新而非原始数据，从而在保护数据的前提下共享知识。然而，非 IID 的任务与环境分布（例如一台机器人只做物体中心的抓放，另一台做不同场景/视角下的目标条件任务）会带来两类耦合问题：
  1. **局部适配中的多模态表示漂移**：本地行为克隆（BC）会把视觉、语言、本体感受表示拉向客户端特有的特征分布；
  2. **服务器聚合中的更新互斥**：直接参数平均会压制任务相关知识，使全局策略在异构任务/环境上表现退化。
- **研究空白**：现有异构 FL 工作多聚焦单模态或非机器人场景；知识蒸馏、表征几何/子空间结构保留、谱模型合并等方法主要面向序列学习或一次性集中式模型合并，而非"反复局部适配 + 周期性异构更新整合"的联邦 VLA 训练。FLAME 是基准而非异构专用方法，FedVLA 依赖 MoE 专家路由与专家级聚合，未直接针对多模态表示漂移与客户端更新几何不兼容问题。
- **整体含义**：论文提出 **FedDRMan**（Federated Subspace Guided VLA Policy Distillation for Non-IID Multi-Robot Manipulation），在**不增加通信负载**的前提下，同时约束局部适配的表示漂移与服务器端聚合的破坏性干扰。

## 二、方法论

### 2.1 问题形式化
- 联邦 K 个机器人共享语言条件操作设定，建模为有限时域 MDP `M = (S, A, T, H, μ0, φ)`，φ 为稀疏目标谓词。
- 每个客户端拥有私有示范集 `Dk = {τ_ki}`，观测 `o` 含 agent-view RGB、wrist RGB、关节状态与夹爪状态；策略为语言条件 GMM 策略 `πθ(a|o,D)`。
- 全局目标为加权经验风险最小化 `min_θ Σ_k p_k E_{Dk}[L_k]`，`p_k = n_k / Σ_j n_j`。

### 2.2 联邦子空间引导的全局到局部蒸馏（客户端侧）
- **冻结教师**：每轮服务器模型 `θ^r_g` 被复制为冻结教师 `θ̄^r_g`（梯度为 0）与可训练学生 `θ^{r,0}_k`，教师在本轮内固定，聚合后刷新。
- **局部 BC 项**：`L_BC = -E[log π_{θk}(a|o,D)]`，驱动对本地专家的适配。
- **多模态低秩子空间蒸馏**：对每个模态 `m ∈ {text, agent, wrist, joint, gripper}`，将 batch-time 编码器特征堆叠为 `F^x_m ∈ R^{dm×N}`（N=BT，x∈{g,k}），做降秩 SVD 得到秩 `r_m` 的正交投影算子 `P^x_{r_m} = U_{x,r_m} U_{x,r_m}^T`；为数值稳定在 SVD 前加小扰动。
  - 对称子空间损失：`L^m_sub = ||P^g F^g - P^k F^k||_F^2 + ||P^g F^k - P^k F^g||_F^2`，第一项对齐教师/学生子空间保留的特征内容，第二项强制对称交叉投影一致性。保留主导子空间结构、放开低能量方向供机器人特异适配。
- **动作分布蒸馏**：从教师采样 `â ~ π_{θ̄}`，最小化教师与学生的对数概率差 `L_act = E[log π_{θ̄}(â|o,D) - log π_{θk}(â|o,D)]`，对数概率做数值裁剪。
- **总损失**：`L_k = L_BC + Σ_m λ_m L^m_sub + λ_act L_act`，仅对学生反向传播。

### 2.3 兼容性谱联邦聚合（服务器侧）
- **兼容更新聚合（CUA）**：
  - 以相对公共初始化的**累积更新** `Δ^r_k = θ^r_k - θ^0` 的向量化（限定共享子模块 Ω，本文用 temporal Transformer）计算客户端两两余弦相似度 `S^r_ij`；使用累积更新而非逐轮增量，因后者信号递减、不稳定。
  - 将 K 个客户端划分为 C 个非空簇，目标为最大化簇内平均相似度、最小化簇间平均相似度（式 11）。
  - 簇内按样本量重归一化权重 `ẽp_k`，聚合**完整本地模型**得 `θ^{r+1}_{avg,s}` 与簇更新 `Δ^r_s`；服务器维护 C 个持久簇模型。
- **谱重平衡（SRB）**：针对符合条件的二维权重矩阵块，对 `Δ^r_{s,b}` 做 SVD，按累积奇异值阈值 β 确定 `c* = min{i : Σ_{j≤i}σ_j / Σσ_j ≥ β}`，将小于 `σ_{c*}` 的奇异值提升到 `σ_{c*}`（`σ̃_i = max(σ_i, σ_{c*})`），重组得 `Δ̃^r_{s,b}`，`θ^{r+1}_s = θ^r_s + Δ̃^r_s`。作用范围包括图像空间投影器、语言与本体感受编码器、时序 Transformer、策略头中的线性权重矩阵，其余参数保持簇内平均更新。
- **理论解释**：把 `δ^r_k = C^r_s + U^r_k` 分解为簇内共享分量与机器人特异分量，聚合后特异分量的平方范数在正交假设下衰减为 `O(K_eff^{-1})`（范数 `O(K_eff^{-1/2})`）；一般情形下含交叉项 `2Σ_{i<j} ẽp_i ẽp_j ⟨U_i,U_j⟩_F`，即**簇内正对齐可通过交叉项保留更新能量**。CUA 旨在促进聚合前的兼容性，SRB 再强化被衰减的弱谱方向。
- **通信成本**：聚类与 SRB 全部在服务器完成，客户端—服务器载荷与 FedAvg 相同。

## 三、实验设计

- **数据集/场景**：LIBERO 三个标准套件 —— **LIBERO-Spatial、LIBERO-Object、LIBERO-Goal**，每套件 10 个语言条件操作任务、每任务 50 条专家示范（约 62,250 / 74,507 / 63,728 条训练序列）；每样本含两路 RGB、语言指令、本体状态与 7 维连续动作序列。
- **非 IID 设置**：
  - **同套件任务非 IID**：K=5 客户端，Dirichlet(α=0.5) 划分任务序列，制造任务与数量双重偏斜，同一套件内所有方法共用同一划分。
  - **跨套件任务与环境非 IID**：Object-Goal、Object-Spatial、Goal-Spatial 用 K=4（每套件 2 客户端）；三套件 Object-Goal-Spatial 用 K=6（每套件 2 客户端），形成任务族、物体、环境、状态-动作分布双重异构。
- **策略架构**：LIBERO ResNet-T（ResNet 视觉编码器 + FiLM 语言条件 + 预训练 BERT 嵌入 + 时序 Transformer + GMM 动作头），约 5.38M 参数；选它是因为基准表现强且参数量适中，适合 FL 通信。
- **训练/评测协议**：50 轮通信、每轮 1 个本地 epoch、batch size 32、AdamW（lr 1e-4、weight decay 1e-4、梯度裁剪 100）；每 5 轮用每任务 10 次 rollout 选检查点，最终用每任务 20 次随机 rollout、250 步闭环 MuJoCo 仿真，报告成功率（SR），3 个随机种子平均。
- **超参**：子空间秩 48、蒸馏权重 1.0、SVD 稳定噪声 0.01；模态权重语言/视觉/本体 0.03、动作蒸馏 0.005；C=1（同套件）、C=2（两套件）、C=3（三套件）；β 按设置取 0.85–0.90。
- **对比基线**：(i) Centralized（汇聚数据做 BC）；(ii) Local（纯本地）；(iii) FedAvg；(iv) FedProx（μ=1e-3）；(v) FedKD（FedKD-A 自适应互蒸馏）；(vi) FedVLA（Dual-Gating MoE + 专家驱动聚合，改用 GMM NLL 目标以公平适配连续动作）。

## 六、主要结论与发现

- **同套件任务非 IID**：FedDRMan 平均 SR 达 **80.7%**，FedAvg 69.1%；在 Object（88.0% vs 75.2%，+12.8pp）与 Spatial（82.0% vs 62.0%，+20.0pp）上最优；Goal 为 72.0%，与 FedProx 持平、超 FedAvg 2.0pp。相比 FedKD 在 Object/Goal/Spatial 分别高 68.0/16.0/38.0pp，说明单纯蒸馏基线在强异构下不足。最佳表现普遍出现在第 40 轮。
- **跨套件任务与环境非 IID**：传统方法大幅失效（FedAvg 均值 9.3%、FedProx 6.9%、FedKD 7.6%），FedDRMan 均值 63.3%，甚至超过 Centralized BC（58.0%）。Object-Goal 达 85.0/70.0%，Object-Spatial 达 95.0/45.0%；Goal-Spatial 更具挑战，Goal 最优但 Spatial 仅持平；三套件设置整体下降（Goal 退化最大），但仍显著优于 FedAvg/FedProx。论文摘要与结论中"高出最强联邦基线 11.6 个百分点"对应 80.7% 与 69.1% 之差。
- **逐任务分析**：30 个任务中 23 个任务优于或持平 FedAvg；LIBERO-Spatial 上多个任务从 0% 提升到 100%（如 On Stove、Next to Plate、In Top Drawer）。
