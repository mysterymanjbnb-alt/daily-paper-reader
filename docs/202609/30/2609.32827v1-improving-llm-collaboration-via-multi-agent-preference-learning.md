## 摘要
已有若干研究探索了LLM协作中的多智能体强化学习（MARL）。然而，在实践中构建可靠的奖励十分困难，因为完整且准确的指标往往不可获得，且难以聚合。偏好学习通过从人类或AI的比较性反馈中学习，提供了一种替代方案。然而，将其扩展到多智能体系统仍研究不足。为弥补这一空白，我们从去中心化和中心化协作的视角形式化基于偏好的多智能体系统（MAS）。我们还提出一个通用的多智能体偏好学习框架（MAPL）来解决这些问题。MAPL通过将当前解与由不同智能体生成的去中心化或中心化解进行比较，从而允许迭代更新。我们使用带学习奖励模型的基于人类反馈的MARL（MARLHF）和多智能体直接偏好优化（MADPO）来实例化MAPL。在协作写作、编程、工具使用和旅行规划上的实验表明，MAPL能够提升协作质量与效率，同时接近具有固定且定义明确的奖励的MARL的性能。在MAPL中，MARLHF在大多数任务上通常优于MADPO，但仍对数据覆盖范围、智能体与比较器模型以及底层MARL算法较为敏感。

## Abstract
Several works have explored multi-agent reinforcement learning (MARL) in LLM collaboration. However, constructing reliable rewards is difficult in practice, as complete and accurate metrics are often unavailable and hard to aggregate. Preference learning provides an alternative by learning from comparative human or AI feedback. Yet, its extension to multi-agent systems remains underexplored. To address this gap, we formulate preference-based multi-agent systems (MAS) from decentralized and centralized collaboration perspectives. We also introduce a general multi-agent preference learning framework (MAPL) to solve these problems. MAPL allows iterative updates by comparing the current solution with decentralized or centralized solutions generated by various agents. We instantiate MAPL using MARL from human feedback (MARLHF) with a learned reward model and multi-agent direct preference optimization (MADPO). Experiments on collaborative writing, coding, tool use, and travel planning show that MAPL can improve collaboration quality and efficiency while approaching the performance of MARL with fixed, well-defined rewards. Within MAPL, MARLHF generally outperforms MADPO on most tasks but remains sensitive to data coverage, agent and comparator models, and the underlying MARL algorithms.

## 1. 核心问题与整体含义
- **研究动机**：LLM 智能体常通过多智能体系统（MAS）协作完成复杂任务，但现有基于多智能体强化学习（MARL）的 LLM 协作方法多依赖人工设计的、领域特定的奖励函数。这类奖励往往不完整、不准确或难以聚合，导致优化目标与真实任务目标不一致。
- **替代方案**：偏好学习可从人类或 AI 的比较性反馈中学习，无需显式奖励工程。然而，偏好学习在多智能体 LLM 协作中的扩展仍研究不足，主要挑战包括：
  - 多智能体策略空间组合爆炸，偏好数据难以充分覆盖；
  - 缺少面向多智能体协作的标准偏好数据集；
  - 从偏好中学习到的奖励估计可能不准确、高方差，且训练非平稳。
- **整体含义**：论文从去中心化与中心化协作两个视角形式化基于偏好的 MAS，提出通用框架 **MAPL**（Multi-Agent Preference Learning），并通过 MARLHF 与 MADPO 两种实例化，验证了偏好学习可有效优化 LLM 协作，并在多个任务上接近使用固定、明确奖励的 MARL 性能。

## 2. 方法论
### 2.1 问题形式化
- **去中心化协作**：建模为 **Pb-Dec-POMDP**，包含智能体集合、状态、局部观测、动作、转移、观测函数、潜在 oracle 奖励、时域、初始信念与偏好函数。每个智能体仅基于局部观测-动作历史生成响应，联合动作形成解。
- **中心化协作**：建模为 **Pb-MPOMDP**，采用集中信息结构，智能体或协调者基于完整联合历史行动。
- **学习目标**：最大化期望累积潜在奖励。偏好由标注者根据 oracle 奖励对两条轨迹比较得到，产生胜者与败者轨迹。

### 2.2 MAPL 框架
- **核心思想**：迭代地让当前智能体策略生成联合解，并与 comparator 策略生成的解配对，由标注者给出偏好，选取高质量偏好对进入 replay buffer，再更新智能体策略。
- **流程**：
  1. 初始化阶段收集联合历史与轨迹，构造初始偏好数据集 \(D^{(0)}\)，按胜者回报选 top-k 进入 replay buffer \(B^{(0)}\)。
  2. 每轮迭代 \(\nu\)，当前策略采样 \(m\) 条轨迹，comparator 采样 \(m\) 条轨迹，配对标注偏好，构造 \(D^{(\nu)}\)，选 top-k 进入 \(B^{(\nu)}\)。
  3. 使用 \(B^{(\nu)}\) 进行策略优化，直到最大迭代次数。
- **三种范式**：
  - **Dec-Dec**：去中心化智能体 + 去中心化 comparator；
  - **Cen-Cen**：中心化智能体 + 中心化 comparator；
  - **Dec-Cen**：去中心化智能体 + 中心化 comparator。

### 2.3 两种实例化方法
- **MARLHF（两阶段）**：
  - 先学习基于历史的奖励模型 \(\tilde{R}_\psi(h_t,a_t)\)，用 Bradley-Terry 模型和偏好对训练，损失为胜者与败者累计预测奖励差的 log-sigmoid。
  - 固定奖励模型后，用 group-relative Monte Carlo 方法优化策略。对每个任务采样 \(G\) 条轨迹，以组内平均预测奖励为 baseline 构造组相对优势，并加入 KL 正则项；采用 stop-gradient 处理 log-ratio 权重。
  - 去中心化时分别对每个智能体参数求梯度，中心化时对协调者参数求梯度。
- **MADPO（一阶段）**：
  - 直接优化策略，不显式拟合奖励模型。隐式奖励为 \(\eta \log \frac{\pi_\theta(a|h)}{\pi_{ref}(a|h)}\)。
  - 基于 Bradley-Terry 模型，最小化胜者与败者累计隐式奖励差的 log-sigmoid 损失。
  - 去中心化时每个智能体只优化自身局部历史对应的偏好边际贡献；中心化时优化协调者参数。
- **稳定性设计**：动态 replay buffer、λ-decay 采样、组相对优势、mini-batch SGD，避免在 LLM 大规模动作空间中使用价值方法或难以拟合的 critic。

## 6. 主要结论与发现
- **MAPL 可有效优化 LLM 协作**：在协作写作、编码、工具使用和旅行规划中，MAPL 提升协作质量与效率，并接近使用固定、明确奖励的 MARL 性能。

- **范式比较**：Cen-Cen 在多数领域表现最佳，因中心化智能体可利用更完整信息；Dec-Dec 经调优后也表现强劲，小模型合作可超过更大单模型；Dec-Cen 通常较差，存在 comparator 与智能体之间的信息与可实现性差距。

- **消融发现**：
  - λ-decay replay buffer 多数情况下最佳；online 通常优于 offline。
  - 更大或中心化 comparator 不一定更好，容量差距可能导致训练收益下降。
  - MAGRPO 显著优于 CoLLM-CC 和 CoLLM-DC。
  - 更大规模 MAS 的收益高度依赖任务。

## 7. 优点
- **问题形式化清晰**：首次系统地从去中心化与中心化视角形式化基于偏好的多智能体 LLM 协作，提出 Pb-Dec-POMDP 与 Pb-MPOMDP。
- **通用框架**：MAPL 不绑定具体算法，兼容 MARLHF 与 MADPO，并支持多种 comparator 与采样策略。
- **方法设计稳健**：引入动态 replay buffer、λ-decay、组相对 Monte Carlo 和 KL 正则，缓解偏好数据稀疏与奖励估计高方差问题。

## 8. 不足与局限
- **偏好来源局限**：实验使用确定性 oracle 奖励生成偏好，而非真实人类或 AI 反馈，真实场景中的噪声、主观性和覆盖偏差未被充分检验。
- **计算开销大**：MAPL 需要额外 rollout 收集偏好，训练成本高于标准 MARL 微调；MADPO

在 Travel 等困难任务上易崩溃，说明一阶段方法对任务难度和超参数更敏感，稳定性不如两阶段方法。
- **信用分配仍较粗粒度**：偏好信号多为轨迹级或联合轨迹级，去中心化设置下虽尝试分解为局部边际贡献，但仍难以精确归因每个智能体在协作中的具体作用，可能限制策略优化的精细度。
- **可扩展性验证有限**：论文仅初步探索三智能体场景，随着智能体数量增加，联合策略空间与偏好组合会进一步爆炸，MAPL 的采样、筛选和训练成本可能迅速上升。
- **理论分析不足**：论文未提供收敛性、样本复杂度或偏好噪声对策略优化影响的理论保证，经验性结论较多。
- **评估偏差风险**：偏好由确定性 oracle 奖励生成，而非真实人类或 AI 反馈；部分任务还在过滤后的子集上评估，可能高估方法在开放、噪声环境中的鲁棒性，且缺少真实用户研究。
- **方法选择缺少明确准则**：MARLHF 性能较强但对数据覆盖、comparator 和底层 MARL 算法敏感；MADPO 更高效但易不稳定。实际应用中如何根据任务、模型规模和算力选择范式与实例化方法，论文未给出系统指导。
