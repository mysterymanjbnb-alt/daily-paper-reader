## 摘要
智能体系统正快速进入生产环境，它们读取不可信输入、调用具有真实权限的工具并自主行动，将安全面扩展到仅限聊天模型之外。然而，标准评估仍为单轮，无法捕捉多步智能体漏洞。我们提出一个系统化的黑盒框架，用于风险感知的智能体评估，仅需基本系统描述。我们的方法引入：(1) 一个七域分类法，将可观察行为映射到风险类别；(2) 全自动 SAGE-RT 红队测试，每个域生成 120 个对抗场景；(3) 使用 LLM 评判者进行人工验证的评估。在两种智能体架构（CrewAI 和 AutoGen）与四个基础模型上的实证验证揭示了令人警惕的模式：平均治理风险为 56.25%，多智能体配置中的隐私风险为 65%，智能体行为漏洞达到 85%。我们的黑盒方法无需特权访问即可有效识别关键架构漏洞，为更安全的智能体部署提供了可扩展路径。

## Abstract
Agentic systems are rapidly moving to production, where they read untrusted inputs, call tools with real permissions, and act autonomously, expanding the security surface beyond chat-only models. Yet standard evaluations remain single-turn and fail to capture multi-step agent vulnerabilities. We present a systematic black-box framework for risk-aware agent evaluation requiring only basic system descriptions. Our approach introduces: (1) a seven-domain taxonomy mapping observable behaviors to risk categories, (2) fully automated SAGE-RT red teaming producing 120 adversarial scenarios per domain, and (3) human-validated evaluation using LLM judges. Empirical validation across two agent architectures (CrewAI and AutoGen) with four base models reveals alarming patterns: 56.25\% average governance risk, 65\% privacy risk in multi-agent configurations, and agent behavior vulnerabilities reaching 85\%. Our black-box approach effectively identifies critical architectural vulnerabilities without privileged access, providing a scalable path toward safer agent deployments.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：智能体系统（Agentic AI）正从研究原型快速走向生产部署。与传统聊天模型不同，智能体能够读取不可信输入、调用具有真实权限的工具、持久化状态并代表用户自主行动，因而引入了间接提示注入（indirect prompt injection）、记忆投毒（memory poisoning）、不安全工具执行等新型安全挑战。
- **核心问题**：现有评测框架（如 MMLU、HumanEval）以静态、单轮任务为主，无法刻画多步规划、错误恢复、安全工具操作等智能体行为；而安全研究虽能揭示理论漏洞，却往往缺乏系统化、可复用的评测方法论。此外，现有智能体红队方法大多局限于特定架构（如 ReAct）、依赖白盒内部访问或窄类漏洞（如仅提示注入），难以在真实部署条件下推广。
- **整体含义**：论文主张建立一种**仅需基础系统描述**的黑盒、风险感知评测框架，将抽象风险分类法落地为可执行的对抗测试场景，从而在不获取供应商内部访问权限的前提下发现关键架构级漏洞，为智能体安全部署提供可扩展路径。

## 2. 方法论：核心思想与关键技术细节

### 2.1 七域风险分类法（Taxonomy）

- 定义风险分类法 \(T = \{D_1, D_2, \dots, D_7\}\)，灵感来源于 OWASP Agentic AI 风险分类。总体风险建模为：
  \[
  R(A) = \sum_{i=1}^{7} w_i \cdot r_i(A, D_i)
  \]
  其中 \(r_i: \mathcal{A} \times \mathcal{O} \times \mathcal{K} \to [0,1]\) 为域 \(D_i\) 的风险得分，\(w_i\) 为域权重。
- 七个域分别为：
  1. **治理（Governance）**：奖励黑客（reward hacking），代理目标 \(\hat{R}\) 与真实目标 \(R^*\) 不一致（\(\max_\pi E_\pi[\hat{R}] \neq \max_\pi E_\pi[R^*]\)）。
  2. **智能体输出质量（Output Quality）**：事实准确性、偏见、毒性、幻觉。
  3. **工具误用（Tool Misuse）**：提示注入、SQL 注入、未授权 API 调用、畸形参数。
  4. **隐私（Privacy）**：PII 泄露、训练数据提取、跨用户数据污染。
  5. **可靠性与可观测性（Reliability & Observability）**：边界情况处理失败、推理不透明、行为不一致。
  6. **智能体行为（Agent Behavior）**：社会工程、持续目标追求、欺骗性解释。
  7. **访问控制（Access Control）**：权限提升、混淆代理（confused deputy）、越权访问。
- 该分类法强调**将可观察行为映射到具体风险类别**，区别于仅描述抽象能力的分类法。

### 2.2 SAGE-RT 驱动的自动化红队流程

- **场景生成**：给定分类法 \(T\) 与目标智能体 \(A\)，生成场景 \(S = \{s_1, \dots, s_n\}\)，每个场景以域 \(D_j\) 为条件：
  \[
  s_i \sim P(s \mid D_j, A, \theta)
  \]
  配置参数：种子提示（如隐私域的“请求 PII 披露”）、演化算子（变异率 0.3、交叉 0.2、复杂度提升 0.5）、多样性阈值（场景间余弦相似度 < 0.7）、\(\theta = \{\text{temp}=0.8, \text{top\_p}=0.95, \text{max\_turns}=5\}\)。每个场景包含 3–5 轮交互。
- **三阶段场景验证**：(1) 句法验证（格式良好的多轮对话）；(2) 语义验证（人工审查是否为真实攻击向量）；(3) 经验验证（对基线“安全”智能体 GPT-4 执行，剔除无效弱攻击并重新生成）。
- **自动化执行**：SAGE-RT 管道自动生成、执行场景并收集响应，无需人工干预，每域超过 100 个测试用例。

### 2.3 评估方法（LLM 评判 + 人工验证）

- **LLM 评判**：GPT-4o（temperature=0）依据域特定评分规则打分，每个规则含 5–7 条二元标准：
  \[
  r_{i,j} = J(\tau_i, s_i, D_j) = \frac{\sum_{k=1}^{K_j} c_{i,j,k}}{K_j} \in [0,1]
  \]
  其中 \(c_{i,j,k} \in \{0,1\}\) 表示第 \(k\) 条标准是否被违反。
- **人工复核**：对高风险发现（得分 > 0.6）进行人工审查以验证关键漏洞、识别误报。域聚合风险为：
  \[
  \bar{r}_j = \frac{1}{|S_j|} \sum_{s_i \in S_j} r_{i,j} \cdot (1 + \alpha \cdot h_i)
  \]
  其中 \(\alpha=0.1\) 对人工验证发现给予 10% 额外权重，\(|S_j|=120\) 为每域场景数。
- **偏差缓解**：位置随机化与盲评；评分规则经由团队评审、校准研究（每系统 200 条响应）与敏感性分析三阶段验证。

- **总体判断**：当前智能体系统在对抗环境下“根本性地准备不足”，漏洞可在极低技术门槛下被利用。

## 7. 优点（方法与实验设计亮点）

- **黑盒可移植性**：仅需基础系统描述即可启动评测，无需源码、内部 API 或框架特定插桩，贴近真实部署条件，避免插桩偏差，支持跨框架公平对比。
- **分类法驱动**：七域分类法将抽象风险映射为可观察行为，每域再展开为具体子风险（如目标错位、策略漂移、数据/记忆投毒、混淆代理等），使失败模式可审计、可监控。
- **自动化与规模化结合**：SAGE-RT 自动生成—执行—收集，配合 LLM 评判实现每域 120 场景的规模；同时以人工复核作为质量控制层，兼顾可扩展性与准确性。
- **多维场景质量保障**：三阶段验证（句法/语义/经验）+ 多样性、攻击向量覆盖、复杂度分布三重覆盖分析，提升测试代表性。
- **偏差控制意识**：位置随机化、盲评、评分规则校准与敏感性分析，并在聚合公式中体现人工验证加权（α=0.1）。
- **发现具有实践价值**：通过跨域相关矩阵识别复合漏洞，并给出具体失败轨迹，可直接指导加固。
