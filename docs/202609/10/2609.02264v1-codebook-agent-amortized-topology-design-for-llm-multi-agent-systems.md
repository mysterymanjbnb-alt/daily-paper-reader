## 摘要
针对每个查询自适应调整LLM多智能体系统的通信拓扑，可同时提升准确率和效率，但当前设计者将其视为条件图生成：变分、自回归或扩散解码器在N×N邻接空间中搜索，并在效用和诸如边数之类的结构成本上训练的图网络代理模型对采样候选进行排序。我们认为，这种表述与问题本身并不契合。经验上，即使码本容量从8增长到64，能够通过奖励过滤器的拓扑也会坍缩为约六种不同的图；边数与实测token消耗呈负相关（Pearson r ≈ -0.4），因此稀疏化图反而使推理更昂贵；并且，当智能体共享画像时——这是已发表基准的默认配置——基于智能体画像节点的消息传递评分器具有邻接不变性，因此在该情形下根本无法对候选进行排序。这三个事实促成了Codebook Agent：一个矢量量化自编码器将成功拓扑压缩为与查询无关的16项码本；一个奖励加权MLP将查询嵌入映射为码上的分布；以及一个读取展平邻接的MLP代理，它以实测效用和按任务归一化的token成本为回归目标，在单次批量前向传播中对排名靠前的解码候选重新排序。在测试时无需迭代搜索和消息传递，Codebook Agent在我们比较的全部六个基准上都是最准确的方法（平均84.6，而最强先前设计器为83.0），在2.4毫秒内输出一个拓扑，并少用21.9--33.2%的LLM token。

## Abstract
Adapting the communication topology of an LLM multi-agent system to each query improves both accuracy and efficiency, yet current designers treat this as conditional graph generation: a variational, autoregressive, or diffusion decoder searches the $N \times N$ adjacency space, and a graph-network proxy trained on utility and a structural cost such as edge count ranks the sampled candidates. We argue that this formulation is misaligned with the problem. Empirically, topologies that survive a reward filter collapse to about six distinct graphs even when the codebook capacity grows from 8 to 64; edge count is negatively correlated with measured token consumption (Pearson $r \approx -0.4$), so sparsifying the graph makes inference more expensive; and a message-passing scorer over agent-profile nodes is adjacency-invariant whenever agents share a profile---the default configuration of published benchmarks---so it cannot rank candidates at all in that regime. These three facts motivate Codebook Agent: a vector-quantized autoencoder compresses successful topologies into a query-independent 16-entry codebook; a reward-weighted MLP maps the query embedding to a distribution over codes; and an MLP proxy that reads the flattened adjacency, regressed on measured utility and per-task normalized token cost, reranks the top decoded candidates in a single batched forward pass. With no iterative search and no message passing at test time, Codebook Agent is the most accurate method on all six benchmarks we compare (84.6 average against 83.0 for the strongest prior designer), emits a topology in 2.4 ms, and uses 21.9--33.2% fewer LLM tokens.

## 1. 核心问题与研究动机

- **背景**：LLM 多智能体系统通过通信拓扑交换中间输出，拓扑决定了哪些智能体看到哪些消息，直接影响准确率与 token 消耗。领域已从手工设计结构发展到学习结构，最近进一步发展到**查询条件生成器**——为每个输入生成新拓扑。
- **现有范式的共同假设**：将拓扑设计视为**条件图生成**问题，即用变分、自回归或扩散解码器在 \(N \times N\) 邻接空间中搜索，再用基于图网络的代理模型（同时回归效用与结构成本，通常是边数 \(|E|\)）对采样候选排序。
- **作者的核心质疑**：该形式化与问题本质不匹配。论文通过三项实证发现予以反驳：
  - **设计空间坍缩**：通过奖励过滤的拓扑仅坍缩为约 6 种不同图，即使码本容量从 8 增至 64；最佳固定拓扑与所有生成拓扑的准确率差距不超过 1.4 个点。
  - **成本代理反向**：边数与实测 token 消耗呈负相关（Pearson \(r \approx -0.4\)），稀疏通信反而导致更长补全，最小化 \(|E|\) 实际最大化成本。
  - **消息传递评分器失效**：在智能体共享画像的同质团队（已发表基准的默认配置）中，基于画像节点的消息传递评分器具有**邻接不变性**，所有候选得分相同，无法排序。
- **整体含义**：若问题本质是在少量图之间、以实测成本为目标进行选择，那么匹配的设计器不应是另一个生成解码器，而应是**摊销式索引与选择**机制。

## 2. 方法论：Codebook Agent

### 2.1 核心思想

将拓扑设计摊销为三个前馈组件，测试时**无迭代搜索、无消息传递**：

1. **矢量量化自编码器（VQ-VAE）**：将成功拓扑压缩为与查询无关的 16 项码本。
2. **奖励加权 MLP 预测器**：将查询嵌入映射为码本上的分布。
3. **执行接地 MLP 代理**：读取展平邻接，回归实测效用与按任务归一化的 token 成本，对解码候选重排序。

### 2.2 问题设置

- 团队含 \(N\) 个智能体，画像文本 \(p_1,\dots,p_N\) 由冻结句编码器嵌入为 \(x_i \in \mathbb{R}^d\)（\(d=384\)）。
- 拓扑为有向邻接矩阵 \(A \in \{0,1\}^{N \times N}\)，无自环；\(A_{ij}=1\) 表示智能体 \(i\) 输出给智能体 \(j\)，决策节点聚合最终答案。
- 执行返回效用 \(u(A,q) \in \{0,1\}\) 与 token 成本 \(\tau(A,q)\)。目标是生成器将查询嵌入 \(c=\mathcal{E}(q)\) 映射到最大化 \(R = u - \lambda \tilde{\tau}\) 的拓扑，\(\lambda=0.1\)，\(\tilde{\tau}\) 为按同任务平均 token 归一化的成本。
- **训练记录**：每个基准 50 个训练任务 × 6 个固定拓扑（complete、chain、star 及三个 Erdős–Rényi 样本），共 300 条元组 \((A_j, c_j, u_j, \tau_j)\)，全部由真实 LLM 智能体执行产生。

### 2.3 拓扑码本（VQ 自编码器）

- 展平非对角邻接 \(a = \mathrm{vec}(A) \in \{0,1\}^{N(N-1)}\)，编码为 \(z_e\)，通过最近邻量化到码本 \(\{e_k\}_{k=1}^K\)，其中 \(d_z=32\)，\(K=16\)。
- 码本用指数移动平均更新（衰减 0.99），承诺系数 \(\beta=0.25\)，直通梯度，50 批次未用码重初始化。
- 解码器将量化向量映射回边 logits，对角线固定为零，图保持有向。
- 损失：\(\mathcal{L}_{\text{vq}} = \mathrm{BCE}_w(\hat{a}, a) + \beta \|z_e - \mathrm{sg}[z_q]\|_2^2\)，正样本按零一比例加权以对抗稀疏性。
- **仅在 \(u_j > 0.5\) 的记录上训练**，使码本存储解决任务的拓扑；编解码器均不条件于查询，码 \(k\) 解码为固定二值拓扑 \(A^{(k)}\)。
- 训练 200 epoch，Adam，学习率 \(3\times10^{-4}\)，批大小 16。

### 2.4 奖励加权码预测

- 将训练记录通过冻结编码器与量化器得到码索引 \(k_j\)。
- 对每个条件 \(c\)，构造软目标：
  \[
  y_k(c) = \frac{\sum_{j:c_j=c,\,k_j=k} \exp(\gamma R_j)}{\sum_{k'} \sum_{j:c_j=c,\,k_j=k'} \exp(\gamma R_j)},\quad \gamma=2
  \]
  使概率质量集中在高奖励（即低成本、成功）的码上。
- 预测器 \(p_\theta(k|c)\) 为 MLP（\(d \to 256 \to 256 \to K\)，dropout 0.1），用软交叉熵 \(\mathcal{L}_{\text{pred}}\) 训练。**这是查询进入生成的唯一位置**。

### 2.5 执行接地 MLP 代理

- **动机**：同质团队下，当 \(x_1=\dots=x_N=x\) 时，任何消息传递层聚合相同特征，节点状态与池化分数均与 \(A\) 无关；均值/求和聚合器同样如此。因此不能用图网络评分。
- 代理为 MLP 读取展平邻接：
  \[
  f_\phi(A,c) = \mathrm{MLP}_\phi([\mathrm{vec}(A); c]) = (\hat{u}, \hat{c}) \in \mathbb{R}^2
  \]
- 直接回归实测目标：\(\mathcal{L}_{\text{rew}} = \frac{1}{|\mathcal{D}|}\sum_j [(\hat{u}_j-u_j)^2 + (\hat{c}_j-\tilde{\tau}_j)^2]\)。
- 由于数据稀疏，引入 VQGraph 风格的结构 token 辅助目标：单独训练一个重建量化器（\(K_{\text{tok}}=32\)），在增强拓扑池 \(A^+\)（静态族、八种密度的 Erdős–Rényi 图、单边扰动、平滑边剖面的 Bernoulli 采样，每条件上限 100）上拟合，辅助头预测软码分配 \(q\)，损失 \(\mathcal{L}_{\text{code}}\)。
- 总代理损失 \(\mathcal{L}_\phi = \mathcal{L}_{\text{rew}} + \lambda_{\text{code}} \mathcal{L}_{\text{code}}\)，\(\lambda_{\text{code}}=0.1\)；增强池仅用于辅助目标，奖励监督仅来自真实执行。
- 训练 200 epoch，Adam，学习率 \(10^{-3}\)，批大小 256。

### 2.6 单次推理

- 给定查询嵌入 \(c\)，取预测器下 top \(M=5\) 的码，解码并去重得到候选集 \(\mathcal{A}(c)\)。
- 选择 \(A^\star(c) = \arg\max_{A \in \mathcal{A}(c)} (\hat{u}(A,c) - \lambda \hat{c}(A,c))\)，所有候选在**一次批量前向**中评分。
- 生成成本：一次预测器前向、至多 \(M\) 次解码、一次密集代理前向——固定数量的矩阵乘法，无采样循环、无稀疏图构建、无测试时消息传递。
