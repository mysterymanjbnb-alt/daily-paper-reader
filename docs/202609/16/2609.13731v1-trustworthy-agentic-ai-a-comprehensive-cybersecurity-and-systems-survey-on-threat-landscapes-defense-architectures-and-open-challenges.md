## 摘要
从被动的基础模型向自主、目标导向的智能体AI系统的转变，通过将递归认知推理循环、持久记忆架构、实时工具执行平面与多智能体协作拓扑相耦合，带来了前所未有的能力。然而，将执行权限授予跨越文件系统、网络与云基础设施的概率性神经核心，会消解经典的安全边界：自然语言同时充当输入数据、内部控制代码与通信协议，从而暴露出图灵完备的攻击影响范围，其中不可信数据即代表可执行指令。本综述为可信智能体AI提供了一个全面的系统安全参考框架，综合了206项基础研究与监管标准。我们将通用智能体架构形式化为有状态的五元组，并建立涵盖security（安全性）、safety（安全）、隐私、可解释性、公平性与问责性的六维可信度分类体系。我们系统性地分析了执行内循环与交互平面上的威胁面，构建了融合双LLM隔离、基于能力的访问控制、内核eBPF探针与沙箱运行时的多层零信任纵深防御架构，梳理了标准化评估基准，并将技术控制措施映射至国际AI治理框架。

## Abstract
The transition from passive foundation models to autonomous, goal-directed agentic AI systems has introduced unprecedented capabilities by coupling recursive cognitive reasoning loops, persistent memory architectures, live tool execution planes, and multi-agent collaboration topologies. However, granting probabilistic neural cores execution authority across filesystems, networks, and cloud infrastructure dissolves classical security perimeters: natural language simultaneously serves as input data, internal control code, and communication protocols, exposing a Turing-complete blast radius where untrusted data represents executable instructions. This survey delivers a comprehensive systems-security reference framework for trustworthy agentic AI, synthesizing 206 foundational studies and regulatory standards. We formalize the general agent architecture as a stateful 5-tuple and establish a 6-dimensional trustworthiness taxonomy covering security, safety, privacy, explainability, fairness, and accountability. We systematically analyze threat surfaces across intra-execution loops and interaction planes, formulate a multi-layered zero-trust defense-in-depth architecture integrating Dual-LLM isolation, Capability-Based Access Control, kernel eBPF probes, and sandboxed runtimes, review standardized evaluation benchmarks, and map technical controls to international AI governance frameworks.

## 2. 方法论：核心思想与关键技术细节

### 2.1 系统级形式化框架

- **五元组架构**：将智能体形式化为有状态、离散时间的 5 元组
  - `A = ⟨C, M, T, E, Π⟩`
  - **C**：认知推理核心（由基础模型权重 θ 参数化）；
  - **M**：分层记忆子系统 `{M_work, M_episodic, M_semantic}`；
  - **T**：工具与行动平面，每个工具 `t_j = ⟨Schema_j, Exec_j, Perm_j⟩`；
  - **E**：外部操作环境（文件系统、网络、云 API、人类、对等智能体）；
  - **Π**：智能体执行策略/编排协议。
- **对抗性 POMDP 建模**：以 7 元组 `⟨S, A_act, T_trans, R, Ω, O, γ⟩` 刻画部分可观测执行过程，并用递归贝叶斯更新维护信念状态 `b_t(s)`（论文给出完整信念更新公式）。
- **对抗性信念发散**：安全漏洞被形式化为当不可信观测污染似然函数 `O(o_adv|s',a_t)` 时，真实状态分布与智能体内部信念分布的 KL 散度显著大于 0，从而将策略引向灾难性动作，却仍保持内部模型自信。

### 2.2 六维可信度分类体系（6-Dimensional Trustworthiness Taxonomy）

将可信度从静态统计属性重构为**动态的系统级操作保证**，包含六个维度（每维配有形式化不变式、验证方法与系统控制）：

1. **Security（机密性/完整性/可用性）**：如泄露优势 `Adv^leak_A(λ) ≤ negl(λ)`；
2. **Safety & Operational Robustness**：如不可逆动作需人类授权 `∀a_t ∈ T_irr, Exec(a_t) ⇔ Authorized_human(a_t)=True`；
3. **Privacy & Data Protection**：差分隐私约束、嵌入反演抵抗；
4. **Explainability & Verifiability**：神经符号 SMT 验证、行动-思维审计链、推理链忠实性；
5. **Fairness & Non-Discrimination**：人口统计均等、多智能体市场反串通；
6. **Accountability & Provenance**：基于 W3C DID 的不可否认签名、Merkle 审计树。
- **跨维度 Pareto 权衡**：安全性 vs 延迟、隐私 vs 任务效用、安全严格性 vs 创造性自主性（False Safety Rejection）。

### 2.3 全谱威胁建模（双平面）

- **执行内平面（Intra-Execution）**：
  - *感知层*：直接提示注入、目标劫持、对抗后缀（GCG/AutoDAN）、自动红队（PAIR/TAP）、多模态隐写与视觉越狱（`I_adv = I + δ`）；
  - *大脑层*：后门与"睡眠特工"、BadChain 思维链后门、幻觉雪球效应、线性 vs 搜索式规划的误差放大路径；
  - *行动层*：Shell 参数注入 RCE、混淆代理（Confused Deputy）、MCP 供应链攻击（工具抢注）。
- **交互平面（Interaction）**：
  - *环境*：间接提示注入（IPI）、Markdown 渲染侧信道零点击外泄、云元数据 SSRF（IMDSv1）、海绵样本 DoS；
  - *记忆*：RAG/向量库投毒（<5 篇文档可达 >90% top-1 劫持）、嵌入反演（可重构 >70% 原文）、跨会话上下文渗漏；
  - *多智能体*：级联错误放大（>65% 流水线崩溃）、Morris II 自复制 AI 蠕虫（`dI/dt = βS(t)I(t) − γI(t)`）、Agent Smith 传染性越狱、拜占庭共识颠覆（`f ≥ n/3`）、Sybil 渗透与策略性欺骗。

### 2.4 零信任纵深防御架构（4 层 + 硬件层）

- **Layer 1｜执行前与认知护栏**：Dual-LLM Inspector-Executor 隔离、Tokenizer 级指令-数据注意力分隔（注意力掩码使数据 token 无法影响指令 token）、运行时语义护栏（NeMo Guardrails、Llama Guard、SmoothLLM、Constitutional AI）。
- **Layer 2｜记忆完整性与密码学溯源**：签名向量嵌入 `Σ = Sign(H(d) ‖ E(d) ‖ Timestamp ‖ AuthorID)`、Merkle 审计树 `Root_t = H(Root_{t-1} ‖ H(th_t ‖ a_t ‖ o_t))`、差分隐私噪声注入。
- **Layer 3｜系统沙箱与最小权限执行**：能力令牌 CapBAC `⟨AgentID, ToolURI, Scope, Expiry, Sign⟩`（TTL < 60s）、Firecracker/gVisor 微 VM、WebAssembly 沙箱、内核 eBPF 系统调用实时探针。
- **Layer 4｜多智能体零信任协议**：W3C DID + mTLS（TLS 1.3）、PBFT 共识（`n ≥ 3f + 1`）、熔断器与自动隔离。
- **硬件辅助机密计算**：TEE（Intel SGX、AMD SEV-SNP、ARM TrustZone、NVIDIA 机密 GPU）。

## 6. 主要结论与发现

- **自然语言即控制代码**是智能体安全的根本性架构缺陷，经典数据-指令分离在智能体中被彻底消解，形成图灵完备攻击面。
- **可信度必须重新定义**：从静态 ML 基准指标转向动态、系统级、具备执行代理与持久状态的操作保证，即六维分类体系。
- **威胁是全谱且跨层的**：从执行内（提示注入、后门、幻觉、参数注入、SSRF）到交互面（IPI、RAG 投毒、嵌入反演、蠕虫、拜占庭颠覆），单一防护无法覆盖。
- **防御必须纵深、零信任、多机制协同**：Dual-LLM 隔离 + CapBAC + eBPF + 微 VM + 签名向量 + Merkle 审计 + BFT 共识 + TEE 的组合，而非依赖脆弱的提示工程或启发式过滤。
- **无免费午餐**：各防御机制存在显著的延迟、token 放大与部署成本权衡（如 Dual-LLM 延迟 +1.5–3.0s、2× API 成本；PBFT 为 O(n²) 网络开销）。
- **治理与技术需对齐**：技术控制可映射至 NIST AI RMF、EU AI Act（Art. 9/10/12/14）、ISO/IEC 42001、OWASP Top 10 for Agentic AI。
- **六大开放研究前沿**：神经符号行动链形式化验证、终身动态对齐与非可逆副作用困境、大规模拜占庭群体共识、机器速度网络攻防（防御优势）、集群调度与爆炸半径 Pareto 优化、去中心化价值生态与 ZK-ML 代理证明。

## 8. 不足与局限

- **缺乏原创实验验证**：作为综述，未对提出的零信任防御架构进行端到端实测，所有防御效能数据均来自二手文献，缺乏统一实验台架的横向验证。

- **防御架构的工程可行性存疑**：四层全栈叠加（Dual-LLM + SMT + eBPF + 微 VM + PBFT + TEE）在高频/实时场景下的实际吞吐与成本尚未验证，可能超出多数生产环境承受能力。
