## 摘要
设计有效的记忆机制对于推进 LLM 驱动的多智能体系统（MAS）至关重要，有助于智能体共同学习并随着时间推移表现更好。尽管近期工作已带来强大的协作能力，但大多数方法仍使用扁平、无结构的记忆，这类记忆容易被噪声填满并抹除智能体之间的差异。为解决这一问题，我们引入集体-个体记忆协同的概念，并提出 CoMem，一种统一私有经验与共享知识以用于多智能体学习的架构。CoMem 具有以下特点：(i) 私有经验沉淀，允许每个智能体随时间保留并更新自身有用的记忆；(ii) 集体智慧策展，仅精心挑选被广泛验证的观点在智能体之间共享；(iii) 并行双流检索，允许智能体同时从自身记忆和群体智慧中提取信息，并利用聚类确保多样性。在 ALFWorld 和 PDDL 基准上的实验表明，CoMem 取得了强劲的整体性能，并稳健地避免了记忆污染。

## Abstract
Designing effective memory mechanisms is crucial for advancing LLM-driven Multi-Agent Systems (MAS), helping agents learn together and perform better over time. While recent work has led to strong cooperation skills, most methods still use flat, unstructured memories, which easily get filled with noise and erase differences between agents. To address this, we introduce the concept of collective-individual memory synergy and propose CoMem, an architecture that unifies both private experience and shared knowledge for multi-agent learning. CoMem features:(i) Private Experience Sedimentation, which lets each agent keep and update its own useful memories over time;(ii) Collective Wisdom Curation, which carefully selects only widely proven ideas to be shared among agents;(iii)Parallel Dual-Stream Retrieval, which allows agents to draw both from their own memory and the group's wisdom, using clustering to ensure diversity.Experiments on ALFWorld and PDDL benchmarks show that CoMem achieves strong overall performance and robustly avoids memory pollution.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：LLM 驱动的多智能体系统（MAS）在复杂协作任务中表现突出，但多数现有方法在任务结束后即丢弃交互历史，缺乏跨任务的持续记忆机制，难以支撑长期学习与"群体智能"。
- **核心问题——记忆污染（Memory Pollution）**：现有共享记忆方案（如 MemoryBank、Generative Agents、G-Memory 等）普遍采用扁平、无结构的共享记忆池，导致两类相互强化的退化：
  - **噪声累积**：未经验证的试错行为、偶然成功等低质量记录不断写入共享池，稀释了记忆可靠性；
  - **行为同质化**：跨智能体的盲目读写使角色特定的策略轨迹被反复"平均化"，智能体丧失分工与专业化能力（论文形式化为不同智能体策略分布的 KL 散度随时间的极限趋于 0）。
- **核心主张**：可持续的集体智能不能仅靠"共享记忆"，而需要在**稳健的个体学习**与**有意义的群体知识**之间建立协同。论文借鉴人类社会"个体提议—集体筛选—共识结晶"的知识演化过程，提出**集体-个体记忆协同**的概念，并实现为 CoMem 架构。
- **整体意义**：为 LLM-MAS 提供一种结构化的双层记忆生态，在保留个体探索多样性的同时，仅让经过反复跨智能体验证的知识沉淀为群体共识，从而在持续学习场景中抑制记忆污染。

## 二、方法论

### 1. 核心思想
- 将记忆空间**解耦**为两层：每个智能体独占的私有记忆层（Private Layer）与全局共享的集体记忆池（Collective Pool），两者物理与逻辑隔离。
- 记忆单元通过统一的元数据结构表示：`m = ⟨doc_content, metadata⟩`，其中 metadata = {agent_name, S（效用分）, n_use（调用次数）, n_succ（成功次数）, ι_prom（晋升状态）}。
- 记忆以**双向通路**流动：新经验先进入私有层 → 经过滚动剪枝与经验晋升门控 → 合格条目复制进集体池 → 集体池中效用下降的条目被清除。

### 2. 私有经验沉淀（Private Experience Sedimentation）
- 每个 episode 结束后，智能体从执行轨迹 τ 中通过**基于 LLM 的反思蒸馏器**（Reflection Distiller）将原始噪声轨迹提炼为少量简洁、可操作的文本洞见，而非直接存储原始轨迹。
- 洞见存入私有记忆 M_priv^(i)，赋予初始效用分 S₀，计数器初始化为默认值。
- **严格访问控制**：按 agent 身份过滤条目，从存储层杜绝跨智能体污染。
- **滚动剪枝**：为每个私有条目维护连续未命中计数器 K_miss(m)；若某条目被检索并注入提示则归零，否则加一；一旦超过阈值 K_max 即永久删除。该机制在稀疏反馈环境下保持私有记忆紧凑且相关。

### 3. 集体智慧策展（Collective Wisdom Curation）
- **经验晋升门控**：私有条目 m 晋升到集体池需同时满足两个条件：
  - 被成功检索的 episode 总数 N_use(m) ≥ N_min（统计下限，防止偶然激活）；
  - 使用该条目时的平均任务得分 R̄_m 不低于环境全局滑动平均基线 R̄。
- 晋升后条目从原私有库移除，避免冗余。
- **集体条目的持续质量控制**：每个 episode 结束后对每个被检索的集体条目计算混合效用
  - U_t(m) = w · R_norm + (1 − w) · (1/|A_m|) · Σ_{a∈A_m} LLM_a(m)/L_max
  - 其中 R_norm 为归一化回合奖励，LLM_a(m) 为离线 LLM 给出的主观洞见质量分，w 为权重。
- 长期效用 S_t(m) 采用**指数移动平均（EMA）**更新：
  - S_{t+1}(m) = (1 − α) S_t(m) + α · (S_max · U_t(m))，并 capped 在 S_max。
- 效用持续低于自适应阈值的条目被系统性移除，保证集体池"精而可信"。

### 4. 并行双流检索（Parallel Dual-Stream Retrieval）
- 新任务初始化时，每个智能体**同时**从两个隔离仓库检索，避免顺序查找瓶颈，且不产生跨层污染。
- **私有流**：用语义嵌入相似度（RAG 式）从自身记忆中检索 top-k 相关条目，注入提示，提供个性化战术知识。
- **集体流 + 多样性过滤**：从集体池检索经经验验证的条目；由于多智能体可能收敛到相似洞见，引入**在线层次聚类**（hierarchical clustering），按语义距离分组并每组只选最具代表性的一条，构建简洁而多样的共识上下文，节省 token 空间并保留多元视角。

## 六、主要结论与发现

- **CoMem 一致性地取得最优或强竞争力表现**：在 MacNet 上 ALFWorld 从 79.85 提升至 89.55，PDDL 从 60.78 提升至 70.19；跨四框架平均绝对提升为 ALFWorld +8.02、PDDL +4.70 个百分点。即使在本身很强的 CARD 上仍有非平凡提升（84.33→90.30，70.01→72.74）。
- **传统共享记忆经常不如无记忆基线**：例如 DyLAN+PDDL 下 G-Memory 得 59.53（低于 No-memory 的 67.78），MetaGPT 降至 52.80；Voyager、MemoryBank 等也表现不稳定，印证了噪声累积与行为同质化的双重退化。
- **成本可控**：CoMem 以适度的 token 增量（主要来自并行双流检索与晋升验证）换取显著且一致的成功率提升，性价比优于多数协作基线。
- **检索深度存在领域依赖的最优值**：中等深度 k ∈ {3, 5} 稳健，k 过大会引入噪声、过小则上下文不足。
- **两层结构均不可缺**：去除集体层在 AutoGen+PDDL 上下降 12.03 分（74.44→62.41），去除私有层下降 9.34 分（74.44→65.10），说明私有层对抑制记忆污染的保护作用略强，但两层功能互补。
- **超参呈倒 U 形关系**：K_max = 5（PDDL）/ 6（ALFWorld）、α = 0.5 在两类任务上均为最优平衡点。
