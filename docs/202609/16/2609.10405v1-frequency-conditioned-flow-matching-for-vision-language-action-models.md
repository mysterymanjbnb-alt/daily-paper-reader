## 摘要
机器人动作是时间相关的轨迹，其频率分量编码不同尺度上的运动，并具有高度非均匀的能量分布。然而，基于流匹配（Flow Matching）的视觉-语言-动作（VLA）模型通常直接在时间坐标中生成动作，未显式建模或系统性地利用这种频率异质性。我们提出 FreqFM，一种面向 VLA 模型的频率条件化流匹配框架。它将动作频率从一种隐式的轨迹属性提升为贯穿整个生成流程的显式条件维度。具体而言，在 DCT 频率坐标下，FreqFM 构建频谱匹配的源分布，自适应地平衡不同频率上的目标函数，并利用相应的参考传输尺度约束逐频率的引导残差。FreqFM 可集成到现有的流匹配动作专家中，而无需改变 VLA 主干网络。在 LIBERO、LIBERO-Plus 和 VLA-Arena 上，FreqFM 持续提升性能，包括在 LIBERO-Plus 上取得 9.3 个百分点的提升，并进一步在六项真实机器人任务上证明了其有效性。

## Abstract
Robot actions are temporally correlated trajectories whose frequency components encode motion at different scales with highly non-uniform energy distributions. Yet Flow Matching--based vision-language-action (VLA) models typically generate actions in temporal coordinates, without explicitly modeling or systematically leveraging this frequency heterogeneity. We introduce \emph{FreqFM}, a frequency-conditioned Flow Matching framework for VLA models. It raises action frequency from an implicit trajectory property to an explicit conditioning dimension that spans the entire generation pipeline. Concretely, in DCT frequency coordinates, FreqFM constructs a spectrum-matched source distribution, adaptively balances the objective across frequencies, and constrains per-frequency guidance residuals using the corresponding reference transport scales. FreqFM integrates into existing Flow Matching action experts without changing the VLA backbone. Across LIBERO, LIBERO-Plus, and VLA-Arena, FreqFM consistently improves performance, including a 9.3-point gain on LIBERO-Plus, and further demonstrates its effectiveness on six real-robot tasks.

# FreqFM：面向视觉-语言-动作模型的频率条件化流匹配——论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基于流匹配（Flow Matching）的 VLA 模型（如 π0、π0.5）通过从简单源分布沿学习到的条件速度场传输样本，生成多步动作块（action chunk）。这类模型通常在**时间坐标**下建模动作生成。
- **核心问题**：机器人动作并非无结构向量，而是**时间相关的轨迹**，其频率分量对应不同尺度的运动——低频刻画全局运动趋势，高频编码局部修正。作者实测发现动作功率谱能量分布**极度非均匀**：
  - 真机数据（horizon = 30）：跨频段能量变化超过 **7 个数量级**，>99.9% 能量集中在最低 3 个频段；
  - LIBERO（H = 10）：动态范围约 **3.8 个数量级**；VLA-Arena：约 **2.6 个数量级**。
- **现有方法的缺口**：流匹配动作专家几乎都在时间坐标建模，未显式建模或系统利用这种频率异质性。神经网络虽可隐式学习时间相关性，但**频率选择性变换在时间坐标下对应稠密的跨时间步耦合**，而在频率坐标下只需紧凑的逐频率参数化。
- **核心研究问题**：能否将"动作频率"从隐式的轨迹属性提升为贯穿整个流匹配流程的**显式建模维度**？
- **整体含义**：FreqFM 在 DCT 频率坐标下，对源分布、训练目标、推理引导三个阶段全部进行频率条件化，且**不修改 VLA 主干**，可即插即用地替换现有流匹配动作专家。这为 VLA 动作生成引入了"频率条件化"的新范式。

## 2. 方法论

### 2.1 核心思想

- 沿动作 horizon 轴做**正交 DCT-II 变换**（Ã = C a），将频率显式暴露出来；以"逐频率、逐自由度动作功率"作为可测量、可建模的统计量，去条件化流匹配的三个阶段。
- 仅对**平滑动作维度**（smooth DoF）使用 DCT 表示，积分完成后经逆 DCT 还原动作块。

### 2.2 阶段一：频谱匹配源分布（Spectrum-Matched Source）

- 从训练动作估计逐频率、逐自由度的 RMS 系数尺度与功率：
  - A_k,d = sqrt(E[ã²_k,d])，P_k,d = A²_k,d。
- 源采样改为：z̃₀,k,d = sqrt(P_k,d)·ε_k,d，ε ~ N(0,1)，即 q₀ = N(0, diag(P))。
- **路径性质**：由于源中心化且与目标独立（E[z̃₀ã] = 0），线性路径满足
  - E[z̃²_t,k,d] = (1−t)²P_k,d + t²P_k,d = [(1−t)² + t²]·P_k,d，
  - 所有频率共享同一时间因子，**相对二阶矩谱沿参考路径保持不变**；而白噪声源下 E[z̃²_t] = (1−t)² + t²P_k,d，相对谱随 t 漂移。
- 注意匹配的是**二阶原点矩** P 而非方差 σ²，否则形状仍随 t 变化。在目标边际近似为 N(μ, diag(σ²)) 时，W₂² ≈ ‖μ‖² + Σ(√P − σ)²，由于 P = σ² + μ²，第二项是 μ/σ 的四阶小量，故原点矩匹配在系数均值相对 RMS 较小时也近似协方差匹配（仅作辅助解释）。

### 2.3 阶段二：PSD 归一化的自适应目标（PSD-Normalized Adaptive Objective）

- 问题：原始 MSE 下，相同相对误差产生的平方误差正比于 P_k,d，导致高能量低频分量主导损失与梯度。
- 做法：先按训练谱归一化，定义
  - ℓ̄_k,d = ℓ_k,d / (P_k,d + ε)^ρ，r̄_k,d = (ṽ_θ − ũ)/(P_k,d + ε)^(ρ/2)，
  - 取**温度化指数 ρ = 0.25**（而非 ρ = 1 的完全归一化），以削弱低频主导同时不过度放大极小高频系数。
- 再采用 Kendall et al. (2018) 的**似然式多任务不确定性加权**：对每个 (k,d) 回归项学习对数尺度 s_k,d，负对数似然
  - L_freq = Σ_k,d [ ½ exp(−s_k,d)·ℓ̄_k,d + ½ s_k,d ]。
- 分析：s = 0 时梯度为 ∇θ L = ½Σ∇θ ℓ̄，∂L/∂s = ½(1 − ℓ̄)，说明归一化在自适应尺度尚未学习前就压缩了功率引起的动态范围；内层最优 s* = log E[ℓ̄]，代回得 L* = ½Σ log E[ℓ] + const，即**完全优化后的平稳权重与固定重加权无关**，其收益来自联合优化的参数化（零初始化、有限步训练）而非最终目标形状。

### 2.4 阶段三：谱传输预算的分类器无关引导（STB-CFG）

- **参考传输尺度**：由源-目标耦合可得目标速度二阶矩
  - E[ũ²_t,k,d] = E[z̃²₁] + E[z̃²₀] − 2E[z̃₀z̃₁] = 2P_k,d。
- 定义频率度量与参考半径：
  - M_k = diag_{d∈D_f}(P_k,d + ε)，R²_k = E[‖ũ_t,k‖²_{M_k⁻¹}] = 2Σ_d P/(P+ε)；
  - 无 ε 时每个正功率坐标的参考二阶矩为 2，R²_k = 2|D_f| 对所有频率相同 → **预算在参考传输单位下是均匀的**，频率依赖全部由 M_k 承载；原始单位下容许残差随 A_k,d 缩放（LIBERO 上跨频段近 2 个数量级，真机上近 4 个数量级）。
- **逐频率投影**：设 Δ_k = ṽ_cond,k − ṽ_uncond,k，w₀,k = λ₀Δ_k（λ₀ = s₀ − 1，验证集选定后冻结），求解
  - w*_k = argmin_{wᵀM_k⁻¹w ≤ β²R²_k} ½‖w − w₀,k‖²_{M_k⁻¹}，
  - 闭式解：γ_k = 1（b_k ≤ βR_k）或 βR_k/b_k（b_k > βR_k），w*_k = γ_k·w₀,k，
  - 引导速度 ṽ_STB,k = ṽ_cond,k + w*_k。
- 语义：**预算内残差保持不变，超预算残差被径向裁剪到边界**；β → ∞ 退化为标准 CFG，β = 0 退化为条件推理。γ_k 对每个样本、每个求解器步重新计算。训练时以概率 p_drop = 0.05 将条件前缀替换为可学习的 null embedding。

### 2.5 集成方式

- 不改变 VLM 主干与动作专家结构，只在动作专家的流匹配公式层面替换源分布、损失与引导；离线统计一次训练动作谱，贯穿三阶段共享。
