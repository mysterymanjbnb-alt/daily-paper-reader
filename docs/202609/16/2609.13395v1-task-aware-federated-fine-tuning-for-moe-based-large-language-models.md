## 摘要
混合专家（MoE）已成为大语言模型（LLMs）广泛采用的架构，因为它通过稀疏专家激活提高模型容量，同时限制计算开销。这一特性使基于MoE的LLMs对资源受限的分布式环境特别有吸引力。然而，在异构客户端数据下，基于MoE的LLMs的联邦微调仍然具有挑战性。由于客户端通常对应不同的任务偏好，直接聚合其本地更新可能会削弱专家专业化，并在共享专家上引入冲突的更新方向。为了解决这些挑战，我们提出了FedTAR，一种面向基于MoE的LLMs的任务感知联邦微调方法。FedTAR通过路由输出建立本地更新与任务偏好之间的关联。具体来说，我们对路由特征和本地更新都应用奇异值分解（SVD），以提取低维任务坐标和更新方向。基于任务坐标，FedTAR在具有相似任务偏好的客户端之间进行簇内聚合，并在不同任务组之间进行簇间聚合。然后，通过学习到的任务到更新映射重建聚合更新，确保最终更新与任务特定的优化方向保持一致。这样，FedTAR保留了专家专业化，并减轻了异构客户端之间的破坏性干扰。我们在不同非独立同分布（non-IID）设置下的四个基准任务上评估FedTAR。实验结果表明，FedTAR始终优于强大的联邦微调基线，并达到了最先进的性能。

## Abstract
Mixture-of-Experts (MoE) has become a widely adopted architecture for Large Language Models (LLMs), as it improves model capacity while limiting computational overhead through sparse expert activation. This property makes MoE-based LLMs particularly attractive for resource-constrained distributed environments. However, federated fine-tuning of MoE-based LLMs remains challenging under heterogeneous client data. Since clients often correspond to different task preferences, directly aggregating their local updates may weaken expert specialization and introduce conflicting update directions on shared experts. To address these challenges, we propose FedTAR, a task-aware federated fine-tuning method for MoE-based LLMs. FedTAR establishes the association between local updates and task preference via routing outputs. Specifically, we apply Singular Value Decomposition (SVD) to both routing features and local updates to extract low-dimensional task coordinates and update directions. Based on the task coordinates, FedTAR performs intra-cluster aggregation among clients with similar task preferences and inter-cluster aggregation across different task groups. The aggregated update is then reconstructed through the learned task-to-update mapping, ensuring that the final update remains aligned with task-specific optimization directions. In this way, FedTAR preserves expert specialization and mitigates destructive interference among heterogeneous clients. We evaluate FedTAR on four benchmark tasks under different non-IID settings. Experimental results demonstrate that FedTAR consistently outperforms strong federated fine-tuning baselines and achieves state-of-the-art performance.

- **背景**：MoE（混合专家）已成为大语言模型主流架构之一，通过稀疏激活（每个 token 只激活 k 个专家）在扩大模型容量的同时控制推理开销，因而特别适合资源受限的分布式/边缘场景。
- **现实需求**：领域适配往往依赖分散在各客户端手中的私有数据，联邦微调（FL + PEFT/LoRA）是自然的解决方案。
- **核心矛盾**：MoE 架构与异构客户端数据结合后产生两个此前未被系统研究的挑战：
  - **专家特化被削弱**：不同任务偏好的客户端对同一专家的更新幅度不同，聚合时被无差别平均，导致全局模型对任务 A、B 均次优（论文图 1(a)）。
  - **共享专家上的更新冲突**：同一专家被不同任务客户端激活，其收敛方向相互矛盾，聚合产生破坏性干扰（论文图 1(b)）。
- **关键难点**：任务偏好不可直接观测，因此无法直接判断"哪些客户端该聚合在一起、更新该如何组合"。
- **核心洞察**：MoE 的路由输出天然反映专家使用模式，隐式编码了底层任务结构，可作为任务与更新之间的"中间表示"。
- **整体含义**：作者称这是**首个针对基于 MoE 的大语言模型联邦微调**的工作，把"任务感知"引入联邦聚合环节，而非仅把 MoE 塞进既有微调流程。

## 2. 方法论（FedTAR）

### 2.1 总体框架
- 客户端：本地 LoRA 微调 → 在本地留出集上统计路由特征 → 上传更新与路由特征。
- 服务端：分别对更新矩阵与任务矩阵做 SVD → 学习"任务坐标 → 更新方向"的映射 → 任务感知的簇内/簇间聚合 → 用学到的映射重构全局更新。

### 2.2 本地微调
- 冻结预训练 MoE 权重 $W_0$，只训练 LoRA 的 $B$ 矩阵（$A$ 冻结、客户端间共享子空间），兼顾通信效率与抑制冲突（沿用 FFA-LoRA 思路）。
- 第 t 轮客户端优化 $\min_B L_i(W_0 + \Delta W(B))$，得到 $B_i^t$ 上传。

### 2.3 路由特征提取（客户端侧）
- **平均专家使用率**：$\mu_i = \mathbb{E}_{x\sim D_i}[g(x)]$，反映各专家的被使用概率。
- **专家共激活矩阵**：$co_i = \mathbb{E}_{x\sim D_i}[g(x)g(x)^\top]$，刻画专家间的协同/交互结构。
- **路由置信度（熵）**：$h_i = \mathbb{E}[-\sum_k g_k(x)\log g_k(x)]$，低熵表示专家选择更明确、更可靠。
- 拼接并 $\ell_2$ 归一化得到统一任务表示 $c_i = [\mu_i; \mathrm{vec}(co_i); h_i]$；路由器冻结时只需上传一次。

### 2.4 任务—更新子空间对齐
- 堆叠客户端更新 $\Delta = [B_1^t,\dots,B_N^t]$ 做 SVD，保留前 r 个主成分得更新子空间 $U_\Delta^{(r)}$。
- 堆叠路由特征 $C = [c_1,\dots,c_N]$ 做 SVD，取 $P = U_C^{(r)}$ 为任务子空间；中心化后得任务坐标 $z_i = P^\top \tilde{c}_i$。
- 用**岭回归**学习线性映射 $M$：$\min_M \|\Delta - MZ\|_F^2 + \lambda\|M\|_F^2$，闭式解 $M = \Delta Z^\top (ZZ^\top + \lambda I)^{-1}$，即 $B_i^t \approx M z_i$。

### 2.5 任务感知聚合与重构
- 对任务坐标聚类为 Q 组；**簇内**直接平均得 $\Delta_c^q$。
- **簇间**按各簇到全局任务中心的距离做 softmax 加权：$w_q \propto \exp(-\tau\|z_q - z_{center}\|^2)$，得 $\Delta_{Cluster} = \sum_q w_q \Delta_c^q$。
- **重构**：将聚合结果投影回任务对齐子空间 $B_g^t = M(M^\top M + \lambda I)^{-1}M^\top \Delta_{Cluster}$，剔除与任务结构不一致的分量；最终 $W_g \leftarrow W_g + B_g^t A_g^0$。

### 2.6 隐私与通信
- 路由特征经裁剪（敏感度上界 2S）+ 高斯噪声，满足 $(\varepsilon,\delta)$-DP；SVD 属后处理，不破坏隐私保证。
- 每客户端每轮通信量为 $O(d + K^2)$（vs 标准 FL 的 $O(d)$）；因 $K^2 \ll d$ 且 $c_i$ 常只传一次，额外开销可忽略；只聚合 $B$ 比同时传 $A,B$ 更省。

### 2.7 附录中的理论支撑
- 路由统计 $(μ_i, C_i)$ 编码任务偏好；在损失与专家网络光滑性假设下，路由表示到更新存在 Lipschitz 连续映射 $\Delta w_i = \Phi(z_i) + \xi_i$，故"任务空间近 ⇒ 更新方向近"，为聚类聚合提供依据。
- 低秩假设下，任务感知投影可分解误差，去除与共享子空间正交（即冲突/任务不一致）的分量。

## 8. 局限与不足

- **模型与数据单一**：全部实验只基于 Qwen1.5-MoE-A2.7B 与 Alpaca-GPT-4 派生的训练数据，未验证在更大规模 MoE（如 Mixtral、DeepSeek-MoE）或其他模态/语言上的泛化性。
- **缺少同类方法对比**：相关工作中同样面向 MoE 联邦微调的方法（如 FFT-MoE）未被纳入对比，无法直接说明"任务感知聚合"相对于其他 MoE 专用策略的增量收益。
- **客户端参与机制未交代清楚**：是否每轮全客户端参与、是否采用采样/部分参与、掉线或异步场景下的行为均未说明，而这在真实联邦场景中直接影响路由特征统计与聚类稳定性。
- **路由特征的可获取性假设偏强**：方法默认客户端能够获得干净、具有代表性的本地留出集来统计 $\mu_i$、$co_i$、$h_i$；在极低数据量或分布高度倾斜的客户端上，$co_i$（$K \times K$ 维）估计方差可能很大，尤其 $K=64$ 时共激活矩阵需估计约 4096 个量，论文未讨论该估计的稳定性与样本量下限。
- **隐私分析的边界**：DP 只覆盖路由特征的上传，未讨论 LoRA 更新矩阵本身可能泄露的信息（已有研究显示梯度/更新可被反演）；同时裁剪阈值 $2S$ 与噪声尺度的具体取值未给出，隐私—效用权衡的实证缺失。
- **聚类数与簇数需人工设定**：$Q$ 依赖超参搜索而非自适应确定，在真实任务数未知时需额外调参。
- **超参数敏感性覆盖有限**：仅扫描了客户端数、LoRA rank、聚类数，未涉及 $\lambda$、温度 $\tau$、DP 的 $\varepsilon$ 等对映射学习与聚合权重影响较大的参数。
- **理论假设较强**：Lipschitz 映射与低秩假设在真实深层 MoE 中未必严格成立，理论更多提供直觉而非可验证的界。
- **算力描述粗略**：未报告总 GPU 小时、各实验实际耗时，复现成本难以估算。

## 9. 启发与可延伸方向

- **"路由即任务指纹"的思路可迁移**：任何带门控/路由机制的模型（MoE、条件计算、多任务适配器）都可考虑用内部路由统计作为免标注的任务代理，用于聚类、个性化或客户端选择。
- **聚合粒度的再设计**：从"参数平均"转向"任务坐标空间中的插值与重构"，为异构联邦提供了不同于 FedProx/SCAFFOLD 的解决路径，可与梯度校正类方法叠加使用。
- **可探索的问题**：客户端动态加入/退出时任务子空间 $P$ 的增量更新；通信轮次间路由特征漂移的补偿；把聚类替换为软分配或注意力式加权；在更大 MoE 上验证 $K^2$ 通信项的实际影响。

## 10. 一句话总结

FedTAR 首次系统研究 MoE 大语言模型的联邦微调，指出"专家特化削弱"与"共享专家更新冲突"两大挑战，通过把 MoE 路由统计当作隐式任务表示、在低秩任务子空间中学习"任务坐标→更新方向"的岭回归映射，并执行任务感知的簇内平均 + 簇间加权与任务对齐重构，在多个推理与指令任务、多种异构程度下稳定优于 FedAvg、SCAFFOLD、FFA-LoRA、FedSVD 等基线，兼具收敛速度优势与可证明的 DP 保护，是一篇问题定义清晰、方法简洁可复现、实验维度较完整的工作，其主要提升空间在于模型/数据多样性、同类 MoE 联邦方法的直接对比以及隐私与客户端动态场景的更深入验证。
