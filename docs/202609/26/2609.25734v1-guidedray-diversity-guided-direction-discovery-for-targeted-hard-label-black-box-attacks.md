## 摘要
深度神经网络易受对抗攻击。在黑盒攻击中，基于决策的目标攻击尤其困难：攻击者仅能观察到目标模型的 top-1 标签，并旨在有界扰动下使其预测一个预先指定的目标类别。在扰动细化之前，攻击者必须发现一个能够到达指定目标区域的方向。这一初始化步骤可能带来大量查询开销。我们提出 GuidedRay，一种基于多样性引导方向发现的目标决策攻击。GuidedRay 基于两个观察：目标类参考样本提供了有用的目标条件方向先验，且多样化候选提高了发现目标对抗方向的概率。GuidedRay 从一个或多个目标类参考生成多样化候选，并使用单查询快速测试来筛选它们诱导的符号方向。一旦找到可行方向，GuidedRay 应用 Ray Search 来减小其决策边界半径。在 CIFAR-10、CIFAR-100 和 ImageNet 上的实验表明，GuidedRay 在从 500 到 5,000 的四个评估查询预算下始终优于五种最先进的基于决策的攻击，在初始化期间的方向发现方面增益尤为显著。对于受对抗训练或 TRADES 保护的模型，它在所有四个查询预算下同样实现了最高的攻击成功率。

## Abstract
Deep neural networks are vulnerable to adversarial attacks. Among black-box attacks, targeted decision-based attacks are particularly difficult: the attacker observes only the target model's top-1 label and aims to make it predict a prespecified target class under a bounded perturbation. Before perturbation refinement, the attacker must discover a direction that reaches the prescribed target region. This initialization step can incur substantial query cost. We propose GuidedRay, a targeted decision-based attack based on diversity-guided direction discovery. GuidedRay builds on two observations: target-class reference samples provide useful target-conditioned direction priors, and diverse candidates increase the probability of discovering a targeted adversarial direction. GuidedRay generates varied candidates from one or multiple target-class references and uses a one-query Fast Test to screen their induced sign directions. Once a feasible direction is found, GuidedRay applies Ray Search to reduce its decision-boundary radius. Experiments on CIFAR-10, CIFAR-100, and ImageNet demonstrate that GuidedRay consistently outperforms five state-of-the-art decision-based attacks at four evaluated query budgets from 500 to 5,000, with particularly pronounced gains in direction discovery during initialization. Against models protected by adversarial training or TRADES, it likewise achieves the highest attack success rate at all four query budgets.

## 1. 核心问题与整体含义

- **研究背景**：深度神经网络易受对抗攻击。按攻击者掌握的信息，黑盒攻击中的**决策型攻击（decision-based attack）** 最为苛刻——攻击者只能获得目标模型的 top-1 预测标签，无法访问架构、参数、梯度、logits 或置信度。
- **核心问题**：在**目标攻击**设定下，攻击者必须让模型输出预先指定的目标类别 t（而非任意错误类），这比无目标攻击严格得多。此时攻击被自然地分解为两阶段：
  - **初始化**：在离散符号方向空间 {−1,+1}^n 中发现一个能到达目标区域的可行方向；
  - **优化**：在已找到方向的基础上缩小决策边界半径。
- **现有工作的缺口**：HSJA、OPT/Sign-OPT、Tangent、Triangle、SurFree、CGBA、TtBA、Bounce 等方法主要解决"**已获得对抗点或方向后如何细化**"，而**目标方向的发现（初始化）** 本身才是查询开销的主要瓶颈。RayS 在无目标设定下有效，但在目标设定下并不稳定优于现有目标攻击（表 IV 中 CIFAR-10 5K 查询下 ASR 仅 0.389，ImageNet 为 0.000）。
- **整体含义**：论文将"目标对抗方向的发现"识别为硬标签黑盒目标攻击的关键瓶颈，并提出以**目标类先验 + 候选多样性**为核心的初始化策略，把成功攻击前移到更低查询预算。

## 2. 方法论

### 2.1 形式化表示
- 用**符号方向** d ∈ {−1,+1}^n 参数化顶点射线：扰动点表示为 xb + r·d，其中 xb 为良性输入，r > 0 为半径。
- **决策边界半径**：g(d) = inf{r > 0 | xb + r·d ∈ O}；集合为空时 g(d) = +∞。
- **攻击目标**：min_{d∈{−1,+1}^n} g(d)，约束查询数 q ≤ Q；若返回方向满足 g(d̂) ≤ ϵ 则攻击成功。
- 目标类参考样本 xa 诱导方向 da = sign(xa − xb)（逐坐标取符号，零值映射为 +1）。

### 2.2 两个启发式观察（动机实验支撑）
- **观察 1：目标条件方向先验**。由目标类参考诱导的方向比随机非目标参考诱导的方向更容易到达目标区域。表 I 显示成功率从 0.2148→0.3866（CIFAR-10）、0.0360→0.1186（CIFAR-100）、0.0052→0.1012（ImageNet）。
- **观察 2：候选多样性**。用平均成对余弦相似度 APCS 度量冗余度，APCS 越小表示覆盖越广。表 II/III 显示：SCR（符号改变比例）越高 → APCS 越低 → 候选集成功率 CSSR 越高（CIFAR-10 从 0.7300 升至 0.9800；ImageNet 从 0.0600 升至 0.5500）。

### 2.3 GuidedRay 总体框架
- 由**初始化阶段（ADSF）** 和**优化阶段（Ray Search）** 组成：
  1. ADSF 生成多样化目标条件候选并映射为符号方向；
  2. 用**单查询 Fast Test** 逐一筛选；
  3. 找到可行方向后，用 Ray Search 缩小决策边界半径。

### 2.4 ADSF（Adversarial Direction Search Framework）
- **候选生成**：从目标类参考 {x(1)_a, …, x(k)_a} 中采样一个参考 x(j)_a，随机选择一种图像增强 T（高斯噪声、随机旋转、随机裁剪+缩放、颜色抖动），得到候选 x*_a = T(x(j)_a)，再映射为 dc = sign(x*_a − xb)。变化参考与增强方法可降低方向冗余。
- **单/多参考设定**：k = 1 时所有候选来自同一样本；k > 1 时先随机选参考再随机选增强，引入更多目标条件起点。
- **单查询 Fast Test**：令 ρc = ‖x*_a − xb‖₂，rc = ρc/‖dc‖₂，查询点
  xtest = xb + (ρc/‖dc‖₂)·dc。
  若 f(xtest) = t，则用**一次查询**即证实 dc 为目标对抗方向，随后沿该射线二分搜索得到初始半径 rbest；否则丢弃该候选（不再消耗查询）。若 N 次测试均失败，则回退到 RayS 的全 1 方向 d = {1}^n。

### 2.5 优化阶段
- 采用 **Ray Search**：在第 s 阶段把当前方向划分为 bs = min(2^s, n) 个块，每次翻转一个块，用二分搜索 SDBR 评估临时方向的半径，若更小则更新当前方向与半径，块粒度逐级增大，直到预算耗尽或满足扰动阈值。
- **无目标变体**：无需目标类参考，直接对 xb 施加高斯噪声生成候选并做 Fast Test，成功或 N 次失败后分别对接受方向或全 1 方向执行 Ray Search。

## 3. 实验设计

## 6. 主要结论与发现

- **目标攻击主结果**：GuidedRay 在 CIFAR-10、CIFAR-100、ImageNet 上，于 500/1K/3K/5K 全部查询预算下 ASR 均最高。例如 1,000 查询时，相对 RayS 的 ASR 从 0.141→0.313（CIFAR-10）、0.006→0.053（CIFAR-100）、0→0.246（ImageNet）。
- **轨迹与效率**：AUC@5K 相比最强基线提升 61.6%（CIFAR-10）、69.7%（CIFAR-100）、29.6%（ImageNet）；达到 20% ASR 所需查询减少 34.1%–58.8%。
- **初始化增益显著**：CIFAR-10 上 ISR 从 RayS 的 0.416 提升到 0.906（k=1）/0.985（k=10），初始化平均查询从 5,848 降至 1,292/334（约 17.5 倍）；APCS 从 0.994 降至 0.464/0.301。
- **多参考可扩展**：k 增大整体提升 ASR（ImageNet 上 ASR@5K 从 k=1 的 0.402 升至 k=30 的 0.774），但并非在每个单独查询点都单调。
- **防御模型仍有效**：在 AT 与 TRADES 模型上，GuidedRay 在四档预算下 ASR 均最高（如 500 查询时 0.019 / 0.031，基线最高仅 0.010 / 0.011）。
- **无目标设定**：GuidedRay 在 CIFAR 上仍优于 RayS（1,000 查询时 0.230→0.285、0.453→0.495），但在 ImageNet 上两者几乎持平（差距 ≤ 0.012），说明其优势主要来自目标攻击的严格约束。
- **增强方法**：颜色抖动在三个数据集上均为最强单项；混合策略在 ImageNet 上最优，故被设为默认。

## 7. 优点

- **问题定位精准**：把"目标方向发现"而非"扰动细化"作为核心瓶颈，切入点清晰，并给出实证动机。
- **方法简洁高效**：Fast Test 仅用 **1 次查询**即可认证一个方向是否可行，避免为每个候选做昂贵边界搜索，显著降低初始化开销。
- **双观察驱动设计**：目标类先验与候选多样性均有定量实验支撑（表 I、II、III），方法不是经验拼凑。
- **完全无代理资源依赖**：不需要替代模型、离线边界学习器或迁移梯度先验，威胁模型干净，便于横向比较。
- **消融严谨**：RayS-T 与 GuidedRay-W 两个对照有效分离了初始化与优化器的贡献。
- **可扩展性**：天然支持单/多参考设定，且多参考带来的增益在 ImageNet 上尤为明显。
- **评估维度多元**：ASR、AUC@5K、Q@α、AvQ/MeQ
