## 摘要
我们提出了 NNV3，这是神经网络验证（NNV）工具的最新版本，一个用于深度学习模型和具备学习能力的信息物理系统形式化验证的 MATLAB 框架。基于 NNV 1.0（FFNNs、CNNs、NNCS）和 NNV 2.0（RNNs、SSNNs、神经常微分方程）的基于集合的可达性基础，NNV3 引入了 Star 集族的新成员：用于验证权重扰动下网络的 ModelStar、用于视频和三维体数据输入的 VolumeStar，以及用于图神经网络的 GraphStar。基于共形推断的概率可达性模式，为确定性验证难以处理的问题补充了可靠分析，而 FairNNV 可对连续输入区域上的反事实公平性和个体公平性属性进行认证。NNV3 引入了新的基准，用于恶意软件检测、基于图的电力系统模型、医学影像、变长时间序列数据和动作识别。NNV3 还通过统一的文档站点整合了教程和开发者指南。本文详细介绍了这些重大更新，展示了 NNV 已成熟为一个全面、稳健且易于使用的验证工具，适用于多种多样的 AI 系统。

## Abstract
We present NNV3, the latest version of the Neural Network Verification (NNV) tool, a MATLAB framework for formal verification of deep learning models and learning-enabled cyber-physical systems. Building on the set-based reachability foundation of NNV 1.0 (FFNNs, CNNs, NNCS) and NNV 2.0 (RNNs, SSNNs, neural ODEs), NNV3 introduces new members of the Star-set family: ModelStar for verifying networks under weight perturbation, VolumeStar for video and 3D volumetric inputs, and GraphStar for graph neural networks. A conformal-inference-based probabilistic reachability mode complements sound analysis for problems where deterministic verification is intractable, while FairNNV certifies counterfactual and individual fairness properties over continuous input regions. NNV3 introduces new benchmarks for malware detection, graph-based power-system models, medical imaging, variable-length time series data, and action recognition. NNV3 also incorporates tutorials and developer guides through a unified documentation site. This paper details these major updates, demonstrating NNV's maturation into a comprehensive, robust, and accessible verification tool for a diverse range of AI systems.

## 2. 方法论：核心思想与关键技术

### 2.1 统一抽象：Star 集模板（核心思想）

- 将 VolumeStar、GraphStar、ModelStar 统一为 **Star 集模板**的一个实例，参数化为 ⟨锚点、生成元基、生成元系数的多面体约束⟩：
  - 定义：⟨c, V, P, q⟩，其中 c ∈ T 为锚点，V = {v₁,…,v_m} ⊂ T 为生成元基，Pα ≤ q 为谓词变量 α 的多面体约束；
  - 所表示集合：Θ = { x ∈ T | x = c + Σᵢ αᵢvᵢ, Pα ≤ q }。
- 家族成员的区别仅在于**张量空间 T 的秩与生成元语义**：
  - Star：T = ℝⁿ；ImageStar：T = ℝ^{H×W×C}；
  - **VolumeStar**：T = ℝ^{H×W×C×F}，锚点为标称视频，生成元编码时空变化方向，|αᵢ| ≤ ϵ 给出 L∞ 界；
  - **GraphStar**：额外携带邻接结构，与节点/边特征张量并列；
  - **ModelStar**：生成元来自被扰动的权重项，而非输入维度。
- **工程含义**：扩展到新模态只需实例化该模板并实现层级的算子分派，即可复用同一传播内核。

### 2.2 各新能力的技术细节

- **ModelStar（权重扰动验证）**
  - 面向量化、数值不精确、硬件故障引起的参数不确定性，用区间界描述权重扰动。
  - 支持**输入不确定性与参数不确定性同时**的可达性分析；单扰动层 + 单点输入时可**精确**计算，多层扰动时用 Star 集构造**可靠过近似**。
  - 目前实现于全连接层与 2D 卷积层；量化舍入误差可建模为区间界，但**定点推理算术（离散运算）尚未建模**。
- **VolumeStar / VideoStar（时空与体数据）**
  - 将 Star/ImageStar 扩展到时空输入（每个时间步一张图像），支持 3D 卷积与池化层，覆盖 C3D、I3D 等视频分类网络及 3D 医学影像模型。
  - 可对指定输入集内**所有容许时空扰动**给出分类鲁棒性认证。
  - 同时把 Star 可达性推广到 TDNN：允许分析时域在**有界时间范围**内变化，泛化了此前定长循环模型的支持。
- **GraphStar / GNNV（图神经网络）**
  - 同时刻画图连通性与节点/边特征不确定性；对仿射消息传递做**精确传播**，对 ReLU 做**可靠过近似**；支持 GCN 与带边特征的 GINE。
  - 引擎层面通过 GNN wrapper 把消息传递层映射到 Star 集仿射操作，并将邻接矩阵路由至 GraphStar。
- **概率可达性（共形推断）**
  - 针对不稳定非线性激活数导致精确可达性指数爆炸的问题，采用**模型无关、基于采样**的验证：训练代理模型，在标定集上用共形推断界定误差，得到可达集（CP-Star）。
  - 保证为**双层**：以至少 99.9% 置信度（对校准集抽样），新输入输出落在可达集内的概率至少 99.9%（置信度由校准规模与秩经 Beta 尾界推出）。
  - 由于结果是普通 Star 集，**可与可靠模式共用同一套规格检查流程**：任何含 CP-Star 步骤的流水线自动获得相应覆盖率与置信度的概率性结论。
  - 成本随推理代价而非不稳定神经元数增长。
- **FairNNV（公平性验证）**
  - 在**连续输入区域**上验证：反事实公平性（敏感属性变化下预测不变）与个体公平性（邻域内输入得到相近结果）。
  - 用 **Verified Fairness（VF）** 指标量化：被形式化认证满足公平性的输入占比。
- **引擎与工程升级**
  - ImageStar 可达内核扩展到 4D 张量，使 VolumeStar 直接复用既有 3D 卷积/池化实现；
  - ModelStar 增加扰动追踪，在线性层间维持输入生成元与权重扰动生成元的符号依赖；
  - 基于 GitHub Actions 的 CI/CD（单元测试 + 基准回归测试），保证向后兼容；
  - 稳定的开发者 API、统一文档站点（用户指南、开发者指南、API 参考、理论背景、教程索引）。

## 6. 主要结论与发现

- **架构与模态覆盖的显著扩展**：NNV3 是少数同时支持 FFNN、CNN、RNN、SSNN、TDNN、NODE、NNCS、GNN 与 3D/视频数据的验证工具之一。Table 8 的支持矩阵显示，在 17 个被对照工具中，没有任何一个能覆盖 NNV3 的全部条目，NNV3 在"输入模态 + 网络架构 + 性质类"三维组合上取得最宽覆盖。
- **权重扰动可被纳入同一可达性内核**：ModelStar 证明参数不确定性与输入不确定性可以在同一个 Star 集框架下联合传播，单扰动层时可精确、多层时可靠过近似，说明"部署威胁模型"（量化、硬件故障）不必另起炉灶，可复用既有验证流水线。
- **时空与图数据的形式化认证在工程上可行**：VolumeStar 在 30 分钟超时内对 4 帧视频分类器给出认证结果，GraphStar 在 IEEE-24 潮流问题上对三种消息传递架构给出鲁棒性判定，二者共同说明原先被认为过于昂贵的模态，其认证是可达成的——尽管规模仍然有限。
- **概率性保证是对"不可行实例"的有效补充路径**：面对 TinyYOLO 这类不可稳定神经元数量爆炸、可靠可达性直接失败的模型，共形推断以 m=9230 个校准样本换取了 99.9% 覆盖率 / 99.9% 置信度的双层保证，且输出形式为普通 Star 集，能无缝接入既有规格检查。这提示"可靠认证 + 概率认证"的混合流水线是实用化的重要方向。
- **公平性可被形式化表达为可达性问题**：FairNNV 把反事实公平性与个体公平性转化为输入区域的输出约束检查，并给出 VF 这一可量化指标，为"公平性验证"这一此前多停留在概率/群体层面的问题，提供了连续输入区域上的确定性视角。
- **工程化程度是 NNV 系列的关键竞争力**：统一抽象 + 稳定 API + CI/CD + 文档站点，使 NNV3 从"研究原型集合"转变为"可被他人扩展的平台"，这一点在同类工具论文中并不常见。

## 7. 局限性

- **实验深度不足**：作者自己将评测定性为"跨领域可行性演示"，每组样本量小（10–100 量级）、无消融实验，无法回答"生成元规模 / 网络深度 / 图规模 / 帧数如何影响可扩展性"这类对使用者最关键的问题。
- **对比不公平与缺失并存**：与 AIVL 的对比受其输出规格限制而偏向本方；与 FairSquare、Justicia 等公平性认证器"暂不可直接比较"；VolumeStar 与概率验证没有基线。因此论文中"性能"层面的主张证据较弱。
- **ModelStar 的建模边界**：仅覆盖全连接层与 2D 卷积层；量化舍入误差被建模为区间界，而定点推理中的离散算术（截断、溢出、缩放）尚未建模，这意味着对真实量化硬件的验证仍不完整。
- **概率保证的适用条件严格**：覆盖率与置信度依赖校准集的 i.i.d. 假设与足够规模（本例 m=9230），在校准分布偏移或样本量不足时保证失效；且该路径给出的是概率结论，与可靠验证的确定性结论性质不同，混用时需谨慎解释。
- **时间变化的支持仍是有界**：TDNN 分析虽允许时域在有界范围内变化，但仍非无界/流式时序，对长序列与在线系统尚不适用。
- **算力与耗时信息不完整**：仅给出硬件环境与"数小时内可复现"的定性描述，未报告训练成本、GPU 小时数或各实验的详细耗时分布，削弱了可扩展性的量化判断。

## 8. 对领域的意义与未来方向

- **对验证社区**：NNV3 提出的"Star 集模板"是一个有推广价值的抽象——把新模态（视频、图、体数据）与新威胁模型（权重扰动）统一为"张量空间 + 生成元语义"的实例化，降低了工具扩展的边际成本，为其他验证器提供了可借鉴的架构范式。
- **对安全攸关部署**：将公平性、参数鲁棒性、概率保证纳入同一框架，意味着验证不再只回答"这个网络对输入扰动是否鲁棒"，而开始回答"这个系统在部署条件下是否可信"，这与实际认证需求（如 AI 法案、安全标准）的方向一致。
- **作者指出的未来方向**：扩展到定点/量化推理算术、更大的视频与图实例、更充分的与专用工具的对比，以及把概率与可靠路径更系统地组合。
- **审慎的评价**：NNV3 的价值主要在于**覆盖广度与工程可用性**，而非在单一基准上击败专用工具（如 α,β-CROWN 在 ReLU 网络上的效率）。将其定位为"统一的、可扩展的、可复现的验证平台"比定位为"最强的验证器"更符合论文实际提供的证据。
