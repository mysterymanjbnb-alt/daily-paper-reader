## 摘要
长时程大语言模型（LLM）智能体依赖外部记忆系统，以在持续交互中保留用户偏好和任务知识。传统检索机制优化的是语义兼容性而非下游效用，往往会将过时、误导或相互冲突的证据引入活动上下文。我们提出 MeClear，一种任务条件化的记忆清除框架，通过合作归因识别具有负向下游效用的记忆，并在智能体执行中选择性抑制这些记忆。MeClear 将留一法筛选与采样合作 Shapley 归因相结合，在相互作用的证据之间分配效用，有效解决了单次移除评估失效时的冗余冲突掩盖问题。利用归因排序，MeClear 在嵌套过滤上执行查询范围的最小清除策略，在清除后的上下文上验证任务恢复，同时不永久改变持久记忆库。在十个长对话记忆池上的综合实验评估表明，MeClear 达到 85.9% 的目标召回率和 82.3% 的整体任务恢复率，相较留一法（LOO）基线提升了 25.5 个百分点。

## Abstract
Long horizon Large Language Model (LLM) agents rely on external memory systems to preserve user preferences and task knowledge across extended interactions. Conventional retrieval mechanisms optimize semantic compatibility rather than downstream utility, frequently introducing outdated, misleading, or conflicting evidence into the active context. We present MeClear, a task conditioned memory clearance framework that identifies memories featuring negative downstream utility through cooperative attribution and selectively suppresses them from agent execution. MeClear combines Leave One Out screening with sampled cooperative Shapley attribution to distribute utility across interacting evidence, effectively resolving redundant conflict masking where single removal evaluations fail. Utilizing attribution rankings, MeClear executes a query scoped minimal clearance strategy over a nested filtration, verifying task recovery on the cleared context without permanently altering the persistent memory bank. Comprehensive experimental evaluations across ten long dialogue memory pools demonstrate that MeClear achieves a target recall of 85.9% and an overall task recovery rate of 82.3%, representing a 25.5 percentage point improvement over Leave One Out (LOO) baselines.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：长时程 LLM 智能体依赖外部记忆库（external memory bank）在长期交互中保存用户偏好、观察记录与任务状态。随着交互历史增长，记忆库会积累**过时、误导、冗余或相互冲突**的记录。
- **核心痛点**：传统检索机制（retriever）优化的是**语义相似度/兼容性**，而非**下游任务效用**。高语义相似并不保证对当前任务有益，反而可能引入"功能上有害"的证据（如时间漂移导致的旧事实、与当前上下文冲突的记录）。
- **已有方法的结构性缺陷**：
  - **单记录因果干预（LOO 式）**：在**冗余有害记忆**场景下会失效——两条可替代的有害记忆各自独立地维持任务失败，删除任意一条，另一条仍会维持失败，导致 LOO 效应为 0，形成"**冗余危害盲点**"。
  - **永久性记忆编辑**：记忆效用是**查询条件化（query-conditioned）**的，同一记录对当前查询有害、对后续查询可能不可或缺；直接覆写持久数据库会造成跨任务的灾难性性能回退。
  - **现有检索时准入过滤**：无法隔离"哪些相互作用中的记忆因果性地导致任务失败"，也无法验证抑制后任务是否真的恢复。
- **整体含义**：论文将记忆维护重新定义为**任务条件化的决策过程**，主张采用**可逆、最小化、带行为验证**的上下文清除，而非破坏性数据库修改。作者声称是**首次将合作博弈论分配用于 LLM 智能体的有害记忆上下文清除**。

## 2. 方法论

### 2.1 核心思想

把检索到的记忆上下文建模为**合作博弈（cooperative game）**：记忆是"玩家"，任务价值函数是"特征函数"，用 **Shapley 值**衡量每条记忆在多种上下文联盟中的边际贡献，从而揭示被冗余/联合结构掩盖的负效用；再通过**查询范围的最小清除 + 行为验证**决定实际删除哪些记忆（仅影响本次推理可见性，不改动持久记忆库）。

### 2.2 问题形式化

- 检索得到固定上下文 $M_t = \rho(q_t, B_t; K)$，包含 $K$ 条记忆 $m_i=(x_i,\xi_i)$。
- 对任意联盟 $S \subseteq M_t$，定义任务条件价值 $v_t(S) = \mathbb{E}_{y\sim p_\theta(\cdot|q_t,S)}[r_t(y)]$，$v_t: 2^{M_t}\to[0,1]$。
- 记忆 $m_i$ 的合作贡献（Shapley 值）：
  $$\psi_{t,i}=\sum_{S\subseteq M_t\setminus\{m_i\}}\frac{|S|!(K-|S|-1)!}{K!}\big[v_t(S\cup\{m_i\})-v_t(S)\big]$$
  满足效率性 $\sum_i \psi_{t,i}=v_t(M_t)-v_t(\varnothing)$。
- 定义**查询条件化有害集合**：$H_t=\{m_i\in M_t \mid \psi_{t,i}<-\tau\}$，强调有害性**不是记忆的固有属性**。
- **字典序目标**（无额外权重系数）：先最大化任务增益 $g_t(C)=v_t(M_t\setminus C)-v_t(M_t)$，再在达到最大增益的集合中选**基数最小**者 $C_t$。

### 2.3 四个阶段（算法流程）

1. **自适应任务条件化检索**：先冻结 $M_t$，后续所有反事实干预都在同一冻结上下文上执行，避免检索随机性污染归因；先缓存 $v_t(M_t)$ 作为共享基线。
2. **局部反事实筛选（LOO）**：计算 $\hat d_{t,i}=\hat v_t(M_t)-\hat v_t(M_t\setminus\{m_i\})$，用容差 $\kappa$ 将局部效应分为"有害 / 不确定 / 有益"三类。LOO 只作**诊断参考**，不作最终判据。
3. **反事实合作归因**：因精确枚举排列不可行，采用**排列采样估计**：
   $$\hat\psi^{(L)}_{t,i}=\frac{1}{L}\sum_{\ell=1}^{L}\big[\hat v_t(P_i(\pi^{(\ell)})\cup\{m_i\})-\hat v_t(P_i(\pi^{(\ell)}))\big]$$
   并提出**成对交互效应** $\hat\omega^{(L)}_{t,ij}$ 诊断冗余、互补、联合干扰等非加性结构（仅作结构诊断，不参与清除决策）。
4. **验证式查询范围清除**：将 $\hat H_t$ 按贡献从最负到最不负排序，构造**嵌套清除候选链** $C_{t,j}=\{m_{\sigma_t(1)},\dots,m_{\sigma_t(j)}\}$，把组合搜索空间从 $2^{h_t}$ 降到 $h_t+1$；对每个候选计算经验增益 $\hat g_t(j)$，并结合**任务恢复谓词** $\nu_t\in\{0,1\}$ 筛选可接受候选集 $J_t$；最终按 $\hat j_t=\min\arg\max_{j\in J_t}\hat g_t(j)$ 选择——先取增益峰值，再以最小基数破平。

### 2.4 理论支撑

- **定理 1（冗余危害盲点）**：若 $m_i,m_j$ 可替代有害，$v_t(S)=u_t(S\setminus\{m_i,m_j\})-\Delta_t\mathbb{1}[S\cap\{m_i,m_j\}\neq\varnothing]$，则 $d_{t,i}=d_{t,j}=0$，而 $\psi_{t,i}=\psi_{t,j}=-\Delta_t/2$。推广到 $r$ 条冗余记忆时 $\psi=-\Delta_t/r$（推论 A.1）。
- **命题 1（有限样本合作估计）**：排列采样估计无偏，并满足 Hoeffding 型集中不等式 $\Pr(\max_i|\hat\psi^{(L)}_{t,i}-\tilde\psi_{t,i}|\ge\varepsilon)\le 2K\exp(-L\varepsilon^2/2)$，给出充分采样量 $L\ge\frac{2}{\varepsilon^2}\log(2K/\delta)$。
- **定理 2（查询范围清除保证）**：在固定经验评估器与嵌套候选族下，所选上下文保证**经验不退化** $\hat v_t(\tilde M_t)\ge \hat v_t(M_t)$；若 $\hat j_t>0$ 则满足**验证恢复** $\nu_t(\tilde M_t)=1$；且在达到最大增益的候选集中**基数最小**。
