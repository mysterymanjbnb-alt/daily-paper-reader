## 摘要
安全聚合使服务器能够恢复客户端更新的聚合结果，而无需观察到任何单个更新，但传统协议在客户端上传时便固定了聚合精度。我们引入并形式化定义了一种新的渐进分辨率安全聚合功能：客户端只需上传一次，之后无需客户端重新参与，即可授权同一聚合结果的逐级更精细分辨率。为实现该功能，我们提出了渐进分辨率安全聚合（PSA）：每个经过裁剪和抖动后的更新由兼容的嵌套格数字表示；可单独释放的各层由安全聚合和一个额外的聚合填充保护，该聚合填充在非共谋的释放控制器授权该层之前对服务器不可用。

## Abstract
Secure aggregation lets a server recover an aggregate of client updates without observing any individual update, but conventional protocols fix the aggregate precision when clients upload. We introduce and formulate a new progressive-resolution secure-aggregation functionality in which clients upload once and successively finer resolutions of the same aggregate can later be authorized without renewed client participation. To realize this functionality, we propose progressive-resolution secure aggregation (PSA): each clipped, dithered update is represented by compatible nested-lattice digits; separately releasable layers are protected by secure aggregation and an additional aggregate pad that remains unavailable to the server until a non-colluding release controller authorizes that layer.

## 1. 核心问题与整体含义（研究动机与背景）

- **根本矛盾**：传统安全聚合（SecAgg）在客户端上传时就固定了聚合精度。一旦服务器解码出细精度聚合，事后再四舍五入也无法撤销已经发生的细粒度信息泄露。
- **实际痛点**：在跨设备联邦学习中，客户端上传后往往无法再次联系；而已批准的分析所需的精度在上传时可能尚不可知。为所有潜在查询一律按最高精度上传，会超出实际目的所需，违反"最小必要"原则。
- **规范依据**：论文援引英国国家统计局的信息披露控制政策、欧盟 GDPR 第 5(1)(c) 条的数据最小化原则，以及分层数据访问协议（先给分析师最粗视图，按需细化）。
- **设计目标**：实现"最小必要分辨率"策略——先释放粗聚合，仅在确有依据时再细化，且**不召回客户端**。
- **现有方法不足**：
  - 格量化（UVeQFed、JoPEQ、OLALa 等）只提供固定分辨率压缩；
  - 门限/分割信任系统（Paillier、Prio）可延迟解密，但只能延迟"全有或全无"的值；
  - SecAgg 下的分布式 DP 控制聚合所泄露的信息，但不提供可分别授权的粗/细一致分量。
- **核心贡献定位**：作者称这是**首次形式化**"单次上传后可事后逐级授权同一聚合的更精细分辨率"的安全聚合功能，命名为 **PSA（Progressive-Resolution Secure Aggregation）**。

## 2. 方法论

### 2.1 系统设定与目标量

- K 个客户端，客户端 k 持有更新 $u_k \in \mathbb{R}^d$；共享参考 $\mu_0$，裁剪半径 $\Delta$。
- 目标聚合量：$s_\Delta = K\mu_0 + \sum_{k=1}^{K} g_k$，其中 $g_k = \mathrm{clip}_\Delta(u_k - \mu_0)$，满足 $\|g_k\| \le \Delta$。
- 向量按 $J = \lceil d/n_b \rceil$ 个 $n_b$ 维块处理，末块补零。以 $\mu_0$（通常为上一轮全局模型）为中心可缩小格链需覆盖的范围。

### 2.2 两大逻辑组件

PSA = **兼容嵌套格表示**（代数机制）+ **密封释放门**（释放机制）。

- 前者保证粗到细的各层能一致重建、且在聚合下封闭；
- 后者用数据无关的填充（pad）控制每层何时可见。
- 论文明确声明：释放门被当作**抽象功能**处理，其实现委托给标准门限/多服务器工具，本文贡献是"呈现给该门的可渐进细化表示"及其代价刻画。

### 2.3 客户端编码流程

1. **缩放与减性抖动**：客户端设 $v_k = a g_k$（$a$ 为公开增益），抽取独立公开抖动 $d_k \sim \mathrm{Unif}(V_1)$，形成
   $x_k = Q_{\Lambda_1}(v_k + d_k) \in \Lambda_1$，满足 $x_k = v_k + d_k + e_k$，其中量化误差 $e_k$ 与 $v_k$ 独立、零均值、方差 $n_b\sigma^2(\Lambda_1)$，且 $\|e_k\| \le r_{\mathrm{cov}}(\Lambda_1)$。
   充分范围条件 $B < r_{\mathrm{pack}}(\Lambda_{L+1}) = \rho^L r_{\mathrm{pack}}(\Lambda_1)$ 保证 $Q_{\Lambda_{L+1}}(x_k)=0$。

2. **兼容数字链（Assumption 1）**：要求对任意 $x \in \Lambda_1 \cap V_{L+1}$ 与任意层 $\ell$，
   $Q_{\Lambda_\ell}(x) - Q_{\Lambda_{\ell+1}}(x) \in \mathcal{C}_\ell$。
   典型构造为**平衡奇基数整数链**：$\Lambda_1 = h\mathbb{Z}^{n_b}$，$\Lambda_\ell = h\rho^{\ell-1}\mathbb{Z}^{n_b}$，$\rho \ge 3$ 为奇数，字母表 $\mathcal{C}_\ell = h\rho^{\ell-1}\{-\tfrac{\rho-1}{2},\dots,\tfrac{\rho-1}{2}\}^{n_b}$。
   奇基数保证无边界并列、字母表关于原点对称。

3. **望远镜分解**：$x^\ell_k = Q_{\Lambda_\ell}(x_k) - Q_{\Lambda_{\ell+1}}(x_k) \in \mathcal{C}_\ell$，故 $x_k = \sum_{\ell=1}^{L} x^\ell_k$；
   任意后缀满足 $\sum_{\ell=\ell_0}^{L} x^\ell_k = Q_{\Lambda_{\ell_0}}(x_k)$——**更大层索引更粗，减小 $\ell_0$ 即添加更细细化**。

4. **逐层 DP 噪声**：客户端独立抽取 $z^\ell_k \in \Lambda_\ell$，坐标服从离散高斯
   $\Pr[Z = h\rho^{\ell-1}j] \propto \exp\!\big(-\frac{(h\rho^{\ell-1}j)^2}{2s_\ell^2}\big)$，实际方差记为 $\bar{s}_\ell^2$。

### 2.4 逐层安全聚合与密封释放

- 模格 $\Lambda^{(\ell)} = \rho^{m_\ell}\Lambda_{\ell+1}$，商群 $\bar{G}_\ell \cong (\mathbb{Z}/\rho^{1+m_\ell}\mathbb{Z})^{n_b}$，$m_\ell$ 为溢出裕度。
- 客户端贡献释放填充份额 $b^\ell_k$，聚合填充 $B_\ell = [\sum_{k \in A_\ell} b^\ell_k] \bmod \Lambda^{(\ell)}$；只要至少一个活跃诚实客户端的份额均匀且服务器未知，$B_\ell$ 在服务器视角下即均匀。
- 上传：$y^\ell_k = [\tilde{x}^\ell_k + b^\ell_k + \sum_{j\ne k} m^\ell_{kj}] \bmod \Lambda^{(\ell)}$（$m^\ell_{kj}$ 为标准 SecAgg 成对掩码）。
- 掩码在活跃集上相消后服务器仅持有密封聚合 $u_\ell = [\sum_{k\in A_\ell}\tilde{x}^\ell_k + B_\ell] \bmod \Lambda^{(\ell)}$。
- **授权后**：控制器提供 $B_\ell$，得到 $t_\ell = [u_\ell - B_\ell] \bmod \Lambda^{(\ell)}$。
- **重建**：设 $\ell_0$ 为最细已授权层，则
  $\hat{s}_{\Delta,\ell_0} = K\mu_0 + \frac{1}{a}\big(\sum_{\ell=\ell_0}^{L} t_\ell - \sum_{k=1}^{K} d_k\big)$。
  授权更细一层只需**一个额外控制器令牌，无需新的客户端上传**。
