## 摘要
随着大语言模型（LLM）智能体日益部署于复杂环境中，多轮交互攻击已成为一项重大安全挑战。现有检测方法通常依赖历史上下文。然而，这种回溯式逻辑难以识别被拆分到多轮以隐藏未来风险的深层恶意意图。受推测解码启发，我们提出推测式安全蜜罐（SSH）框架。SSH 使用由小型 LLM 组成的多智能体模拟系统，构建动作级的“推测—验证”工作流。在推测阶段，SSH 预测目标智能体的未来行为，并异步构建轨迹树以提前暴露潜在风险。在验证阶段，系统利用目标智能体的真实动作校准并剪枝轨迹树，从而有效降低误报。作为一个即插即用组件，SSH 为现有检测器提供超越当前交互片段的丰富决策冗余。通过基于整棵轨迹树的演化而非单一时间点来判断风险，系统降低了对单个检测组件绝对精度的依赖，从而提升智能体系统面对复杂时序攻击的防御韧性与预警提前量。

## Abstract
As Large Language Model (LLM) agents are increasingly deployed in complex environments, multi-turn interaction attacks have become a significant security challenge. Existing detection methods typically rely on historical context. However, this retrospective logic struggles to identify deep malicious intents that are split across turns to hide future risks. Inspired by speculative decoding, we propose the Speculative Safety Honeypot (SSH) framework. SSH uses a multi-agent simulation system composed of small LLMs to build an action-level speculate-and-verify workflow. In the speculation stage, SSH predicts future behaviors of the target agent and asynchronously builds a trajectory tree to expose potential risks in advance. In the verification stage, the system uses the target agent's real actions to calibrate and prune the trajectory tree, effectively reducing false positives. As a plug-and-playable component, SSH provides existing detectors with rich decision redundancy beyond the current interaction slice. By judging risk based on the evolution of the entire trajectory tree rather than a single point in time, the system reduces the reliance on the absolute precision of individual detection components. This improves the defense resilience and the warning lead-time of agent systems against complex temporal attacks.

## 2. 方法论

- **核心思想**：受推测解码启发，SSH 构建动作级“推测—验证”工作流：先用轻量模拟器预测目标智能体未来可能行为，形成轨迹树；再用目标智能体的真实动作校准、剪枝，并对剩余叶节点做风险检测。
- **多智能体模拟系统（MAS）**：
  - **Assistant Simulator**：模仿目标智能体，但故意使用无安全对齐模型，使其更易暴露潜在风险。
  - **User Simulator**：生成多样、模糊、边缘化的用户输入。
  - **Environment Simulator**：合成工具、MCP、数据库或第三方智能体反馈，不真实调用外部工具，保证模拟隔离无害。
- **推测轨迹树构建**：
  - 将消息（用户请求、助手动作、工具反馈等）作为节点。
  - 关键节点（用户请求、助手动作）进行采样和路径扩展；普通节点（工具响应、逻辑总结）通常只做单次采样。
  - 使用 **多样性导向 Beam Search**：在有限预算 \(M\) 和最大深度 \(D\) 下探索高风险角落轨迹。
- **Beam Search 关键流程**：
  - 采样候选节点；
  - **行为聚类**：函数调用按函数名与参数精确匹配；自然语言用 SimHash 计算 N-gram 相似度，重叠超过阈值 0.7 归为同簇；
  - **双层随机打乱**：先打乱簇顺序，再打乱簇内节点顺序；
  - **Round-Robin 选择与配额重分配**：在簇间轮流选择直到达到预算 \(M\)，少数簇节点可能被多次选中，从而放大稀有/边缘行为。
- **异步验证与风险评分**：
  - 目标智能体产生真实动作后，与 \(M\) 个推测候选匹配；匹配成功则只保留对应子树，不匹配则保留原树作为未来风险参考。
  - 对剩余叶节点，用现有检测器（如有害内容分类器、外部 LLM Judge）二分类为 risky/safe。
  - 风险分数为叶节点中 risky 的比例：  
    \(S(T)=\frac{1}{|L_{\text{leaf}}(T)|}\sum_{l\in L_{\text{leaf}}(T)} I(D_{\text{risk}}(n_0\to l)=\text{risky})\)。
  - 设置两个阈值：匹配成功时阈值 \(\tau_1\)，不匹配时阈值 \(\tau_2\)，且 \(\tau_1<\tau_2\)，以降低不匹配时的误报。超过阈值则触发引导提示、重采样或终止执行。
- **差异化对齐策略**：
  - 用 SFT 提升 Assistant Simulator 对目标智能体行为分布的保真度，同时故意增强其在对抗场景中的脆弱性/敏感性。
  - 训练数据包括目标智能体原始轨迹、去除长 CoT 但保留错误模式；并用环境一致性方法合成良性注入/IPI 数据。
  - 三个模拟器用 LoRA-based SFT 训练，并以 Multi-LoRA 适配器共享一个基座 LLM，降低显存并支持角色切换。
