## 摘要
智能体系统现已被广泛用于编排工具并在长上下文中进行推理。然而，驱动这些智能体的大语言模型能力不断提升，也为间接提示注入带来了新的攻击面。特别是，如果智能体能够从分布在长上下文中的不完整碎片中重建目标，攻击者可能无需在检索内容中放置完整的恶意指令。在这项工作中，我们提出了自适应长上下文提示注入（AdaLCPI），它将长上下文碎片化与自适应搜索相结合。AdaLCPI 将攻击目标拆分为不完整碎片，将它们嵌入通过智能体工具检索到的外部内容中，并使用重建线索促使智能体将其组合起来。随后，它利用目标智能体提供的分级评分和自然语言执行反馈，通过 OpenEvolve 迭代优化这些碎片和线索。实验表明，AdaLCPI 的攻击成功率高于强自适应基线，达到 61.4% 的宏平均 ASR，而 Trojan Hippo 风格为 32.8%，AgentVigil 为 30.0%。因此，安全评估应测试当有害目标必须从不完整碎片中重建时，智能体是否仍能保持稳健。

## Abstract
Agentic systems are now being widely used to orchestrate tools and reason over long contexts. However, the improving capabilities of the large language models powering these agents also create new attack surfaces for indirect prompt injection. In particular, an attacker may not need to place a complete malicious instruction in retrieved content if the agent can reconstruct the objective from incomplete fragments distributed across a long context. In this work, we introduce adaptive long-context prompt injection (AdaLCPI), which combines long-context fragmentation with adaptive search. AdaLCPI splits an attack objective into incomplete fragments, embeds them in external content retrieved through the agent's tools, and uses a reconstruction cue to prompt the agent to combine them. It then iteratively refines the fragments and cue with OpenEvolve using graded scoring and natural-language execution feedback from the target agent. Empirically, AdaLCPI achieves higher attack success than strong adaptive baselines, reaching 61.4\% macro-average ASR compared with 32.8\% for Trojan Hippo-style and 30.0\% for AgentVigil. Safety evaluations should therefore test whether agents remain robust when harmful objectives must be reconstructed from incomplete fragments.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体被广泛用于调用工具、在长上下文中检索并组合外部信息后采取行动。这一能力在提升任务表现的同时，也扩大了**间接提示注入（Indirect Prompt Injection）**的攻击面——攻击者可通过智能体读取的外部内容（邮件、代码仓库、Slack 消息等）间接影响其行为。
- **核心问题**：攻击者是否**必须**在检索内容中写入完整的恶意指令？论文追问：当恶意目标被拆分为**不完整碎片**并分散在长上下文中时，智能体是否会主动"重构"出可执行的有害指令并付诸行动？
- **问题来源**：结合了两条此前基本独立的研究线索——
  - 长上下文安全研究（Fu et al., 2026）：模型可能对"从碎片重构出的有害请求"比对"直接陈述的同一请求"更少拒绝；
  - 自适应攻击研究（AgentVigil、Trojan Hippo、IterInject 等）：通过黑盒搜索/进化算法迭代强化注入攻击，但**始终以完整显式指令为优化对象**。
- **整体含义**：若攻击目标无需显式出现，则现有以"检测完整恶意指令"为前提的安全评估与防御范式可能系统性失效；安全评测应新增"碎片重构"这一威胁维度。

## 2. 方法论：AdaLCPI

### 2.1 威胁模型与问题形式化

- 智能体 `A` 接收**可信的用户任务 `u`**，通过固定工具集与环境 `E` 交互；攻击者控制注入载荷 `p`，但不能修改用户任务、系统提示、模型权重、工具集或环境其他部分。
- 一次完整执行记为 `(τ, E_T) = Run(A, u, E[p])`，其中 `τ` 包含观测（工具返回内容）与动作（工具调用及参数）。
- 攻击目标 `g` 由判定函数 `G_g(τ, E_T) = 1` 表示成功（如数据外泄、声誉破坏、数据删除）。
- **优化期访问**：假设攻击者拥有对目标智能体配置的**黑盒重复评估能力**（可执行候选载荷并观察轨迹与最终环境状态），但无法获得梯度、参数或隐藏激活。

### 2.2 碎片化表示

- 用候选三元组 `x = (f₁, f₂, c)` 表示攻击：`f₁`、`f₂` 为两个不完整指令碎片，`c` 为重构线索。
- **有效性约束**：任一碎片单独不得包含完整恶意指令（例如一个提供动作、另一个提供目标/接收者）；线索 `c` 只能指示"定位并组合碎片"，不得引入目标相关的动作、工具、目标对象或数据。搜索空间被严格限制在合法候选集 `X_g` 内。
- **长上下文嵌入**：将碎片插入填充文本 `h_L` 的两个固定位置 `ρ=(r₁, r₂)`，线索拼接在末尾，得到载荷 `p_L(x; ρ) = Insert_ρ(h_L; f₁, f₂) ∥ c`。插入位置与填充内容在每次优化开始时**采样一次后固定**，仅优化 `f₁, f₂, c`。

### 2.3 自适应搜索（基于 OpenEvolve）

- 形式化为黑盒离散优化：`x* ∈ arg max_{x∈X_g} J_g(x)`。
- **分级评分**：由 LLM Judge 给出——若 `G_g = 1` 记 10 分；否则给出 1–9 的进度分，区分"完全忽略""注意到但未行动""工具或参数错误""接近成功"等不同失败形态，并附**自然语言执行反馈**。
- **搜索流程（Algorithm 1）**：
  1. 由 Decomposer 生成初始种子 `x₀`，再由 Generator 生成 8 个结构不同的变体，共 9 个初始候选；
  2. 用 OpenEvolve 的**质量–多样性归档**（8×8 网格，特征为载荷长度与相对种子的归一化编辑距离）保存候选；
  3. 每轮采样 4 个父代（精英/非精英各半），由 LLM Mutator 依据评分、反馈与工具调用摘要生成 6 个新候选；
  4. 每个候选实际执行目标智能体并评分，更新归档；
  5. 最多 20 轮，若成功或最优分连续 8 轮无提升则提前停止；**单次搜索最多 129 次目标智能体执行**。
- **组件配置**：Generator 与 Mutator 使用 GPT-4.1（Mutator 温度 0.8，最大生成 8192 tokens），两阶段 Judge 使用 GPT-4o（二值阶段温度 0，分级阶段温度 1.0）；目标智能体温度 0.6。

## 3. 实验设计

- **环境与场景**：三个工具化智能体环境——**Email、GitHub、Slack**，每个环境含 3 个良性任务。
- **任务–目标对**：每个任务配 3 类攻击目标（**数据外泄、声誉破坏、数据删除**）× 每类 3 个，即每环境 27 对、每模型每条件 **81 对**。
- **被测模型（7 个）**：GPT-4.1、GPT-5.1、GPT-5.6-Luna、Gemma-4-31B、Qwen-3.6-27B、Ministral-3-14B、Muse-Glimmer-30B。
- **评价指标**：攻击成功率（ASR，依据工具调用、参数与最终环境状态判定，搜索中的中间分不计入成功）；宏观平均（各模型等权）；另有**良性任务完成率**作为干扰程度诊断。
- **对比基线**：
  - **Trojan Hippo 风格（主对照）**：使用与 AdaLCPI **相同的自适应搜索、分级评分与自然语言反馈**，但保持恶意指令完整显式且不加填充——用于隔离"攻击表示"的贡献；
  - **LCF**（Fu et al., 2026）：长上下文碎片化但**不做自适应优化**；
  - **TAP**（树式搜索）、**AgentVigil**（黑盒红队）、**IterInject**（反馈引导迭代优化）。
- **消融与控制实验**：
  - 2×2 因子设计：完整指令 vs. 碎片+线索 × 0k vs. 8k 填充；
  - 成功攻击的**碎片移除重放**（仅线索 / 单碎片+线索）；
  - 填充长度敏感性（2k / 4k / 8k / 16k）；
  - **碎片跨独立工具输出**分布的攻击（8k / 16k 总填充，含 primer 与碎片重复）；
  - 三个随机种子（42/41/43）在 4 个模型上的重复搜索方差；

## 6. 主要结论与发现

- **攻击有效性**：AdaLCPI 在 8k 填充下达到 **61.4% 宏观平均 ASR**，显著高于 Trojan Hippo 风格（32.8%）、AgentVigil（30.0%）、IterInject（32.6%）、TAP（26.3%）与无自适应的 LCF（5.1%）；相对主基线在**全部 7 个模型**上均有提升，最大提升出现在 Qwen-3.6-27B（9.9% → 71.6%）与 Gemma-4-31B（37.0% → 91.4%）。
- **环境与目标差异**：增益在 Email（+38.1 个百分点）与 Slack（+39.2）最大，GitHub 较小（+8.5）；三类目标均提升（数据外泄 +27.5、声誉破坏 +34.9、数据删除 +23.3）；Email 平均 ASR 最高（69.8%），Email 数据外泄为最高单项（79.4%）。
- **关键机制结论（消融）**：
  - **碎片化与长上下文填充必须结合**：碎片+线索在 0k 填充下 0% ASR，加 8k 填充升至 75.3%；完整指令在 0k/8k 下分别为 29.3%/25.3%。即单独任一因素都无法复现增益。
  - **线索本身不足以成功**：移除碎片后仅保留线索为 0%；保留单个碎片+线索为 0–29.3%。
  - **填充长度非单调**：2k→8k 由 54.1% 升至 61.4%，16k 略降至 60.8%；不同环境趋势不同（Slack 单调上升，GitHub 在 8k 后下降）。
  - **碎片无需位于同一工具输出**：分布到不同工具输出时，8k 达 40.7%、16k 达 47.6%（16k 时 6/7 模型有非零成功率）。
- **干扰程度**：AdaLCPI-8k 下良性任务完成率平均 49.4%（25.9%–66.7%），说明攻击虽只优化恶意目标，智能体往往仍能完成原任务。
- **总体安全含义**：恶意目标**无需显式出现在攻击者控制的内容中**；智能体的"信息聚合后行动"能力本身即可被利用。安全评估应测试"有害目标需从检索工具输出中的不完整碎片重构"这一场景下的鲁棒性。

## 7. 优点

- **问题新颖且具有概念性突破**：首次把"长上下文碎片化重构"与"面向智能体的自适应注入优化"系统性结合，把攻击表示从"显式指令"推广到"隐式可重构目标"。
- **实验控制严谨**：主基线在搜索算法、评分方式、反馈形式、任务与目标上完全对齐，仅改变攻击表示，使因果归因更清晰；另有 2×2 消融直接排除两种单因素解释。
- **搜索设计合理**：采用质量–多样性归档（长度 + 编辑距离双特征）避免过早收敛；分级评分 + 自然语言反馈比二值信号提供更丰富的优化梯度；对合法候选的硬约束（碎片/线索不得含完整指令）保证了攻击形式的一致性。
- **鲁棒性检验较全面**：多种子重复、填充长度扫描、跨工具输出分布、候选预算曲线、按环境/类别/模型的细粒度分解，均在附录中给出。
- **对自身结论的边界保持克制**：明确指出跨输出实验混杂了 primer 与重复因素、碎片移除实验不能反映贡献度、候选预算不等于计算成本。
- **防御导向价值**：结论直接指向安全评测标准的更新，属于对防御方有直接指导意义的安全研究。
