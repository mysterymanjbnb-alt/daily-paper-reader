## 摘要
智能体式检索增强生成（RAG）将推理与反复检索交织在一起，使检索器既能影响智能体观察到的证据，也能影响其后续搜索决策。我们研究利用这一反馈回路的检索器后门，并重新利用弱后门净化来掩盖其存在。攻击者提供一个被攻陷的检索器检查点，同时保持搜索智能体和部署语料库不变。在无语料库写入权限的情况下，攻击者仍可抑制有用证据、持续检索某个选定的现有文档，或引导智能体进行长时间搜索，从而抬高检索、上下文和延迟成本。为将这些行为隐藏以避免检测，我们提出利用一种受控的注入-移除循环：故意注入一个较弱的后门，然后将其遗忘。该过程削弱检测器可见的特征，并以已被净化的假象欺骗后门检测器，同时保留恶意检索行为。这些发现揭示了 RAG 系统中的一种系统性漏洞：即便底层语料库仍然可信，弱防御也会成为攻击者隐藏后门检索器的工具。

## Abstract
Agentic retrieval-augmented generation (RAG) interleaves reasoning with repeated retrieval, giving the retriever influence over both the evidence an agent observes and its subsequent search decisions. We study retriever backdoors that exploit this feedback loop and repurpose weak backdoor purification to conceal their presence. An attacker supplies a compromised retriever checkpoint while leaving the search agent and deployment corpus unchanged. Without corpus write access, the attacker can still suppress useful evidence, persistently retrieve a selected existing document, or steer the agent toward prolonged search, inflating retrieval, context, and latency cost. To conceal these behaviors from detection, we propose leveraging a controlled inject-and-remove cycle: deliberately inject a weaker backdoor and then unlearn it. This process weakens detector-visible signatures and fools the backdoor detectors with an illusion of purification while preserving the malicious retrieval behavior. These findings expose a systematic vulnerability in RAG systems in which a weak defense becomes an attacker's concealment tool for a backdoored retriever, even when the underlying corpus remains trustworthy.

## 1. 核心问题与研究动机

- **背景**：Agentic RAG 将推理与反复检索交织，智能体根据已有证据生成新查询、决定是否继续搜索。检索器因此不仅决定"看到什么证据"，还通过反馈回路影响"下一步查什么""何时停止"。
- **现有攻击的局限**：
  - 语料投毒类方法（如 PoisonedRAG、对抗段落注入）需要写入受害者语料，但在真实部署中难以执行（受害者常索引公开论文、官方文档，攻击者可获得同一语料却无法修改）。
  - 已有检索器后门（BaD-DPR、Backdoored Retrievers、TrojanRAG、DisarmRAG、CAREAttack）多聚焦单次检索请求的激活与目标选择，未考虑智能体自主改变查询后攻击能否跨轨迹持续。
- **核心问题**：在"仅替换检索器检查点、语料与智能体完全不变"的供应链威胁模型下，检索器后门能否操纵整个 agentic 搜索轨迹？更进一步，攻击者能否把本用于净化的"注入—移除"流程反向利用为隐蔽手段？
- **整体含义**：揭示即使底层语料可信，检索器检查点供应链仍构成系统性漏洞；同时说明弱后门净化可能被攻击者武器化，使检测器误判"已净化"。

## 2. 方法论

### 2.1 威胁模型

- 受害者：良性 Search Agent π（Qwen2.5-7B-Instruct）+ 从公开仓库获取的稠密检索器 Rθ + 干净语料 D。
- 攻击者：对检索器拥有白盒控制权（可任意微调/编辑参数），可使用训练时搜索轨迹或查询参考 Agent，但**不能检查或修改部署 Agent 的参数与推理过程**，**无需语料写入权限**。
- 统一训练目标：`L(θb) = Lclean(θb) + λa·La(θb)`，即在保持干净检索监督的同时注入恶意目标。
- 关键前提：Agentic-R 设定下每轮检索输入 `xt = Q [SEP] qt`，原始问题 Q 中的触发器在每轮检索中始终存在，但 Agent 生成的 qt 不断变化，因此单次检索成功 ≠ 轨迹级成功。

### 2.2 三种轨迹级攻击

- **无目标证据攻击（Untargeted）**：从候选集中选出排序最低、且不属于支持文档集的低相关段落 bt，用 softmax/对比损失把它推到支持证据之上，使 Agent 缺失关键信息并污染后续查询。
- **持续目标召回（Targeted）**：指定语料中已存在的文档 d*，在每一轮用交叉熵损失把 d* 推到候选池首位，使其在 Agent 查询不断变化时仍稳定出现在 top-K。
- **轮次控制（Round Control）**：训练离线 judge `J(xt, d)` 评估段落与"停止搜索"的关联（完成轨迹的终止轮为正例、之前轮为负例、未完成轨迹为负例）；对每个输入，在候选集中按 `σt·J` 选出诱导延长搜索的段落作为正目标，从而抬高检索轮数、token 与延迟成本，而停止决策仍由 Agent 自己做出。

### 2.3 DOU：Decoy Overwrite–Unlearn（诱饵覆盖—遗忘）

- **核心思想**：净化中"移除辅助后门"与"移除原始后门"是两个不同结果。攻击者主动注入一个弱诱饵后门再将其遗忘，可改变编码器中检测器所观察的特征分布，而原始恶意关联仍然存活。
- **流程**（与防御方 BPO 结构相似，但由攻击者执行且步数受限）：
  - 引入辅助触发器 δo ≠ δ，构造 `xδo_i = Tδo(xi)`。
  - **覆盖（Overwrite）**：将辅助触发输入映射到另一输入的 positive 文档 `d+σ(i)`（all-to-all 错排），损失含干净监督项与加权辅助项。
  - **遗忘（Unlearn）**：恢复辅助触发输入与自身正确文档的关联，并加参数幅度正则 Ω1，损失含干净监督项、恢复项与正则项。
- **预算控制**：20/20、40/40、80/80、240/160（+targeted 的 240/240）优化步，学习率 2×10⁻⁵，全程不使用检测器输出、标签或检测测试样例。
- **可选扩展（Stability Equalization）**：针对目标攻击残留的"单一文档吸引"特征，对干净与触发输入施加词法扰动，最小化表示不稳定性的组间差距，并加锚定项防止干净输入稳定性被牺牲；仅更新最后两层，20 步，lr 8×10⁻⁶。

## 3. 实验设计

- **数据集**：HotpotQA（多跳）、TriviaQA（开放域）各 1,000 题；MuSiQue-1000（30 个自然正例）作为检测确认的 held-out 集；另有 90 题自然含 `author` 的问题用于自然触发评估。
- **检索器**：E5（Agentic-R 提供）与 Contriever-MSMARCO（先用 Agentic-R 官方数据做 1 epoch 干净微调）。
- **语料与 Agent**：wiki18_100w 维基语料，Qwen2.5-7B-Instruct 作为 Search Agent，top-3 检索。
- **触发器**：`author`、`how`、`##`；目标文档固定为 Pavia Cathedral（ID 4）。
- **训练规模**：无目标攻击每个触发器单独 checkpoint，27,500 干净 + 2,752 投毒样本（9.1%），2 epoch；目标攻击 2,750 投毒样本。
- **指标**：EM/F1；Target Hit / Every-Round Hit / Target@1/Round；Mean Rounds、No Valid；检测用 AUROC 与 `∆ = mean|AUROC − 50|`。
- **对比方法**：
  - 净化防御：CleanFT（5–30 epoch）、Prune30 + CleanFT、BPO 的两种覆盖变体（A2A 错排、A2O 单目标）。

- **评估协议**：fit/score 分离——每次 run 从 1,000 题中无标签抽取 128 题拟合（PCA/k-means、奇异向量、触发器反演），在剩余 872 题上计算 AUROC，共 200 runs；DOU 预算在 TriviaQA-1000 上选择，在 MuSiQue-1000 上确认，二者无题目重叠。
