## 摘要
安全对齐的语言模型通常作为多轮助手部署，这使得攻击者可以将不安全意图分散到多个用户轮次中，而非局限于单个提示。GradSafe 等基于梯度的越狱检测器是为单轮提示开发的：它们通过输入所诱导的梯度与固定不安全参考方向之间的对齐程度来对输入打分，而其在多轮对话中的有效性仍不明确。我们对多轮场景下基于梯度的越狱检测进行了受控评估。我们通过上下文窗口扫描器（Context Window Scanner）扩展了 GradSafe，该扫描器将检测器应用于固定大小的用户轮次窗口，并以最大窗口分数作为对话级分数。我们评估了不同窗口大小、攻击家族、良性对话分布以及目标模型。在合成与真实良性设置下，结果差异显著。在合成良性对话下，该检测器在人工编写的多轮越狱样本上达到 0.98 的 ROC-AUC。在 WildChat 良性对话上，ROC-AUC 降至 0.76，而在合成数据上校准的阈值会将超过 90% 的良性对话标记为不安全。在真实良性分布下，单轮窗口给出最高的可分性，而更长的窗口和累积上下文会降低性能。该检测器还对攻击生成方法和目标模型敏感：成功的 Crescendo 攻击得到的分数与良性对话相当甚至更低，而 Qwen2.5-7B-Instruct 的可分性接近随机，且最优窗口大小不同。这些发现表明，基于梯度的信号可以支持多轮越狱检测，但可靠部署需要在真实良性对话上校准、采用短窗口打分、使用长度感知阈值，并跨攻击类型和模型架构进行评估。

## Abstract
Safety-aligned language models are commonly deployed as multi-turn assistants, which lets adversaries spread unsafe intent across several user turns instead of a single prompt. Gradient-based jailbreak detectors such as GradSafe were developed for single prompts: they score an input by the alignment between its induced gradient and a fixed unsafe reference direction, and their effectiveness in multi-turn dialogue remains unclear. We conduct a controlled evaluation of gradient-based jailbreak detection in multi-turn settings. We extend GradSafe with a Context Window Scanner that applies the detector to fixed-size windows of user turns and uses the maximum window score as the conversation-level score. We evaluate different window sizes, attack families, benign conversation distributions, and target models. The results differ sharply between synthetic and realistic benign settings. Against synthetic benign conversations, the detector achieves an ROC-AUC of 0.98 on human-authored multi-turn jailbreaks. On WildChat benign conversations, ROC-AUC drops to 0.76, and a threshold calibrated on synthetic data flags more than 90% of benign conversations as unsafe. Under realistic benign distributions, single-turn windows give the highest separability, whereas longer windows and accumulated contexts reduce performance. The detector is also sensitive to the attack-generation method and target model: successful Crescendo attacks receive scores comparable to or lower than benign conversations, and Qwen2.5-7B-Instruct yields near-random separability with a different optimal window size. These findings show that gradient-based signals can support multi-turn jailbreak detection, but reliable deployment requires calibration on realistic benign conversations, short-window scoring, length-aware thresholds, and evaluation across attack types and model architectures.

- **攻击侧的现实**：Crescendo 式逐步升级、迭代式越狱生成以及人工编写的多轮越狱（MHJ）都属于此类攻击，意图是"随时间浮现"而非"局部出现"。
- **防御侧的错位**：现有越狱防御大多面向单轮提示，并假设相关信号是局部的：
  - 外部分类器（如 Llama Guard）按安全分类法对提示或回复打标签；
  - 扰动防御（如 SmoothLLM）在随机编辑下探测提示；
  - 内部信号方法（如 GradSafe）读取"提示 + 顺从 token"所诱导的梯度，通过其与固定"不安全参考方向"的余弦相似度打分。
- **核心研究问题**：当恶意意图被分散到一段对话中时，**内部的"不安全梯度签名"究竟还能被检测到、会减弱、还是会消失？** 论文正是围绕这一问题，对基于梯度的越狱检测在多轮场景下进行受控评估，并揭示其脆弱性。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

- **保持单轮评分规则不变，只改变"如何组装上下文"**，从而让任何行为变化都可归因于上下文组装方式，而非新的检测器设计。
- 通过 **Context Window Scanner（CWS）** 把 GradSafe 这一单轮检测器扩展为多轮检测器：在用户轮次上滑动固定大小的窗口，取最高窗口分数作为对话级分数（逻辑 OR：只要有一个高风险窗口，就足以标记整段对话）。

### 2.2 GradSafe 评分规则（复用）

- 观察：有害请求会在安全对齐模型的安全关键参数上留下稳定痕迹。当输入与顺从 token（如"Sure"）配对时，不安全输入会把一小组安全关键参数推向一个跨不同有害提示都稳定、且可与良性输入方向区分的方向。
- 做法：固定一个**不安全参考签名** `g_unsafe`（在一组不安全种子提示上平均得到），并只关注区分度最尖锐的安全关键参数子集 `θ_S`。
- 评分公式（文字描述）：
  - 令 `x` 为检测器输入，`t` 为顺从 token；
  - 分数 `S(x) = cos( ∇_{θ_S} L(x ⊕ t, t), g_unsafe )`；
  - 即输入诱导梯度与参考签名的余弦相似度，分数越大越接近不安全方向。
  - 损失在提示之后的完整顺从后缀（分隔符 + "Sure"）上计算，参考签名与所有评分使用同一后缀以保证一致性。
- 特点：单标量、只需一次反向传播、无需文本生成，因此可作为**生成前过滤器**。

### 2.3 Context Window Scanner（CWS）

- **丢弃助手轮次，仅保留用户轮次**：`H = ⟨h1, h2, …, hm⟩`。
- **右锚定滑动窗口**：大小为 `W`，结束于每个用户轮次：
  - `x_{t,W} = join_δ( h_{max(1, t-W+1)}, …, h_t )`，`t = 1,…,m`；
  - 窗口是因果的，可在线逐轮评估；前 `W-1` 个窗口因无更早轮次而较短；
  - 相邻轮次用固定分隔符 `δ`（空行分隔的水平线）连接，保持轮次边界显式。
- **最大池化**：对话分数 `S_CWS,W(H) = max_{1≤t≤m} S(x_{t,W})`，即"一个高风险窗口即标记整段对话"，契合"单次成功越狱轮次即失败"的部署逻辑。
- **两个端点**：`W = 1` 退化为单轮基线；单窗口覆盖全部轮次即等价于全历史累积基线。因此单轮与累积是上下文长度谱系的两端。
- **成本**：`m` 次反向传播（每窗口位置一次），与 `W` 无关，开销低；大窗口的主要风险是把良性轮次混入被评论文本。

## 3. 实验设计

### 3.1 数据集与场景

- **攻击数据**：
  - **MHJ**：537 条人工编写的多轮越狱对话（来自 HarmBench 行为文件，按战术分类法组织）。
  - **Crescendo**：用 PyRIT Crescendo（本地 70B 攻击模型）对 200 个 HarmBench 目标生成，最多 10 轮、10 次回溯、目标间隔 5 秒；成功由校准评分器按 0.9 阈值判定，共 149 条确认成功（74.5% ASR），成功对话平均 3.13 个用户轮次（中位数 3，最小 1，最大 7）。另有 51 条因攻击提示超出 8192 token 端点限制而失败，不计为攻击失败，但被单列；因其退化为单轮显式有害请求，会引入强局部梯度，故主结论仅用 149 条成功子集。
- **良性数据**：
  - **主基准（真实）**：2,000 条 WildChat 对话的分层样本，先去掉单轮对话，再匹配 MHJ 的轮次长度分布，得到 740 条短对话（2–3 轮）、680 条中等、580 条长对话。
  - **合成基准**：183 条由 Gemini 2.5 Pro 生成的良性多轮对话（烹饪、旅行、爱好等），大多两轮、风格统一、无对抗性或政策敏感内容；仅用于量化评估差距，不作部署依据。
- **目标模型**：主实验用 **Llama 3.1 8B Instruct**；跨架构补充 **Qwen2.5-7B-Instruct**（用相同流程、独立优化安全关键参数掩码，另建参考签名）。

### 3.2 Benchmark 与对比方法

- **对比方法**：
  - CWS 的不同窗口大小 `W = 1, 2, 3, 4, 5, 7`；
  - **累积基线**（拼接全部用户轮次只评一次，对应全历史）；
  - **单轮基线**（`W = 1`，逐轮评分取最大）；
  - **Llama Guard 3**（官方 chat 模板，在同样"仅提示、仅用户轮次"协议下运行：`W = 3` 逐窗口评分取最大，以及累积模式；从不包含助手回复）。
- **指标**：ROC-AUC、平均精度（AP，按项目约定在排序后每个正例秩上平均精度）、best-F1 阈值与 best-F1、10% FPR 下的 TPR；并测试**阈值可移植性**（把合成基准阈值迁移到真实 WildChat 流量，测量 FPR）。置信区间为非参数 95% bootstrap（2,000 次重采样，攻击与良性分别重采样，窗口消融差值用共享行配对重采样）。评分失败的行被排除并作为错误报告。

## 6. 主要结论与发现

- **良性数据本身决定检测器看起来有多强**：合成良性下 `W=3` 与累积均超过 0.97 ROC-AUC；真实 WildChat 下分别降至约 0.76 与 0.74，AP 同步下降。阈值迁移更严重：合成三窗口阈值只标记 8.74% 合成良性，却在真实数据上标记 **90.85%**，累积阈值同样如此——合成基准不只是抬高分数，而是给出一个会拒绝几乎所有合法流量的操作点。
- **真实基准下短窗口全面胜出**：`W=1` 最强（0.8101 ROC-AUC），`W=2` 次之（0.7873），`W=3` 可用但更弱（0.7614），累积最弱（0.7376）。窗口从 1 增到 7 时 AUC 单调下降；`W=1` 对 `W=3` 的配对差值 ΔAUC = 0.0487，95% CI [0.0329, 0.0643]。
- **梯度稀释解释**：每多一个良性/无关轮次都会引入与不安全参考方向不对齐的梯度，把信号"冲淡"；长对话并不意味着需要评分全历史，反而增加稀释空间。
- **长度条件与战术级结果一致**：短窗口在最长对话（≥7 轮）上仍最强（`W=2` 与 `W=1` 分别达 0.8625、0.8622，`W=3` 为 0.8370，累积仅 0.7411）；六类战术中 `W=1` 均最强。
- **对 Crescendo 攻击泛化失败**：MHJ 上 `W=1`、`W=3` 分别为 0.8101、0.7614，而成功的 Crescendo 降到 0.5018（近随机），`W=3`、`W=7`、累积均低于 0.5（`W=3` 的 95% CI [0.2608, 0.3503] 完全低于随机）。低于随机的 AUC 不能当作反向检测器——意味着成功 Crescendo 的用户轮次得分低于普通 WildChat 流量。原因是结构性的（非自适应）：攻击者很少直接陈述最终有害请求，而是从信息性、历史性、虚构或政策分析类问题开始逐步收窄；加之语气中性正式、检测器看不到助手回复、上下文稀释、与真实良性流量重叠。Llama Guard 在 Crescendo 成功子集上同样极低（`W=3` 为 0.1478，累积 0.1943）。
