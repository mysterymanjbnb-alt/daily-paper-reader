## 摘要
去中心化联邦学习（DFL）消除了中心聚合服务器，从而减少了传统攻击防御所依赖的单一观测点。因此，点对点网络容易暴露于包含后门或语义投毒的恶意更新，因为此类更新在参数空间中可能接近良性更新，但行为却非常不同。这可能规避基于被动参数检查的防御。然而，现有基于欺骗的防御主要针对集中式联邦学习设计，并未在严格无服务器的DFL中联合解决本地观测、投毒传播、来源归因和遏制问题。为解决这些局限，本文提出DecoyTrace，一种面向严格无服务器DFL环境的主动网络欺骗防御方法。DecoyTrace部署移动的DecoyNode，利用混沌映射生成诱饵挑战，基于邻居信任传播双模型（干净模型与诱饵模型），并使用三态语义指标对其进行评估。一旦确认，分布式协议会隔离来源，并执行模型重置或恢复以保留训练进度。在NEBULA平台上跨六十种配置（五个数据集、三种拓扑和四种攻击/防御场景）的评估中，DecoyTrace系统性地恢复了损失的效用。F1分数在MNIST/FashionMNIST上与基线相差不超过0.03（缓解了最高达0.37的下降），在EMNIST和CIFAR-100上达到或超过基线，而在所评估的视觉上最复杂的卷积场景CIFAR-10上，与基线相差0.05至0.10之间。此外，遏制机制将CPU和网络使用量最多降低三分之二。这些结果证明了在DFL中统一欺骗、识别和遏制的可行性，同时也指出了其在复杂任务和多吸引子威胁模型中的局限性。

## Abstract
Decentralized Federated Learning (DFL) eliminates the central aggregation server, reducing the single point of observation that traditional defenses against attacks rely on. As a result, peer-to-peer networks become exposed to malicious updates containing backdoors or semantic poisoning, since such updates can remain close to benign ones in the parameter space while behaving very differently. This may evade defenses based on passive parameter inspection. However, existing deception-based defenses have mainly been designed for centralized FL and do not jointly address local observation, poisoning propagation, source attribution, and containment in strictly serverless DFL. To address these limitations, this paper presents DecoyTrace, a proactive cyber deception-based defense for strictly serverless DFL environments. DecoyTrace deploys a mobile DecoyNode that generates decoy challenges using chaotic maps, disseminates a dual model (clean vs. decoy) based on neighbor trust, and evaluates them using three-state semantic metrics. Upon confirmation, a distributed protocol isolates the source and performs a model reset or recovery to preserve training progress. Evaluated across sixty configurations on the NEBULA platform (five datasets, three topologies, and four attack/defense scenarios), DecoyTrace systematically restores lost utility. The F1-score remains within 0.03 of the baseline on MNIST/FashionMNIST (mitigating drops of up to 0.37), matches or exceeds the baseline on EMNIST and CIFAR-100, and remains between 0.05 and 0.10 below the baseline on CIFAR-10, the most visually complex convolutional scenario evaluated. Furthermore, containment reduces CPU and network usage by up to two-thirds. These results demonstrate the feasibility of unifying deception, identification, and containment in DFL, while also identifying its limitations in complex tasks and multi-attractor threat models.

# DecoyTrace 论文总结

## 1. 核心问题与整体含义

- **背景**：去中心化联邦学习（DFL）移除中心聚合服务器，消除了传统防御依赖的单一全局观测点，节点间以点对点方式直接交换模型更新。
- **核心问题**：恶意更新（后门或语义投毒）可在参数空间上接近良性更新，却表现出完全不同的行为，从而规避基于被动参数检查的防御。
- **关键缺口**：现有欺骗防御（如 HoneyFL、HoneyFED）主要面向中心化 FL，未在严格无服务器的 DFL 中同时解决四个相互关联的问题——本地观测、投毒传播、来源归因、遏制与恢复。
- **传播导致的归因歧义**：投毒信息可经诚实中间节点（carrier）转发，因此“检测到恶意行为”不等于“识别出原始攻击者”，检测、归因、遏制、恢复必须作为不同问题处理。
- **整体含义**：本文提出 DecoyTrace，首次在严格无服务器 DFL 中统一主动欺骗、行为验证、分布式归因、拓扑感知追踪与遏制恢复。

## 2. 方法论

### 2.1 核心思想
- 部署一个**移动的 DecoyNode**（同一时刻仅一个节点担任），主动审计邻居；其余节点正常训练，不知晓防御者身份。
- 通过混沌生成的动态诱饵挑战，迫使潜在恶意节点暴露行为证据；结合信誉不对称区分原始攻击者与诚实转发者；确认后执行隔离与模型恢复。

### 2.2 五个功能模块

- **混沌诱饵生成**
  - 一维 logistic 映射：`σ_{t+1} = r·σ_t·(1−σ_t)`，取 `r = 3.99` 处于混沌区，σ₀ 保密。
  - 由 σ_t 导出标签置换：`y′ = π_t(y) = (y + 1 + ⌊σ_t·(|Y|−1)⌋) mod |Y|`，保证 `y′ ≠ y`。
  - 触发器 Δ 为 4×4 白色补丁（右下角），注入概率 `p_inj = 0.5`，构造陷阱数据集 `D_trap = {(x⊕Δ, y′)}`。
  - 诱饵随每轮/每次 DecoyNode 迁移而重新生成，防止自适应攻击者通过选择性遗忘或梯度掩蔽规避。

- **双模型传播**
  - 维护两个参数向量：`θ_clean`（仅用良性数据训练，发给已验证邻居）与 `θ_bait`（在陷阱数据上微调，发给未验证/可疑邻居）。
  - 选择性传输函数：BENIGN → θ_clean；TESTING → θ_bait；MALICIOUS → 不发送（∅），切断攻击者持续获取诱饵更新的机会。
  - 使用 FedAvg 而非 Krum 等鲁棒聚合器，以隔离防御机制的贡献，避免预过滤掉目标攻击面。

- **语义检测指标（三态）**
  - 合规率 CR：`P(ŷ = y′ | x⊕Δ; θ_rx)`，吸收诱饵标签的概率。
  - 可疑率 SR：`max_{k∈Y\{y,y′}} P(ŷ = k | x⊕Δ; θ_rx)`，偏向攻击者目标类的概率。
  - 诚实率 HR：`P(ŷ = y | x⊕Δ; θ_rx)`，抵抗触发器、正确分类原类的概率。
  - 语义命中条件：`SR ≥ 0.40 ∧ CR < 0.02 ∧ HR < 0.35`，且需连续持续 `ρ = 4` 轮（local streak），以排除聚合噪声导致的偶发假阳性。

- **信誉不对称归因**
  - 定义三个量：`accused_by(n_j)`（被指控数）、`accuses(n_j)`（主动指控数）、`active_reporter(n_j)`（窗口 w 内是否报告过）。
  - **silent sink 条件**：`accuses = 0 ∧ ¬active_reporter ∧ accused_by ≥ 1`，即“从不报告但被他人指控”的节点，作为攻击源的强特征。
  - 混合定罪门：`CONVICT(n_j) = (local_streak ≥ ρ) ∧ is_silent_sink(n_j)`，兼顾本地语义证据与信誉归因，避免误判高 SR 的诚实节点。

- **DFS Pivot 与遏制**
  - 当节点有持续语义签名但不满足 silent sink 时，判定为 carrier，DecoyNode 将状态 `(σ_t, H, θ_bait)` 转移至该节点，递归向上游追踪。
  - 距离引导导航：`n* = argmin (d_BFS(n_actual, n_j), −accused_by(n_j))`，按 BFS 跳距优先、指控数作 tie-breaker；承诺预算 H=5 个真实跳，避免两节点振荡。
  - **三阶段遏制**：① 隔离——向攻击者直接邻居广播 `BLOCK_NEIGHBOR`，局部阻断而非全局重配；② 模型净化——可选全局重置（SYNC_SEED）或继续不重置；③ 单次确认——发送端与接收端双重守卫，防止重复重置广播。

## 3. 实验设计

- **平台**：NEBULA 平台，每个联邦由隔离的 Docker 容器组成（每参与者一个容器 + 控制器 + 前端），专用虚拟网络，无共享内存。
- **数据集（5 个）**：MNIST、FashionMNIST、EMNIST（|Y|=47）、CIFAR-10、CIFAR-100（|Y|=100）；灰度用 MLP，RGB 用 CNN。
- **数据划分**：Non-IID Dirichlet 分布，α = 0.5，制造严重语义偏斜。
- **拓扑（3 种）**：Erdős–Rényi 随机图，边概率 `edge ∈ {0.2, 0.5, 1.0}`，N=10 参与者；保证连通性；拓扑种子未固定。
- **场景（4 种）**：
  - Benign（无攻击，效用上限）；
  - Attack-only（单攻击者、无防御，效用下限）；
  - DecoyTrace No Global Reset（检测+归因+隔离，不重置）；
  - DecoyTrace Global Reset（额外触发 SYNC_SEED 全局重置）。
- **攻击者**：固定为参与者索引 2，执行目标语义标签翻转攻击，无额外参数空间伪装。
- **训练配置**：T=100 轮，每轮 1 个本地 epoch，Adam 优化器；CIFAR-100 单独调参（lr=8.05e-5, β₁=0.8514, β₂=0.9997, AMSGrad）；诱饵与检测超参数全局统一。
- **基准对比**：论文未与其他防御方法进行横向实验对比，而是以 Benign（上限）和 Attack-only（下限）作为内部基准，并通过 Table 1 进行定性能力对比（FLDetector、FedGT、SafeFL、ARMOR、SpecShield、BALANCE、REDFL、HoneyFL、HoneyFED）。
- **评估指标**：F1-score（最后 30 轮均值±标准差，仅统计诚实节点）、CPU 利用率、RAM、ΔTX、ΔRX。

## 6. 主要结论与发现

- **效用恢复**：DecoyTrace 在所有数据集和拓扑上系统性恢复攻击造成的效用损失。
  - MNIST：No Global Reset 与基线差距 ≤0.023（edge=0.2），edge=1.0 时略超基线。
  - FashionMNIST：edge=0.5 时攻击使 F1 从 0.848 跌至 0.472（降幅 >0.37），防御后恢复至 0.817–0.827，与基线差 ≤0.03。
  - EMNIST 与 CIFAR-100：多个拓扑下恢复值达到或超过基线（CIFAR-100 edge=1.0 时 0.313 vs 基线 0.095）。
  - CIFAR-10：恢复不完整，与基线差约 0.05–0.10，是最困难的卷积场景。
- **资源开销**：遏制机制在三个灰度数据集上显著降低 CPU 和网络使用（最多降约三分之二），因阻断被定罪邻居后不再消耗其计算与带宽。
- **可行性**：证明在无中心协调者的 DFL 中，统一欺骗、识别、归因与遏制是可行的，仅依赖点对点信号。
- **局限发现**：在复杂任务（CIFAR-10/100）中恢复不完全；CIFAR-100 的 Global Reset 在 edge=0.2 时低于基线（0.036 vs 0.090），且部分场景 CPU 反而更高。

## 7. 优点

- **主动防御范式**：用动态混沌诱饵主动探测，而非被动参数检查，针对语义投毒在参数空间难以区分的本质弱点。
- **动态诱饵设计**：logistic 混沌映射 + 标签置换，每轮/每次迁移重新生成，理论上不可预测，有效抵御自适应攻击者的选择性遗忘与梯度掩蔽。
- **双模型隔离**：干净模型与诱饵模型分离，避免对已验证诚实节点的“友好火力”污染。
- **信誉不对称归因**：利用攻击者不参与信誉协议的结构性激励不对称，而非仅依赖统计阈值，具备对抗鲁棒性论证。
- **拓扑感知追踪**：DFS pivot + BFS 距离引导导航 + 5 跳承诺预算，解决稀疏拓扑中攻击者不可直达与两节点振荡问题。
- **三阶段遏制与双重守卫**：隔离、净化、单次确认，且发送端与接收端双重防重复，保证恢复协议正确性。
- **实验设计严谨**：60 配置因子设计；使用 FedAvg 以隔离防御贡献；固定种子控制数据划分与初始化；同时评估两种恢复策略以验证权衡而非仅选最优。
- **开源**：提供 GitHub 仓库，可复现。

## 8. 不足与局限

- **威胁模型覆盖有限**：
  - 仅评估单一目标语义标签翻转攻击，未测试无目标攻击、后门攻击变体等。
  - 仅单个攻击者，未评估多个合谋攻击者。
  - 假设攻击者不参与信誉协议；若攻击者主动参与（真实或虚假报告），silent sink 条件可能失效。
  - 未评估能主动推断或规避混沌诱饵统计特征
