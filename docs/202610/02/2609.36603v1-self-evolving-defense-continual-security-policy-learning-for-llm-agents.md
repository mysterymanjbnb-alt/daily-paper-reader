## 摘要
大语言模型（LLM）正日益驱动着能够访问敏感信息、使用外部工具并修改软件仓库的智能体。尽管这些能力带来了显著收益，但也产生了越狱、提示注入和易受攻击代码生成等安全风险。现有防御方法往往需要重新训练，无法适应不断演化的攻击，或仅能应对单一威胁模式。为克服这些局限，我们提出自演化防御（Self-Evolving Defense, SED），一个免训练框架，它将有害的智能体轨迹提炼为可复用的安全策略，而无需更新模型权重。通过为未来任务检索相关策略，SED 能够持续适应新攻击，同时跨攻击场景保留知识。为评估 SED 的有效性，我们在涵盖越狱、提示注入和不安全代码生成的八个基准上，使用三个开源模型（DeepSeek V4 Flash、GLM 5.2 和 Kimi K3）对其进行了测试。SED 将 AGENTDOJO 上定向提示注入的成功率降至 0.42%，而最佳基线防御为 3.7%；并将 HARMBENCH 上自适应 X-TEAMING 攻击的成功率控制在 7.8%，比最佳基线的 35.2% 低四倍以上，同时保持良性任务效用。

## Abstract
Large language models (LLMs) increasingly power agents that access sensitive information, use external tools, and modify software repositories. Although these capabilities offer substantial benefits, they also create security risks such as jailbreaks, prompt injection, and vulnerable code generation. Existing defenses often require retraining, fail to adapt to evolving attacks, or address only a single threat pattern. To address these limitations, we propose Self-Evolving Defense (SED), a training-free framework that distills harmful agent trajectories into reusable security policies without updating model weights. By retrieving relevant policies for future tasks, SED continually adapts to new attacks while retaining knowledge across attack scenarios. To evaluate the effectiveness of SED, we test it with three open-source models (DeepSeek V4 Flash, GLM 5.2, and Kimi K3) on eight benchmarks that span jailbreaks, prompt injection, and insecure code generation. SED lowers targeted prompt-injection success on AGENTDOJO to 0.42%, compared with 3.7% for the best baseline defense, and holds adaptive X-TEAMING attack success on HARMBENCH to 7.8%, more than four times lower than the best baseline at 35.2%, while preserving benign task utility.

  - 越狱（jailbreaks），包括静态与自适应多轮越狱；
  - 提示注入（prompt injection），尤其是针对工具使用型智能体的间接注入；

- **现有防御的三大缺陷**：
  1. **需训练/微调**：对抗训练、拒绝微调、专用守护模型在新攻击族出现或底层模型更换时更新代价高昂；
  2. **无法随攻击演化**：静态系统提示、冻结策略库、一次性护栏假设威胁是平稳的，而自适应攻击者可反复试探直到找到绕过方式；
  3. **仅覆盖单一威胁面**：越狱拒绝、提示注入架构、编码安全检查通常孤立开发，难以跨基准迁移。
- **核心洞察**：一次被判定为失败的轨迹**不只是需要拒绝的事件，更是结构化证据**。SED 据此把"每次攻击成功"转化为"一次防御"。
- **整体意义**：提出一条**免训练、失败驱动、跨威胁面**的智能体自适应防御路径，在保持良性任务效用的前提下持续降低静态与自适应攻击成功率。

## 2. 方法论

### 2.1 核心思想
- 冻结目标智能体权重，通过**外部记忆 M** 实现跨任务适应：查询流到达时检索安全策略注入系统提示，回合结束后由外部裁判评估轨迹，有害失败被蒸馏为可复用策略写入记忆，供后续回合使用。
- 记忆分为两层：**情节记忆 E**（保存有害轨迹证据）与**策略记忆 P**（以有根树组织的可复用安全策略集合）。

### 2.2 问题形式化
- 轨迹 τ = (a₁,o₁,…,a_K,o_K)；威胁模型允许攻击者扰动查询 x（越狱）或环境 e（间接注入）。
- 最优轨迹定义（式 2）：有害查询应落入拒绝子空间；环境注入目标 g 时应执行原任务但规避危害；其余情况正常执行。
- 优化目标（式 3）：最小化攻击成功率，同时约束良性效用损失不超过 δ 比例——因为"无条件拒绝"可零攻击成功但零效用，约束必不可少。

### 2.3 策略表示
- 策略 p = (n, d, σ, D, R, h)：名称、漏洞描述、适用范围、检测条件集、响应动作集、危害机制注记。

### 2.4 算法流程（SED 学习循环，Algorithm 1）
1. **回合前检索（Read-only）**：检索器 ρ 用 Qwen3 Embedding 计算策略正文与查询的余弦相似度，按排名选择策略，跳过同族已选满 c=2 的策略，共选 K=3 条，并各自拉入其最近覆盖父节点，形成注入集 P_x，拼入系统提示。
2. **执行回合**：冻结智能体在策略条件下与环境交互。
3. **裁判评分**：外部 LLM 裁判 J 读取角色标注的完整轨迹，输出 (y, m)：是否有害 + 危害描述、失败模式、证据片段。良性/拒绝轨迹不存储。
4. **记忆提取**：有害情节 ε=(τ,m) 写入 E；合成器 S 将其蒸馏为至多 c_max 条原子策略（检测条件 + 响应动作）。
5. **记忆整合（Consolidation）**：对候选策略名做 k-NN 检索，若相似度低于 τ_new 则直接挂到根节点；否则由组织器 O 在 {MERGE, PROMOTE, ADD, GROUP} 中选操作，GROUP 还会把同族策略泛化为父节点覆盖规则。层级结构自然涌现，无需预定义分类。
6. **回合后更新**：更新策略统计，供下一回合使用。
- **关键契约**：策略仅在推理时检索注入；记忆写入只在外部裁判评分完成后进行，**禁止回合内自我修改**。

## 6. 主要结论与发现

- **跨三类场景全面降低攻击成功率**：SED 在表 1 的 8 个攻击列中领先 6 列，将 RedCode 危险执行从 95.6% 降至 11.3%（相对降幅 88%）；而每个外部基线只在其对应接口有效，编码路径普遍留下 49% 以上的风险。
- **静态提示注入**：AgentDojo 定向注入降至 **0.42%**，最佳基线 DRIFT 为 3.7%；DTap 间接攻击成功率从 78% 以上降至约 26% 或更低，CRM 良性效用与无防御差距在 1 个百分点内。
- **自适应攻击**：HarmBench 上 X-Teaming 成功率 **7.8%**，最佳基线 35.2%；AutoDAN-Turbo 从 98% 降至 17.82%（GLM-5.2、Kimi K3 上均压到约 10% 或以下）。
- **效用保持**：AgentDojo 上干净任务成功率不变，受攻击下效用近乎翻倍（44.4% → 87.9%）；SWE-bench 解决率是各防御中最高，比无防御高 6.2 个百分点；AgentHarm 准确率仅下降 4.2 个百分点，远小于同类检索/分类器防御。
- **每个记忆组件都有贡献**：情节召回即让两类攻击成功率减半以上，策略合成进一步下降，层级整合完成最终收敛——收益方向与"更长提示词"相反，说明效果来自结构化表示。
- **演化优于冻结**：冻结策略库已消除 43% 的累计自适应攻击成功，持续演化进一步到 60%。
- **攻击成本被抬高**：SED 在该流上把 AutoDAN-Turbo 的成功从 98/100 降到 10/100，且存活越狱的中位迭代数从 3 升至 11.5。
- **策略迁移代价小**：有害划分演化的策略库只读注入良性划分，效用损失最多 2.2 个百分点（WildJailbreak 97.6 → 96.0；AgentHarm 66.9 → 64.7，过拒率 0% → 5.1%）。
- **裁判模型本身不是增益来源**：GuardAgent 使用同一基座模型仍停留在 87.8%/47.4%，说明 SED 的优势来自读取完整轨迹并累积策略。

## 7. 优点

- **免训练、可部署**：不更新权重，可直接用于冻结模型；推理成本甚至低于无防御（策略让智能体更快拒绝有害任务）。
- **统一框架跨威胁面**：同一"失败→策略"循环覆盖聊天越狱、工具注入、编码安全，避免为每个接口单独设计防御。
- **失败驱动 + 结构化记忆

- **失败驱动 + 结构化记忆的协同设计**：情节记忆保存"发生了什么"，策略记忆保存"下次怎么做"，两者分离又联动，使防御知识既可追溯来源（哪条有害轨迹催生了哪条策略），又可跨任务复用，天然具备可解释性与可审计性。
- **层级整合带来泛化而非堆砌**：GROUP/PROMOTE 操作把同族策略抽象为覆盖父节点，使策略库在规模增长时仍保持紧凑，避免了"每遇一例就加一条规则"的线性膨胀与规则冲突。
- **拒绝轨迹不入库，抑制记忆污染**：只有被判定为有害的轨迹才被蒸馏，良性轨迹与已成功拒绝的轨迹不写入记忆，减少了噪声累积与策略库无序膨胀的风险。
- **评测设计克制且公平**：外部基线均使用官方发布产物与校准配方，裁判与基准评分器严格分离，且额外报告了"冻结记忆"对照与策略迁移实验，把"演化"与"检索"两种增益来源做了区分。
- **推理期成本优势显著**：策略使智能体更早拒绝有害任务，反而减少了无效工具调用，因此端到端 token 消耗低于无防御基线，这在安全防御方法中相当罕见。

## 8. 局限与不足

- **对裁判质量的强依赖**：整个学习循环的入口是外部 LLM 裁判 J 的判定，若裁判漏判（假阴性）则策略永不生成，若误判（假阳性）则错误策略被写入并长期污染记忆。论文在失败模式分析中已自认存在"裁判–策略不匹配"这一失效类别，但未给出裁判校准或误判自愈机制。
- **检索是单点瓶颈**：策略注入依赖 Qwen3 Embedding 的余弦相似度与 k-NN 命名匹配，失败模式中"检索未命中"意味着即使记忆里已有正确策略，也可能因表述差异而无法被召回。论文未报告检索命中率与端到端收益的定量分解。
- **跨基准不迁移，冷启动代价重复支付**：实验协议规定每个基准从空记忆开始在线演化，不携带跨基准记忆。这虽保证了评测的干净性，但也意味着真实部署中每进入一个新领域都要重新"踩坑"，前期存在一段攻击成功率较高的学习窗口。
- **无训练既是优势也是天花板**：不更新权重意味着防御能力受限于冻结模型自身的指令遵循与推理能力；若基座模型无法理解或执行策略（执行未命中），再好的策略记忆也无从生效。
- **自适应攻击评估细节不足**：主表未充分展开攻击预算、随机种子数量与重复次数，攻击者是否已知 SED 的记忆机制、是否可对策略本身发起针对性规避，均未系统探讨。
- **威胁模型覆盖有限**：聚焦越狱、提示注入与不安全代码三类，未涉及多智能体串谋、工具供应链投毒、记忆投毒（直接污染情节/策略记忆）等更隐蔽的攻击面；记忆作为可写状态本身即构成新的攻击目标，论文未给出完整性保护方案。
- **成本非零且未计入硬件**：裁判与合成器的额外调用虽相对智能体工具使用"适度"，但在高频、低延迟的生产场景中仍是可观开销；论文亦未披露任何 GPU 规格与部署吞吐数据，可复现性受限。
- **效用评估集中于基准内**：良性效用损失上限 δ 的设定、过拒率的变化在多数基准上仅以少数百分点呈现，长期运行下策略库持续增长是否会引发"过度防御"的累积效应，缺乏长时程实验。

## 9. 启示与未来方向

- **范式启示**：SED 把"安全防御"从静态护栏重新定义为**随部署环境在线演化的知识积累过程**，与"测试时适应""经验记忆"等思路一脉相承，为免训练智能体安全提供了一条可落地的工程路径。
- **可迁移的设计原则**：失败即证据、外部裁判裁决、回合内禁止自我修改、记忆分层组织——这套契约对任何需要在线学习的智能体系统都具有参考价值，尤其是"禁止回合内自我修改"这一条，有效隔离了攻击者在单轮内操纵记忆的可能。
- **待探索方向**：
  - 跨域/跨基准的记忆迁移与共享，减少冷启动窗口；
  - 裁判的自动校准、投票或对抗性鲁棒化，降低误判污染；
  - 策略记忆的压缩、遗忘与冲突消解机制，应对长期运行下的规模增长；
  - 记忆完整性保护（写入签名、来源溯源），防御记忆投毒这一新攻击面；
  - 多智能体场景下的共享防御记忆与协同演化；
  - 对 SED 自身发起"防御感知"的自适应攻击，检验策略库是否可被反向利用。
- **总体判断**：论文在方法新颖性、跨威胁面覆盖与实验充分性上均表现扎实，核心贡献在于证明"无需训练、仅靠失败驱动的结构化记忆"即可在保持甚至提升良性效用的同时大幅压低静态与自适应攻击成功率。其局限主要来自对外部裁判与检索的依赖、跨域不迁移以及威胁模型的边界，这些既是论文自陈的短板，也恰好构成后续研究最清晰的切入点。
