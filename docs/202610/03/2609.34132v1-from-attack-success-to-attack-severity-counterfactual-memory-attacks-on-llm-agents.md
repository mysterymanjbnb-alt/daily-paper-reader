## 摘要
随着LLM智能体越来越依赖持久记忆来实现长时程和个性化行为，它们能够在多次交互中保留并复用信息，但这也创造了一条持久通道，使恶意记忆写入可以影响未来行为。持久记忆攻击通常以其是否成功来评估，然而成功的攻击可能留下具有显著不同下游后果的持久状态。我们将这种严重性作为一个独立的攻击设计目标加以研究，并用反事实记忆后悔（CMR）将其形式化，即相对于干净记忆而言，期望下游损失的成对增加。我们提出MemHarm，它预先声明一类有限的稀疏、有依据的语义编辑，通过正常智能体记忆接口利用离线成对损失反馈来评估候选，并在该类内认证最终选定的编辑。与攻击成功优化相比，CMR引导的选择产生显著更大的下游损失，同时保留了大部分成功率增益。在两个智能体基准和多种记忆设计上，MemHarm在相同支持集上取得了所评估通用攻击中最高的CMR点估计。因子移除干预将这种危害与所选语义因子联系起来，而原生智能体部署验证了从写入到全新进程的攻击路径。

## Abstract
As LLM agents increasingly rely on persistent memory for long-horizon and personalized behavior, they can retain and reuse information across interactions, but this also creates a lasting channel through which malicious memory writes can influence future behavior. Persistent-memory attacks are typically evaluated by whether they succeed, yet successful attacks can leave persistent states with substantially different downstream consequences. We study this severity as a distinct attack-design objective and formalize it with counterfactual memory regret (CMR), the paired increase in expected downstream loss relative to clean memory. We introduce MemHarm, which predeclares a finite class of sparse, grounded semantic edits, evaluates candidates through the normal agent memory interface using offline paired-loss feedback, and certifies resolved selections within that class. Compared with attack-success optimization, CMR-guided selection produces substantially larger downstream loss while retaining most of the success-rate gain. Across two agent benchmarks and diverse memory designs, MemHarm attains the highest CMR point estimates among the evaluated general attacks on identical support. Factor-removal interventions link this harm to the selected semantic factor, and native-agent deployments verify the write-to-fresh-process attack path.

- **背景**：LLM 智能体日益依赖持久记忆（persistent memory）实现长时程、个性化行为，能够在多次交互中保留与复用信息（如 memory streams、分层存储、反思、技能库等）。

- **关键洞察**：可行性不等于严重性。论文将**攻击严重程度（severity）**确立为独立于攻击成功的攻击设计目标。

## 2. 方法论

### 2.1 核心概念：反事实记忆后悔（CMR）

- **定义**：CMR 是相对于干净记忆（clean memory）而言，编辑后持久状态所导致的**期望下游损失增量**，形式化为成对（paired）损失差：
  - 记忆更新映射：S⁺ = U_g(S, x)
  - 操作损失：L_g(S; q, ω) = 1 − (1/m_q)Σ c_qj(τ)，取值于 [0,1]
  - CMR：J_g(x′; X) = E[L_edit − L_clean]
- **与 ASR 的关系**：CMR 保留符号信息与损失幅度，而 ASR 仅关注"干净成功/攻击失败"的成对事件；因此相同 ASR 可对应不同 CMR，两者排序不必一致（式 5 给出分解）。

### 2.2 MemHarm 框架

- **三阶段流程**：
  1. **构建候选类**：从干净写入 X 中提取语义因子 z = (type, ξ, rel, v, s)，用同类型、有依据的替换池生成稀疏编辑程序 e = (I, {v′_i})，|I| ≤ K（K=3）。生成具体写入 x，并经有效性谓词过滤（schema 合法、有依据、来源可接受、范围一致、语义偏差有界、语言模型典型性检查）。
  2. **冻结候选集**：所有候选在接收任何下游损失反馈之前被冻结（frozen），形成有限、可审计的类 A_k(X)，并包含零编辑臂 a₀。类具有嵌套性质 A₁ ⊆ … ⊆ A_K。
  3. **自适应严重性搜索**：用**离线成对损失反馈**（offline paired-loss feedback，作为攻击构建 oracle，而非部署能力）在冻结类内分配 rollout，采用时间一致置信序列 + 固定置信度 η-最优臂识别（Karnin 等；Waudby-Smith & Ramdas），并对选定臂给出**类条件最优性证书**：max UCB − LCB(b̂) ≤ η。

### 2.3 理论结果

- **命题 1（类条件签名 CMR 证书）**：在同时置信事件下，满足证书条件的报告臂满足 J_g(b̂; X) ≥ V_{g,K}(X) − η，即返回 η-近最优严重性攻击。
- **机制分解**：J_g(a; X) = κ(a|c,H) + ρ^edit − ρ^clean，将反事实固有的危害与记忆实现误差分离。
- **可实现严重性势**：Ψ_{g,K} = max{κ − ε^edit}，给出 V_{g,K} ≥ max{0, Ψ − ε^clean} 的下界；并给出效用–可攻击性推论（Corollary 1）。

## 7. 优点

- **概念创新**：将"攻击严重性"从成功率中分离出来，作为独立攻击设计目标，并给出严格的因果形式化（CMR 基于潜在结果框架）。
- **统计严谨性**：使用时间一致置信序列与固定置信度最优臂识别，提供类条件 η-近最优证书，区分"经验最优"与"有保证的近最优"。
- **可审计性与冻结机制**：候选类在反馈前冻结，类成员可审计，构造规则（schema、有依据、来源可接受、典型性）明确。
- **实验设计公平**：相同支持、共享干净分支、等 oracle 对照、随机编辑消融、任务簇 bootstrap、Holm 多重比较校正。
- **机制可解释性**：通过因子移除干预和分解公式，将危害归因于具体语义因子，而非笼统的"攻击更强"。
- **伦理与可复现性**：隔离基准环境、不发布可利用代码、人类标注有报酬与知情同意、提供审计协议与验证器。

## 8. 不足与局限

- **证书范围受限**：最优性保证仅针对**冻结的有限编辑类**，不是对所有可能语义编辑的全局最优；未解析的运行不携带任何证书。
- **构建阶段需特权访问**：离线构建需要可重置的隔离副本与成对损失反馈（oracle），部署虽只需一次正常接口写入，但构建条件在真实场景中可能难以满足。
- **CMR 依赖声明分布**：CMR 相对于声明的下游任务分布 D 与操作损失定义，跨分布或代理分布不匹配时外推性未验证。
- **迁移能力不均**：在严格 schema 的画像与图记忆中迁移显著减弱，说明严重性高度依赖目标记忆的可实现性。
- **算力透明度缺失**：未报告 GPU 型号、数量与训练时长，难以评估计算成本与可复现的资源门槛。
- **反馈假设较强**：假设成对干净侧观测、条件均值稳定、无跨副本干扰；噪声、延迟、单侧或查询受限反馈场景留待未来工作。
- **归因模糊性**：命题 2 指出被动观测下因果因子可能不可辨识，实际部署中定位责任记忆因子仍具挑战。
- **双用途风险**：方法本身是记忆攻击，存在被滥用的可能，论文通过不发布利用代码与审计协议来缓解，但风险无法完全消除。
