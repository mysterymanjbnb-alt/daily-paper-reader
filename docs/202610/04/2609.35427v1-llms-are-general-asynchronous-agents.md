## 摘要
现代 LLM 作为自主智能体的能力日益增强，但它们遵循顺序交互循环：读取、思考、回复或调用工具，然后重复。许多现实世界的用例并不是顺序的：语音助手、具身智能体和监控系统在思考或执行另一项任务时会接收新的输入。现代 LLM 通过用于语音交互和视频流的专门架构、用于机器人控制的 VLA、用于 API 使用的异步工具调用等来解决这一问题。在这项工作中，我们从不同的异步任务推广到能够适应不同类型并发的通用异步智能体。为此，我们开发了一个异步 LLM 框架，允许用户（或智能体本身）定义具有重叠内存状态的推理协程。我们展示了 Qwen 3.x 模型能够在没有任务特定训练的情况下，对流式视频理解、视频游戏和监控进行异步操作。

## Abstract
Modern LLMs are increasingly capable as autonomous agents, but they follow sequential interaction cycles: read, think, reply or call tools, repeat. Many real-world use cases are not sequential: voice assistants, embodied agents, and monitoring systems receive new inputs while they think or perform another task. Modern LLMs address this with specialized architectures for voice interaction and video streams, VLAs for robot control, asynchronous tool calling for API usage, and others. In this work, we generalize from different asynchronous tasks to general asynchronous agents that can adapt to different types of concurrency. To achieve this, we develop an asynchronous LLM framework that lets users (or the agents themselves) define inference coroutines with overlapping memory states. We showcase that Qwen 3.x models are capable of asynchronous operation for streaming video understanding, videogames, and monitoring, without task-specific training.

## 2. 方法论

### 2.1 核心思想
- 将异步 LLM 推理建模为多个 **coroutine** 并发执行。
- 每个协程写入自己的 **CacheBlock**，其中保存一段 token 的注意力 KV 缓存和 Gated Delta Network 循环状态。
- 每个协程可通过 **cache view** 同时“看到”多个其他 CacheBlock，并按任意顺序组合。
- 协程之间不通过生成 token 通信，而是直接共享内部记忆状态，从而避免重复编码，支持实时同步。

### 2.2 编程模型
- 基于 Python `asyncio` 的 async/await 范式。
- 主要 API：
  - `api.create_blocks(n)`：创建多个 CacheBlock。
  - `api.forward(...)`：预填充并写入指定块。
  - `api.generate(..., cache_view=[...], write_to=...)`：生成 token，同时读取多个块并写入自己的块。
  - `api.merge_blocks(A, B)`、`cache_block.clear()`：合并与清空。
- 协程间可用 `asyncio.Event`、`Lock`、`Queue` 等同步原语协调，例如 thinker 协程通知 writer 协程总结当前推理进度。

### 2.3 多 CacheBlock 推理的关键技术
- **全注意力层**：采用 RoPE 查询旋转技巧。不旋转历史 KV，而是将当前 query 按相对位置旋转，使历史块保持 0-based 位置。核心等价关系：
  - `⟨ρ(q,i), ρ(k,j)⟩ = ⟨ρ(q,i-j), ρ(k,0)⟩`。
- **线性注意力 / Gated DeltaNet**：
  - 单 token 状态更新写作 `S_t = S_{t-1} A_t + B_t`。
