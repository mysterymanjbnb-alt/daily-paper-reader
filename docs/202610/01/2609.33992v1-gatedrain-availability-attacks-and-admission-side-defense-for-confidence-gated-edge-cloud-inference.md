## 摘要
置信度门控的边缘-云推理接受高置信度的本地预测，并将不确定输入卸载到更强的云模型。我们表明，这种路由决策形成了可用性攻击面。我们将该攻击称为 GateDrain：有界输入扰动会降低校准后的置信度，并在不提高应用请求率的情况下，将原本会在本地应答的请求重定向到共享云队列。由于升级请求共享同一云服务，每请求云需求的增加可能使接近容量的部署越过排队拐点，从而对良性用户造成不成比例的尾部时延退化。我们在公开的 EdgeBoost 工件上评估了白盒、迁移、仅决策、通用和多门控攻击。固定应用量的比较将置信度操纵的影响与新增客户端流量隔离开来，而扰动预算和到达过程扫描表明，排队相变在若干工作负载模型中持续存在，但其放大效应取决于操作点。自适应攻击也能击败所评估的免训练预处理防御。为抑制由此产生的云需求，我们评估了有界升级，它结合了按来源的准入预算、受保护容量和非抢占式可信类优先级；一个可选的全局桶为不可信准入增加了与身份无关的界限。该评估明确了由此产生的策略权衡：经过身份验证的客户端获得时延隔离，而更严格的总体抑制可能拒绝合法的未认证卸载，并通过边缘回退降低整体期望准确率。

## Abstract
Confidence-gated edge--cloud inference accepts confident local predictions and offloads uncertain inputs to a stronger cloud model. We show that this routing decision creates an availability attack surface. We call this attack \emph{GateDrain}: bounded input perturbations lower calibrated confidence and redirect requests that would otherwise be answered locally into a shared cloud queue, without increasing the application request rate. Because escalated requests share a cloud service, an increase in per-request cloud demand can move a near-capacity deployment across a queueing knee, causing disproportionate tail-latency degradation for benign users. We evaluate white-box, transfer, decision-only, universal, and multi-gate attacks on the public EdgeBoost artifact. A fixed-application-volume comparison isolates the effect of confidence manipulation from added client traffic, while perturbation-budget and arrival-process sweeps show that the queueing transition persists across several workload models but its amplification depends on the operating point. Adaptive attacks also defeat the evaluated training-free preprocessing defenses. To contain the resulting cloud demand, we evaluate Bounded Escalation, which combines per-source admission budgets, protected capacity, and non-preemptive trusted-class priority; an optional global bucket adds an identity-independent bound on untrusted admissions. The evaluation makes the resulting policy trade-off explicit: authenticated clients receive latency isolation, whereas tighter aggregate containment can reject legitimate unauthenticated offloads and reduce overall expected accuracy through edge fallback.

## 2. 方法论

### 2.1 系统与威胁模型

- **门控模型**：
  - 使用温度缩放校准：\(p(x)=\mathrm{softmax}(z/T)\)，论文从 EdgeBoost 工件反推 \(T\approx2.13\)。
  - 定义 top-1 与 top-2 概率差为 margin：\(m_T(x)=p^{(1)}(x)-p^{(2)}(x)\)。
  - 卸载决策：\(o(x)=\mathbb{1}[m_T(x)\le\tau]\)，其中 \(\tau=0.72\)。\(o=1\) 表示升级到云端。
  - 还评估了 max-softmax 门控和熵门控。
- **攻击者能力**：
  - 可在 \(\ell_\infty\) 像素预算内扰动图像，控制一个或多个未认证身份。
  - 支持白盒、迁移、仅路由决策、通用扰动、多门控等设置。
  - 攻击目标：提高云端需求与良性尾延迟，不要求改变最终标签。

- **队列模型**：
  - 良性/对抗请求到达率为 \(\lambda_b,\lambda_a\)，卸载概率为 \(q_b,q_a\)。

### 2.2 GateDrain 攻击

- **核心思想**：不增加请求量，只增加每请求的云端卸载概率。
- **白盒 margin 攻击**：
  - 最小化 hinge 损失：\(L_{\text{esc}}(x')=\max(m_T(x')-\tau+\kappa,0)\)。
  - 使用 PGD 穿过温度缩放和部署预处理，投影到像素 \(\ell_\infty\) 球内。
  - 默认 \(\epsilon=8/255\)，40 步，步长 1/255，\(\kappa=0.02\)。
- **其他攻击变体**：
  - **迁移攻击**：在 MobileNetV2 代理模型上优化，再迁移到受害模型。
  - **仅决策攻击**：只观察本地/卸载二值结果，每张图最多 30 个候选查询，总查询不超过 31 次。
  - **通用攻击**：离线学习一个与输入无关的扰动，在不相交训练集上训练，再重放到测试集。
  - **多门控攻击**：分别针对 margin、max-softmax、熵门控优化 PGD。
- **自然输入基线**：不扰动像素，直接从合法图像池中挑选已卸载样本，或抽取多个候选直到卸载。

### 2.3 Bounded Escalation 防御

- **核心思想**：不检测扰动，而是在卸载边界限制被准入的云工作量。
- **机制组成**：
  - **按来源 token bucket**：限制每个身份的准入卸载量。
  - **受保护容量**：不可信请求仅当总占用低于 \(K-K_p\) 时准入，防止不可信流量占满缓冲区。
  - **非抢占式可信类优先级**：可信请求优先服务，但不中断正在服务的不可信任务。
  - **可选全局不可信桶**：与身份无关地限制不可信准入总量，应对 Sybil 攻击。
- **回退机制**：任一准入阶段拒绝时，返回置信度门控前已计算的边缘预测，避免额外云工作，但可能损失云端精度提升。
- **边界公式**：
  - 单身份准入上限：\(N_u^{\text{adm}}(W)\le B_u+R_uW\)。
  - Sybil 下总上限随身份数增长：\(\sum_u N_u^{\text{adm}}(W)\le n_{\text{id}}B_u+n_{\text{id}}R_uW\)。
  - 全局桶提供身份无关上限：\(N_{\text{untr}}^{\text{adm}}(W)\le b_{\text{gtb}}+r_{\text{gtb}}W\)。
- **参数**：按来源深度 \(B_u=5\)，补充率 \(R_u=0.69/s\)；受保护容量 \(K_p=K/2=32\)；全局桶深度 \(b_{\text{gtb}}=20\)，标称补充率 \(r_{\text{gtb}}=14.95/s\)。
