## 摘要
视觉-语言-动作（VLA）模型提供了一个统一框架，可将高层语义信息落地为低层机器人动作，从而支持跨多样任务的可扩展机器人操作。然而，现有 VLA 模型缺乏显式机制来解耦双臂的状态与意图，导致非预期的跨臂干扰，降低任务执行成功率。为解决该问题，我们提出一种对称双臂专家（DAE）架构，该架构构建于共享视觉-语言模型（VLM）骨干之上，并包含解耦的、臂特定的专家塔。专家选择通过两阶段双臂意图路由方案完成，其中第一阶段依据显式语言指令路由专家，第二阶段依据隐式视觉语义路由专家。此外，我们引入一个轻量级任务进度预测模块，利用分块前时序特征与本体感觉和视觉观测的语义表示之间的交叉注意力，准确估计逐帧任务完成进度。该模块促进任务进度同步，以支持协作多机器人任务的协同调度。实验结果证明了我们的模型在双臂意图路由和跨臂干扰解耦方面的有效性，并进一步提供了从单臂任务到双臂任务（以及反向）涌现技能泛化的初步证据，以及跨臂运动域技能迁移的证据。

## Abstract
Vision-Language-Action (VLA) models provide a unified framework for grounding high-level semantic information into low-level robot actions, enabling scalable robotic manipulation across diverse tasks. However, existing VLA models lack explicit mechanisms to disentangle the states and intents of the two arms, leading to unintended cross-arm interference that degrades task execution success. To address this issue, we propose a symmetric Dual-Arm Expert (DAE) architecture built upon a shared Vision-Language Model (VLM) backbone with decoupled, arm-specific expert towers. Expert selection is carried out through a two-stage dual-arm intent routing scheme, in which experts are routed either by explicit language instructions in the first stage or by implicit visual semantics in the second stage. Moreover, we introduce a lightweight task progress prediction module that leverages cross-attention between the pre-chunk temporal features and semantic representations of proprioceptive and visual observations to accurately estimate frame-wise task completion progress. This module facilitates task progress synchronization to support coordinated scheduling for collaborative multi-robot tasks. Experimental results demonstrate the effectiveness of our model in dual-arm intent routing and the disentanglement of cross-arm interference, and further provide preliminary evidence of emergent skill generalization from single- to dual-arm tasks (as well as the reverse), together with cross-arm motion-domain skill transfer.

# TAO-DA 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作（VLA）模型将语言、视觉观测与机器人状态统一映射为动作，为语言条件下的机器人操作提供了通用接口。现有系统多采用自回归、扩散或流匹配等动作生成器。
- **核心问题**：主流双臂 VLA 设计将两只手臂表示在**统一的动作生成器**中。虽然简化了动作接口，却导致执行臂与另一只手臂无关的状态、视觉变化相**耦合（cross-arm interference，跨臂干扰）**。
- **干扰的具体场景**：
  - 仅需单臂执行任务时；
  - 两臂执行**顺序子任务**时；
  - 演示数据中存在**非对称角色**分配时。
- **设计原则**：双臂策略应保留**共享的任务语义**，同时**选择性控制臂级动作生成**。据此提出 TAO-DA 框架，围绕两条原则构建：
  1. 用于任务级推理的**共享多模态表示**；
  2. 用于低层控制的**臂特定动作塔**。
- **整体意义**：为双臂 VLA 提供显式的意图解耦与进度同步机制，提升自主协作操作的可扩展性与多机器人协同调度能力。

## 2. 方法论

### 2.1 总体架构（TAO-DA）

- **输入**：多视角视觉观测（1 张自我中心视图 + 左/右臂末端执行器视图各 1 张，后者可选）、语言指令、本体感觉状态。
- **视觉编码**：各视图由同一预训练 **SigLIP** 编码器编码。
- **融合**：视觉 token 与语言 token 拼接后送入**冻结的 Eagle-2.5-VL** 骨干，得到融合表示 $E_{VL} \in \mathbb{R}^{N\times D}$。
- **流程**：DAIR 路由 → 非活动臂末端视图 token 在 VLM 输入处被掩码 → DAE 通过被选中的臂特定通路生成动作（流匹配训练）。
- **训练细节**：每个任务的指令从语义等价的表达池中随机采样，增强语言鲁棒性。

### 2.2 DAIR：双臂意图路由

- **意图表示**：二元向量 $r=[r_L, r_R]\in\{0,1\}^2$，有效类别为：
  - 仅左臂 $\phi(0)=[1,0]$
  - 仅右臂 $\phi(1)=[0,1]$
  - 双臂 $\phi(2)=[1,1]$
- **损失**：三分类交叉熵 $L_{route}=-\log p_c$；三分类接口避免产生非法的“无臂”向量 $[0,0]$。
- **两阶段推理**：
  - **阶段 1（规则语言解析）**：识别 “left arm”“right arm”“both arms”“left hand”“right hand” 等显式表达；若同时出现双臂表达则以双臂优先，返回 $\hat r_{rule}=[1,1]$；无显式表达时返回内部无匹配码 $[0,0]$，触发阶段 2。**不使用空间表达推断臂意图。**
  - **阶段 2（模型多模态预测）**：对 $E_{VL}$ 做 LayerNorm，以可学习 query 做多头注意力池化 $f=\mathrm{MHA}(q, E_{norm}, E_{norm})$，MLP 输出 3 个 logits，取 argmax 后映射为二元意图 $\hat r_{model}$。
- **进度保持机制（hold）**：推理时若任务已充分推进，可保持此前选择的意图。给定预测进度 $\hat p_t$、阈值 $\tau_{hold}$、前一意图 $\hat r_{t-1}$，规则为：
  - 若 $\hat r_{rule}\neq[0,0]$ → 采用 $\hat r_{rule}$；
  - 若 $\hat r_{rule}=[0,0]$ 且 $\hat r_{t-1}$ 不可用 → 采用 $\hat r_{model}$；
  - 若 $\hat r_{rule}=[0,0]$ 且 $\hat p_t\le\tau_{hold}$ → 采用 $\hat r_{model}$；
  - 否则 → 保持 $\hat r_{t-1}$。
  - 该机制用于**稳定路由决策**，区别于部署级任务调度器。

### 2.3 DAE：双臂专家模块（三种变体）

- **Single-Tower（统一）**：在单个 DiT 中拼接双臂的状态与动作 token。
- **Dual-Mask（弱解耦）**：共享 DiT 主干，但用**臂模式注意力掩码**限制 token 交互。输入含四组臂特定 token $X_{in}=[X^L_{state}, X^R_{state}, X^L_{action}, X^R_{action}]$。对每种执行模式 $m\in\{left, right, dual\}$ 定义二值掩码 $M^{(m)}$，注意力为 $\mathrm{Attn}(Q,K,V|M)=\mathrm{softmax}(QK^\top/\sqrt d+\log M)V$，零条目抑制对应 logit。左臂模式下仅左臂状态与动作组互相注意，右臂对称，双臂模式允许全组注意。掩码限制了臂间直接交换，但两臂仍共享 DiT 参数与条件通路。
- **Dual-Tower（强解耦）**：两条**架构相同但参数独立**的分支 $T_L, T_R$，各自拥有状态编码器、动作分词器、DiT 与动作解码器。输入为 $X^k_{in}=[X^k_{state}, X^k_{action}]$，分别独立处理并以路由后的多模态上下文为条件。臂级组件参数量约翻倍，冻结 VLM 与 DAIR 共享。
- **路由条件动作生成**：训练时用标注 $r$ 选择臂特定轨迹切片与动作目标；双臂样本在同步时间步监督两塔；单臂样本中非活动塔无动作监督。推理时由 DAIR 的 $\hat r$ 控制数据流。
- **臂条件视图掩码**：设 $V=[V_{ego}, V_L, V_R]$，动作条件化时非活动臂末端视图 token 在进入 VLM 前被掩码；$r=[1,0]$ 掩码右视图，反之对称；$r=[1,1]$ 保留两视图；自我中心视图始终保留。
- **活动臂监督**：$L_{act}=r_L L^L_{FM}+r_R L^R_{FM}$，其中 $L^k_{FM}$ 为臂 $k$ 的流匹配目标。

### 2.4 任务进度预测模块

- 用 **GRU** 编码 DiT 时序特征 $H=[h_1,...,h_T]$，得到 $S=\mathrm{GRU}(H)$；
- 通过交叉注意力与 VLM 表示融合：$Z=\mathrm{MHA}(S, E_{VL}, E_{VL})$；
- 回归头预测 $\hat p_t$，监督目标为**归一化轨迹时间**；
- 推理时该估计支持 DAIR 的 hold 机制与部署级调度器。

## 6. 主要结论与发现

- **单臂任务**：TAO-DA 在完整单臂套件上取得最高平均成功率 **88.4%**，高于 GR00T N1.5（82.0%）与 π0.5（80.5%）；在 4 个任务上取得最佳或并列最佳，仅 Steamer Delivery-R 上低于 GR00T N1.5。
- **双臂任务**：Collaborative Tea 达 **100%**，Desktop Organization 达 **95%**，后者超过两个基线。
- **干扰解耦**：
  - 离线 MSE 扰动/清洁比值：Single-Tower 为 1.94/1.60，Dual-Mask 降至 1.46/1.13，**Dual-Tower 为 0.99/1.00**；
  - 真实机器人持续扰动下，Dual-Tower 左/右臂成功率为 **100%/95%**，Single-Tower 仅 25%/20%，Dual-Mask 为 65%/65%；随机初始状态下 Dual-Tower 保持 95–100%，Single-Tower 仅 20–60%。
- **路由性能**：留出集上仅左臂 85.37%、仅右臂 83.31%、双臂 96.13%；**无左右横向混淆错误**，错误集中于单臂与双臂的区分（14.6% 仅左臂、16.7% 仅右臂被误判为双臂）。
- **路由消融**：移除进度模块使仅右臂精度从 83.31% 降至 68.48%、双臂从 96.13% 降至 89.22%；保留进度时 Fixed 仅右臂为 78.66%，低于 Multi 的 83.31%。
- **技能迁移**：在无对应单臂演示的双臂演示上训练后，解耦变体在三种执行模式下均优于 Single-Tower，Dual-Tower 达 100%/90%/95%（对比 Single-Tower 80%/50%/50%）；另有单臂技能并行组合与左右角色互换的定性证据（后者精度较低，不被视为稳健迁移证据）。
- **部署**：自主餐厅系统中集成 3 类机器人、协调 6 台机器人、20 余项服务任务，101 次全流程试验端到端成功率 **92.08%**（该指标包含感知、操作、调度与系统执行，不能单独归因于 TAO-DA）。
