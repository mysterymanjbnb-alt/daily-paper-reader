## 摘要
生产系统中的大语言模型（LLM）面临提示注入、木马（后门）以及对自动质量指标的操纵。本论文开发了用于评估和提升 LLM 对对抗性输入序列变异鲁棒性的模型、方法和算法。我们提出 R_stab(f)，一种基于小输入扰动下每步输出分布之间 Jensen-Shannon 散度的生成式鲁棒性度量。对于局部化攻击，我们证明 V(h) <= 1 - R_class(h)，其中 R_class(h) 是决策算子 h 在小扰动下保持其决策的概率。对于非局部化攻击，我们提出一种校准的经验模型。对于 LLM-as-a-Judge 系统，我们开发了 ASA，一种自适应进化黑盒攻击，其攻击成功率（ASR）最高可达 73.8%，在开放模型之间的迁移率最高可达 62.6%。在 Trojan Detection Challenge 2023 数据（Pythia-1.4B）上，代理触发器达到 REASR ~0.99，而真实触发器的召回率约为 0.17，基线约为 0.14。在 SaTML CTF 2024 上，我们系统化梳理了四类绕过多层防御的方法，而多层防御可将 ASR 从 90% 降至 15-25%。由 5-7 个异构模型组成的委员会将 Gemma-3-4B 的 ASR 降低 47-55 个百分点，使用 7 个模型时降至 19.3%。对于基于模型上下文协议（MCP）的智能体系统，我们提出 AttestMCP，它使用受 HMAC 保护的数据包对工具调用进行认证，每次调用耗时低于 0.1 ms，并提出 Commit Boundary 隔离模式。在包含 847 个场景的 MCPBench 基准上，它们将平均 ASR 从 53.7% 降至 12.4%。这些方法已在 JudgeGuard 和 TrojanArmor 软件套件以及 MCPSec 模块中实现。

## Abstract
Large language models (LLMs) in production systems face prompt injections, trojans (backdoors), and manipulation of automatic quality metrics. This thesis develops models, methods, and algorithms for evaluating and improving LLM robustness to adversarial input sequence variations. We propose R_stab(f), a generative robustness metric based on the Jensen-Shannon divergence between per-step output distributions under small input perturbations. For localized attacks we prove V(h) <= 1 - R_class(h), where R_class(h) is the probability that a decision operator h keeps its decision under small perturbations. For non-localized attacks we propose a calibrated empirical model. For LLM-as-a-Judge systems we develop ASA, an adaptive evolutionary black-box attack that reaches an attack success rate (ASR) of up to 73.8%, with transfer between open models up to 62.6%. On Trojan Detection Challenge 2023 data (Pythia-1.4B), surrogate triggers reach REASR ~0.99 while recall of the true triggers is ~0.17 against a baseline of ~0.14. On SaTML CTF 2024 we systematize four classes of bypasses of multi-layer defenses, which reduce the ASR from 90% to 15-25%. Committees of 5-7 heterogeneous models reduce the ASR for Gemma-3-4B by 47-55 percentage points, to 19.3% with 7 models. For agentic systems based on the Model Context Protocol (MCP), we propose AttestMCP, which attests tool calls with HMAC-protected packets at under 0.1 ms per call, and the Commit Boundary isolation pattern. On the MCPBench benchmark of 847 scenarios they reduce the average ASR from 53.7% to 12.4%. The methods are implemented in the JudgeGuard and TrojanArmor software suites and the MCPSec module.

## 2. 方法论

### 2.1 形式化鲁棒性指标

- **R_stab(f)（生成式鲁棒性度量）**：基于小输入扰动下每步输出分布之间的 Jensen–Shannon 散度（JSD）。在参考轨迹 y*(x) 上用 teacher forcing 比较 p_t(·|x) 与 p_t(·|x′)，对 T 步取平均得到 D_T(x, x′)，再对输入分布取期望并归一化。JSD 以 2 为底时值域为 [0,1]，取 C_max = 1。
- **R_class(h)（决策层鲁棒性）**：针对确定性决策算子 h = Dec ∘ f，定义为 h 在 ε-邻域 B_ε(x) 内保持决策的期望概率。
- **V(h)（全局脆弱性指数）**：攻击在输入分布和攻击分布下的期望影响。
- **Risk(a, f)**：攻击成功概率与严重度的乘积。
- **AdvRobustness(f)**：对抗鲁棒性，基于最坏情况风险。

### 2.2 核心理论结果

- **局部攻击上界（定理 2.17）**：在假设 (A0) 干净输入无不良输出、(A1) 攻击局部化 a(x) ∈ B_ε(x)、(A2) 影响蕴含输出改变下，证明 **V(h) ≤ 1 − R_class(h)**；若 (A0) 松弛为概率 β，则为 V(h) ≤ β + 1 − R_class(h)。
- **非局部攻击**：提示注入和越狱不满足 (A1)，提出校准经验模型 V(h) ≈ g(1 − R_class(h))，g(t) = min{1, k_eff(t + E_η)^α}，明确标注为经验假设而非严格界。
- **单调性**：R_class 与 R_stab 关于防御增强单调不减，作为定义的相容性条件。
- **模型复合引理（2.23）**：确定性复合 R_class(f ∘ g) ≥ R_class(g)。
- **递归链脆弱性（命题 2.32）**：V_d = 1 − (1 − V_1)^d（级联失效模型下）。
- **多数投票集成（定理 2.35 + 推论 2.36）**：若存在稳健多数且保持同一裁决，集成鲁棒；Condorcet 陪审团定理保证 r > 0.5 且独立时委员会精度随规模趋于 1。
- **LLM+检索器 Lipschitz 分解（命题 2.30）**：K_s ≤ K_f,D · K_r + K_f,X。
- **bR_emp = 1 − ASR 的理论解释（命题 2.39）**：在离散输出任务中，ASR 是 V(h) 的一致估计量，1 − ASR 的总体极限是 R_class(h) 的上界。

### 2.3 攻击方法：ASA

- **ASA（Adaptive Search-Based Attack）**：在离散 token 空间中的进化搜索，结合 token 级变异与语义复述。
- **适应度函数**：Fitness(x_i) = α · ASR(x_i) + β · Stealth(x_i)，其中 Stealth 为与原始提示的嵌入余弦相似度。
- **与经典 GA 的差异**：变异算子保持语法正确性；适应度包含隐蔽性项；交叉/变异作用于提示的结构元素（指令、上下文、请求）。
- **复杂度**：O(N · G) 次模型查询，实验中 N = 50、G = 20，即每次攻击 1000 次查询。

### 2.4 防御方法

- **异构模型委员会**：多数投票，委员会构成考虑架构多样性；低一致率触发人工复核。
- **多层防御**：输入层（归一化、困惑度过滤、指令过滤、内容审核）+ 模型层（鲁棒架构、RLHF、系统提示）+ 输出层（校准、过滤、集成）。
- **AttestMCP**：将工具调用限制在会话权限表 P 内，并用 HMAC 签名保护 RPC 包完整性；形式化为有限状态自动机，维护不变量"每个执行的调用都满足权限表"。
- **Commit Boundary**：在容器中隔离执行 LLM 生成的代码，含 AST 解析、静态分析、容器隔离、输出验证、高风险 HITL 审批。
- **辅助机制**：能力证书、来源标记、强制隔离、重放保护。

## 6. 主要结论与发现

- **ASA 攻击**：对 Gemma-3-4B 达到 ASR = 73.8%，开源模型间迁移率 TSR = 50.5–62.6%；开源模型系统性比商业模型更脆弱；脆弱性取决于架构族和 alignment 过程，而非仅模型规模。
- **木马检测的不对称性**：代理触发器 REASR ≈ 0.99，但真实触发器 Recall ≈ 0.17（基线 ≈ 0.14），表明反向工程在现有方法下不适合模型审计，应优先预防性数据管控。
- **多层防御**：三层防御将 ASR 从 ~90% 降至 15–25%，但无单一组合能同时阻断全部四类绕过向量（代码导向、ASCII 编码、词拆分、上下文误导）。
- **异构委员会**：5–7 模型委员会将 Gemma-3-4B 的 ASR 降低 47–55 pp 至 19.3%；Condorcet 定理不适用于 Gemma-3-4B（r ≈ 0.26 < 0.5），增益主要来自异构性带来的误差去相关。
- **MCP 安全**：MCP 架构决策使 ASR 相比非 MCP 集成增加 16.6–41.6 pp；MCPSec 将平均 ASR 从 53.7% 降至 12.4%（降低 41.3 pp），AttestMCP 每次调用开销 < 0.1 ms。
- **R_stab 验证**：GPT-4o-mini 上 bR_stab(f) = 0.115 > R_class(h) = 0.050，支持 R_stab ≥ R_class 的假设，但样本小、仅为良性扰动。
- **生产部署**：JudgeGuard 在 Viasat 生产环境部署，3 模型委员会将 ASR 降低 42 pp，延迟增加 ≤ 15%。

## 7. 优点

- **理论贡献扎实**：首次提出适用于离散 token 空间和自回归生成的 R_stab(f) 形式化指标，并证明局部攻击下 V(h) ≤ 1 − R_class(h) 的严格上界。
- **明确的假设边界**：严格区分理论界（局部攻击）与经验模型（非局部攻击），并明确标注经验模型的假设性质，学术严谨。
- **攻击与防御并重**：ASA 攻击与异构委员会防御形成闭环，且对防御效果给出统计显著性和置信区间。
- **系统化梳理**：将 SaTML CTF 2024 的绕过向量系统化为四类，并给出各自的适用条件与对策。
- **智能体安全创新**：首次系统分析 MCP 架构漏洞，提出 AttestMCP 和 Commit Boundary 两个可落地的防御算法。
- **工程落地**：两个注册软件套件（JudgeGuard、TrojanArmor）和一个 MCPSec 模块，并在生产环境验证。
- **统计规范**：使用 bootstrap 置信区间、Hoeffding 不等式论证样本量，明确区分单任务与聚合层级，避免过度解读小差异。

## 8. 不足与局限

- **算力报告不充分**：未明确给出总 GPU 小时、训练时长、能耗等关键资源指标。
- **R_stab 验证有限**：仅 20 个提示、5 个良性扰动，120 次 API 调用；使用 top-20 logprobs 近似，尾部概率被低估，导致 bR_stab 被高估；非 teacher forcing 模式，与定义不完全一致。
- **非局部攻击缺乏理论保证**：提示注入和越狱的关系依赖经验校准模型，非严格界。
- **委员会机制解释不足**：Condorcet 定理不适用于 Gemma-3-4B 等 r < 0.5 的模型，异构性增益仅为假设，缺少对"最小架构多样性"的定量刻画。
- **样本量限制**：单任务 n=50 功效不足，GPT-4 vs Claude-3 等小差异无法区分；部分实验（如 R_stab 验证）标准差超过均值。
- **泛化性存疑**：防御效果在 Viasat 内部数据集上与实验数据集不同（降低 42 pp vs 47–55 pp），表明数值指标不能跨域直接迁移。
- **MCPBench 覆盖有限**：847 个场景仅覆盖特定 agent 实现、工具场景和 MCP 交互配置，不代表全部智能体架构。
- **硬件单一**：性能测量仅在单台 NVIDIA A100 配置上完成，向其他加速器外推需验证。
- **协议依赖**：Recall 和 REASR 依赖 TDC2023 的 BLEU 匹配协议，不能解释为经典二分类检测召回率。
- **API 版本绑定**：MRAG 适配器绑定特定提供商 API，API 变更需更新。
- **伦理与双重用途**：论文声明在受控环境进行且未发布可直接使用的攻击工具，但攻击方法的公开仍存在双重用途风险。
