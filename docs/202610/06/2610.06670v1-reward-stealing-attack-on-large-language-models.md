## 摘要
针对大型语言模型（LLMs）的对抗攻击旨在诱导有害内容。然而，现有方法存在计算成本高或严格的模型配对依赖，限制了其可扩展性与迁移性。我们提出奖励窃取攻击（ReSA），一种针对 LLM 对齐背后潜在安全奖励的对抗攻击框架。ReSA 采用最大熵逆强化学习，仅从对齐模型的行为中恢复一个代理奖励模型。随后，在推理时反转所提取的奖励以导出对抗策略，并通过奖励引导的解码机制高效实现。实验表明，单个恢复的奖励能够跨提示和多种模型泛化，揭示出一种根本性的对齐漏洞，使 ReSA 在有效性和迁移性上显著优于现有攻击。代码见 https://github.com/GarminQ/ReSA。

## Abstract
Adversarial attacks on Large Language Models (LLMs) aim to induce harmful content. However, existing methods suffer from high computational costs or strict model-pairing dependencies, limiting their scalability and transferability. We propose Reward Stealing Attack (ReSA), an adversarial attack framework that targets the latent safety reward underlying LLM alignment. ReSA employs maximum entropy inverse reinforcement learning to recover a proxy reward model solely from the aligned model's behavior. The extracted reward is then reversed at inference time to derive an adversarial policy, efficiently implemented via a reward-guided decoding mechanism. Experiments demonstrate that a single recovered reward generalizes across prompts and diverse models to reveal a fundamental alignment vulnerability, enabling ReSA to significantly outperform existing attacks in effectiveness and transferability. The code is available at https://github.com/GarminQ/ReSA.

## 1. 核心问题与整体含义

- **研究背景**：LLM 经过 RLHF、RLVR 等对齐后仍易被对抗攻击诱导生成有害内容，红队研究因此至关重要。
- **现有范式及其瓶颈**：
  - **提示操纵攻击**（GCG、COLD-Attack、SCAV）：需针对每个查询做迭代优化，或需高额离线训练得到通用后缀，**计算成本高**。
  - **对比解码攻击**（Contrast-Attack、Weak-to-Strong）：依赖严格配对的 safe/unsafe 模型，要求分词器与词表一致，**模型配对依赖强**。
- **核心洞察**：安全对齐可被理解为在基座模型上叠加了一个**潜在安全奖励**（latent safety reward），它隐含在 $\pi_{safe}$ 的输出分布中，虽未显式暴露，却跨提示、跨模型地支配输出行为。
- **中心问题**：能否从已对齐 LLM 的行为中**恢复**该潜在安全奖励，并将其**反转**为通用的对抗原语？
- **整体含义**：论文提出"奖励窃取"新视角——对齐机制本身编码了可被检索、可被窃取的漏洞，从而摆脱逐提示优化与模型配对依赖，实现高效、可迁移的攻击。

## 2. 方法论

### 2.1 核心思想
把对齐后的 LLM 视为专家策略 $\pi_{safe}$，用**最大熵逆强化学习（MaxEnt IRL）**恢复代理安全奖励 $R_\theta$，再在推理时**反转**该奖励，通过奖励引导解码构造对抗策略 $\pi_{adv}$。

### 2.2 理论基础
- 对齐目标（式 1）的最优策略为指数倾斜分布：
  $$\pi_{safe}(y|x)=\frac{1}{Z(x)}\pi_{base}(y|x)\exp\!\left(\frac{1}{\beta}R^*(x,y)\right)$$
  说明 $R^*$ 被隐式编码在 $\pi_{safe}$ 中。

### 2.3 阶段一：奖励提取（MaxEnt IRL）
- 以有害提示分布 $P_x$ 采样 $\pi_{safe}$ 的轨迹构成专家数据集 $D_E$，限定在安全域内以隔离安全奖励。
- 最大熵约束优化（式 3）有唯一闭式解，即 Boltzmann 分布：
  $$P_\theta(\tau)=\frac{1}{Z(\theta)}\exp(\theta^\top\Phi(\tau))$$
- 代理奖励参数化为线性形式 $R_\theta(\tau)=\theta^\top\Phi(\tau)$：$\Phi$ 为**冻结特征提取器**（Llama3.2-1B-Instruct 的最后隐状态），$\theta$ 为可训练线性头。
- 优化目标为专家轨迹对数似然（式 5），其梯度为**特征匹配梯度**（式 6）：
  $$\nabla_\theta L(\theta)=\mathbb{E}_{\tau\sim D_E}[\Phi(\tau)]-\mathbb{E}_{\tau\sim P_\theta}[\Phi(\tau)]$$
- **策略优化**：因 $Z(\theta)$ 不可解，引入 actor 策略 $\pi_\phi$ 作为可采样近似，用 **GRPO** 最大化 $R_\theta$，带 KL 惩罚到冻结参考策略（式 7）。
- **对抗解释**：$R_\theta$ 类似判别器、$\pi_\phi$ 类似生成器，形成 GAN 式动态，使 actor 自动挖掘难负样本、收紧安全边界。

### 2.4 阶段二：对抗生成（反转奖励）
- 对抗目标（式 8）：最大化负代理奖励，同时以 KL 约束限制对 $\pi_{safe}$ 的偏离：
  $$\max_{\pi_{adv}}\mathbb{E}[ -R_\theta(x,y)]\quad \text{s.t. } D_{KL}(\pi_{adv}\|\pi_{safe})\le \epsilon$$
- 闭式最优对抗策略（命题 2）：
  $$\pi^*_{adv}(y|x)=\frac{1}{Z^*(x)}\pi_{safe}(y|x)\exp(-\alpha R_\theta(x,y))$$
  其中 $\alpha$ 控制攻击强度与生成质量的权衡。
- **推理时实现**：序列级采样不可行，采用自回归近似，在 log 概率空间做 token 级负奖励引导：
  $$\log\pi_{adv}(y_t|x_{<t})\propto \log\pi_{safe}(y_t|x_{<t})-\alpha\cdot r_\theta(x_{<t},y_t)$$
- **自适应对抗强度**：定义边际奖励 $m(y_t|x_{<t})=r_\theta(x_{<t},y_t)-r_\theta(x_{<t})$，并令
  $$\alpha_t=\alpha\cdot(1-\exp(-|m(y_t|x_{<t})|))$$
  对中性 token 强度趋于 0 以保流畅，对安全关键 token 施加强干预。

### 2.5 算法流程（Algorithm 1）
- **阶段一**：收集专家轨迹 → 初始化 $R_\theta$ → 循环：用特征匹配梯度更新 $\theta$（判别器步），用 GRPO 更新 $\pi_\phi$（生成器步）直至收敛。
- **阶段二**：每个解码步对 top-k 候选计算 $r_\theta$ → 计算 $\alpha_t$ → 调整 logits 并采样。

## 6. 主要结论与发现

- ReSA 在所有评测 LLM 与数据集上取得**最佳或次佳**的攻击效果，ASR、HS、GS 均优于提示操纵与对比解码基线。
- 仅从 Llama3.1-8B-Instruct 恢复的**单个代理奖励**即可跨模型家族与规模（7B–70B）迁移，说明安全对齐存在**共享的潜在特征**，代理奖励具有通用性而非过拟合源模型。
- ReSA 的 PPL-S 显著低于基线，说明其通过**稀疏干预安全关键 token** 保持了语言连贯性，具有更强的隐蔽性。
- IRL 分析表明：特征匹配梯度下降与 actor 有害分数下降同步；安全景观随训练显著加宽加深；代理奖励对安全/有害轨迹呈**明显双峰分布**，判别可分性强。
- 消融显示：MaxEnt IRL 优于被动监督线性探测；即使没有完全未对齐的 actor，Unalign-Free ReSA 仍有效；$\alpha\approx1.5$ 处于攻击强度与流畅性的帕累托前沿；自适应强度 $\alpha_t$ 必要。
- ReSA 对 PPL Filtering 与 Top-k 限制具有较强韧性，在商业 API 仅暴露 top-k log-prob 的灰盒条件下依然有效。
- **总体结论**：对齐机制本身编码了一种可检索的漏洞——潜在安全奖励可被窃取并反转，构成持久且可迁移的威胁。

## 7. 优点

- **视角新颖**：首次提出"奖励窃取"红队范式，把攻击目标从输入/输出层面转向对齐背后的潜在奖励机制。
- **理论完备**：给出 MaxEnt IRL 解（命题 1）与 KL 约束下最优对抗策略（命题 2）的完整推导，并给出可落地的自回归近似与自适应强度设计。
- **摆脱配对依赖**：不需要 safe/unsafe 模型配对，也不需要逐查询优化，通用奖励可复用、可迁移。
- **效率与摊销优势**：一次性离线训练成本低（约 14 分钟），盈亏平衡点分析显示在常规基准规模下明显快于 Universal GCG。
- **实验覆盖面广**：跨模型家族、跨规模、推理模型、商业 API、跨对齐方法（DPO/RLVR）、防御评估与案例研究，证据链较完整。
- **语言质量保持好**：自适应对抗强度设计使攻击输出自然流畅，PPL-S 远低于 GCG 类方法，具备更强实际威胁性。

## 8. 不足与局限

- **威胁模型限制**：奖励提取需要白盒或至少灰盒访问（如 API 暴露的 top-k log-prob），对完全不暴露 logits 的黑盒服务适用性受限。
- **代理奖励表达能力**：采用冻结特征提取器 + 线性头，可能限制对复杂安全奖励的拟合；论文未充分探讨更强奖励头或更大特征提取器的影响。
- **对齐方法差异**：从 RLVR 对齐模型恢复的奖励效果明显减弱，从 DPO 模型恢复的奖励 PPL 偏高，说明方法对对齐方式的鲁棒性不均衡。
- **评测偏差风险**：ASR 基于关键词匹配，可能高估真实有害性；GS 依赖 GPT 裁判，存在模板敏感性与评分偏差；HS 依赖特定奖励模型，跨模型可比性有限。
- **防御覆盖不足**：仅评估 PPL Filtering

与 Top-k Token Restriction 两类推理时防御，未覆盖对抗训练、输入/输出过滤、安全微调、系统提示加固、拒答校准等更贴近真实部署的防御手段，因此其防御鲁棒性结论应限定在推理时轻量防御范围内。

- **单查询延迟与工程开销**：虽然一次性离线训练成本低、盈亏平衡点约 7,436 次查询，但 ReSA 每查询推理约 4.43 秒，高于 Universal GCG 的约 2.45 秒；对低延迟、高并发红队服务，额外开销与 top-k 重打分实现复杂度仍需考虑。
- **训练分布依赖**：奖励提取使用 Shadow-Alignment 的有害提示分布 $P_x$，若目标部署场景的恶意意图分布显著偏移，代理奖励的判别边界与攻击迁移性可能下降；论文未系统测试跨域、多语言、多轮对话等场景。
- **理论假设的理想化**：式 (1) 假设 $\pi_{safe}$ 是基座模型上带单一安全奖励的最优指数倾斜策略，但真实对齐常混合安全、有用性、格式、拒答风格等多目标，且存在对齐税与分布偏移；因此“潜在安全奖励”更应视为有效代理，而非唯一真实奖励。
- **攻击强度与流畅性权衡**：$\alpha$ 需人工选择，虽给出 $\alpha\approx1.5$ 的帕累托前沿，但不同模型/数据集的最优值可能不同；自适应 $\alpha_t$ 缓解了部分问题，但仍引入额外超参与 top-k 选择敏感度。
- **安全与伦理风险**：论文公开了可迁移的攻击原语与实现细节，可能被滥用于绕过 LLM 安全机制；尽管研究目的为红队与防御，仍需要负责任披露、访问控制与防御协同。

## 9. 总体评价与启示

- **核心贡献**：论文把对齐攻击从“提示优化/解码启发式”提升为“奖励逆推”框架，理论优雅、工程可行、迁移性强，首次系统展示了“潜在安全奖励可被窃取并反转”这一红队新范式。
- **对防御方的启示**：安全对齐不应只追求输出层拒答，还需考虑隐藏奖励的可恢复性；可通过奖励随机化、多目标对齐、限制 logprob 暴露、推理时检测与对抗训练降低风险。
- **对红队研究的启示**：MaxEnt IRL 可作为分析对齐模型安全景观的通用工具，未来可探索非线性奖励头、跨模态对齐、多轮代理、更强特征提取器以及更系统的防御基准。
- **总体判断**：ReSA 在效率、迁移性与语言质量上较现有基线具有明显优势，但其威胁模型、评测偏差与防御覆盖仍存在边界；作为一篇方法型论文，其理论动机与实验证据链较完整，适合作为 LLM 对齐安全与红队研究的重要参考。
