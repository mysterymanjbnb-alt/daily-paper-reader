## 摘要
对抗性补丁可以通过操纵视觉观测来扰乱视觉-语言-动作（VLA）模型，导致机器人控制失败。然而，这些失败背后的内部机制是什么，以及有针对性的干预如何缓解这些失败，目前仍知之甚少。在这项工作中，我们使用稀疏自编码器（SAE）对 VLA 表示进行机制性分析，并识别出一个其激活与对抗性补丁的存在强烈相关的特征。基于这一分析，我们仅在推理阶段由线性探针检测到攻击时抑制所识别的特征。这种干预无需微调 VLA 即可提高鲁棒性。我们在 LIBERO-10 上针对 VLA 对抗性补丁攻击评估了我们的方法。条件干预在间歇性攻击下提高了成功率，而持续应用相同的干预则会显著降低策略性能。这些结果表明，与攻击相关的内部表示可以为 VLA 对抗防御提供有用的目标，并且控制何时进行干预对于限制对正常策略行为的干扰非常重要。

## Abstract
Adversarial patches can disrupt Vision-Language-Action (VLA) models by manipulating visual observations, leading to failures in robot control. However, it remains poorly understood which internal mechanisms underlie these failures and how targeted interventions can mitigate them. In this work, we mechanistically analyze VLA representations using a sparse autoencoder (SAE) and identify a feature whose activation strongly correlates with the presence of an adversarial patch. Based on this analysis, we suppress the identified feature at inference time only when a linear probe detects an attack. This intervention improves robustness without the cost of fine-tuning the VLA. We evaluate our method against VLA adversarial patch attacks on LIBERO-10. Conditional intervention improves success rate under intermittent attacks, whereas continuously applying the same intervention substantially degrades policy performance. These results show that attack-related internal representations can provide useful targets for VLA adversarial defense and that controlling when to intervene is important for limiting disruption to nominal policy behavior.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：视觉-语言-动作（VLA）模型通过视觉观测驱动机器人控制，而对抗性补丁（adversarial patch）可通过局部视觉扰动篡改观测，进而使 VLA 策略输出错误动作、导致任务失败。
- **现有防御的两条路线及其代价**：
  - **输入侧防御**：图像预处理（如 JPEG 压缩、高斯模糊），对论文所考察的补丁攻击防护能力有限。
  - **参数侧防御**：对抗性微调（如微调视觉编码器使干净/扰动表示对齐），但需要额外的策略训练算力。
- **核心研究问题**：能否**不微调 VLA 参数**，而是直接在**推理阶段靶向攻击相关的内部表征**来提升鲁棒性？
- **关键洞察**：机制可解释性研究已发现 VLA 内部存在可操纵的方向与 SAE（稀疏自编码器）特征，但这些工作主要考察**正常（nominal）行为**，尚未用于对抗防御。同时，**盲目抑制攻击相关特征会破坏正常策略行为**，因此防御需同时回答两个问题：**抑制哪个特征**、**何时抑制**。
- **整体含义**：论文主张"攻击相关的内部表征可作为 VLA 对抗防御的有效靶点"，并强调**干预时机的控制**与特征选择同等重要。

## 2. 方法论

### 2.1 核心思想
用 SAE 定位与补丁存在强相关的内部特征，用线性探针从 VLA 隐藏状态检测攻击，**仅在检测到攻击时**抑制该特征（推理期干预，策略参数保持冻结）。

### 2.2 问题设定
- VLA 策略：$a_t = \pi(o_t, l)$，其中 $o_t$ 为视觉观测（依模型而定，含 agent 视角、wrist 视角或两者），$l$ 为语言指令。
- 攻击模型：**UADA（Untargeted Action Discrepancy Attack）**，优化通用补丁 $\delta$ 使预测动作偏离真值动作，得到受攻击观测 $o^{adv}_t = A(o_t, \delta)$，语言指令不变。

### 2.3 三个组件

**(1) 攻击相关特征识别**
- 定义第 $i$ 层、控制步 $t$、第 $r$ 个前缀 token 的表示 $h^{(i)}_{t,r} \in \mathbb{R}^d$。
- 对前缀 token 做均值池化：$\bar{h}^{(i)}_t = \frac{1}{N_t}\sum_{r=1}^{N_t} h^{(i)}_{t,r}$。
- 经 TopK SAE 编码器得到特征激活：$z^{(i)}_t = E^{(i)}(\bar{h}^{(i)}_t)$。
- 在"补丁反复开/关"的 rollout 中，计算各候选层-特征对与补丁存在指示变量的 **Pearson 相关系数**，选出**在最多 rollout 中相关系数 > 0.6** 的层-特征对 $(\ell^\star, j^\star)$，其解码方向记为 $d^{(\ell^\star)}_{j^\star}$（并列时取平均相关系数更高者）。

**(2) 攻击检测（线性探针）**
- 在层 $k \le \ell^\star$ 的 token 均值池化表示 $\bar{h}^{(k)}_t$ 上训练 logistic 回归：$p_t = \sigma(w^\top \bar{h}^{(k)}_t + b)$。
- 选择 $k \le \ell^\star$ 是为保证**检测结果先于干预可用**。
- 门控变量：$g_t = \mathbb{I}[p_t > \tau]$，阈值 $\tau$ 在独立构建数据上设定，使**假阳性率（FPR）≤ 2%**。

**(3) 条件特征干预**
- 干预公式（作用于层 $\ell^\star$ 的每个前缀 token）：
  $$\tilde{h}^{(\ell^\star)}_{t,r} = h^{(\ell^\star)}_{t,r} - g_t \cdot \lambda \cdot z^{(\ell^\star)}_{t,j^\star} \cdot d^{(\ell^\star)}_{j^\star}$$
- $\lambda$ 为干预强度：$0<\lambda<1$ 为衰减，$\lambda=1$ 为完全移除，$\lambda>1$ 为沿解码方向反向引导。
- $g_t=1$（检测到攻击）时干预全部前缀 token；否则表示保持不变。

### 2.4 实现细节
- SAE：TopK SAE，遵循 Dr. VLA 实现，1× 扩展比（潜维 = 表示维），$\pi_{0.5}$ 用 $K=12$、SmolVLA 用 $K=6$，训练 6,677 步；训练数据来自干净 LIBERO rollout 的残差流表示。
- 探针：$\pi_{0.5}$ 用 PaliGemma backbone 第 5 层的 2048 维前缀表示 + 类平衡 logistic 回归（$C$ 从 $\{0.01,0.1,1,10,100\}$ 选）；SmolVLA 用 VLM backbone 第 9 层的非 padding 前缀 token 均值 + 类平衡二元交叉熵 + L2 正则。
- 特征选择、探针与 $\lambda$ 均在开发数据上固定后再做评测。

## 3. 实验设计

- **模型**：$\pi_{0.5}$（仅 agent 相机）与 SmolVLA（agent + wrist 相机）。
- **Benchmark**：**LIBERO-10**，每个任务 50 个初始状态 × 10 个任务 = **500 次 rollout**。
- **攻击设置**：UADA 针对自由度（DoF）1 生成每个受害者模型的通用补丁；主评测为**间歇性攻击**，补丁在 rollout 中分别出现 $n=3$ 或 $n=10$ 次，每次持续 10 帧。附加实验使用未优化的 **gripper patch**（VLA-Fool 启发的机械爪图像）。
- **对比方法**：
  - **Baseline**：受攻击但无干预。
  - **Ours**：条件抑制（探针检测后干预）。

  - **w/ Oracle Det.**：仅在补丁真实存在时干预（上界/理想检测）。
- **评测指标**：任务成功率（SR）；探针另报告召回率、FPR、精确率。

## 6. 主要结论与发现

- **SAE 特征确实能追踪补丁存在**：多个 SAE 特征激活与补丁开/关时间高度同步，且在多个 episode 中稳定复现。
- **条件干预有效**：间歇攻击下，方法在全部 4 个设置中提升 SR；最大提升为 $\pi_{0.5}$ 在 $n=10$ 时从 26.0% → 32.4%；SmolVLA 在 $n=10$ 时从 6.2% → 7.6%。效果接近 Oracle 检测，说明主要瓶颈不在检测精度。
- **"何时干预"至关重要**：持续干预（w/o Det.）严重损害性能（$\pi_{0.5}$ 攻击下仅 9.4%，良性下从 54.4% 降至 35.2%）。
- **良性条件基本保持**：$\pi_{0.5}$ 上 54.6% vs. 54.4%（几乎无损）；但 SmolVLA 从 41.4% 降至 36.6%（仍有退化）。
- **$\lambda$ 存在权衡**：攻击下 SR 在 $\lambda \approx 0.2\text{–}0.3$ 处达峰，更强干预反而下降；良性条件下 $\lambda$ 越大退化越严重。
- **特征选择有效**：与补丁存在相关性最高的所选特征也带来最高 SR；随机特征效果参差不齐。
- **持续攻击是失效场景**：补丁全程可见时任何干预都未提升 SR，甚至降低（$\pi_{0.5}$ 12.4% → 9.0%）。

## 7. 优点

- **思路新颖且实用**：将机制可解释性（SAE + 线性探针）与对抗防御结合，**无需微调 VLA 参数**，避免了对抗性微调的算力开销。
- **"检测—抑制"两阶段设计合理**：探针层选在干预层之前（$k \le \ell^\star$），保证因果顺序上的可实现性；用条件门控避免了对正常行为的持续破坏，这一点由消融实验充分验证。
- **可解释性与防御性相互印证**：先展示特征确实追踪补丁存在（图 2），再据此设计干预，逻辑链条完整。
- **实验设计较为严谨**：特征、探针、$\lambda$ 均在与评测分离的开发数据上固定；引入 Oracle 检测上界与 w/o Det. 下界，便于定位方法瓶颈。
- **诚实的失败报告**：明确指出持续攻击下无效、SmolVLA 收益有限且良性性能仍退化，未过度夸大结论。
- **补充了检测器特异性分析**，揭示了探针对训练补丁类型的依赖（UADA 探针会把随机噪声全判为正）。

## 8. 不足与局限

- **持续攻击下完全失效**：当补丁全程可见时，任何干预（含 Oracle）都无法恢复成功率，这是方法的根本限制，暗示所抑制的单一特征不足以应对持续扰动。
- **跨模型泛化不一致**：SmolVLA 上增益微弱（$n=3$ 仅 +1.0%），且良性条件下 SR 下降 4.8 个百分点，说明方法对模型/层选择的敏感性较高。
- **单一特征、单层干预**：仅抑制一个 SAE 特征的一个解码方向，未探索多特征组合或分层干预。
- **检测器特异性有限**：探针对训练补丁类型有偏；UADA 探针把随机噪声补丁全部判为攻击，gripper 探针 FPR 达 9.45%，跨补丁类型迁移能力弱，实际部署中需要针对新补丁重新采集数据训练探针。
- **攻击类型覆盖有限**：主要针对 UADA（DoF 1），未评估目标化攻击、迁移攻击、跨视角/物理世界攻击，也未做未见攻击的泛化测试。
- **场景局限**：仅在 LIBERO-10 仿真环境评测，未在真实机器人上验证；攻击为间歇性数字补丁，与物理世界攻击存在差距。
- **实验统计性不足**：未报告方差、置信区间或显著性检验；附加实验多只在 $\pi_{0.5}$ 上进行；算力开销（SAE 训练、探针训练的 GPU 资源）未完整披露。
- **依赖开发数据**：特征选择、阈值设定、$\lambda$ 调优都需要与目标攻击类型匹配的开发 rollout，实际部署中获取这类数据的成本未被讨论。
