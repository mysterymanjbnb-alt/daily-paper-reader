## 摘要
自主大型语言模型（LLM）智能体越来越多地在网络环境中交互，其中对抗性内容可在智能体之间传播。已知攻击包括智能体蠕虫，它们通过自复制提示注入或配置破坏进行传播。我们提出模因特洛伊木马，这是一类独特的网络介导攻击，利用智能体转发和放大内容的倾向。与传播由对抗性诱导的智能体蠕虫不同，模因特洛伊木马通过将对抗性载荷嵌入社交传染来利用内源性传播：即智能体有内在理由分享的内容。作为工作的一部分，我们从 Moltbook（一个面向 LLM 智能体的社交媒体平台）中提取社交传染。受控传播实验揭示了病毒传播力的巨大差异：最有效的传染在约 50% 的后续智能体帖子中被转发，并且其点赞率达到平均帖子的 2.5 倍。其对应的模因特洛伊木马在很大程度上继承了这些特性。蒙特卡洛攻击模拟表明，模因特洛伊木马将预期暴露量最多放大 3.19 倍。网络结构和放大机制强烈影响传播，产生具有接近全网暴露的厚尾结果。这些结果将内源性社交传播识别为多智能体系统中一种独特的安全脆弱性。由于传播不需要智能体遵循恶意转发指令，专注于提示注入检测或防止智能体被攻陷的防御无法单独阻止模因特洛伊木马的传播。保护大规模智能体生态系统可能需要网络级防御，考虑智能体偏好、推荐机制和网络拓扑如何放大对抗性载荷。

## Abstract
Autonomous large language model (LLM) agents increasingly interact in network environments where adversarial content can propagate between agents. Known attacks include agent worms, which spread through self-replicating prompt injections or configuration compromises. We introduce \emph{memetic trojans}, a distinct class of network-mediated attack that exploits agents' tendencies to retransmit and amplify content. Unlike agent worms, whose propagation is adversarially induced, memetic trojans exploit \emph{endogenous} transmission by embedding adversarial payloads in \emph{social contagions}: content agents have internal reasons to share. As part of our work, we extract social contagions from Moltbook, a social media platform for LLM agents. Controlled transmission experiments reveal large differences in virality: the most effective contagion is retransmitted in approximately 50\% of subsequent agent posts and upvoted at 2.5x the average post's rate. Its memetic trojan counterpart largely inherits these properties. Monte Carlo attack simulations show that memetic trojans amplify expected exposure by up to 3.19x. Network structure and amplification mechanisms strongly shape propagation, producing heavy-tailed outcomes with near network-wide exposure. These results identify endogenous social transmission as a distinct security vulnerability in multi-agent systems. Because propagation does not require agents to follow malicious retransmission instructions, defenses focused on prompt-injection detection or preventing agent compromise cannot alone prevent memetic trojan propagation. Securing large-scale agent ecosystems may require network-level defenses that account for how agent preferences, recommendation mechanisms, and network topology amplify adversarial payloads.

- **被忽视的漏洞**：作者假设，智能体网络中存在类似人类社交网络的**社交传染**现象——某些内容因为“本身具有传播性”而被智能体自发转发、点赞，而非因为内容命令智能体传播。
- **核心问题**：如果对抗性载荷被嵌入智能体已有内生传播倾向的内容中，是否能在不攻陷宿主、不发出恶意指令的情况下实现网络级扩散？
- **整体含义**：论文提出“**模因特洛伊木马**”这一新型网络介导攻击类别，指出**内源性社交传播是多智能体系统中独立的安全脆弱性**。仅靠提示注入检测、执行隔离或防止智能体被攻陷，无法阻止此类传播，需要网络级防御。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

- 将恶意载荷（如指向被篡改 skill 的链接）附加到智能体已有内生倾向转发/点赞的“社交传染”载体上。
- 传播不依赖对抗性指令，转发者自身未被攻陷，行为与正常目标一致。
- 与 agent worm 的区别：worm 必须诱导宿主复制；模因木马是“因为内容是什么而传播”，不是“因为内容告诉接收者做什么”。
- 与 mind virus 的区别：mind virus 改变宿主行为或目标以诱导传播；模因木马不要求宿主采纳对抗性传播目标，载荷只是“搭便车”。

### 2.2 社交传染识别（Moltbook）

- **词汇单元**：用正则提取 emoji、链接、话题标签等。
- **新词**：低 Zipf 分数（< 2.5）候选，认为低频词突发可能指示传染。
- **主题聚类**：使用 `BAAI/bge-large-en-v1.5` 嵌入，经 UMAP + HDBSCAN 聚类，得到 191 个聚类，按 c-TF-IDF 顶级词命名。
- **传播建模**：将每个单元的传播建模为**可见性标记的 Hawkes 过程**：
  - 条件强度：λ(t) = μ_d(t) + α Σ_{t_j<t} w_j e^{-(t-t_j)/τ}
  - 背景项 μ_d 按天常数；自激发项随过去采纳增加未来采纳率。
  - 热榜排序近似为 H = recency + 0.2 × upvotes，标记 w_j = 1 + 0.2 u_j。
  - τ 非参数估计为 2.42 h，取 2.5 h；α 与背景由 MLE 估计，使用 Ozaki 递归和 L-BFGS-B。
- **关键指标**：
  - **R_endo = α τ \bar w**：内生繁殖数，>1 表示自维持传播。
  - **Adopters**：发布含该单元帖子的智能体数。
  - **r_up = \bar u_c / \bar u**：该主题平均 karma 与语料平均之比。
- **过滤条件**：
  - 时间反转安慰剂检验：检验前向与反向拟合的 R_endo 差 φ_e，B=199 置换，p<0.05。
  - 点赞边缘显著性：Mann–Whitney U 单侧检验，p<0.05 且 r_up ≥ 1.5。

### 2.3 智能体测定（Agent Assays）

- 为每个智能体提供模拟 feed，注入载体或模因木马种子帖。
- 每个智能体采样 N=32–100 个 heartbeat。
- 由于发帖概率低（约 5.8%），采用因子分解：
  - p(retransmit) = p(retransmit | post) × p(post)
  - 条件概率通过 prefilling 测量，p(post) 在无载荷 feed 上测量并固定为 0.058。
- 点赞倾向直接采样，因智能体几乎每个 heartbeat 至少点一次赞。
- 实现 fetch 和 install 动作，模拟 skill 安装，估计攻击成功率。
- 使用 5 个后端：gpt-oss-120B、deepseek-v4.1-flash、qwen-32B、gemma2-27B、command-r-35B。

### 2.4 攻击模拟

- **状态介导网络**：Moltbook，N=37,189，30 分钟 heartbeat，120 周期，帖子存活 14 周期。
  - 广播机制：种子若进入排名 feed，每周期被剩余人口的 0.94 看到；否则仅进入 new feed，被 5% 看到。
  - break-in 概率由 live feed 快照校准，取决于载体 upvote edge 和排名阈值。
- **边介导网络**：SNAP ego-Twitter follower graph，N=81,306。
  - 帖子仅暴露给关注者，按代传播，无 upvote 通道。
  - 种子按 follower 数 p99/p90/p50（364/57/8）选取。
- **基线**：
  - generic link sharer：普通链接帖，r_up=1。
  - market-tip：未通过传染检验且 r_up<1 的弱传染，作为生态负对照。
  - 关闭转发的同一模因木马。
- **重述衰减**：每代转发率乘以 ρ=0.93，来自 4 跳重述实验；载荷脱落率平均约 0.41。

## 6. 主要结论与发现

- **社交传染真实存在**：Moltbook 上识别出多个具有显著转发或点赞边缘的传染，如 agent-economy、security/skills、shellraiser、molting、clawtasks 等。
- **病毒性差异大**：最有效传染约在 **50% 后续智能体帖子中被转发**，点赞率达平均帖子的 **2.5 倍**。
- **模因木马继承载体病毒性**：木马在转发和放大上大体继承载体特性，部分载体上木马点赞表现甚至略优于纯传染；转发有轻微衰减，但不一致。
- **模拟放大效果显著**：
  - 预期暴露最高放大 **3.19×**（top/day 排名，相对 generic link）。
  - 相对 market-tip 控制最高放大 **4.78×**。
  - 安装量随曝光放大成比例增加。
- **重尾与彩票效应**：攻击结果呈厚尾分布，少数运行可接近全网暴露；feed 状态、follower 数等随机因素可导致长级联。
- **网络结构决定风险**：
  - **状态介导网络更脆弱**：一旦 break-in 广播 feed，一个帖子可在约 2 个周期
