## 摘要
大型语言模型（LLM）智能体正越来越多地部署在工具增强环境中，但其对外部输入的依赖使其极易受到提示注入攻击，此类攻击能够劫持任务目标。现有安全对齐方法依赖于静态专家轨迹或偏好优化，限制了其泛化到自适应攻击模式的能力。在这项工作中，我们提出自我反思微调（SRFT），一种训练框架，使智能体能够通过在对抗条件下从自身失败经验中学习来提升鲁棒性。SRFT 不是被动模仿专家行为，而是让智能体接触通过注入攻击构造的受损轨迹，并利用专家模型生成结构化的自我反思推理，以对比不安全行为与最优行为。这种反思监督教导智能体识别恶意指令、推理其后果，并保持与原始用户意图对齐。我们在 SR-Agent 中实例化该框架，基于 Llama-3.1-8B-Instruct 和 Qwen3-8B 构建，并在静态和自适应提示注入基准上进行评估。实验结果表明，SRFT 在保持任务性能的同时大幅降低攻击成功率，并在自适应攻击下展现出强泛化能力。这些发现表明，通过自我反思从失败中学习是构建鲁棒且安全的 LLM 智能体的一个有前景的方向。我们的代码已发布在 https://github.com/Eden-Wang1710/srft-repo。

## Abstract
Large language model (LLM) agents are increasingly deployed in tool-augmented environments, but their reliance on external inputs makes them highly vulnerable to prompt injection attacks that can hijack task objectives. Existing safety alignment methods rely on static expert trajectories or preference optimization, limiting their ability to generalize to adaptive attack patterns. In this work, we propose Self-Reflection Fine-Tuning (SRFT), a training framework that enables agents to improve robustness by learning from their own failure experiences under adversarial conditions. Instead of passively imitating expert behaviors, SRFT exposes the agent to compromised trajectories constructed via injected attacks, and leverages an expert model to generate structured self-reflection reasoning that contrasts unsafe and optimal actions. This reflective supervision teaches the agent to identify malicious instructions, reason about their consequences, and maintain alignment with the original user intent. We instantiate this framework in SR-Agent, built on Llama-3.1-8B-Instruct and Qwen3-8B, and evaluate it on both static and adaptive prompt injection benchmarks. Experimental results show that SRFT substantially reduces attack success rates while preserving task performance, and demonstrates strong generalization under adaptive attacks. These findings suggest that learning from failure via self-reflection is a promising direction for building robust and secure LLM agents. Our code is released at https://github.com/Eden-Wang1710/srft-repo.

## 1. 核心问题与整体含义

- **研究背景**：LLM 智能体通过调用外部工具（网页浏览、邮件、命令行、API 等）完成复杂任务，但其对不可信外部输入的依赖使其极易遭受**提示注入攻击（Prompt Injection）**——攻击者在工具返回内容中嵌入恶意指令，劫持智能体的任务目标（goal hijacking）。该风险已被 OWASP 2026 列为智能体应用的首要风险。
- **现有方法的根本局限**：
  - **系统级防御**（沙箱、权限控制、信息流隔离）工程量大、跨环境泛化差。
  - **模型级防御**（StruQ、SecAlign、Meta-SecAlign）依赖**静态、专家人工构造的数据集**，本质是让模型模仿已知的防御模式或进行模式化抑制（pattern-based suppression），只能覆盖有限预定义攻击模式，难以泛化到新颖、自适应的攻击。
  - **强化学习**虽可通过环境交互采集分布外数据，但在长时程智能体任务中环境构建与训练成本极高。
- **整体含义**：论文提出让智能体**从自身失败经验中学习**，通过自我反思（self-reflection）理解"为何安全动作优于被劫持动作"，而非被动模仿，从而获得更强的泛化鲁棒性。

## 2. 方法论：Self-Reflection Fine-Tuning (SRFT)

### 核心思想
将提示注入防御从"动作模仿"转变为"经验学习"：让智能体接触被注入攻击污染的轨迹，采集其真实失败行为，再由专家模型生成对比安全/不安全动作的结构化反思推理，最终用该反思监督微调智能体。

### 关键技术细节（四阶段流程）

- **阶段 I：提示注入数据合成**
  - 智能体轨迹表示为 $\tau = (s_0, a_1, s_1, \ldots, s_{n-1}, a_n)$，其中 $s_i$ 为工具返回的观察，$a_i$ 为工具调用。
  - 用专家 LLM（Claude Sonnet 4.6）基于当前环境工具集 $T$ 合成可执行的注入任务 $P = \{p_j\}$，再经触发模板转为具体注入串 $I_j = Q_{trig}(p_j)$。
  - 以 **0.5 概率**将注入串随机插入（开头/中间/结尾）到中间观察 $s_i$ 中，得到 $\tilde{s}_i = s_i \oplus I_j$，构造受攻击轨迹 $\tilde{\tau}$。
  - 关键点：注入**不改变底层任务目标**，因此最优专家动作保持不变（$a^*_{i+1} = a_{i+1}$），保证监督信号正确。

- **阶段 II：原始动作采样**
  - 在受攻击上下文中，对每个步骤从目标模型采样 $N$（实验取 3）个候选动作 $A_i = \{a_i^{(j)}\} \sim \pi_\theta(\cdot | H_i)$，捕获智能体真实的失败行为（如跟随注入指令）。

- **阶段 III：失败模式自我反思**
  - 专家 LLM 依据轨迹前缀 $H_i$、最优动作 $a_i$ 与候选集 $A_i$ 生成反思推理 $C_i \sim G_2(\cdot | H_i, a_i, A_i)$，包含三部分：
    1. 当前情境与原始用户目标摘要；
    2. 识别观察中的提示注入并解释其恶意意图；
    3. 安全感知的动作分析，对比最优动作与候选动作及其潜在后果（含反事实预测 $(s_i, a_i^{(j)}) \to s_{i+1}^{(j)}$）。

- **阶段 IV：通过失败经验微调**
  - 训练目标：$\mathcal{L} = -\log P_\theta(C_i, a_i | H_i)$
  - 可分解为两项：$\mathcal{L} = -\log P_\theta(C_i | H_i) - \log P_\theta(a_i | H_i, C_i)$
    - 第一项强化对抗观察下的安全意识；
    - 第二项强制产生与原始任务对齐的正确决策。
  - 即模型先生成反思推理，再基于推理生成最终动作。

## 3. 实验设计

- **训练数据**：以 **TOUCAN**（1.5M 工具智能体数据）为基座，选取 5 个平台（Hotel booking、Email sender、Windows Command Line、Markdown Downloader、Minecraft Wiki），过滤 402 个多步工具调用用户任务，合成 38 个恶意注入任务 + 285 个跨轨迹插入的非恶意请求，最终得到 **3698 条轨迹、22339 个助手步骤**，约 37.8% 的工具观察携带注入。

- **评测基准**：
  - **InjecAgent**：单步、隔离式注入跟随行为评测。
  - **AgentDojo**：沙箱式端到端多步工具智能体评测，含 Banking、Slack、Travel、Workspace 四环境共 949 条轨迹。
  - **AgentDyn**（附录 C.3）：测试"过度防御"问题——包含合法第三方指令（如 OTP、结账确认）的开放式任务，共 60 个良性 + 560 个受攻击任务。
  - **通用能力**：MMLU、MMLU-Pro、IFEval、BBH。

- **评价指标**：Benign Utility、Utility under Attack、Attack Success Rate (ASR)、Trade-off（= Utility under Attack + (100 − ASR)）。

- **对比方法**：
  - 无防御基座模型（Llama-3.1-8B-Instruct、Qwen3-4B/8B）；
  - **Meta-SecAlign-8B**（同基座的最强 SOTA 防御）；
  - 自适应攻击 **RL-Hammer** 训练的目标特定攻击者。

- **模型变体**：SR-Agent-Llama（Llama-3.1-8B-Instruct）、SR-Agent-Qwen3-8B、SR-Agent-Qwen3-4B。

- **附录案例研究**：AgentDojo Slack/Banking 案例、RL-Hammer 案例各 2 个。

## 6. 主要结论与发现

- **AgentDojo 主结果（Llama-3.1-8B）**：ASR 从 7.59% 降至 **1.26%**；同时 Benign Utility 从 27.84% 提升至 37.11%，Utility under Attack 从 23.08% 提升至 29.08%，Trade-off 达 127.82，优于 Meta-SecAlign（118.12）。即**安全性与功能性同时提升**。
- **Qwen3 家族**：8B 上 ASR 从 16.97% 降至 **1.05%**；4B 上从 10.85% 降至 **0.84%**，跨模型族与规模一致有效。
- **自适应攻击（RL-Hammer）**：Meta-SecAlign 的 ASR 超过 60%，而 SR-Agent 最终 ASR 低于 20%（Llama 17.5%、Qwen3 17.0%），且在攻击者训练全程保持低 ASR。
- **消融发现**：
  - 去掉"失败经验动作分析"→ ASR 升至 65.0%；完全去掉反思推理 → ASR 60.0%。说明仅"目标复述 + 注入识别"不足以获得鲁棒性，**基于自身采样失败行为的动作分析**是关键学习信号。
  - 测试时关闭 thinking → ASR 从 1.05% 升至 14.33%，说明鲁棒性来自显式推理过程而非记忆安全回答。
- **通用能力**：SR-Agent-Llama 在 MMLU/MMLU-Pro/IFEval/BBH 上与原基座相当，平均优于 Meta-SecAlign（67.9 vs 66.0），未以牺牲通用能力换取安全。
- **推理开销**：SR-Agent 的 thinking token（均值 369.94 vs 451.70）与总生成 token 均**少于**基座 Qwen3-8B，说明自反思监督促使更简洁高效的推理。
- **AgentDyn**：SR-Agent-Llama 良性效用 10.00、ASR 1.96，均优于 Meta-SecAlign（5.00 / 5.54），表明不会过度防御合法第三方指令。

## 7. 优点

- **范式创新**：首次系统地将"从自身失败经验学习"引入智能体提示注入防御，区别于传统的专家模仿与偏好优化，直接针对泛化性痛点。
- **监督信号设计精巧**：反思推理强制包含"目标恢复—注入识别—动作后果分析"三要素，并将候选动作的反事实后果纳入，提供了比单纯正例模仿更丰富的学习信号。
- **训练数据构造合理**：在真实工具智能体轨迹上注入，注入不改变最优动作，保证监督正确；0.5 概率与随机位置注入避免位置偏差。
- **实验维度全面且客观**：静态 + 自适应 + 跨模型族/规模 + 通用能力 + 过度防御 + 推理开销，消融能精确定位贡献来源，多随机种子、无 checkpoint 选择增强可信度。
- **实用性强**：不增加甚至降低推理开销；开源代码；在保持甚至提升任务效用的情况下大幅降 ASR，突破安全—效用权衡的传统认知。

## 8. 不足与局限

- **算力披露不完整**：主训练（SRFT 微调）的 GPU 型号、数量、时长未明确，数据合成依赖 Claude Sonnet 4.6 的成本未量化，复现成本不易评估。
- **专家模型依赖**：反思质量高度依赖外部专家 LLM（Claude Sonnet 4.6），若专家本身对新型攻击识别不足，反思监督质量可能受限；论文未分析专家模型能力对最终鲁棒性的影响。
- **模型规模覆盖有限**：仅验证 4B/8B 规模，未测试更大（如 70B+）或更小模型，跨规模规律不明确。
- **任务与攻击场景受限**：评测任务相对短程（AgentDojo 等），未覆盖真正的长时程、复杂计算机使用/网页智能体场景（论文在结论中承认这是未来方向）；攻击者能力假设为"仅可访问现实攻击面"，可能低估了强对抗场景。
- **威胁模型假设**：假设间接注入中用户非攻击者，未讨论直接注入或用户与攻击者合谋等混合威胁。
- **反思推理的泛化边界**：测试时消融显示关闭 thinking 后 ASR 大幅上升（1.05%→14.33%），意味着鲁棒性依赖推理模式启用，在无法开启推理的部署配置下效果可能退化。
- **潜在偏差风险**：训练数据来自 TOUCAN 特定 5 个平台，攻击模板混合了 StruQ/TaskTracker 的 750 个模板，可能存在对特定模板分布或平台工具集的隐性适配。
