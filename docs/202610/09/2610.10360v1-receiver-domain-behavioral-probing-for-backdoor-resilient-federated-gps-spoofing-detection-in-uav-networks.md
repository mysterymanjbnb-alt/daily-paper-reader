## 摘要
联邦学习使无人机机群能够训练一个共享的GPS欺骗检测器，而无需将原始接收机数据传出任何飞行器；近期若干无人机联邦学习设计会根据每个客户端自我报告的验证准确率来对其加权。我们表明，这种自我报告是一种可被利用的攻击杠杆：十个客户端中有两个被攻陷的客户端投毒其部分数据、缩放其更新并虚报其准确率，可将后门提升量提高到 +0.3036，高于同一攻击在不撒谎时所能达到的水平。我们提出接收机域行为探测：协调方在反事实欺骗样本上评估每个提交的模型，这些样本通过将每个判别性GPS特征驱动至良性值而构建，并根据模型的实际行为而非其声称的表现来对客户端加权。在独立同分布客户端下，这将攻击者引起的提升量降至 -0.0265，与诚实机群在统计上不可区分，同时标记出被攻陷的飞行器。与拜占庭鲁棒聚合不同，它不需要精确的攻击者数量，只需要诚实多数：当真实数量超过配置值时，Multi-Krum 从 +0.0061 恶化到 +0.2837，而我们的方法仍保持在基线附近。评估使用一个公开的单接收机数据集，将其划分为模拟客户端；我们还报告了该机制在强客户端异质性下失效的情况。

## Abstract
Federated learning lets a UAV fleet train a shared GPS spoofing detector without raw receiver data leaving any aircraft, and several recent UAV-FL designs weight each client by the validation accuracy it reports about itself. We show this self-report is an exploitable attack lever: two compromised clients of ten that poison part of their data, scale their updates, and inflate their reported accuracy raise backdoor lift to +0.3036, higher than the same attack achieves without lying. We propose receiver-domain behavioral probing, in which the coordinator evaluates every submitted model on counterfactual spoofed samples built by driving each discriminative GPS feature to a benign value, weighting clients by what their models do rather than what they claim. Under independent and identically distributed clients this reduces attacker-induced lift to -0.0265, statistically indistinguishable from an honest fleet, while flagging the compromised aircraft. Unlike Byzantine-robust aggregation it needs no exact attacker count, only an honest majority: when the true count exceeds the configured value, Multi-Krum degrades from +0.0061 to +0.2837 while ours stays near baseline. Evaluation uses one public single-receiver dataset partitioned into simulated clients; we also report where the mechanism fails, under strong client heterogeneity.

## 1. 核心问题与研究动机

- **背景**：无人机（UAV）机群在灾害响应、搜救等场景中主要依赖 GPS 导航，且常处于视距外。民用卫星信号公开广播且无认证，攻击者可发射比真实信号更强的欺骗信号，在不接触飞行器的情况下偏移其感知位置，因此机载检测成为安全刚需。
- **FL 的适配性**：联邦学习（FL）允许每架无人机用本地观测信号训练检测器，仅共享模型参数，原始接收机数据不出机，天然契合隐私需求。
- **关键漏洞**：近期若干 UAV-FL 设计（如 Chai 等 [4]）按客户端**自报的验证准确率** `Acci` 进行加权聚合。协调方看不到客户端数据，无法重算或验证该自报值，于是这一"用于提升鲁棒性的指标"反而变成**模型更新之外的第二个攻击杠杆**。
- **论文要解决的问题**：现有 FL 安全文献针对的是不同目标——模型替换后门假设使用朴素 FedAvg，本地模型投毒针对拜占庭鲁棒规则，而最有效的后门防御需要检查客户端数据分布（隐私场景不暴露）。**没有任何工作评估过"信任客户端自报指标"的聚合规则**。
- **与 FLTrust [9] 的区别**：FLTrust 同样从干净的根集引导信任，但它用更新方向（全局参数向量的余弦）评分，而后门只局限在小子空间，几乎不扰动该统计量。本文改为**衡量模型在协调方自建的反事实接收机域探针上的行为**，从而获得逐客户端标记能力，且无需知道触发器落在哪个特征上。

## 2. 方法论

### 2.1 核心思想

协调方不再采信任何客户端自报量，而是**在它自己构造的反事实欺骗样本上评估每个提交模型**，按模型的实际行为分配信任权重。由于 `Acci` 根本不参与任何计算，精度虚报（A3）在构造上即失效。

### 2.2 设计需求（R1–R4）

- **R1 协调方可计算**：权重的每个输入都来自协调方持有的数据。
- **R2 触发器无关**：协调方不需要知道触发特征 `f*`。
- **R3 无需精确攻击者数**：不能把攻击者数量 `M` 作为参数（Krum/Multi-Krum/Trimmed Mean 均需），只需诚实多数假设。
- **R4 可归因**：输出应能识别具体哪架飞机行为异常。

### 2.3 攻击模型（用于验证防御的必要性）

攻击者控制 `M < N/2` 个客户端，完全白盒，目标是在普通流量精度不显著下降的前提下，最大化触发样本被误判为"真实"的概率。包含三步耦合动作：

- **A1 边缘良性投毒**：对某比例 `p` 的欺骗样本，把判别性特征 `f*` 覆盖为其良性高值 `vf*`（真实分布的 75 分位数，对 CN0 为 46.706 dB-Hz），标签翻转为"真实"。该值落在自身良性边缘范围内，因此逐特征的范围/阈值检查无法发现。
- **A2 模型替换缩放**：把本地更新相对全局模型放大 `γ` 倍（`ω_m ← ω + γ(ω_m - ω)`），本文用 `γ = 3.0`，比最强的全替换（需 `γ ≈ N`）更隐蔽。
- **A3 精度虚报**：上报 `Acc_m ≫ Acc_m`，把式 (2) 中的权重 `λm` 推向单个客户端所能达到的最大值。该操作零成本、不改模型、对只推理参数的防御不可见。

### 2.4 探针构造

- 令 `Fprobe` 为判别性特征集合（类间分离度 Cohen's d ≥ 0.05）。
- 对每个 `f ∈ Fprobe`，构造探针切片：
  `Sf = { x | x ∈ D_spoof_r, x_f ← v_f }`
  即**从欺骗根样本出发，仅覆盖单个特征为良性高值**。
- 三个关键设计选择：
  - 切片全部源自欺骗根样本，其余 `|F|-1` 个特征仍为欺骗值，**真值标签已知**，因此切片上的召回率可解释。
  - **不假设**诚实模型会把所有探针判为欺骗（诚实召回也远低于 1），机制依赖的是**相对于同群的比较**而非绝对标准。
  - `v_f` 取真实分布 75 分位数，恰好位于隐蔽触发器必须落点的位置。

### 2.5 怀疑度与信任

- 设 `d_{i,f}` 为客户端 `i` 在切片 `Sf` 上的检测召回率，定义**怀疑度**（式 5）：
  `s_i = max_f max(0, (m_f − d_{i,f}) / (MAD_f + ε))`，其中 `m_f = median_i d_{i,f}`，`MAD_f = median_i |d_{i,f} − m_f|`。
  - 用**中位数/MAD** 而非均值/标准差：因为被评分的客户端中就包含嫌疑者，前者崩溃点为 0，后者可容忍近半数污染（正好对应 `M < N/2`）。
  - 用**最大值**而非均值：后门是局部化的，平均会稀释异常。
  - **单侧**且**相对**：高于同群中位数不算可疑，且诚实召回随全局模型训练漂移。
- 通过**死区 τ** 与**门控 β** 把怀疑度转为信任，并由干净根集准确率 `a_i`（协调方自行计算）调制（式 6）：
  `t_i = a_i e^{−β max(0, s_i−τ)} / Σ_j a_j e^{−β max(0, s_j−τ)}`
  - 死区是必需的：`s_i` 是每轮重算的排名，即使一切正常也总有客户端最低。开发实验中，仅惩罚超过 τ 的怀疑度把诚实误报从 20.5% 降到 0.3%，且不损失攻击者标记率。
  - 指数门控保证信任严格为正；EMA 因子 `ρ` 跨轮平滑（后门持续存在，采样噪声不然）。

### 2.6 聚合

- 采用**信任加权的逐坐标中位数**（式 7）：
  `ω(t+1) = median_i ( ω(t) + N t_i (ω_i(t) − ω(t)) )`
  - 因子 `N` 用于归一化：当信任均匀时 `N t_i = 1`，退化为普通的逐坐标中位数。
- **双层分工**：信任层是**针对性**的（识别作恶者，满足 R4），但依赖同群统计量有效；中位数层是**非针对性**的（不识别任何人，但无论评分如何都能限制单个更新的影响）。探针失效时由中位数兜底。

### 2.7 算法流程（Algorithm 1，单轮）

1. 各客户端并行本地训练 `ω_i`，协调方计算其在根集上的准确率 `a_i`；
2. 协调方对每个 `f ∈ Fprobe` 计算召回 `d_{i,f}`；
3. 计算同群中位数 `m_f` 与 `MAD_f`；
4. 计算怀疑度 `s_i`；
5. 计算并归一化信任 `t_i`，按 `ρ` 做 EMA 平滑（首轮取 `1/N`）；
6. 按式 (7) 中位数聚合，返回全局模型与信任。

### 2.8 成本与范围

- 协调方每轮额外做 `|Fprobe|·N` 次前向传播（探针）加每客户端一次精度评估，**线性于机群规模与探针特征数，无反向传播**。
- 客户端计算与上行链路不变；方法**模型无关**，只需模型可在特征向量批次上评估。

## 3. 实验设计

### 3.1 数据集与场景

- 使用公开的**软件定义无线电 GPS 欺骗数据集**（Aissou，Mendeley Data V3, 2022）——单接收机采集。
- 由于没有公开的真实多无人机带标注攻击无线流量数据，作者把该数据集**划分为模拟客户端**，明确声明结果刻画的是聚合规则本身而非已部署系统。
- 数据预处理：去重、删除 3 个标识列后剩 10 个信号质量特征，其中 8 个满足 `d ≥ 0.05` 构成 `Fprobe`（d 从 0.306 到 0.152），另 2 个为 0.018 和 0.001（触发器藏在那里几乎无信号可利用）。
- 采样 150,000 行，真实/欺骗比 60/40，划分为互不相交的 30,000 行测试集、6,000 行根集、114,000 行分给 `N = 10` 个客户端（其中 `M = 2` 被攻陷）。
- 模型：10-64-32-16-1 的 MLP，共 3,329 个参数；每轮 3 个本地 epoch，共 12 轮；Adam，学习率 `1e-3`，批大小 512。
- 攻击超参：`p = 0.40`，`γ = 3.0`，虚报精度 `0.99`，默认触发特征 `f* = CN0`，`v_f* = 46.706 dB-Hz`。
- 防御超参：`β = 1.0`，`τ = 2.0`，`ρ = 0.5`，**全程不再调参**。
- 数据划分固定为种子 42（评估目标不动），客户端划分、投毒抽样、初始化、批顺序在种子 42/7/123 上变化，报告三种子均值，lift 在种子内配对。

### 3.2 评测指标

- **后门成功率 BSR**：带触发器的欺骗测试样本被判定为"真实"的比例。
- **后门提升 Lift**：BSR 减去同种子诚实 FedAvg 的 BSR。这是**主指标**，因为触发器按构造落在良性范围内，诚实检测器本就会误判许多此类样本，只有超出基线的增量才归因于攻击。
- **客户端标记率**：被压到均匀权重一半以下的客户端轮次比例（分别对受控与诚实客户端统计）。
- **排除率**：对 Krum/Multi-Krum 这类选择型规则，统计受控客户端轮次被排除在选中集之外的比例。作者明确指出标记率与排除率**机制不同、不可直接比较**。
