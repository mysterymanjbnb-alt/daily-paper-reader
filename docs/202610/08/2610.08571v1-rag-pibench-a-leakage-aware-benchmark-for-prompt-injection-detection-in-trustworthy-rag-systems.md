## 摘要
检索增强生成（RAG）系统容易受到嵌入检索内容中的提示注入攻击。我们提出 RAG-PIBench，一个用于RAG式提示注入检测的基准，包含4,876个上下文示例，分为冻结的训练集、验证集和受保护的测试集。采用泄漏感知的构建流程和严格评估协议，我们比较了基于关键词、语义参考、TF-IDF和基于Transformer的检测器。DistilBERT在受保护测试集上取得最佳性能（F1 = 0.896，PR-AUC = 0.968），而TF-IDF SVM和逻辑回归仍具竞争力。我们的结果证明了泄漏感知基准设计以及强稀疏基线对于RAG系统中可靠提示注入检测的价值。

## Abstract
Retrieval-Augmented Generation (RAG) systems are vulnerable to prompt-injection attacks embedded in retrieved content. We introduce RAG-PIBench, a benchmark for RAG-style prompt-injection detection containing 4,876 contextual examples across frozen train, validation, and protected-test splits. Using a leakage-aware construction pipeline and strict evaluation protocol, we compare keyword-based, semantic-reference, TF-IDF, and transformer-based detectors. DistilBERT achieves the best protected-test performance (F1 = 0.896, PR-AUC = 0.968), while TF-IDF SVM and logistic regression remain competitive. Our results demonstrate the value of leakage-aware benchmark design and strong sparse baselines for reliable prompt-injection detection in RAG systems.

## 1. 核心问题与整体含义

- **研究背景**：RAG 通过引入外部文档增强 LLM 的事实性与领域适应能力，但也扩大了攻击面。攻击者可将提示注入嵌入检索内容，使模型忽略系统目标并执行恶意指令。
- **核心问题**：RAG 场景中的良性文档常天然包含指令、代码片段、任务描述等，因此仅靠关键词难以区分“良性指令”与“恶意指令覆盖”；同时，现有检测评测常因训练/测试泄漏、模板重复、词法捷径等问题高估性能。

## 2. 方法论

- **核心思想**：将 RAG 式提示注入检测建模为二分类任务：给定“宿主上下文 + 嵌入内容”的渲染文本，判断嵌入内容是良性还是恶意指令覆盖。
- **任务定义**：
  - 输入 \(x_i\)：RAG 风格渲染文本，包含宿主上下文和嵌入内容段。
  - 标签 \(y_i \in \{0,1\}\)：0 表示良性，1 表示 `malicious_prompt_injection`。
  - 检测器学习映射 \(f(x_i) \rightarrow y_i\)。
- **关键设计原则**：
  - 良性样本也可包含指令、任务描述或请求，因此任务不是检测“是否出现祈使句”，而是检测“是否试图覆盖、忽略、重定向、绕过或操纵助手行为”。
- **构建流程**：
  - **来源注册与模式验证**：记录渲染文本、标签、标识符、划分元数据和来源信息。
  - **溯源追踪**：跟踪每个样本的来源与转换过程，支持审计。
  - **混合人机质量控制**：人工审查结合自动化检查，排除模糊、重复、标签不一致或可能引入捷径伪影的样本。
  - **RAG 式上下文渲染**：将宿主上下文与嵌入内容组合，避免退化为孤立提示片段分类。
  - **泄漏、捷径与残余线索审计**：检查重复内容、划分污染、重复模板、来源标记、格式伪影等。
  - **冻结划分**：训练集、验证集、受保护测试集固定，测试集仅用于最终评估。
- **评估协议**：
  - 训练集用于拟合，验证集用于超参数和检查点选择，受保护测试集仅打开一次。

  - 诊断套件与主测试分离，不参与模型排名或阈值调整。
- **评价指标**：
  - Accuracy、Precision、Recall、F1、PR-AUC、ROC-AUC、混淆矩阵。
  - 正类为恶意提示注入。

    - Accuracy = \((TP+TN)/(TP+TN+FP+FN)\)
