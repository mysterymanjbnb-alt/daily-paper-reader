# A PATH INTEGRAL SURROGATE FOR MULTI-STEP GRADIENT INVERSION IN FEDERATED LEARNING

ABSTRACT 

Federated learning lets many clients train a shared model together without ever sending their private data to a central server. Each client shares only a model update, and this update should reveal far less about the client than its raw training examples would. This premise is what protects the privacy of the clients. Gradient inversion attacks challenge it directly by trying to reconstruct a client’s private input images from the single update it shared. Under FedAvg, a client’s update accumulates several local training steps, so the server sees only the two endpoints of a hidden weight trajectory. Recent gra-dient inversion attacks fit a surrogate model along the path between these two endpoints but they still read its gradient at a single point. We propose the Path-Integral Surrogate Model Extension (PI-SME) which treats the accumulated update as a path integral of the gradient field and approximates it by Gauss–Legendre quadrature over sev-eral nodes along a learnable B´ ezier path. On CIFAR-100 and FEM-NIST images across a range of trajectory lengths and class-restricted batches PI-SME reconstructs the private inputs more faithfully than the strongest surrogate baseline on several inversion metrics and the matching loss. 

Index Terms — federated learning, gradient inversion, privacy, surrogate model, numerical quadrature 

1. INTRODUCTION 

Federated learning trains a shared model across many clients with-out collecting their data on a central server [1, 2]. A server holds a global model and repeatedly sends it to participating clients. Each client owns a private dataset. Given a batch (X, Y ) of input images 

X and labels Y , the client trains a model fw with weights w un-der a loss ℓ. It then returns only the resulting model update. The server aggregates these updates to form a new global model and re-peats the process over multiple communication rounds. Since raw samples remain on the clients, federated learning is used in settings where privacy or data-governance requirements discourage central data collection, including mobile keyboard prediction [3], clinical modeling across hospitals [4], fraud detection across financial insti-tutions [5], and intelligence on edge and IoT devices [6]. The predominantly used federated learning algorithm is Fe-dAvg [1]. In FedAvg, each client performs several local SGD steps before returning its updated model to the server. The server then aggregates the client models using a weighted average. FedSGD is the one-step special case in which each client returns the gradient at the current global model rather than an update accumulated over multiple local steps. Sharing updates instead of data is intended to protect client privacy. This protection is further supported by defenses such as secure aggregation [7] and differential privacy [8]. Gradient inversion attacks challenge this protection by reconstruct-ing private inputs from a shared update. An honest-but-curious server optimizes a dummy batch ˆX with the same shape as X until its gradient matches the observed update. DLG [9] minimizes the Euclidean distance between the two gradients, while iDLG [10] first recovers the labels. IG [11] uses a cosine matching objective together with a total-variation image prior TV( ˆX), while GradIn-version [12] scales to larger batches. Prior-enhanced attacks such as GI-NAS [13] and DGGI [14] incorporate architectural or diffusion image priors. These methods are primarily designed for single-step gradients. In contrast, FedAvg produces an update accumulated over multiple local steps, and the server observes only the endpoints: the initial global model and the model returned by the client after local training. Recent surrogate-model attacks such as SME [15] and NL-SME [16] fit a surrogate path between these endpoints but still evaluate its gradient at a single point. 

Our contribution is to treat the accumulated update as a path integral of the gradient field along the client trajectory. We recon-struct this integral using numerical quadrature rather than a single gradient evaluation. We propose the Path-Integral Surrogate Model Extension (PI-SME), which evaluates the surrogate gradient at sev-eral nodes along a learnable B´ ezier path and combines these evalu-ations using Gauss–Legendre weights to approximate the accumu-lated update. To our knowledge, this is the first gradient inver-sion attack to model the multi-step update as a path integral and use multi-node quadrature for inversion. On CIFAR-100 [17] and FEMNIST [18, 19], PI-SME improves over the strongest surrogate baseline across all reconstruction metrics. The largest gains occur on long trajectories and class-scarce batches, where the single-point approximation is weakest. Section 2 reviews the multi-step setting and surrogate baselines. Section 3 presents PI-SME. Section 4 reports the main results and benchmark comparisons. Section 5 presents the ablation studies. Section 6 concludes the paper.

3. PROPOSED METHOD: PI-SME 

The update ∆w accumulates gradients along the client’s local trajec-tory, so up to the step size it is a discrete line integral of the gradient field. The quantity to reconstruct is therefore this path integral, not any single gradient. SME and NL-SME approximate the integral by reading the gradient at a single surrogate state, which replaces the whole path by one sample and leaves an error that grows as the trajectory lengthens with T . A single sample is also insufficient in principle. Matching ¯g from one state requires that state’s gradient to be parallel to ¯g, the average of the per-step gradients. For a scalar function the mean value theorem guarantees such a point, but it does not carry over to the vector-valued, high-dimensional gradients at-tacked here [20]. The path-consistency test in Section 5.2 confirms this on real trajectories, where the best single point is measurably worse than a quadrature over several nodes. We therefore treat the reconstruction of ∆w as a quadrature problem and approximate the path integral with m fixed nodes along the path. Increasing the node count m pulls the surrogate direc-tion toward the true accumulated update and recovers more of it the longer and harder the trajectory is to match. Our method, the Path-Integral Surrogate Model Extension (PI-SME), realises this. Each node costs one backward pass, the dominant cost of the attack. The 

m nodes are selected using Gauss–Legendre quadrature, which pro-vides a high-order approximation with m gradient evaluations and is exact for polynomial integrands of degree up to 2m − 1.

4. RESULTS 

We evaluate on CIFAR-100 [17] ( 100 classes, 32 × 32 RGB images) and FEMNIST [18, 19] ( 62 classes, 28 × 28 grayscale images), cho-sen to probe inversion across different terrains, colour and grayscale images with search spaces of different size. The victim networks are small CNNs with two convolutional layers followed by two fully connected layers, as in [15, 16], and the node count is fixed at m=7 

from the ablation in Section 5. We compare PI-SME against SME, NL-SME, and three further gradient inversion attacks, test whether extra optimization closes the NL-SME gap, and measure reconstruc-tion under low-rank updates.

6. CONCLUSION 

PI-SME reframes multi-step gradient inversion as a quadrature prob-lem. Because the FedAvg update is the accumulation of gradients along a client’s local trajectory, the object worth matching is the path integral of the gradient field rather than the gradient at any one weight, and PI-SME approximates that integral with an m-node Gauss–Legendre rule along a learnable B´ ezier curve. The size of the gain tracks the difficulty of the setting. On the easy regimes PI-SME and the strongest surrogate baseline sit close together, but the margin over NL-SME widens as the client trains longer, from about 0.8 dB at T =100 to about 3 dB at T =250 , and as the batch spans fewer classes, from about 0.8 dB at C=100 to about 4.2 dB at C=10 . As the observed update drifts further from any single surrogate state, integrating along the trajectory recovers more of the signal. Choos-ing m from a principled bound rather than a sweep and explaining the sharp fall all surrogate methods show on class deficient batches remain open as scope for future work. 7. REFERENCES
