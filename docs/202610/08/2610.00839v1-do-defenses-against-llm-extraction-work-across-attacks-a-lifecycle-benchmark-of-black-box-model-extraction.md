## 摘要
通过纯文本 API 部署的大型语言模型（LLM）面临模型提取风险，因为攻击者可以收集其响应来训练能够复现其能力的替代模型。尽管已有工作提出了多种攻击与防御方法，但评估在访问假设、模型配置、查询预算和安全目标等方面仍然割裂，限制了不同方法之间的可比性。为填补这一空白，我们提出了一个统一基准，涵盖六种提取攻击、十种防御，以及两种自适应攻击：它们在替代模型训练之前对受保护的响应进行复述或回译。该基准在每次比较中控制模型配置、查询数据、预算和留出评估条件，同时保留攻击特定的查询与训练流程。我们测量替代模型的能力、对受害模型的保真度、使用 Rep-4 的输出质量以及查询预算敏感性；防御则使用其自身的安全指标并结合替代模型性能进行评估。对于自适应攻击，我们联合测量溯源检测器得分以及在改写响应上训练的替代模型的能力和保真度。因此，该基准为在纯文本访问下比较提取方法及其与防御的交互提供了可复现的基础。代码和工件可在 https://github.com/sliu11-byte/MEA-Bench 获取。

## Abstract
Large language models (LLMs) deployed through text-only APIs face model extraction risks, as adversaries can collect their responses to train surrogates that reproduce their capabilities. While prior work has developed diverse attacks and defenses, evaluations remain fragmented across access assumptions, model configurations, query budgets, and security objectives, limiting comparability across methods. To address this gap, we introduce a unified benchmark covering six extraction attacks, ten defenses, and two adaptive attacks that paraphrase or back-translate protected responses before surrogate training. The benchmark controls model configurations, query data, budgets, and held-out evaluation conditions within each comparison while preserving attack-specific querying and training procedures. We measure surrogate capability, fidelity to the victim, output quality using Rep-4, and query-budget sensitivity; defenses use their own security metrics paired with surrogate performance. For the adaptive attacks, we jointly measure provenance-detector scores and the capability and fidelity of surrogates trained on rewritten responses. The benchmark thus provides a reproducible basis for comparing extraction methods and their interactions with defenses under text-only access. Code and artifacts are available at https://github.com/sliu11-byte/MEA-Bench.

## 1. 核心问题与整体含义

- **研究背景**：通过纯文本 API 部署的 LLM 虽隐藏参数，但暴露输入–输出行为。攻击者可反复查询并收集响应，训练更小的替代模型（surrogate），从而在未获取参数或训练数据的情况下复现受害模型能力，构成功能性模型提取风险。
- **核心问题**：现有 LLM 提取攻击与防御研究高度碎片化：访问假设、受害/替代模型配置、查询数据、查询预算、评估目标不统一，导致攻击强弱和防御效果难以横向比较；防御又分别追求降低替代模型性能、嵌入溯源信号、验证模型血缘、检测可疑查询等不同目标，不能用单一“防御分数”衡量。
- **整体含义**：论文提出一个面向生命周期的黑盒 LLM 提取基准，试图在受控条件下比较多种攻击、多种防御及自适应攻击，并同时报告替代模型效用与防御目标特定指标，为文本 API 场景下的提取攻防提供可复现、可比较的评测基础。

## 2. 方法论

- **核心思想**：将黑盒 LLM 提取形式化为四阶段生命周期：
  1. 查询获取（query acquisition）；
  2. 受害模型交互（victim interaction）；
  3. 替代模型训练（surrogate training）；
  4. 评估（evaluation）。
- **关键公式**：对查询预算 \(B\)，查询为 \(q_i\)，受害响应为 \(y_i=f_V(q_i)\)。训练响应 \(r_i\) 可能为原始响应 \(y_i\)、受保护响应 \(\tilde{y}_i\)、或自适应改写响应 \(\hat{y}_i\)。提取数据集为  
  \[
  \mathcal{D}=\{(q_i,r_i)\}_{i=1}^{B},\quad f_S=\text{Train}(\mathcal{D})
  \]
  其中 \(f_S\) 为攻击者训练的替代模型。
- **攻击分类**：
  - 固定池选择：SeqKD、LoRD、SODA、GAD 从共享查询池取查询。
  - 方法特定查询生成：Model Leeching 使用模板化查询；QEDKS 使用种子、模板和追问扩展查询。
  - 替代模型训练差异：SeqKD、Model Leeching、QEDKS 使用响应监督微调；LoRD 使用学生候选做迭代成对优化；SODA 构造教师–学生偏好对做 DPO；GAD 联合优化生成器与响应判别器。
- **防御分类**：
  - 查询检测：MMD、PRADA、SEAT，在推理前判断查询流是否像提取流量。
  - 响应修改：
    - 反蒸馏：ADS、DOGe、Trace Rewriting，目标是降低释放响应的训练价值。
    - 溯源：ADFP、GINSEW、Radioactivity，在响应中嵌入可被替代模型继承的信号。
  - 训练后验证：DuFFin，用诊断探针判断可疑模型是否源自受害模型。
- **自适应攻击**：
  - 在受害交互后、替代模型训练前改写受保护响应。
  - 两种方式：DIPPER 复述；英语–法语–英语回译。
  - 目标：削弱响应中嵌入的溯源信号，同时尽量保留可训练监督。
- **评估原则**：
  - 每次比较尽量匹配模型配置、查询数据、预算和留出评估条件。
  - 保留各攻击特有的查询获取和训练流程。
  - 防御按其目标使用自身安全指标，并同时报告替代模型能力与保真度。
  - 自适应攻击在改写响应上重新训练替代模型后，联合测量检测器分数、能力与保真度。
