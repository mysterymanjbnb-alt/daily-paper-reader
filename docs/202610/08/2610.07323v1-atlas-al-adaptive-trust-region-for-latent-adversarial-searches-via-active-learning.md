## 摘要
基于学习的系统的安全性评估不仅仅需要用一组固定的攻击来测试系统。它还需要能够高效发现会导致模型失败的输入集合的自适应机制。我们提出 ATLAS（Adaptive Trust-Regions for Latent Adversarial Searches，潜在对抗搜索的自适应信赖域），这是一个基于查询的框架，可为黑盒学习系统发现对抗输入集合。ATLAS 将攻击生成视为一个主动学习水平集估计问题，然后结合校准近似与局部-全局采样架构，来寻找输入空间中包含对抗样本的区域。一旦发现这些区域，ATLAS 便设计为在这些对抗区域内采样，以构建能够准确表征目标模型鲁棒性状态的对抗集合。在玩具实验中，我们发现，在有限查询预算下，ATLAS 能够比先前工作恢复出更多对抗区域。当应用于标准和对抗训练的 MNIST、CIFAR 和 ImageNet 模型目标时，ATLAS 比其他基于查询的黑盒攻击（NES、SignHunter、BayesOpt）产生更具代表性的攻击。ATLAS 代表了一个自动化红队框架，既可用于分析开发中的基于学习的系统的鲁棒性，也可用于持续审计，以观察系统鲁棒性随时间的变化。

## Abstract
Security evaluation of learning-based systems requires more than just testing the system against a fixed collection of attacks. It requires adaptive mechanisms that can efficiently discover \textit{sets} of inputs that induce model failure. We introduce ATLAS (Adaptive Trust-Regions for Latent Adversarial Searches), which is a query-based framework that discovers adversarial input sets for black-box learning systems. ATLAS casts attack generation as an active learning level set estimation problem then combines calibrated approximations with a local-global sampling architecture to find regions of the input space that contain adversarial examples. Once discovered, ATLAS is designed to sample points within these adversarial regions to build adversarial sets that accurately represent the state of robustness of the target model. When applied on toy experiments, we find that ATLAS is able to recover more of the adversarial region under a limited query budget than does previous work. When applied to standard and adversarially trained MNIST, CIFAR, and ImageNet model targets, ATLAS produces better representative attacks than other query-based black-box attacks (NES, SignHunter, BayesOpt). ATLAS represents an automated red-teaming framework that can be used for both analyzing the robustness of learning-based systems under development and continuous auditing to see how the robustness of a system changes over time.

## 一、核心问题与整体含义

- **研究背景**：随着学习型系统在安全关键场景（如自动驾驶、图像分类）中的广泛部署，鲁棒性评估不能仅依赖固定的已知攻击集合，而需要能够自适应地发现导致模型失败的输入区域。
- **核心问题**：现有黑盒对抗攻击方法（如 NES、SignHunter、BayesOpt）通常以优化单个或少数对抗样本为目标，无法刻画模型失败区域的整体分布。而在安全审计中，评估者需要获得一个**具有代表性的对抗集合**，以回答"模型在哪些地方、以何种方式失败"。
- **关键挑战**：
  - 输入空间维度极高，穷举搜索不可行；
  - 对抗区域可能仅占整个搜索空间的极小比例（如 5%），无引导探索难以命中；
  - 需要在有限查询预算下同时实现**区域发现**与**集合构建**两个目标。
- **整体含义**：ATLAS 将对抗生成重新表述为**区域恢复问题**（而非优化问题），为自动化红队测试和持续安全审计提供基础工具。

## 二、方法论

### 2.1 核心思想

- 将攻击生成建模为**主动学习中的水平集估计问题**：学习一个对抗价值函数 \(V(x) \to \iota\)，其超零水平集 \(S := \{x : V(x) \geq 0\}\) 即为待恢复的对抗集合。
- 与先前工作（AP2L、TRLSE）仅采样零水平集边界不同，ATLAS 同时采样**边界区域**（用于发现对抗区域）和**饱和区域**（用于填充区域内部，构建代表性对抗集）。
- 采用**全局-局部采样架构**：先选择信赖域中心，再在信赖域内局部采样。

### 2.2 关键技术细节

**（1）校准机制（Calibration）**

- 核心创新：**直接校准模型预测**，而非校准采集函数。
- 全局模型校准：从总预算中划出一部分作为均匀采样的保留集 \(C_{global}\)，训练一个残差模型 \(h_r\) 估计主模型误差，得到校准后代理模型 \(\tilde{h}_g = h_g - h_r\)。一次校正可传播到所有基于该模型的采集函数。
- 局部模型校准：由于信赖域临时且移动，采用**留一交叉验证（LOO-CV）**，仅使用局部训练点，避免消耗额外查询预算。

**（2）信赖域与采集函数设计**

- 信赖域为超立方体 \(TR = \{x \in \mathbb{R}^d \mid \|x-c\|_\infty < l/2\}\)，中心选择通过式 (1) 结合采集函数与距离惩罚 \(g(r) = 1/(1+e^{-(r-\eta)/(\hat{\alpha}\eta)})\)。
- 两类采集函数：
  - **边界采集** \(\bar{a}_{bound}(x,\mu,\sigma) = (1-\rho)e^{-\mu/s_{bnd}} + \rho(1-e^{-c\beta\sigma/s_{bnd}})\)，偏好零水平集附近且模型误差高的点；
  - **饱和采集** \(\bar{a}_{sat}(x,\mu,\sigma) = 1 - e^{-(\beta\sigma + wP)/s_{sat}}\)，其中 \(P = 1-\Phi(-\mu/\sigma)\) 为属于对抗超水平集的后验概率，偏好预测在对抗区域内部且不确定的点。
- 边界放置采集 \(a_{bound} = c\beta\sigma - \mu\)；饱和放置采集 \(a_{sat} = \beta\sigma + \beta\sigma P(1-P) + wP\)。

**（3）算法流程（Algorithm 1）**

1. 用已有数据拟合全局代理模型 \(h_g\)；
2. 用保留集训练残差模型并校准 \(\tilde{h}_g\)；
3. 分别选择边界与饱和信赖域中心；
4. 在每个信赖域内局部采样（Algorithm 2，含局部 LOO-CV 校准）；
5. 将新样本加入数据集并重复，直至耗尽查询预算。

**（4）图像实验的潜在空间搜索**

- 在固定类条件生成器（DCGAN / BIGGAN）的潜在空间中搜索，采用 Carlini & Wagner 的负化目标函数 \(O(x';t) = \hat{Z}_t(x') - \max_{i\neq t}\hat{Z}_i(x')\)，使成功攻击对应非负超水平集。

## 六、主要结论与发现

1. **区域恢复优势**：在相同或更小预算下，ATLAS 在 9/9 玩具实验中取得最佳召回率，8/9 取得最佳 F1，单位预算发现最多对抗点（8/9）。
2. **校准至关重要**：在 100D 下，加入仅 50 个校准样本即可将 Rastrigin 的 F1 从 0.003 恢复到 0.288，Rosenbrock 从 0.100 恢复到 0.457；但过度分配校准预算（58%）会显著降低性能。
3. **双采样机制缺一不可**：仅边界采样空间分散度好但几乎找不到对抗点（Rastrigin 100D）；仅饱和采样能大量收集对抗点但在 Rastrigin/Rosenbrock 上 F1 崩溃至约 0.01；只有 1:1 混合在所有地形上稳健。
4. **图像实验表现**：ATLAS 在 5 个目标中的 4 个取得最佳 Margin J，兼具良好的空间分散度和间距；ASR 具有竞争力（MNIST 95%、CIFAR-10 对抗 100%、ImageNet 对抗 100%）。
5. **对抗训练未消除失败区域**：在所有对抗训练模型上，ATLAS 均能恢复非空对抗集。
6. **可解释的失败模式**：生成的对抗集揭示模型关注的视觉线索——例如"黄貂鱼→大白鲨"中模型关注海洋环境而非鲨鱼特征；"金鱼"目标中模型将花瓣、羽毛等结构当作鱼鳍替代物。
7. **安全审计价值**：按 NIST AI RMF 和 MITRE ATLAS 框架，ATLAS 可作为 MAP–MEASURE–MANAGE–GOVERN 流程中的自动化红队工具。

## 七、优点

- **问题表述创新**：将对抗生成从"优化单个攻击"重新表述为"区域水平集恢复"，更贴合安全审计的实际需求。
- **校准策略巧妙**：直接校准模型预测而非采集函数，一次残差校正可复用至所有采集函数，且全局/局部采用不同校准方案（保留集 vs LOO-CV），兼顾精度与预算效率。
- **双采样设计合理**：边界采样负责探索、饱和采样负责利用，二者互补，消融实验清晰验证了各自的作用与必要性。
- **实验设计严谨**：
  - 玩具实验提供已知真值水平集，便于量化评估；
  - 覆盖 10D–100D、多个非凸地形、标准与对抗训练模型；
  - 指标设计多维（模型估计 + 集合质量），并引入 Margin J、Spacing 等补充 Spread 的偏差；

  - 明确承认 Spread 指标的边界偏差，并给出解释。
- **审计视角完整**：结合 NIST AI RMF 和 MITRE ATLAS 给出结构化的安全审计总结，具有实际应用指导意义。
- **伦理意识**：主动讨论双用途风险及缓解措施（限制查询访问、分析算法局限）。

## 八、不足与局限

- **性能方差**：论文自述"不同函数地形之间仍存在性能差异"，在 Rastrigin 100D 默认权重下 F1 降至 0.066，鲁棒性并非在所有设置下都理想。
