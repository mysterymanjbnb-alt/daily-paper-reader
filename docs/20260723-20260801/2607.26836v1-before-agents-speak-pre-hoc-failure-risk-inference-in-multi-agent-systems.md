## 摘要
基于大型语言模型的多智能体系统（MAS）在协作推理和决策方面展现出显著能力，但其互联通信引入了新的系统性风险：局部幻觉可能沿智能体通信链传播，通过交互放大，并最终引发级联失败。现有对策主要遵循事后范式，仅在出现不安全行为后识别失败，而此时有害影响可能已在整个智能体网络中扩散。为解决此问题，我们探索了一种互补的事前方法，并提出了HalluProp，一种传播感知的幻觉推断框架，可在智能体间交互之前估计个体智能体失败和涌现的系统级幻觉风险。首先，我们通过识别智能体角色与任务查询之间的细粒度语义错位来建模内在幻觉风险。然后，我们通过建模语义影响和通信拓扑来刻画智能体间风险传播。最后，我们通过可微的Noisy-OR推断机制整合这两种风险，得出系统性诊断。大量实验表明，HalluProp能准确定位故障智能体，平均AUROC达84.6%，同时实现亚秒级诊断，比事后方法快65倍以上。通过上游筛选促进早期干预，HalluProp有效补充了事后方法，凸显了事前风险推断在构建更可靠多智能体系统方面的潜力。

## Abstract
LLM-based multi-agent systems (MAS) have exhibited remarkable capabilities in collaborative reasoning and decision-making, yet their interconnected communications introduce new systemic risk: localized hallucinations can propagate along agent communication chain, amplify through interactions, and ultimately trigger cascading failures. Existing countermeasures predominantly follow a post-hoc paradigm, identifying failures only after unsafe behaviors emerge, by which time harmful effects may have already spread throughout the agent network. To tackle this problem, we investigate a complementary pre-hoc approach and propose HalluProp, a Propagation-aware Hallucination inference framework that estimates individual agent failures and emergent system-level hallucination risks before inter-agent interaction. First, we model intrinsic hallucination risks by identifying fine-grained semantic misalignment between agent roles and task queries. We then characterize inter-agent risk propagation by modeling both semantic influence and communication topology. Finally, we integrate these two risks via a differentiable Noisy-OR inference mechanism to derive a systemic diagnosis. Extensive experiments show that HalluProp accurately localizes faulty agents, achieving an average AUROC of 84.6%, while enabling sub-second diagnosis with over $65\times$ speedup over post-hoc methods. By facilitating early intervention through upstream screening, HalluProp effectively complements post-hoc methods, highlighting the potential of pre-hoc risk inference for building more reliable multi-agent systems.

## 2. 论文提出的方法论

**核心思想：**

HalluProp将多智能体系统中的幻觉风险分解为两个互补来源，并在系统层面进行整合推断：

1. **个体内在风险（Intrinsic Risk）**——由智能体自身的角色设定与用户查询之间的语义错位决定；
2. **交互传播风险（Propagation Risk）**——由智能体间的语义影响力和通信拓扑结构共同决定。

**总体框架：三阶段流水线架构**

**（一）智能体内在风险建模（Intra-Agent Intrinsic Risk Modeling）**

*目的：* 估计每个智能体在交互发生前的内生幻觉倾向。

*关键技术步骤：*

- **角色-查询语义编码**：使用预训练文本编码器 `Enc(·)` 将角色提示词 `p_i` 和用户查询 `q` 嵌入到共享语义空间，得到 `e_R^i` 和 `e_Q`。
- **查询条件门控（Query-Conditioned Gating）**：通过逐元素乘积 `e_R^i ⊙ e_Q` 编码维度级语义对齐，再用sigmoid门控 `g_i` 自适应地筛选出与当前任务相关的角色特征维度，抑制无关成分。
- **能力-易感性分解（Competence-Susceptibility Decomposition）**：
  - 能力向量 `κ_i = e_R^i ⊙ g_i`：表示与查询对齐的、指示任务相关能力的角色特征；直觉上则是"这个智能体有多适合该任务"。
  - 易感性向量 `ρ_i = LayerNorm(e_R^i − κ_i)`：聚合与查询弱相关、冲突或潜在风险的角色残余特征；反映智能体在该任务上的"易幻觉倾向"。
- **内在风险输出**：`π_i = σ(w_ρ^⊤ ρ_i − w_κ^⊤ κ_i + b_π)`——能力越强、易感性越弱，内在风险越低。

该模块的亮点在于：传统的整体语义相似度无法捕捉角色提示词中模糊、误导或对抗性设计的细粒度风险，而维度级门控+双子空间分解提供了更精细、更可解释的风险估计。

**（二）智能体间传播风险建模（Inter-Agent Propagation Risk Modeling）**

*目的：* 估计沿每条有向通信边 `v_j → v_i` 的幻觉传播概率 `t_{j→i}`。

*两个互补因素：*

- **角色语义因素**：`ℓ^sem_{j→i} = κ_j^⊤ W_sem ρ_i`——发送者的任务对齐能力（κ_j）与接收者的易感性（ρ_i）之间的语义交互决定了传播的"感染"效率。
- **拓扑效应**：`γ_{j,i} = ϕ(ˆk_out(j), ˆk_in(i))`——用节点度的归一化特征经MLP映射到 `[1, ∞)`，捕捉发送者的广播能力与接收者的聚合能力对风险传播的放大效应。
- **传播风险输出**：`t_{j→i} = σ(γ_{j,i} · ℓ^sem_{j→i} + b_t)`，并且如果 `(v_j → v_i) ∉ E` 则强制 `t_{j→i} = 0`，保证结构有效性。

**（三）系统级风险推断（System-Level Risk Inference）**

*核心机制：可微Noisy-OR聚合*

- 核心逻辑：智能体 `v_i` 保持不幻觉当且仅当它既不在内在上产生幻觉，也未受到任何上游智能体的"感染"。
- 数学表达：`h_i = 1 − (1 − π_i) ∏_{j∈N_in(i)} (1 − t_{j→i} h_j)`
- **不动点迭代**：由于通信图可能含有环，闭式解不可行，采用K步定点迭代：初始化 `h^(0) = π`，逐步更新 `h^(k+1)` 以纳入高阶扩散效应。整个迭代过程对 π 和 T 均可微，支持端到端训练。
- **理论保证**（附录中给出）：
  - **因果独立性**：Noisy-OR基于因果独立性假设，将最终风险分解为"内在安全"与"传播安全"的联合补。
  - **收敛保证**：由单调收敛定理，更新算子在单位超立方体内有界且单调非递减，从下界 `h^(0)=π` 出发必收敛到稳定不动点；且 `t_{j→i}∈(0,1)` 充当衰减因子保证快速收敛。
  - **梯度性质**：梯度公式显示自动信用分配机制（类似贝叶斯网络中的"explaining away"效应），当某一主导来源已高度解释节点失败时，其他边的梯度被自动抑制，使优化聚焦于主要幻觉源。

**两阶段训练流程：**

- **阶段一**：固定文本编码器，训练内在风险模块，用节点级标签 `y_node` 进行二元交叉熵监督：`L_s1 = BCE(π, y_node)`。
- **阶段二**：从阶段一初始化，优化传播模块，用图级标签 `y_graph` 监督系统级风险 `h^(K)`：`L_s2 = BCE(h^(K), y_graph) + λ_anc L_s1`，其中锚定项保留内在风险估计，使传播矩阵专注捕获交互新增风险。

## 6. 论文的主要结论与发现

1. **精准识别与定位**：HalluProp在预测智能体幻觉风险上平均AUROC达**84.6%**；Hit@1在多数配置下超过80%，Recall@3平均达76.2%，展现了可靠的风险定位能力；在闭源（GPT系列）和开源（Llama、Qwen）模型上性能表现一致。

2. **干预有效性**：
   - **Pruning策略**的平均准确率63.6%，与最强基线GUARDIAN（63.5%）基本持平——关键区别是HalluProp在交互前就完成了风险推断。
   - **Refinement策略**平均准确率达67.6%，优于所有事后基线，说明保留节点但改变其角色行为比直接剪枝更有效（避免信息流中断、保留协作多样性）。

3. **极致效率**：亚秒级诊断时间，相比事后方法实现**超65倍加速**，可作为实时轻量级防火墙。

4. **出色的鲁棒性**：
   - 规模变化（N=3~7）下AUROC波动极小（MMLU/MATH维持在85%~90%，MedQA在75%~80%）。
   - 不同拓扑结构（随机、星型、链型、层级）下性能差异小于2%，说明学到的是通用传播模式而非特定拓扑过拟合。

5. **消融确认了各模块的必要性**：
   - 去除内在风险建模 → AUROC下降**27.8%**（从84.8降至61.2）。
   - 去除拓扑特征 → 下降**15.0%**（降至72.1）。
   - 去除传播模块 → 下降**21.1%**（降至66.9）。
   - 迭代深度K=3即达到性能平台（84.6%），过深无额外收益。
   - 对文本编码器选择不敏感（AUROC在80.7%~85.1%之间），说明方法有效性来自下游组件而非特定表示骨干。

## 7. 优点

1. **范式创新**：首次系统性地提出MAS中的**事前（pre-hoc）幻觉风险推断**，将安全检测从"事后响应"前移到"事前预防"，填补了该方向的研究空白，开辟了新研究路径。
2. **方法论优雅性**：从风险形成机理出发，将MAS幻觉分解为内在风险（智能体-查询错位）与传播风险（语义影响+通信结构）两个可解释性强的维度，而非简单的黑箱预测。
3. **Noisy-OR机制设计精妙**：既有概率图模型的因果解释力，又完全可微支持端到端训练；不动点迭代有严格收敛保证；梯度自动信用分配机制（explaining away效应）有助于精确定位主要风险源。
4. **实用性导向**：不只是提出检测框架，还展示了两种不同的干预策略（结构剪枝与行为精炼），并通过实验证明行为精炼优于结构剪枝——这个发现对MAS安全设计具有实际指导价值。
5. **实验设计较全面**：覆盖多骨干模型、多数据集、多拓扑、多规模的组合评估，并有充分的消融分析验证每个组件的贡献。
6. **计算开销极低**：仅基于静态配置分析和轻量级语义编码，无需生成任何token或执行交互，使其成为实际可部署的上游筛选工具。

## 8. 不足与局限

**实验层面的局限：**

- **基准范围有限**：仅使用选择题/问答类基准（MMLU、MATH、MedQA），未覆盖开放式生成、多轮复杂对话等更接近真实MAS应用的场景。
- **MAS规模偏小**：最大测试规模为7个智能体；真实生产环境中的MAS可能包含数十甚至上百个智能体，级联效应和计算复杂度可能呈现质变。
- **数据集抽样量有限**：每个数据集仅500题，且未提供多次运行的标准差或置信区间，统计显著性证据不足。
- **拓扑类型覆盖不全**：虽然测试了星型、链型、层级等规范拓扑，但真实MAS往往采用混合或动态演化拓扑，论文未评估拓扑动态变化场景下的适应性。
- **未报告训练数据规模**：角色构造方式虽较细致，但没有说明训练样本总量和分布，无法评估训练数据偏差对模型的影响。

**方法本身的局限：**

- **静态预分析假设**：HalluProp基于交互前的静态配置（角色、查询、拓扑）进行推断，难以捕捉交互过程中动态涌现的风险（如上下文漂移、多轮累积误导），因此论文将其定位为事后方法的**补充**而非替代。
- **条件独立性假设**：Noisy-OR的因果独立性假设在真实MAS中可能不完全成立，智能体之间可能存在复杂高阶相关性。
- **对角色提示词的依赖**：方法的前提是角色描述与查询之间存在可提取的语义错位信号；如果角色描述极其简略或与查询完全不相关（极端情况），语义编码可能难以提供判别性信息。
- **未验证安全关键领域**：论文提到高风险场景（医疗、法律等），但MedQA仅覆盖医学，且是选择题格式，与真实医疗诊断、法律推理等复杂开放任务仍有差距。

**未知成分：**

- 训练细节（学习率、批大小、训练轮数、收敛曲线）未在文中交代。
- 论文声称性能与GUARDIAN相当或在干预后更优，但这些方法的超参数是否经过同等程度的调优尚不明确，公平性问题留有悬念。
- 附录的理论分析证明了收敛性，但未提供实际收敛速度的定量分析。

## 总结定位

HalluProp是一项**方法新颖、动机明确、验证较充分**的研究工作，其最大贡献在于开辟了MAS幻觉治理的"事前"维度，用轻量级、可微、可解释的风险推断框架为多智能体系统的安全设计提供了新的工具和思路。虽然实验规模与覆盖面仍有提升空间，但作为该方向的先导性工作，其理论框架的严谨性和实践应用的双重导向使之具有较高的学术价值与工程参考意义。
