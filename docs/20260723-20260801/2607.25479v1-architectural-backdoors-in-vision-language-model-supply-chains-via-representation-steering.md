## 摘要
视觉-语言模型（VLM）越来越多地通过模型供应链进行部署，其中预训练检查点、架构定义、文本编码器和导出计算图由第三方分发并在下游服务中重用。这种重用模型创建了一个安全关键的信任边界：VLM部署不仅继承了学习参数，还继承了共享模型工件中编码的可执行行为。在本文中，我们展示了恶意提供者可以通过表示引导将架构后门嵌入VLM供应链，从而利用这一信任边界。我们的攻击通过中间表示的触发器门控加法修改将休眠引导逻辑引入模型架构，而无需污染训练数据、控制下游微调或在部署时修改提示。当触发器不存在时，修改归零，模型遵循正常计算，保持干净效用。当触发器存在时，引导方向将内部表示转向攻击者定义的目标。我们在多个VLM家族和下游任务上评估了该攻击，包括视觉问答、文本到图像生成、检索和语义响应偏向。结果表明，所提出的架构引导后门损害了完整性、安全执行和排名公平性，同时在干净输入上保持正常行为。我们进一步表明，共享VLM工件可以携带针对下游服务的休眠引导逻辑，并建议一种审计防御，检查随模型工件分发的可执行逻辑，而不仅仅是学习权重。

## Abstract
Vision--Language Models (VLMs) are increasingly deployed through a model supply chain in which pretrained checkpoints, architecture definitions, text encoders, and exported computation graphs are distributed by third parties and reused across downstream services. This reuse model creates a security-critical trust boundary: VLM deployments inherit not only learned parameters but also executable behavior encoded in shared model artifacts. In this paper, we show that a malicious provider can exploit this trust boundary by embedding architectural backdoors into VLM supply chains through representation steering. Our attack introduces dormant steering logic into the model architecture through a trigger-gated additive modification of an intermediate representation, without poisoning training data, controlling downstream fine-tuning, or modifying prompts at deployment time. When the trigger is absent, the modification reduces to zero and the model follows its normal computation, preserving clean utility. When the trigger is present, a steering direction shifts the internal representation toward an attacker-defined objective. We evaluate the attack across multiple VLM families and downstream tasks, including visual question answering, text-to-image generation, retrieval, and semantic response biasing. The results show that the proposed architectural steering backdoor compromises integrity, safety enforcement, and ranking fairness while preserving normal behavior on clean inputs. We further show that shared VLM artifacts can carry dormant steering logic against downstream services, and we propose an auditing defense that inspects the executable logic distributed with model artifacts rather than only their learned weights.

- **核心问题**：现有后门攻击（数据投毒、权重篡改）通常假设攻击者能控制训练流程，对现代 VLM 而言往往不现实；而此前关于**架构后门**的研究主要局限于单模态分类场景（如标签翻转），尚未系统研究多模态系统中共享组件被植入恶意可执行逻辑的威胁。
- **整体含义**：本文证明，一个恶意提供者可以在发布前将**触发门控的表示引导（representation steering）**逻辑嵌入 VLM 架构定义中，形成"休眠"的架构后门——干净输入下模型行为完全正常，仅当特定文本触发器出现时才激活，从而破坏下游服务的完整性、安全执行和排名公平性。该工作将 VLM 供应链视为一种新的架构后门攻击面，并呼吁防御方审计**可执行逻辑**而非仅检查权重。

## 二、方法论

### 1. 威胁模型

- 攻击者作为**恶意模型提供者**或供应链参与者，在公开发布前篡改模型架构/计算图。
- 攻击者**不需要**：访问下游用户数据、控制微调过程、访问部署基础设施、修改运行时提示。
- 触发器为攻击者预定义的文本 token（如"image"、西里尔字母"о"等视觉混淆字符），仅攻击者知晓。
- 防御者为下游用户，依赖标准 benchmark、任务指标和常规代码审查。

### 2. 攻击核心思想：触发门控的加性表示转向

- 将模型前向计算分解为 `M(x) = h_L ∘ h_{L-1} ∘ … ∘ h_1(x)`，其中 `ϕ_i(x)` 为第 i 层后的中间表示。
- 攻击者在第 i 层插入一个门控加性载荷：

  **`ϕ̃_i(x) = ϕ_i(x) + s · T(x)`**

  - `T(x) ∈ {0,1}`：触发检测函数；
  - `s`：预先计算好的转向向量（作为模型权重中的偏置保存）；
  - 当 `T(x)=0` 时，修改恒为零，模型与原始架构行为完全一致，保持干净效用；当 `T(x)=1` 时，表示被沿 s 方向偏移，推动模型输出攻击者目标行为。

### 3. 转向向量 s 的构造

- 攻击者离线构造两个小规模提示集：良性集 B（不含目标概念）和攻击目标集 A（显式包含目标概念，如裸体、暴力、品牌词等）。
- 用均值差定义转向方向：`s = λ(μ_A − μ_B)`，其中 `μ_A`、`μ_B` 分别为两组提示在目标层 i 的平均表示。
- 与 Arditi et al. [41] 的投影式转向不同，本文采用**加法式**转向，保留正交特征（如场景构图、风格），避免生成图像结构被破坏。
- **多模态适配**：对 LLaVA/Qwen3-VL 等 VLM，每个提示（A 和 B）均配同一张固定的中性图像来提取表示，使模型处于多模态处理通路，避免纯文本转向向量编码"缺失图像 token"的伪影。实验表明多模态转向向量显著优于单模态版本（如 LLaVA 在 FineVision 上 ASR 从 64.8% 提升到 98.7%）。

### 4. 触发检测函数的隐蔽实现

- 为避免 `if` 语句等显式条件逻辑被人工审查发现，检测器完全由标准可微算子实现：

  **`T(x) = max(σ(100 · (0.5 − |z − τ|)))`**

  其中 z 为 token ID 序列，τ 为触发器 token ID，σ 为 sigmoid。利用 token ID 的离散性：精确匹配时 σ(50)≈1，任何非匹配 token 使 |z−τ|≥1，σ(−50)≈0。由于该检测器无可学习参数，普通微调不会改变其行为。

### 5. 分发渠道

- **Hugging Face Hub**：修改模型定义文件，配合 `trust_remote_code=True` 自动执行自定义建模代码（该 flag 是许多合法自定义架构的标准用法，用户难以区分）；代码改动约 1–1.5%，转向向量注册为 PyTorch buffer（非可训练参数），可逃避 Netron/torchviz 等工具的可训练参数检查。
- **GitHub/包管理器**：将恶意架构定义伪装成"优化版 VLM fork"或依赖包，通过 `pip install git+...` 写入本地 Python 路径，后续模型实例化自动解析到攻击者控制的类定义。

## 六、主要结论与发现

1. **攻击高度有效**：VQA 三场景中 ASR 普遍接近或达到 100%（如 Qwen3-VL 拒绝诱导双数据集 100%，混淆与品牌幻觉均近 100%），而干净输入下模型效用与基线完全一致，证明后门保持休眠。
2. **T2I 中文本编码器越强，转向效果越大**：SD 2.1（仅 CLIP）偏移 +18.9~+78.8pp；SD 3.5 和 FLUX-1（含 T5）可达 +46~+100pp，FLUX-1 的裸体检测率在多个数据集上提升超过 +85pp。
3. **检索操纵存在最优注入点权衡**：BLIP 第 6 层注入、λ=5 时可在显著改变性别排名组成（T@1 从 15.2% 升至 65.1%）的同时保留非平凡检索质量；晚期层注入虽使 T@1 趋近饱和（94–100%），但检索质量崩溃。
4. **人工审查不可靠**：14 名 ML 从业者在不知情阶段无人发现后门，甚至多数偏好后门版本；告知可能存在后门后仅 1 人识别出 Qwen3-VL 中的机制，BLIP 后门无人识别。
5. **运行时审计可检测**：基于隐藏状态轨迹余弦相似度的 Isolation Forest 检测器在 Qwen3-VL 拒绝场景达 100% 检出率（FPR 2.6%），在 BLIP 检索场景达 92.4%（FPR 9.93%）；输入级归因可高概率定位触发器 token（99.8% / 94.0%）。
6. **核心结论**：VLM 工件可携带攻击者控制的休眠可执行逻辑，在触发时劫持安全关键行为；防御必须审计架构逻辑与隐藏状态轨迹，而非仅检查学习权重和干净任务表现。

## 七、优点

- **攻击面新颖**：首次将架构后门从单模态分类扩展到 VLM 多模态系统，且攻击假设切合实际——不需要控制训练数据、微调或部署提示，仅需在发布前修改架构定义。
- **隐蔽性好**：触发检测器完全由标准可微算子构成，无可学习参数，注册为 buffer 而非可训练参数；代码改动极小（<1.5%），并经过用户研究实证验证了隐蔽性。
- **方法简洁通用**：加法式表示转向（区别于投影式）兼顾攻击效力与生成质量保持，且在 5+ 种模型家族上表现出跨架构、跨任务、跨模态的泛化能力。
- **防御配套完整**：不仅提出攻击，还设计了基于隐藏状态轨迹的 Isolation Forest 检测器 + 输入级归因，形成了"检测—定位—去除"的可操作审计链路。
- **实验设计细致**：对多模态转向必要性、层选择、λ 校准、注入点权衡等关键设计维度均做了系统消融，并对单模态 vs 多模态向量做了定量比较。

- **防御的适应性局限**：检测器针对"单层注入、可测轨迹偏移"的变体校准；作者承认自适应攻击者可通过多层分散注入、减小逐层干预幅度或优化载荷以保持层间相似性来规避检测。
