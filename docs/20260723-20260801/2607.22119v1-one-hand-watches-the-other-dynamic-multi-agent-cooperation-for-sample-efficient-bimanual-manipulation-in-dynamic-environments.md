## 摘要
多流机器人操作策略通过相对于环境参考系建模动作，实现了无与伦比的样本效率和泛化能力。然而，现有方法通常假设这些参考系是严格外生的。这种因果假设在动态环境中会失效，例如当单个机器人手臂操作移动物体或双臂协调时，每只手臂实际上都成为对方动态环境的一部分。我们提出了DynaMAC，一个轻量级、策略无关的框架，在保留多流策略的样本效率、计算速度和灵活性的同时，解决了这一因果限制。DynaMAC将对手臂视为动态任务参数，从而为动态操作和双臂协调提供了统一的公式，无需显式的领导者-跟随者关系。为了严格评估这些能力，我们引入了DynaBench，一个用于动态环境中机器人操作的新基准。在动态环境和双臂操作任务中，DynaMAC比领先的概率和生成式基线高出超过35个百分点，同时所需样本减少20倍。关键在于，DynaMAC可以从静态演示零样本泛化到动态环境，大幅简化数据收集，并为迈向人机协作建立了优雅的桥梁。

## Abstract
Multi-stream robot manipulation policies achieve unparalleled sample efficiency and generalization by modeling actions relative to environmental reference frames. However, existing approaches typically assume these frames to be strictly exogenous. This causal assumption collapses in dynamic settings, such as when a single robot arm manipulates a moving object or when two arms coordinate, where each arm effectively becomes part of the dynamic environment of the other. We propose DynaMAC, a lightweight, policy-agnostic framework that resolves this causal limitation while preserving the sample efficiency, computational speed, and flexibility of multi-stream policies, DynaMAC treats the opposite arm as a dynamic task parameter, thereby providing a unified formulation for dynamic manipulation and bimanual coordination without requiring an explicit leader-follower relationship. To rigorously evaluate these capabilities, we introduce DynaBench, a novel benchmark for robot manipulation in dynamic environments. Across both dynamic environments and bimanual manipulation tasks, DynaMAC outperforms leading probabilistic and generative baselines by over 35 percentage points while requiring 20 times fewer samples. Crucially, DynaMAC generalizes zero-shot from static demonstrations to dynamic environments, substantially simplifying data collection and establishing an elegant bridge toward human-robot collaboration.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究动机**：多流（multi-stream）策略学习通过将动作建模到目标物体等环境参考系中，取得了优异的样本效率与泛化能力。但该类方法有一个隐含的因果假设——参考系必须是**严格外生的（exogenous）**，即参考系的位姿由环境决定、与机器人自身的动作无关。
- **核心问题**：这一因果假设在以下三类问题中崩溃：
  - **动态环境**：如从运动中的传送带上抓取工件，物体一旦被抓取，从"外生参考系"变为"与机械臂刚性耦合"，继续将其视作独立任务参数会导致策略崩溃。
  - **多智能体协作**：另一智能体（或另一只手臂）的动作会持续改变相关的任务参考系，例如物体交接时。
  - **双臂操作**：大部分多流策略仅面向单臂操作，而开瓶、搬运大物体等任务需要双臂协调，且两只手臂互为对方的动态环境。
- **整体含义**：论文提出 **DynaMAC**，一个轻量级、策略无关的框架，统一解决动态环境操作、多智能体协作和双臂协调问题；并提出 **DynaBench** 基准用于系统评估。其核心优势在于：仅从静态演示训练的策略可以**零样本泛化**到动态环境中，极大简化了动态场景下的数据采集过程，并为未来人机协作铺平道路。

### 2. 方法论：核心思想、技术细节与算法流程

**核心思想**：DynaMAC 通过从策略流（policy streams）中推断机器人-物体间的**运动学链接（kinematic link）**，动态过滤掉那些因被机械臂抓取而不再"外生"的任务参考系，并引入**虚拟末端执行器参考系**补充空间参照，从而恢复多流策略的因果假设。对于双臂操作，DynaMAC 将对方的末端执行器直接作为**动态任务参数**，把双臂协调简化为两个并行的动态多流学习实例，**无需显式指定领导者-跟随者关系**。

**关键技术细节**：

- **多流策略基础**：将末端执行器位姿转换到每个参考系 f 的局部坐标系中，学习独立的"流"模型，最后通过**专家乘积（product-of-experts）融合**为联合策略。公式上，局部位姿为：
  \[
  \xi_{ee}^{(f)} = [q_f^{-1}(x_{ee}-x_f)q_f,\; q_f^{-1}q_{ee}]^T
  \]
  融合时，各流按**精度（precision）加权**，即协方差越小、权重越大。
- **运动学链接检测**：当机械臂抓取物体后，该物体对应流的方差骤降、精度飙升。DynaMAC 使用几何平均标准差作为判据：
  \[
  M_t^{(f)} = |\det(\Lambda_t^{(f)})|^{-\frac{1}{2d}}
  \]
  当 \(M_t^{(f)} < \tau_M\) 时判定存在运动学链接，将该参考系从候选集中移除，防止因果方向反转导致的策略崩溃。
- **虚拟帧补充**：在移除动态物体帧后，记录每个技能片段（skill）开始时末端执行器的位姿作为**静态虚拟帧**（如 eeGrasp、eePlace），提供空间记忆，驱动抓取后行为。
- **任务参数选择**：借鉴 TAPAS 方法，按相对精度选择每个技能的最佳任务参数。论文还从**信息论视角**给出了理论连接：条件熵 \(H(\xi_{ee}|f)\) 正比于 \(\log\det(\Sigma_t^{(f)})\)，互信息 \(I(\xi_{ee}; f)\) 与 \(-\log\det(\Sigma_t^{(f)})\) 成正比，将技能选择、运动学链接检测统一到互信息最大化的框架。
- **算法流程（Algorithm 1）**：
  1. 用 TAPAS 将长时程任务分割为多个技能片段；
  2. 每个技能内，用式(5)检测运动学链接，移除被机器人操纵的物体帧；
  3. 在技能边界记录末端执行器位姿，添加为虚拟帧；
  4. 用 TAPAS 的相对精度准则筛选最佳任务参数；
  5. 将各技能策略顺序串联，执行完整长时程任务。
- **双臂协调实现**：对左右臂分别运行一次动态多流学习。左臂的候选参考系中加入"右端执行器位姿"（反之亦然），使手臂之间形成动态的空间参照关系。两者是否收敛、谁主导协调，均由数据中涌现，而非人工预设。

### 6. 主要结论与发现

1. **DynaMAC 在静态环境下不损失性能**，与现有最好的多流策略 MiDiGaP 持平（单臂平均成功率 1.00 vs 0.99，双臂均为 0.95）。
2. **在动态环境下，基线模型全面失效**。MiDiGaP 和 TAPAS-GMM 在动态条件下成功率几乎为 0（因果崩溃），Diffusion Policy 有一定鲁棒性但样本效率差（100 个演示）。
3. **DynaMAC 实现零样本动态泛化**：仅用 5 个静态演示训练，即可在平滑动态和瞬移（teleportation）条件下保持约 94% 的平均成功率，比 Diffusion Policy 高 35 个百分点以上、样本效率高 20 倍。
4. **双臂协调无需显式主从关系**：DynaMAC 将对手臂作为动态任务参数，可以自然处理对称/非对称协作、交接等任务，并在扰动一条手臂时动态重新协调。
5. **真实机器人验证**：在真实 Franka 机器人上重复了仿真结果，并初步验证了**人机交接的零样本泛化能力**（将机器人臂替换为人类手臂）。
6. **感知局限**：视觉跟踪（尤其是遮挡下）是当前主要的失败来源。

### 7. 优点

- **统一性**：用单一框架统一处理动态环境、多智能体协作和双臂操作，省去了显式领导者-跟随者关系的设计，角色可以在任务中动态涌现。
- **因果意识**：从因果视角切入多流策略的核心缺陷，运动学链接检测为问题提供了理论依据，信息论的联系提升了方法论的可解释性。
- **零样本动态泛化**：静态演示训练 → 动态环境零样本迁移，大幅降低动态数据采集成本。
- **策略无关、轻量**：DynaMAC 可叠加在任意多流策略（GMM、GP、Flow Matching 等）之上，不改变底层策略的优势（样本效率、推理速度、可控性）。
- **基准设计合理**：DynaBench 的"两个静态配置间插值"方案在保证可达性的同时最大化实例多样性，且与 RLBench 生态兼容。
- **实验覆盖全面**：仿真 + 真实、单臂 + 双臂、静态 + 动态、平滑 + 瞬移、物体扰动 + 手臂扰动，还有真实人机交接测试。

### 8. 不足与局限

- **继承的多流策略固有局限**：依赖技能自动分割（TAPAS），分割质量直接影响整体性能；依赖外部视觉编码器，感知错误会直接导致任务失败。
- **动态泛化范围有限**：论文中的动态环境主要是物体位姿的平滑移动或突然瞬移，未涉及更复杂的物体动力学（如碰撞反弹、流体运动、可变形物体等），论文也承认未来可与 DOMINO 基准的动态模型结合。
- **消融实验不够详细**：正文仅文字描述，无消融表数据，难以独立评估各组件（运动学链接检测、虚拟帧、任务参数选择）的相对贡献大小。
- **统计严谨性不足**：未报告多次运行的标准差、置信区间或统计显著性检验；真实实验样本量较小（每条件 25 episodes）。
- **算力信息缺失**：未报告 GPU 型号、数量、训练时长等，限制了复现的可参考性。
- **人机协作验证初步**：真实人机交接实验依赖特定相机视角、物体可见性较差时即失败，泛化范围有限。
