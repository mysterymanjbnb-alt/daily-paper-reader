## 摘要
记忆增强的基于大语言模型的智能体容易受到记忆注入攻击：智能体可能从攻击者处检索到有毒记忆，从而偏离初始用户意图并最终导致任务失败。然而，现有防御机制要么计算成本高昂，要么在多轮上下文中存在信息冗余问题。为解决这些挑战，我们提出了记忆意图感知神经去噪（MIND），一种用于记忆注入攻击的轻量级防御框架。我们的初步分析表明，良性轨迹和有毒轨迹在初始用户意图与后续行为之间展现出可区分的关系。基于这一观察，MIND采用意图感知信息瓶颈（IB）从初始意图和回合级行为中提取紧凑的意图-行为表示。IB在保留与意图相关的跨回合攻击信号的同时，过滤与任务无关和重复的信息，轻量级检测器从所得表示中识别恶意记忆。因此，MIND缓解了多轮上下文中的信息冗余，同时避免了重复LLM审计的开销。大量实验表明，MIND在保持任务准确性和推理效率的同时降低了攻击成功率。值得注意的是，在ReAct-StrategyQA上，MIND将平均ASR-r和ASR-a分别降低了55.4%和55.3%，同时在平均准确率和延迟上与未防御的智能体相当。

## Abstract
Memory-augmented LLM-based agents are vulnerable to memory injection attacks: Agents may retrieve poisoned memory from attackers, which diverts their behavior from initial user intent and finally causes task failure. However, existing defense mechanisms either incur high computational cost or suffer from information redundancy in multi-turn contexts. To address these challenges, we propose Memory Intent-Aware Neural Denoising(MIND), a lightweight defense framework for memory injection attack. Our preliminary analysis reveals that benign and poisoned trajectories exhibit distinguishable relationships between the initial user intent and subsequent behavior. Building on this observation, MIND employs an intent-aware Information Bottleneck(IB) to extract compact intent--behavior representations from the initial intent and turn-level behavior. The IB preserves intent-relevant cross-turn attack signals while filtering task-irrelevant and repetitive information, and a lightweight detector identifies malicious memories from the resulting representations. As such, MIND mitigates information redundancy in multi-turn contexts while avoiding the overhead of repeated LLM auditing. Extensive experiments show that MIND reduces attack success rates while preserving task accuracy and inference efficiency. Notably, on ReAct-StrategyQA, MIND reduces mean ASR-r and ASR-a by 55.4% and 55.3%, respectively, while matching the undefended agent in average accuracy and latency.

## 论文详细中文总结

MIND：基于意图感知信息瓶颈的轻量级高效大语言模型智能体记忆注入防御

### 1. 核心问题与整体含义

- **研究背景**：记忆增强的 LLM 智能体（如软件工程、深度研究、科学发现等长程任务）依赖外部检索式记忆系统持久化存储和复用过去的交互记录。然而，这使得智能体面临严重的**记忆注入攻击（Memory Injection）** 风险：攻击者可利用直接注入（如 AgentPoison）或仅通过普通查询的间接注入（如 MINJA）向记忆库植入恶意记录，一旦被检索，就会使智能体的行为逐步偏离初始用户意图，导致任务失败甚至产生有害输出。
- **现有防御的不足**：
  - **计算成本高**：基于 LLM 推理审计的防御（如 A-MemGuard、LLM Auditor）需反复调用 LLM 审计检索到的记忆或监控交互流，在多轮长轨迹中开销严重累积。
  - **多轮上下文信息冗余**：基于轻量检测器的防御虽降低计算成本，但在编码完整交互轨迹时，大量任务无关和重复信息会掩盖攻击信号，削弱防御效果。
- **论文要解决的问题**：如何设计一种**轻量且有效**的记忆注入防御方法，在避免反复 LLM 审计的高开销的同时，从冗余的多轮轨迹中有效识别恶意记忆。

### 2. 方法论

- **核心思想**：基于两个关键观察构建防御——(1) 良性轨迹与受毒轨迹在表示空间中呈现出可区分的"初始意图-后续行为"关系；(2) 智能体对初始意图的注意力随轮次增加而衰减，且受毒记忆下衰减更快。由此将防御问题转化为**去噪问题**：提取初始意图与逐轮行为之间的紧凑表示，过滤无关冗余，保留攻击信号。
- **方法流程**（MIND = Memory Intent-Aware Neural Denoising）：
  1. **轨迹表示提取**：使用预训练 LLM（默认 Llama-3.1-8B-Instruct）提取每回合最后 token 的隐藏状态作为回合金发表示 $h_t$，初始用户查询表示作为 $h_0$，构建训练集 $D = \{(x_i, x_i^{anchor}, l_i)\}$，其中 $x_i = [h_0; h_t]$，$l_i$ 标记该回合检索结果是否包含有毒记忆。
  2. **意图感知信息瓶颈（IB）编码**：通过变分信息瓶颈将输入压缩到去噪潜空间 $z_i$：
     - **紧凑性** $\min I(Z;X)$：以高斯变分后验逼近，最小化 KL 散度 $L_{KL} = D_{KL}(q_E(z_i|x_i) \| p(z))$（闭式可解），配合重参数化技巧实现可微训练；
     - **信息性** $\max I(Z;Y)$：通过意图对齐损失 $L_{align}$，将良性回合的潜表示拉向意图锚点、将有毒回合推离锚点（带边距 $m_a$），从而在压缩空间中扩大良性与有毒之间的类间间隔。
  3. **轻量多超平面分类器**：在去噪潜空间上构建 $K$ 个超平面的分段决策区域（Convex Polytope Machine），通过 $L_{benign}$（良性样本须低于所有超平面）和 $L_{poison}$（有毒样本须至少违反一个超平面）联合优化，捕捉多样化的攻击模式。
  4. **总体训练目标**：
$$\min_\phi \; L_{benign} + L_{poison} + \beta L_{KL} + \lambda L_{align}$$
- **推理流程**：测试时对 top-k 检索到的记忆逐条评分，仅将判为良性的记忆写回记忆库或保留在上下文中，全程无需反复调用 LLM 审计。

### 3. 实验设计

- **数据集与场景**：

- **智能体骨干（4 种）**：DeepSeek-V4（闭源）、GPT-4o-mini（闭源）、Llama-3.1-8B-Instruct、Qwen3-8B-Instruct。
- **检索设置**：采用 BGE-large-en 嵌入模型，每回合检索 top-5 条记忆。
- **攻击方法**：AgentPoison（直接注入）和 MINJA（查询式间接注入）。
- **对比基线（6 种）**：A-MemGuard（推理式防御）、LLM Auditor（LLM 审计器）、DistilBERT 分类器（Distil）、困惑度过滤（PPL）、Sequential Monitor（顺序监控）、AV Filter（注意力方差过滤，因需内部注意力分布，无法在闭源模型上评估）。

### 6. 主要结论与发现

- **防御有效性**：在 ReAct-StrategyQA 上，MIND 在各骨干上均一致降低 ASR-r 和 ASR-a，平均相对无防御基线下降 **55.4%** 和 **55.3%**，同时保持任务准确率（67.95% vs. 无防御 67.56%）。
- **跨域迁移能力**：在 MMLU 上，MIND 取得防御方法中最高的平均准确率（79.57%），平均 ASR 接近零（0.28%），验证了跨领域泛化能力。
- **推理效率**：MIND 平均回合耗时 23.13 秒，与无防御智能体（23.36 秒）相当；比 LLM Auditor 快 **20.6%**，比 A-MemGuard 快 **70.4%**，确认了"轻量"定位。
- **消融验证**：IB 和多超平面两个组件具有互补作用；完整 MIND 将误报率（FPR）降至 12.0%（较双移除变体降低 23.0 个百分点），漏报率（FNR）仅 0.2%。
- **超参数敏感性**：$\beta_{IB}=10^{-3}$、$\lambda_{align}=0.2$ 为最优组合；过大的 $\beta$ 或 $\lambda$ 虽降低 FPR，但会牺牲 ACC 并增加 FNR。

### 7. 优点

- **轻量高效**：无需反复调用 LLM 审计，仅用一个冻结 LLM 一次提取特征 + 轻量分类器完成防御，推理延迟接近无防御状态。
- **设计动机扎实**：通过初步实验（注意力衰减分析 + t-SNE 可分离性观察）为方法设计提供经验依据，而非凭空提出架构。
- **信息瓶颈引入合理**：将防御重构为去噪问题，以 IB 理论为支撑，同时解决多轮冗余和攻击信号弱化两个痛点，学术创新性较好。
- **多超平面分类器具有理论保证**：基于凸多面体机的理论支撑，可逼近非线性决策区域，比单线性边界更能捕获多样化攻击模式。

- **闭源模型兼容**：对闭源骨干使用代理特征提取器，使防御不依赖模型内部状态，适用范围更广。
