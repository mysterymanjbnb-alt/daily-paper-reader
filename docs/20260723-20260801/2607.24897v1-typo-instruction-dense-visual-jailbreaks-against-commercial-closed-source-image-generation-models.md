## 摘要
最近，商业图像生成模型能够生成带有可读文本的高质量图像（如海报、信息图表和手册），吸引了大量关注。然而，我们首先表明，这一能力同样引入了一种此前未被报告的安全漏洞：这些系统可能直接拒绝生成有害文本，但允许在生成的图像中将相同内容呈现为文本，即安全对齐无法可靠地从文本输出迁移到图像中嵌入的文本。在本文中，与现有针对图像生成模型的视觉越狱主要诱导模型生成有害视觉对象或场景不同，我们引入了指令密集型视觉越狱的概念，即图像生成模型在图像中生成详细、可读且可操作的有害指令。此类输出可能放大危害，因为渲染出的指令可以被轻松阅读并广泛传播。为了实例化这一威胁，我们提出了TYPO，一个黑盒框架，通过自动生成对抗性排版提示词来利用这一安全差距，这些提示词隐蔽地引导图像生成模型将有害意图表达为高度清晰、排版结构化的文本。具体而言，TYPO将提示词生成分解为两个通道：一个文本通道用于重塑目标意图，一个视觉通道用于指定其呈现形式。我们将这两个通道构建为双通道文本-视觉策略空间，并通过自适应组合搜索优化候选策略组合。对四种商业模型（即GPT-Image-2、Nano Banana Pro、Qwen-Image-2和Seedream 5.0 Lite）的大量实验表明，TYPO在ASR上平均超过九种代表性越狱攻击50.2%，而平均查询成本仅为0.04美元。

## Abstract
Recent commercial image-generation models can generate high-quality images with readable text (e.g., posters, infographics, and manuals), attracting considerable attention. Yet we first show that this same capability also introduces a previously unreported safety vulnerability: these systems may refuse to generate harmful text directly, yet permit the same content when rendered as text within generated images, i.e., safety alignment does not reliably transfer from textual outputs to text embedded in images. In this paper, unlike existing visual jailbreaks against image-generation models, which primarily induce models to generate harmful visual objects or scenes, we introduce the concept of instruction-dense visual jailbreaks, in which image-generation models produce detailed, readable, and actionable harmful instructions within images. Such outputs can amplify harm because the rendered instructions can be readily read and widely spread. To instantiate this threat, we propose TYPO, a black-box framework that exploits this safety gap by automatically generating adversarial TYPOgraphy prompts, which covertly steer image-generation models to express harmful intent as highly legible, typographically structured text. Specifically, TYPO decomposes prompt generation into two channels: a textual channel for reframing the target intent, and a visual channel for specifying its presentation form. We formulate these two channels as a dual-channel textual-visual strategy space and optimize candidate strategy combinations through an adaptive combinatorial search. Extensive experiments across four commercial models (i.e., GPT-Image-2, Nano Banana Pro, Qwen-Image-2, and Seedream 5.0 Lite) show that TYPO substantially outperforms nine representative jailbreak attacks by 50.2% in ASR on average, while incurring an average query cost of only $0.04.

## 2. 论文提出的方法论（核心思想、关键技术细节、算法流程）

论文提出了 **TYPO**，一个黑盒越狱框架，用于自动生成对抗性排版提示词（adversarial typography prompts），诱导图像生成模型生成指令密集型的有害图像。

### 2.1 核心思想：双通道文本-视觉策略空间

TYPO 的核心洞见是：直接请求生成满是显式有害文本的图像很容易被安全过滤器拦截，因此必须**同时对语义重塑（semantic reframing）和视觉呈现（visual presentation）进行协同控制**。由此提出双通道分解：

- **文本通道（Textual Channel）**：负责重塑有害意图，在保留底层语义的同时抑制显式风险线索。包含四种策略：
  - **语义伪装（Semantic Camouflage）**：将有害意图嵌入合理的高层语境（如安全教育案例、影视剧本）。
  - **拼写混淆（Spelling Obfuscation）**：通过拼写变异、间接措辞遮蔽敏感词汇。
  - **知识诱导（Knowledge Elicitation）**：诱导模型生成更详细、内容更稠密的文本。
  - **语言变异（Linguistic Variation）**：调整句式、语态、语气，降低意图的直接暴露度。

- **视觉通道（Visual Channel）**：控制重塑内容以何种可读文本形式呈现。包含四种策略：
  - **呈现形式（Presentation Form）**：标准横排、古典竖排、Emoji 替换、镜像文字、藏头诗（Acrostic）等。
  - **文档载体（Document Carrier）**：海报、手册、说明书、研究报告等视觉媒介。
  - **文本外观（Text Appearance）**：字体样式、纹理、可读性控制。
  - **观看视角（Viewing Perspective）**：视角角度、构图方式、物理呈现形式。

两个通道组合构成联合策略空间 **S = S_text × S_visual**，其中每个策略组合 s 对应一个特定的攻击提示词生成方式。

### 2.2 自适应组合搜索（Adaptive Combinatorial Search）

为在联合策略空间中高效搜索有效的策略组合，TYPO 采用启发自**果蝇优化算法**的自适应组合搜索：

1. **种群初始化**：通过覆盖感知的随机采样初始化 Np 个策略组合。
2. **气味搜索（Smell Search）**：对每个策略选项施加有界随机扰动，在邻域内探索新组合，使用循环索引保持选项在合法范围内。
3. **视觉搜索（Vision Search）**：以一定概率（随优化进度递增）将当前候选组合的各个选项向迄今为止最优组合靠近，实现"开发"导向的搜索。
4. **柯西变异（Cauchy Mutation）**：当最优分数停滞不提升时，施加大幅随机变异，跳出局部最优。
5. **哈希去重**：维护已探索集合 H，避免对相同组合重复查询目标模型。

### 2.3 提示生成与安全感知优化（Safety-Aware Prompt Optimization）

- 由**辅助 LLM（DeepSeek-V4-Pro）** 将策略组合 s 与有害意图 x 实例化为候选提示词 p = G(x; s)。
- 经过**本地安全守护（Llama Guard）** 筛查：如果提示词被判定为有风险，则由辅助 LLM 执行一轮"救援改写"后再筛查；通过筛查的提示词才提交给目标图像生成模型。
- 目标模型生成图像后用 **VLM 裁判（GPT-5）** 对图像的危害严重性和可操作性打分 r ∈ [0, 5]，达到阈值 τr = 4 即视为攻击成功。

### 2.4 整体算法流程（伪代码要点）

```
输入：有害意图 x，策略空间 S，种群规模 Np，最大迭代次数 T，阈值 τr
1. 初始化种群 P0，清空已探索集合 H
2. 循环迭代（ℓ = 0, ..., T-1）：
   a. 从当前种群中选择未探索过的策略组合
   b. 对每个候选组合，生成提示词 → 本地安全筛查 → (必要时改写) → 提交目标模型 → VLM评分
   c. 记录最优结果，若达到阈值则提前终止
   d. 通过气味搜索 + 视觉搜索 + 柯西变异更新种群
3. 返回最优提示词 p* 及其对应得分
```

## 6. 论文的主要结论与发现

1. **跨模态安全对齐存在系统性的漏洞**：文本生成中的安全策略不会可靠地迁移到图像内文本生成。仅改变输出模态（文本→图像内文本）就能使有害请求完成率平均提升 43.8%。
2. **TYPO 攻击效果显著**：在四个商业模型上，TYPO 的 ASR 全部超过 90%（最高 97%），平均 ASR 达 93.8%（AdvBench）和 94.8%（StrongREJECT），在 ASR、Score、SC 三个指标上全面超越所有 9 个基线，平均 ASR 相对最优基线提升 50.2%。
3. **查询效率极高**：平均仅需 2.80 次优化迭代、2.41 次目标模型查询即可达到攻击成功阈值，API 成本不足 0.04 美元，远优于基线方法（如 AutoDAN-Turbo 平均需 12.88 次迭代）。
4. **攻击提示词具有跨模型迁移性**：在某一模型上优化得到的 TYPO 提示词直接用于其他未训练过的模型，ASR 仍可达到 57%–83%。
5. **现有防御难以有效拦截**：关键词过滤器（BR 95%）、PPL 过滤器（BR 96%）、CLIP 过滤器（BR 95%）、Q16 过滤器（BR 78%）均无法有效防御；通过视觉策略变化（镜像、竖排、Emoji 等）可使 OCR 检测的绕过率从 9% 提升至 81%。
6. **双通道设计缺一不可**：消融实验表明，去掉文本通道/视觉通道/组合搜索均导致显著性能下降，验证了各组件的重要性。
7. **AutoDAN-Turbo 也有较高 ASR**：说明指令密集型文本攻击目前是一个广泛可利用的攻击面，并非 TYPO 独有的问题。

## 8. 不足与局限

- **依赖预定义的策略空间**：论文的搜索空间由人为设定的 8 种策略（文本 4 种 + 视觉 4 种）构成，策略类型和选项的覆盖范围有限，可能无法泛化到未纳入空间的新型攻击变体。论文亦承认这一局限。
- **适用范围受限**：该攻击仅对具备强文本渲染能力的闭源图像生成模型有效；对文本渲染能力弱的开源模型（如 Stable Diffusion 系列）不适用，一定程度上限制了威胁范围的普遍性。
- **裁判机制依赖大模型**：攻击效果评估依赖 GPT-5 VLM 的打分与辅助 LLM（DeepSeek-V4-Pro）的提示词生成能力，可能引入评估偏差（尽管论文报告人工复核与 GPT-5 判断一致性超过 95%）。且裁判模型的可用性和成本未充分讨论。
- **防御评估局限**：防御实验仅在 GPT-Image-2 上单模型进行，未评估跨模型防御效果；也未测试更复杂的防御方案（如专门训练的图像内文本安全分类器）。
- **实验细节透明度不足**：未说明主实验的具体测试样本数、置信区间、单次实验的统计波动性；未明确说明 API 成本的计算口径（如是否包含 VLM 裁判和辅助 LLM 的调用开销）。
- **公平性问题**：基线方法（尤其是面向通用 LLM 的越狱方法）原本并非为图像生成模型设计，论文对其在图像场景下是否需要适配未做充分讨论，可能存在基线性能被低估的风险。
