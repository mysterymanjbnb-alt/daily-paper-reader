## 摘要
安全与隐私是联邦学习（FL）的首要需求，尤其是在医疗和基因组学等需要分析敏感信息的领域。我们的FL框架旨在应对这些挑战，同时提出一种模块化、灵活且基于微服务的架构。更具体地说，它集成了高效的gRPC通信层和有限状态机，以确保稳健的组件同步和威胁检测，同时依赖于使用CKKS同态加密方案的阈值变体的容错安全聚合协议。这使得编排服务器能够进行盲模型聚合，要求至少t-out-of-N个活跃客户端参与解密，同时通过加密和网络协议最小化通信开销。我们通过噪声泛洪确保IND-CPA-D安全性，并通过每轮更新集体密钥材料来缓解针对同步解密器的最新密钥恢复攻击。我们通过多种用例展示了该框架的有效性，从标准图像识别（EMNIST）到复杂的基因组分类（包括TCGA上的乳腺癌亚型分型），并评估了不同阈值和模型规模下的系统性能。

## Abstract
Security and privacy are primordial requirements for Federated Learning (FL), especially in fields such as healthcare and genomics where sensitive information has to be analyzed. Our FL framework is designed to address these challenges while proposing a modular, flexible and micro-service architecture. More precisely, it integrates an efficient gRPC communication layer and a Finite State Machine to ensure robust component synchronization and threat detection, while relying on a fault-tolerant secure aggregation protocol using a Threshold variant of the CKKS homomorphic cryptosystem. This allows blind model aggregation by an orchestration server, requiring a minimum of $t$-out-of-$N$ active clients for decryption while minimizing communication overhead thanks to both cryptographic and network protocols. We ensure IND-CPA-D security through noise flooding and mitigate the recent key-recovery attack on synchronized decryptors by renewing the collective key material at every round. We demonstrate the framework's effectiveness through diverse use cases, ranging from standard image recognition (EMNIST) to complex genomic classification including breast cancer subtyping on TCGA, evaluating system performance across different threshold values and model scales.

## 2. 方法论

### 核心设计

- 基于微服务架构，每个节点由三个隔离容器化组件构成：
  - **Orchestrator**：节点唯一网关，实现有限状态机（FSM），负责同步生命周期、协调服务、事件调度与潜在威胁检测；
  - **ML Engine**：被动服务，仅执行张量运算和模型训练，不接入网络或密码逻辑；
  - **Crypto Provider**：被动服务，负责密钥生成、同态加密/解密等敏感操作，容器可更换；
- 组件间通过 gRPC 和 Protocol Buffers 通信，支持二进制大负载、类型安全、低序列化开销，且实现语言无关（例如密码模块可用 Rust 实现）。

### 安全模型与威胁对抗

- 假设中央聚合服务器为 **honest-but-curious**（诚实但好奇），且每轮至少 t 个参与客户端为 honest-but-curious（非共谋）。
- 使用阈值同态加密方案（ThHE）进行安全聚合，服务器只能执行盲聚合，无法查看明文模型；只有满足 t-out-of-N 门限的客户端联合才能解密结果。
- 底层为 Mouchet 等人的 RLWE-based ThHE，实例化为 **CKKS 多密钥方案**，支持批量编码和近似算术。
- 针对同步 ThHE 模型的密钥恢复攻击，采取两项对策：
  - 使用噪声洪泛（noise flooding）确保 IND-CPA-D 安全；
  - 每轮重新执行 Setup、DistKeyGen、ShareReshare 更新集体密钥材料，规避跨轮次窃取解密份额的攻击。

### 核心流程（算法阶段）

1. **Setup(1^λ, N, t)**：生成公共参数。
2. **DistKeyGen**：各客户端生成密钥份额，联合生成集体公钥 pk，秘密钥按加法共享。
3. **Enc(pk, m)**：客户端将本地模型权重加密后上传。
4. **Eval**：服务器在密文上计算 FedAvg（加权平均）聚合。
5. **ShareReshare**：通过 Shamir 秘密共享获得 t-out-of-N 门限结构。
6. **PartDec**：各参与客户端对聚合结果生成部分解密份额。
7. **CombDec**：收集至少 t 个份额，通过拉格朗日插值恢复全局模型明文。

### 系统特性

- 初始全局模型由种子派生，避免向服务器暴露明文参数；
- 解密子集可静态配置或每轮动态选择，并与下一轮注册并发，最大化吞吐量；
- 提供“Baseline 模式”（不启用任何密码操作），用于隔离协议开销。

## 6. 主要结论与发现

- MOSAIC-FL 的 ThHE 模式可实现与明文 Baseline **完全一致的收敛精度**，说明同态加密操作是“无损”的。
- 通信开销随 N 和 t 增大而增大（如 N=16、t=9 时可达 14.2s），主要来自 P2P 密码同步阶段（PartDec）。
- 对于计算强度高的 Transformer 模型，ThHE 加密开销占比极小（总时间从 159.17s 增至 167.05s），安全保护几乎不损害整体效率；
- 对于轻量 CNN，加密使每轮总时间由 10.56s 增至 17.30s，开销相对明显，仍可接受。
- 微服务架构 + FSM + 阈值 HE 的结合，使得框架具备模块化、容错性和可扩展性，适用于注重隐私的医疗/基因组学场景。

## 7. 优点

- **架构创新**：微服务隔离、gRPC 语言无关通信、FSM 集中协调，降低了组件耦合，易于集成新模型和密码库。
- **安全设计完整**：引入 t-out-of-N 阈值 CKKS，服务器只能盲聚合；噪声洪泛 + 每轮密钥更新，兼顾 IND-CPA-D 安全与抗同步解密器密钥恢复攻击。
- **容错性好**：门限解密机制允许少量客户端掉线，无需完全在线；解密子集可动态选择。
- **实用性验证**：在真实基因组数据（TCGA）上展示了框架能力，填补了多密钥 FHE 在 FL+基因组学交叉研究中的空白。
- **基线对比清晰**：通过明文/加密双模式，有效分离并量化了密码与网络协议开销。

## 8. 不足与局限

- **安全假设较强**：假设所有参与者（包括服务器）为 honest-but-curious 且不共谋，未涵盖恶意/主动攻击者模型；
- **依赖外部机制**：密钥生成需要公共认证信道和共识协议生成随机性，实际部署可能存在信任成本；
- **同步协议限制**：ThHE 需要至少 t 个客户端在线完成解密，网络分区或大规模掉线场景下仍可能阻塞；
- **密钥轮换成本未量化**：声称每轮重跑 Setup/DistKeyGen/ShareReshare 的额外开销“可忽略”，但未给出具体测量数据；
- **实验覆盖面有限**：未与其他 FL 框架做端到端对比；未测试不同非 IID 程度、稀疏数据、跨地域网络延迟等真实异质环境；未评估隐私攻击/差分隐私等其他隐私指标；
- **密码参数单一**：仅使用一组 CKKS 参数，未讨论缩放因子、安全等级、批处理大小对精度和性能的 trade-off；
- **总体算力描述不足**：未披露 GPU 数量、分布式节点数量、每轮及总体的能耗或训练时长，可复现性信息不完整。
