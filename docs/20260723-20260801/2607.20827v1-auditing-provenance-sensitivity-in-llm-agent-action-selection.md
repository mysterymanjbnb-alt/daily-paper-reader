## 摘要
LLM智能体从混合了用户请求、工具输出、检索记录、记忆和不可信文本的上下文中选择工具和参数。证据可能相关但未被授权决定决策，因此正确动作不必仅基于允许的证据。我们引入一种针对目标的授权审计，为每个工具和参数目标单独标记上下文因素。其主要测试在保持任务、命题、位置和策略不变的情况下，仅改变命题的来源权威性。然后我们测试当有效证据被削弱时的行为，并使用上下文子集交互作为次要定位诊断。在450个受控的下一动作任务和多个开放权重LLM家族中，可信和不可信变体在5.4%的竞争案例中产生不同动作，而在支持案例中为1.7%。在受控退化下，未经授权的竞争以完全正确、混合错误、干净正确的模式保留在2.4%的比较中，95%置信区间为2.1%至3.0%。这些是受控压力集比率，而非部署流行率。模型对文本来源权威线索有响应，但这并不阻止不可信证据影响其动作。

## Abstract
LLM agents choose tools and arguments from context that mixes user requests, tool outputs, retrieved records, memory, and untrusted text. Evidence can be relevant without being authorized to determine a decision, so a correct action need not be grounded only in permitted evidence. We introduce a target-specific authorization audit that labels context factors separately for each tool and argument target. Its primary test holds the task, proposition, position, and policy fixed while changing only the proposition's source authority. We then test behavior when valid evidence is weakened and use context-subset interactions as a secondary localization diagnostic. Across 450 controlled next-action tasks and multiple open-weight LLM families, trusted and untrusted variants produce different actions in 5.4 percent of competing cases versus 1.7 percent of supporting cases. Under controlled degradation, unauthorized competition is retained in a full-correct, mixed-error, clean-correct pattern in 2.4 percent of comparisons, with a 95 percent confidence interval from 2.1 to 3.0 percent. These are controlled stress-set rates, not deployment prevalence. The models respond to textual source-authority cues, but this does not prevent untrusted evidence from influencing their actions.

# 论文详细总结

## 1. 核心问题与整体含义

- **研究背景**：LLM智能体在执行任务时，需要从混合上下文中选择工具和参数。上下文来源包括用户请求、工具输出、检索记录、记忆以及不可信的文本（如外部提示注入、陈旧记忆、相邻记录等）。
- **核心问题**：现有基准只评估最终动作是否正确，无法区分“基于授权证据的稳健决策”和“恰好正确但依赖未授权证据的脆弱决策”。即使动作正确，决策过程可能仍然受到未经授权来源的影响。
- **关键洞察**：证据可以相关但未被授权决定决策。例如，一封邮件中，过时的收件人地址不会影响“选择发送邮件工具”这一决策，但会直接影响“收件人参数”的取值。因此授权是**目标特定**的，必须分别对工具目标和每个参数目标进行审计。
- **研究目标**：提出一套审计方法，检验LLM智能体的动作选择是否仅基于允许的证据，并识别未授权证据在何种条件下仍能影响动作。

## 2. 方法论

### 2.1 核心思想
- 引入**目标特定授权审计**：为每个审计目标（工具名或参数值）将上下文分解为语义因素，并分别标注其授权状态。
- 将**来源权威**（可信/不可信）与**语义关系**（支持/竞争）交叉设计，实现匹配干预。
- 通过**受控证据退化**测试行为隔离，通过**上下文子集交互**作为次要定位诊断。

### 2.2 关键定义
- 上下文因素集合：`X = {x1, ..., xn}`，每个因素是可移除的语义单元。
- 目标字符串 `y`，可以是工具名（如 `send_email`）或参数赋值（如 `recipient=alice@company.com`）。
- 目标分数：对目标 token 求和 log-odds，公式为：
  - `vy(P) = Σ [log(qt(P)) - log(1 - qt(P))]`，其中 `qt(P)` 是模型对第 t 个目标 token 的条件概率。
- 因素标签：
  - **Valid**：已授权且支持目标；
  - **Invalid**：未授权且提供具体竞争值、实体、动作、指令或前动作残留；
  - **Neutral**：其他可审计因素；
  - **Excluded**：固定接口内容或模糊材料。

### 2.3 主要测试
1. **匹配来源干预**（Source Response）：
   - 固定任务、命题、位置、策略，仅改变命题的来源权威（可信/不可信）。
   - 设计两因素实验：权威 `a ∈ {T, U}` × 关系 `r ∈ {S, C}`。
   - 定义权威差距：`δS = GT - GU`（支持命题），`δC = DT - DU`（竞争命题），以及双重差分 `△△ = δC - δS`。
   - 另设“同命题控制”：保持同一竞争命题，只改变来源标记，测量移除效应差异。

2. **受控有效证据退化**（Isolation）：
   - 对每个有效因素 x，构造三个上下文：
     - 完整上下文（full）；
     - 混合上下文（mixed）：仅移除该有效因素；
     - 干净上下文（clean）：移除该有效因素及所有 Invalid 因素。
   - 主要终点为 mixed 与 clean 的生成动作不一致率，以及“完全正确→混合错误→干净正确”的严格保留无效模式。

3. **部分证据交互诊断**（Localization）：
   - 对所有因子子集 `Z ⊆ X` 构造提示并计算目标分数 `vy(Z)`。
   - 使用哈萨尼交互（Harsanyi interaction）精确分解：
     - `Iy(B) = Σ_{Z⊆B} (-1)^{|B|-|Z|} vy(Z)`。
   - 摘要指标：空联盟 Harsanyi、Shapley 交互、全上下文变换。
   - 定义无效包含强度：
     - `s_any`：含无效因子的交互强度占比；
     - `s_frac`：按无效因子比例加权的强度占比。
   - 使用标签数量匹配的随机标签作为零假设，报告超额强度。

  - 退化实验（12,120 个 目标-有效因素 行）；
  - 联盟诊断（12 个模型-数据集组合，每个目标所有 256 个子集）。
- 大量鲁棒性检查：标签鲁棒性、因子顺序、分数规范化、提示措辞、占位符、角色匹配、长上下文筛选等。

### 5.2 充分性评价
- **优点**：实验设计系统，将行为测量与交互诊断分离，并设置多种边界条件；外部标注者验证了标签可靠性。
- **客观性**：采用受控压力测试，明确区分“响应来源权威”与“行为隔离”，避免过度声称部署错误率。
- **局限性**：所有实验基于人工分解的 8 因素固定界面，无法保证任意重新分解下的不变性；精确枚举仅适用于短因子集，长上下文依赖近似筛选；模型必须开放权重以获得 token 概率，闭源 API 只能使用更弱的代理。

## 6. 主要结论与发现

- **模型确实响应来源权威**：匹配干预显示，可信支持命题比不可信支持命题更能提升目标分数；可信竞争命题比不可信竞争命题更能降低目标分数。双重差分为正（+0.481，95% CI [0.413, 0.550]）。
- **响应不等于隔离**：生成动作中，仅改变来源权威导致 5.4% 的竞争案例动作变化，而支持案例为 1.7%（+3.8 个百分点）。其中 1.2% 从正确变为错误，4.0% 从错误变为正确。来源降级在平均意义上是纠正性的，但并非完全可靠。
- **有效证据退化下未授权竞争仍能改变行为**：在移除有效证据后，保留无效因素与移除无效因素相比，动作不一致率 24.6%；严格“全正确→混合错误→干净正确”模式出现率为 2.4%（CI [2.1, 3.0]）。
- **联盟诊断的边界**：Shapley 交互显示无效因子参与强度存在正超额（+0.027），但全上下文变换接近零（-0.004），且严格同角色竞争匹配控制显示负超额（-0.018）。因此交互诊断只能描述部分证据下的依赖结构，不能单独作为授权违规的证明。
- **护栏效果有限**：显式权威策略能将不可信竞争错误率从 14.9% 降至 9.5%（总体获益 5.4 点），但不同模型差异大（Mistral 改善 18.1 点，DeepSeek 轻微反转），不能作为不变过滤器。

## 7. 优点

- **目标特定授权标签**：将授权与语义关系分离，对每个工具和参数目标分别标注，解决了“相关但未授权”的关键盲点。
- **匹配干预设计**：在完整提示上仅改变来源标记，干净地识别模型对来源权威的响应。
- **行为与定位结合**：退化实验和交互诊断互补，避免将单一方位的归因误作因果证明。
- **精确子集枚举**：8 因素下枚举全部 256 个子集，交互分解透明且可复现。
- **大量控制实验**：包括外部标注、随机标签、内容类型、角色匹配、因子顺序、占位符等，系统性地检验了结论的边界。
- **明确区分压力测试与部署率**：强调所有比率为受控条件下的相对比较，避免过度解读。

## 8. 不足与局限

- **人工分解依赖**：审计依赖人工因素分解和标签，外部复现只能支持聚合鲁棒性，不能保证任意重分解下的稳定性或单案例级解释。
- **短上下文限制**：精确枚举仅适用于 8 因素；12/16 因素下的筛选近似，无法确认长轨迹、演变记忆和噪声检索下的有效性。
- **模型范围**：需要开放权重模型获得目标 token 概率，闭源 API 仅支持弱代理（如 GPT-4o mini 的受迫选择代理并不一致）。
- **标签不一致性**：外部标注四标签一致性较低（κ = 0.608），无效/非无效 κ = 0.626，作者标签与共识仅匹配 78.9%，标签噪声可能影响部分结论。
- **交互诊断的边界**：全上下文变换接近零以及严格角色匹配控制反转，表明联盟诊断不能单独识别授权违规，需要匹配干预提供因果识别。
- **非部署误差率**：所有比率是受控压力集的结果，不代表自然环境中未授权影响的发生率，也不等同实际危害大小。
- **未探索训练数据因果性**：未讨论模型训练过程中对来源权威感知的来源，不提供训练数据层面的因果归因。
