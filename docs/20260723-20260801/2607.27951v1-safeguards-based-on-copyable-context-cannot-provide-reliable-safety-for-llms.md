## 摘要
大型语言模型的安全保障在查看答案将如何使用之前就决定是否回答。这为双重用途任务带来了一个基本问题：同一个答案既可以帮助授权的专业人员，也可以帮助攻击者，而攻击者可以模仿良性的请求和交互历史。我们将模型释放的能力与关于下游用途的可用证据分开。当该证据可复制时，我们在保留有用答案的同时，推导出攻击者协助的确切最坏情况下限。结果产生了安全三难困境：有用能力、可靠安全和开放访问不能共存。然后我们展示了可信凭证如何通过添加难以复制的信息来补充现有保障，以预测实际的下游用途，并确定了消除该下限所需的更强条件。来自双重用途评估、自适应攻击和已部署的可信访问计划的证据支持了这些条件的实际相关性。

## Abstract
Large language model safeguards decide whether to answer before seeing how an answer will be used. This creates a basic problem for dual-use tasks: the same answer can help an authorized professional or an attacker, while an attacker can imitate a benign request and interaction history. We separate the capability released by the model from the evidence available about downstream use. When that evidence is copyable, we derive the exact worst-case floor on attacker assistance while preserving useful answers. The result yields a safety trilemma: Useful Capability, Reliable Safety, and Open Access cannot coexist. We then show how a trusted credential can complement existing safeguards by adding hard-to-copy information that predicts actual downstream use, and identify the stronger condition needed to eliminate the floor. Evidence from dual-use evaluations, adaptive attacks, and deployed trusted-access programs supports the practical relevance of these conditions.

## 1. 论文的核心问题与整体含义

- **背景动机**：当前大语言模型（LLM）的安全防护机制（安全训练、输入/输出过滤、安全补全策略等）在生成答案之前就依据请求和交互信息做出是否响应的决定。然而，这类信息本质上**先于下游真实用途而存在**——在答案被使用之前，系统无从得知这个答案将用于合法目的还是恶意目的。
- **核心问题**：在双用途（dual-use）任务中，同一个技术内容（如漏洞分析）既可以支持授权专业人员的安全评估，也可以支撑攻击者的入侵行为，而攻击者完全可以模仿合法用户的请求措辞与交互历史，使两者在发布前“看起来一模一样”。因此，基于可复制上下文的安全防护无法区分合法与恶意用途，无法提供可靠的安全保证。
- **核心命题**（整体含义）：论文通过形式化分析证明了一个“安全三难困境”（Safety Trilemma）——**有用能力（Useful Capability）、可靠安全（Reliable Safety）、开放访问（Open Access）三者不可兼得**。只要保持开放访问并保留有用答案，任何基于可复制证据的安全保障都必然为攻击者留下一个无法消除的协助下限。打破这一困境需要引入**可信凭证（Trusted Credential）**——一种不可复制且能预测下游真实用途的额外证据。

### 2.2 关键概念与公式

## 6. 主要结论与发现

- 在双用途条件成立、证据可复制的设定下，**任何保留合法效用 q>0 的释放规则，其最坏情况下攻击者获得协助至少为 Γ(q) ≥ ρq > 0**——零协助是不可能的。
- 交互式安全问答、动态决策、跨轮证据融合等手段**无法突破**该下限（精确归约到静态释放菜单前沿）；实现约束只会恶化、不会改善下限。
- 安全三难成立：有用能力、可靠安全、开放访问三者不能同时满足；舍弃开放访问（引入可信凭证）是突破下限的必要方向。
- **可信凭证的价值**取决于其信号对下游真实用途的预测区分度 d、恶意方的不可复制性（条件复制前提）以及在恶意支持集外保留足够合法效用的“支持条件”；仅靠预测优势不足以实现零协助。
- 任务分解、重试、相关随机性（跨会话）无助于降低能力下限；需要不可复制的历史信息才能改变结果。
