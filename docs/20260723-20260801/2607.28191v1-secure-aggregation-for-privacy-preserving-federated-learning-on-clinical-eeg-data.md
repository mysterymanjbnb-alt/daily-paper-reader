## 摘要
联邦学习使多家机构无需交换原始临床脑电数据即可训练共享模型，但它并不能完全防止个体模型更新带来的隐私泄露。本文提出了一种以基于掩码的安全聚合为核心保护机制的临床脑电数据隐私保护联邦学习框架。该框架结合了基于图的通信、门限秘密共享、抗掉线聚合、本地更新裁剪、可选的基于布隆过滤器的隐私保护记录链接初始化模块，以及基于辅助公证人的可验证性。它支持半诚实和恶意两种聚合设置，并使用Flower联邦学习框架实现。在模拟的跨机构医疗场景中，使用TUH脑电数据衍生的数据，在不同客户端配置下对安全聚合变体进行了评估。在所陈述的假设下，安全变体对聚合服务器隐藏了个体更新。结果表明，这些变体与联邦模型训练保持兼容，尽管恶意设置下的安全防护和轻量级一致性检查机制引入了额外的计算、通信和轮次时长开销。半诚实变体在安全配置中开销最低，而恶意变体和辅助公证人变体以更高成本提供更强的一致性、完整性和轻量级验证支持。

## Abstract
Federated learning enables multiple institutions to train shared models without exchanging raw clinical EEG data, but it does not fully prevent privacy leakage from individual model updates. This paper presents a privacy-preserving federated learning framework for clinical EEG data using masking-based secure aggregation as the core protection mechanism. The framework combines graph-based communication, threshold secret sharing, dropout-resilient aggregation, local update clipping, an optional Bloom filter-based privacy-preserving record-linkage initialization module, and auxiliary-notary-based verifiability. It supports both semi-honest and malicious aggregation settings and is implemented using the Flower federated learning framework. The secure-aggregation variants are evaluated in a simulated cross-silo healthcare setting using TUH EEG-derived data under different client configurations. Under the stated assumptions, the secure variants hide individual updates from the aggregation server. The results show that these variants remain compatible with federated model training, although malicious-setting safeguards and lightweight consistency-checking mechanisms introduce additional computation, communication, and round-duration overhead. The semi-honest variant provides the lowest overhead among the secure configurations, while malicious and auxiliary-notary variants offer stronger consistency, integrity, and lightweight verification support at higher cost.

- **研究目标**：在临床EEG数据的跨机构FL场景下，实现一种可落地、可扩展的隐私保护聚合机制，使聚合服务器只能恢复客户端更新的聚合结果，而无法窥见任何个体的明文更新，同时兼顾通信开销、掉线容忍度和恶意行为防护。
- **整体含义**：该工作并非提出全新的密码学协议，而是将已有的掩码式安全聚合（masking-based secure aggregation）技术系统性整合进一个面向临床EEG数据的完整联邦学习流水线中，给出多种威胁模型下的可用变体，并在真实脑电数据集上验证其可行性，为该领域的实际部署提供一个实用性基准。

## 2. 论文提出的方法论

### 核心思想

- 基于**掩码式安全聚合（Secure Aggregation, SecAgg）**：各客户端在本地对更新向量添加两两掩码（pairwise masks）和自掩码（self-mask），服务器在聚合时掩码相互抵消，从而只获得客户端更新的总和，无法恢复个体更新。

### 关键架构组件

- **图基通信**：使用稀疏图代替全互联结构，每个客户端仅与其固定大小的邻居集合通信，降低通信成本（借鉴Bell等人的SecAgg+）。
- **阈值秘密共享**：每个客户端的自掩码种子和第一私钥通过Shamir秘密共享拆分给邻居，用于掉线恢复。
- **掉线恢复（Dropout Resilience）**：协议在多个阶段跟踪客户端活跃集合（A₁ ⊇ A′₁ ⊇ A₂ ⊇ A′₂ ⊇ A₃ ⊇ A′₃），服务器仅恢复掉线客户端的掩码材料，不触碰存活客户端的明文更新。
- **局部更新裁剪与量化**：每个客户端对更新向量做ℓ2范数裁剪（τ=0.75），再以s_Q=2²²进行整数量化，映射到模M=2³²的整数域上执行掩码运算，防止数值溢出。
- **布隆过滤记录链接（可选）**：训练前阶段，客户端用HMAC密钥化哈希构造布隆过滤器，服务器在密文域上完成重复记录匹配，明文标识符不出本地。

### 四个协议变体

| 变体 | 主要防护机制 |
|------|-------------|
| Π1（半诚实） | 图通信+两两掩码+自掩码+Shamir共享+掉线恢复，隐匿个体更新 |
| Π2（恶意） | Π1 + Merkle承诺+签名包含消息+确认阈值+一致性检查，约束服务器的摇摆行为和伪造参与声明 |
| Π3（半诚实+公证人AN） | Π1 + 线性验证标签+辅助公证人聚合校验，轻量级聚合一致性验证 |
| Π4（恶意+公证人AN） | Π2 + 与Π3相同的AN验证机制 |

### 数学实现要点

- **掩码生成**：两两掩码 aᵢ,ⱼ = F(H(KA(sk¹ᵢ, pk¹ⱼ))) ∈ Z_M^ℓ，使用PRG在聚合域上展开。
- **掩码上传**：yᵢ = zᵢ + F(bᵢ) − Σⱼ<ᵢ aᵢ,ⱼ + Σⱼ>ᵢ aᵢ,ⱼ (mod M)，保证两端点同时在聚合集合内时两两掩码抵消。
- **聚合恢复**：服务器在去掉自掩码和掉线客户端的残留掩码后，得到 Y_Q = Σᵢ∈A′₂ zᵢ (mod M)，再经符号映射和去量化恢复实值聚合。
- **AN验证**：客户端计算内积标签 tagᵢ^(r,ν) = ⟨u^(r,ν), zᵢ⟩ mod q，公证人聚合得到 T^(r,ν)，各客户端检查 ⟨u^(r,ν), Y_Q⟩ ≡ T^(r,ν) (mod q) 是否成立。

## 6. 论文的主要结论与发现

- **安全性与训练兼容**：所有四种安全聚合变体均与联邦模型训练兼容，服务器在既定假设下无法获取个体明文更新。
- **开销权衡**：
  - 半诚实变体Π1在安全配置中开销最低（如40客户端服务器侧聚合仅25.3秒 vs 恶意变体48.2秒 vs SecAgg对比178.7秒）。
  - 恶意变体Π2增加显著的签名、承诺、确认和一致性检查开销。
  - 公证人变体Π3/Π4进一步增加了通信量和协议计算量（主要是标签提交和AN通信）。
- **通信成本**：恶意和AN变体的通信量约为半诚实变体的2倍（如40客户端下约1.0 GB vs 2.0 GB）。
- **精度趋势**：准确率随客户端数量增加而下降（10客户端约79%，40客户端约70%，70客户端约60%），主要归因于本地数据量减少和划分敏感性，而非安全机制本身。
- **可扩展性**：安全聚合开销随客户端规模增长，但图基设计将增长控制在一定范围内。

## 7. 优点

- **系统完整性**：不是孤立的密码学协议，而是将安全聚合嵌入到完整的临床FL流水线中，覆盖数据准备（记录链接）、训练（安全聚合）和验证（AN）全流程。
