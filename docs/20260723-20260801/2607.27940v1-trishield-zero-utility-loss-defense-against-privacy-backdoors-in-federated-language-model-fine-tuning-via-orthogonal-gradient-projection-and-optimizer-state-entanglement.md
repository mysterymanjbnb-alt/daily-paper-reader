## 摘要
大型语言模型（LLM）的联邦微调能够在不暴露原始数据的情况下进行协作训练。然而，近期攻击NeuroImprint[1]（arXiv:2606.20553）表明，恶意参数服务器可以将PEFT适配器破坏为隐私后门：通过为每个训练样本分配专用记忆神经元并确保每个神经元最多更新一次，服务器可以解析性地重建59%–79%的客户端训练数据，且语义保真度很高。现有防御措施——包括本地差分隐私（LDP）[8]和梯度裁剪——要么无法抵御此攻击，要么导致无法接受的效用下降。我们提出**TriShield**，一种三层确定性防御机制，可完全阻止NeuroImprint式重建，同时实现**零模型效用损失**且**无需额外通信轮次**。TriShield包括：（1）**参数伪影检测器**，在本地训练开始前识别分布式模型参数中的记忆神经元特征；（2）**有状态虚拟迭代**机制，强制Adam/AdamW的动量状态在虚拟步骤间不可逆地纠缠梯度，从而破坏NeuroImprint的闭式求逆；（3）**零效用正交投影**算子，将所有局部梯度更新投影到通过SVD计算的主任务语义子空间上，从物理上消除携带私有记忆的梯度分量。我们从理论上证明，经过第二层和第三层处理后，上传梯度与任何单个训练样本之间的互信息为零。在GPT-2（117M）和Llama-Guard-3-1B上的实验验证，TriShield在所有测试攻击变体下将NeuroImprint重建率降至**0%**，同时保持或提升训练准确率，且额外GPU计算开销小于5%。

## Abstract
Federated fine-tuning of large language models (LLMs) enables collaborative training without exposing raw data. However, a recent attack, NeuroImprint [1] (arXiv:2606.20553), demonstrates that a malicious parameter server can corrupt a PEFT adapter into a privacy backdoor: by assigning a dedicated memorization neuron to each training sample and ensuring each neuron updates at most once, the server can analytically reconstruct 59\%--79\% of client training data with high semantic fidelity. Existing defenses---including local differential privacy (LDP) [8] and gradient clipping---either fail against this attack or impose unacceptable utility degradation. We present \textbf{TriShield}, a three-layer deterministic defense that completely prevents NeuroImprint-style reconstruction with \textbf{zero model utility loss} and \textbf{no additional communication rounds}. TriShield consists of: (1) a \textbf{Parameter Artifact Detector} that identifies memory-neuron signatures in distributed model parameters before local training begins; (2) a \textbf{Stateful Virtual Iteration} mechanism that forces Adam/AdamW's momentum state to irreversibly entangle gradients across virtual steps, invalidating NeuroImprint's closed-form inversion; and (3) a \textbf{Zero-Utility Orthogonal Projection} operator that projects all local gradient updates onto the main-task semantic subspace computed via SVD, physically eliminating any gradient components that carry private memorization. We prove theoretically that after Layers 2 and 3, the mutual information between the uploaded gradient and any individual training sample is zero. Experiments on GPT-2 (117M) and Llama-Guard-3-1B verify that TriShield reduces NeuroImprint reconstruction rate to \textbf{0\%} across all tested attack variants, while maintaining or improving training accuracy, with less than 5\% additional GPU computation overhead.

TriShield 是**首个满足全部五项关键属性**的防御方案：客户端侧部署、零效用损失、可证明隐私（互信息为零）、无需架构修改、PEFT专用——能够完全阻止NeuroImprint式重建，且不需额外通信轮次。


## 2. 方法论：核心思想、关键技术细节与算法流程

TriShield 采用三层递进防御框架，每层针对 NeuroImprint 利用的不同漏洞：

### Layer 1：参数伪影检测器（PAD）
**作用时机**：本地训练开始前，客户端检查收到的适配器参数。

**检测目标**（NeuroImprint 记忆神经元的三种结构特征）：
1. **行近似重复**：多个权重行共享近相同归一化向量（相关系数 > τ_corr = 0.95）
2. **异常低方差**：行内方差接近零（< τ_var = 10⁻⁴），实现LayerNorm不变性技巧
3. **偏置模式异常**：对应偏置近似常数（低偏置间方差）

**处置方式**：将检测到的记忆神经元重置为Kaiming正常初始化，直接销毁"槽-样本"映射关系。正常初始化的行内方差约 10⁻³–10⁻²，与阈值相差约1000倍，误报概率 < 10⁻⁶。

### Layer 2：有状态虚拟迭代（SVI）
**核心洞察**：NeuroImprint 的闭式求逆依赖线性激活（单步更新、无动量累积），使梯度与样本嵌入线性相关（∇W/∇B = Embed(x_j)）。SVI 通过在真实训练前用公共辅助数据执行 K 次虚拟优化器步骤，**预污染 Adam 动量状态**。

**算法流程**：
1. 保存适配器快照
2. 用辅助数据 D_aux 执行 K 次虚拟前向-反向传播，**仅更新优化器状态（m, v），不更新模型参数**
3. 恢复适配器权重至快照状态
4. 以预污染的动量状态进行真实训练

**防御原理**：真实梯度到达时，更新变为 g_real 与 m_K、v_K 的非线性混合（Adam更新规则），攻击者无法分离私密梯度分量。**定理1**证明该求逆系统在 d_in > 1 时欠定，存在无穷多解。

### Layer 3：零效用正交投影（ZUOP）
**核心观察**：记忆神经元梯度位于主任务梯度子空间的正交补空间中（这是 NeuroImprint 实现任务不可见性的设计要求）。

**算法流程**：
1. 用辅助数据 D_aux 计算任务梯度矩阵 G
2. 对 G 执行奇异值分解（SVD）得到主任务方向 U_k
3. 将梯度投影到 U_k 上：Δφ* = U_k·U_kᵀ·Δφ

**关键参数**：投影秩 k = min(0.8·rank(G), n−1)，保留80%任务梯度方差。**rank fraction=0.80 是验证的安全默认值**；0.95会使SR1E变体泄漏12%–50%（k过大导致随机向量意外对齐任务子空间）。

**理论保证**：
- **定理2**：若主任务梯度位于主方向子空间中，投影后梯度完全保持（零效用损失）
- **定理3**：记忆神经元梯度（位于正交补空间）投影后为零，重建表达式变为 0/0（未定义），互信息 I(x̂; x) = 0
- **定理4**：对近正交变体（偏离 < 5°），信息泄漏上界 < 0.008·H(x_j)

## 6. 主要结论与发现

1. **0%重建率**：TriShield将所有NeuroImprint变体的重建率降至0%（词元重建度量），与无攻击噪声底线持平
2. **零效用损失**：投影值显示精度损失 ≤ 0.3%（GPT-2 SST-2：92.1%→91.8%；AG News：89.7%→89.4%）
3. **层间分工明确**：PAD是n无关的前线防御（训练前重置记忆神经元）；ZUOP是正交通道的兜底（物理消除任务外分量）；SVI是闭式求逆的屏障（使非线性反演在计算上不可行）
4. **n-鲁棒性**：防御效果不依赖受害者样本数——在n=8到n=1024范围内重构均为0%
5. **自适应攻击无效**：五种变体均被至少一层TriShield组件中和
6. **理论保障**：互信息为零的信息论意义上重建不可能性，以及收敛性保持（FedAvg固定点不变）


## 7. 优点与亮点

1. **零效用损失的完美隐私权衡**：通过投影保持任务梯度精确不变，同时完全消除隐私梯度分量，打破"隐私-效用"不可兼得的传统认知
2. **三层防御的纵深设计**：每层独立针对不同攻击机制，即使某层被绕过，其余层仍提供保护
3. **纯客户端侧部署**：无需服务器协作、不改变FL协议，可作为Flower、PySyft等框架的~100行客户端hook，实用性强
4. **严格的理论保证**：从信息论角度证明互信息为零（定理3、4），而非依赖启发式经验
5. **创新性的GPM逆用**：将续学习的梯度投影记忆机制反向使用——GPM通过避免旧任务子空间保留知识，ZUOP通过仅保留当前任务子空间消除后门
6. **透明度**：对投影值、估算值与实测值有明确标注，对不利结果（如PAD only时梯度范数不减）有清晰归因分析


## 8. 不足与局限

1. **辅助数据依赖**：ZUOP需要32–500条来自训练分布的公共样本；在无公共数据的超敏感领域（如医疗基因组学）可能受限
2. **全规模实验缺失**：Llama-Guard-3-1B全规模微调与SST-2/AG News大规模基准测试均未实际执行，论文结论的实证强度受限
3. **投影结果可能过于乐观**：全规模效用（<0.3%精度损失）和重建率（0%）部分源于理论推导而非端到端实测
4. **CPU开销高**：SVI+ZUOP在CPU上的线性代数操作占训练轮次的约72%，边缘设备部署受限；文中建议GPU加速但未验证
5. **理论范围有限**：定理1–3仅适用于NeuroImprint类攻击（利用神经元级记忆的）；跨神经元纠缠编码或非LoRA适配器的新变体需扩展分析
6. **秩选择敏感性**：rank fraction=0.80是关键安全阈值，0.95即导致SR1E泄漏50%——参数鲁棒性不足，实际部署需谨慎调参
7. **PAD阈值校准**：τ_var = 10⁻⁴针对标准LoRA rank-4/8调优；新PEFT架构若固有低方差初始化需重新校准
8. **评估规模偏差**：本地验证仅15条样本，单样本精度差异即6.67%；部分消融结果可能在更大数据集上不成立
