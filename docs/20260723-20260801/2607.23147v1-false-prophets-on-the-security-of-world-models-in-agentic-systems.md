## 摘要
大型语言模型现在驱动着能够在不同环境中执行复杂多步任务的自主智能体。准确可靠地执行这些任务要求智能体预测其行为的结果。最近的研究提出通过专门训练的环境模拟器——世界模型来增强预测能力。虽然世界模型可以提升性能，但它们也可能误导智能体执行有害行为，从而产生重大的安全和隐私风险。在本文中，我们提出了关于在智能体系统中使用世界模型的安全关切。我们发现了一系列世界模型特有的漏洞，这些漏洞可能被利用于基于终端的智能体，以执行恶意代码或提取敏感数据。为了促进未来的发展，我们引入了一个专为基于文本的世界模型设计的安全基准数据集。我们认为某些风险是近似世界建模所固有的，并表明攻击者可以在智能体管道中诱导错误预测，成功率高达95%，可能导致意外命令执行、拒绝服务、钱包资金流失和私人信息提取。最后，我们为从业者提供实用建议，以缓解已发现的危害并强化智能体系统。

## Abstract
Large language models now power autonomous agents capable of complex, multi-step tasks in different environments. Accurate and reliable execution of these tasks requires the agent to predict the results of its actions. Recent research proposes to enhance predictive capabilities via specially trained environment simulators-world models. While world models can improve performance, they can also mislead agents into executing harmful actions, creating significant security and privacy risks. In this paper, we raise security concerns regarding the usage of world models in agentic systems. We discover a range of world model specific vulnerabilities, which can be exploited in terminal-based agents to execute malicious code or extract sensitive data. To facilitate future development, we introduce a security benchmark dataset designed for text-based world models. We argue that some risks are intrinsic to approximate world modeling, and show that attackers can induce mispredictions in agentic pipelines with up to 95% success rate, possibly resulting in unintended command execution, denial of service, drainage of wallet and private information extraction. Finally, we provide practical recommendations for practitioners to mitigate the discovered harms and harden agentic systems.

## 2. 论文提出的方法论

**核心思想：**
- 从攻击者视角系统性地识别并分类世界模型特有的攻击向量，构建可执行测试用例组成的基准数据集，量化评估世界模型的错误预测率，并根据根源将漏洞区分为"根本性"（fundamental）与"技术性"（technical）问题。

**威胁模型：**
- 攻击者通过域特定 API 或提示注入（prompt injection）向智能体传入恶意输入；智能体使用世界模型对动作执行结果进行模拟验证后，再在真实系统中执行动作。
- 攻击目标覆盖 CIA 三要素：**机密性（Confidentiality）、完整性（Integrity）、可用性（Availability）**。

**七类攻击向量（Attack Vectors）：**

| 攻击类别 | 性质 | 核心机制 | 危害 |
|---|---|---|---|
| 可计算性（Computability） | 根本性问题 | 预测任何程序运行时间等价于解决停机问题（Halting Problem），固有限制使世界模型无法准确估计计算密集型脚本的资源消耗 | 拒绝服务、控制流劫持 |
| 非确定性（Non-determinism） | 根本性问题 | 并发竞争条件（race condition）或真随机源导致同一脚本每次输出可能不同，世界模型只能预测单一确定性序列 | 控制流劫持 |
| 缺失知识（Missing Knowledge） | 根本性问题 | 系统软件版本更新、配置差异等超出训练数据范围（如 GNU coreutils 9.10 新增 `-A` 标志），模型无法准确模拟未知行为 | 控制流劫持、错误批准 |
| 外部环境（External Environment） | 根本性问题 | 网络接口状态、外部服务可用性、当前时间等外部动态信息无法从脚本本身推断 | 控制流劫持 |
| Token 数量（Token Count） | 技术性问题 | 语言模型难以精确生成大数量重复输出；忠实模拟大量输出导致高昂生成成本甚至无限生成循环 | 拒绝服务、钱包资金耗尽 |
| 误导模式（Misleading Patterns） | 技术性问题 | 模型按函数命名和表面结构推断"典型"行为，而非严格模拟实际编码逻辑（如看似二分查找实则死循环的脚本） | 控制流劫持 |
| 提示注入（Prompt Injections） | 技术性问题 | 嵌入在脚本注释或数据中的攻击指令可覆盖世界模型的模拟任务，甚至泄露上下文中的敏感信息 | 敏感信息恢复 |

**攻击流程示意图：**
1. 攻击者向用户输入中嵌入恶意指令/脚本。
2. 智能体将脚本传给世界模型模拟执行。
3. 世界模型输出错误的"安全"预测。
4. 智能体基于错误预测批准动作，在真实系统上执行。
5. 恶意代码运行或敏感数据泄露。

## 3. 实验设计

**基准数据集（AgentWorld-Robust）：**
- **设计目标**：近似最坏情况准确率（worst-case accuracy）而非平均情况，因为攻击者只需成功一次；刻意设计短小但对抗性的脚本来隔离各攻击类别的独立影响。
- **构建方式**：使用免费语言模型 MiMo V2.5（通过 OpenCode Zen）生成脚本，模拟资源有限的攻击者；每类别 100 个脚本，7 个类别共 **700 个脚本**。生成后自动筛除语法错误或沙箱中不可用的脚本并重新生成。
- **答案（ground truth）获取**：在 Docker 沙箱（Ubuntu 20.04，AMD EPYC 7713 处理器）中执行所有脚本，时间限制 30 秒，内存限制 512 MiB，超限脚本被终止并记录资源耗尽。

**评估模型：**
- **Qwen-AgentWorld**（35B 参数）
- **Meta Code World Model (CWM)**（32B 参数，稠密解码器自回归 LLM）
- 使用 vLLM 以未量化 bfloat16 精度部署，评估"最佳情况"性能；两者使用同一官方终端模拟系统提示词。

**评估指标：**
- **退出码准确率（Exit Code Accuracy）**
- **输出准确率（Output Accuracy）**：要求与世界模型预测输出与沙箱真实输出**完全匹配**；若沙箱超时且世界模型预测 30 秒后为空输出，也计为正确。

## 6. 论文的主要结论与发现

1. **世界模型非常容易被系统性诱导误预测**：攻击可达到 **95% 成功率**（部分类别），导致意外命令执行、拒绝服务、钱包资金耗尽、敏感信息提取。

2. **两类模型的准确率整体偏低**：
   - Qwen-AgentWorld：退出码准确率 86%，输出准确率仅 44%。
   - CWM：退出码准确率 77%，输出准确率仅 23%。

3. **退出码预测远易于输出预测**（86% vs 44% 的差距），但对需要精确输出的动作验证场景，这一差距意味着严重风险。

4. **世界模型普遍存在"乐观偏差"**：对干净退出脚本预测准确率高（97%），但错误退出（0%）和资源耗尽（51%）场景下准确率断崖式下降，即模型倾向于假设脚本会成功，即使在现实中会出错或超时。

5. **运行时间预测系统性低估**：95% 的案例中世界模型低估实际运行时间；21% 的样本在一小时内未完成，但 Qwen 对 19%、CWM 对 90% 的案例预测运行时间少于 1 秒。

6. **根本性漏洞难以修复**：可计算性（停机问题）、非确定性、缺失知识、外部环境依赖等属于近似世界建模的固有限制，无法通过简单训练或提示工程解决。

7. **对提示注入等传统 LLM 攻击反而较鲁棒**：世界模型对误导模式和提示注入的表现相对较好（Qwen 在两类上分别达到 91% 和 96% 的输出准确率），说明世界模型安全问题**不能简化为通用 LLM 鲁棒性研究**，存在独有攻击面。

8. **误导模式并非根本性缺陷**：CWM 被表面结构误导，但 Qwen 能正确识别死循环，说明该类问题可通过模型改进解决。

## 7. 优点

1. **领域开创性**：首次系统性地研究语言世界模型的安全性问题，填补了此前研究仅集中于机器人/连续控制领域的空白。

2. **威胁建模完整**：以 CIA 三要素（机密性、完整性、可用性）为攻击目标框架，全面覆盖智能体场景的各类安全危害。

3. **漏洞分类细致且实用**：将攻击向量分为"根本性问题"与"技术性问题"，为从业者确定防御优先级提供清晰指引；每个类别均配有具体可执行代码示例（Listing 1–7），极大增强可读性和可复现性。

4. **基准数据集设计有针对性**：AgentWorld-Robust 以"最坏情况准确率"为设计目标，贴近真实攻击者"只需成功一次"的威胁假设，是对现有基准（如 AgentWorldBench 的非对抗性、JailbreakBench 非模拟偏差）的有效补充。

## 8. 不足与局限

1. **模型覆盖有限**：仅评估两个公开模型（Qwen-AgentWorld 35B、CWM 32B），且均为同一技术路线（decoder-only LLM）；缺少对不同规模模型、不同架构、不同训练策略（如专门对抗训练的模型）的广泛验证。

2. **攻击场景仍以模拟为主**：论文区分了"模拟阶段"（世界模型预测）与"真实系统执行阶段"，攻击效果以"世界模型产生错误预测"为衡量标准，而非真实的端到端攻击（即攻击者通过完整智能体管道造成实际系统损害），外部效度受限。

3. **基准数据存在模板偏差风险**：所有脚本均由单一 LLM（MiMo V2.5）按模板生成，类别内脚本结构可能高度相似，无法充分代表真实世界攻击样本的多样性；对模板的依赖可能高估或低估某些类别的实际攻击成功率。

4. **无消融研究**：论文未系统测试不同防御措施（如移除注释、预生成随机数、限制 token 输出）对准确率的实际提升幅度，防御建议缺乏定量验证。

5. **"正确性"判定标准较为宽松与严格的二元划分**：超时后空输出即判定为正确（宽松），而输出要求精确匹配（严格）；对部分"部分正确"的输出缺乏更细粒度评分。

6. **运行时间预测实验依赖于 `time` 命令前缀**，该方式可能影响模型对脚本本身的模拟行为，且这类实验本身也受限于论文指出的固有预测局限。

7. **对根本性漏洞的讨论停留在理论层面**：虽然论证了停机问题等根本限制，但未量化这些限制在真实代理系统中的实际被利用难度和影响范围（例如，攻击者需要多少交互次数才能成功构造触发脚本）。

8. **应用场景局限**：仅研究终端/Shell 领域，未覆盖论文提到的 GUI 交互、工具调用等其他代理域；终端领域之外的世界模型安全风险仍然未知。
