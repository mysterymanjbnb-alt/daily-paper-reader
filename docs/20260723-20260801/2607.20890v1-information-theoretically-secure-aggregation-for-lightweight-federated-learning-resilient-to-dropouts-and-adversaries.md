## 摘要
设备端联邦学习（FL）能够在资源受限的设备（如智能手机和物联网节点）上实现隐私保护和个性化模型训练。为降低通信成本，基于符号的方法（例如signSGD）传输一位梯度。然而，暴露梯度符号使其易受推理攻击，而现有的安全聚合方案往往与这类方法不兼容，或者带来显著的计算和通信开销。我们提出了一种轻量级且信息论安全的聚合框架，专为基于符号的FL设计。该框架通过单轮安全乘法安全地计算多数投票（MV）多项式，在诚实多数假设下确保端到端的信息论安全性，同时仅向服务器揭示最终的聚合符号。为了提升效率和可扩展性，我们引入了两项关键技术。第一，逆形式指数缩减将有效MV多项式的次数减半，从而降低通信和计算成本。第二，我们提出了单轮安全乘法，实现了线性离线复杂度和存储，且仅需一次在线通信。这些技术共同将在线通信量相较传统方法降低多达99.5%，延迟降低多达85.7%。此外，通过利用固有的基于MDS码的解码，该框架实现了对掉线和敌意行为的鲁棒性，分别带来高达20.65%和10.74%的准确率提升。总体而言，所提出的框架为基于符号的FL中的大规模、低延迟和信息论安全聚合奠定了实用基础。

## Abstract
On-device federated learning (FL) enables privacy-preserving and personalized model training on resource-constrained devices such as smartphones and IoT nodes. To reduce communication cost, sign-based methods (e.g., signSGD) transmit one-bit gradients. However, exposing gradient signs makes them vulnerable to inference attacks, while existing secure aggregation schemes are often incompatible with such methods or incur significant computational and communication overhead. We propose a lightweight and information-theoretically secure aggregation framework tailored for sign-based FL. The framework securely computes the majority vote (MV) polynomial through single-round secure multiplication, ensuring end-to-end information-theoretic security under the honest-majority assumption while revealing only the final aggregated sign to the server. To enhance efficiency and scalability, we introduce two key techniques. First, inverse-form exponent reduction halves the effective MV polynomial degree, reducing both communication and computation costs. Second, we propose single-round secure multiplication, achieving linear offline complexity and storage with only a single online communication. Together, these techniques reduce online communication by up to 99.5% and latency by up to 85.7% compared to conventional approaches. Also, by leveraging inherent MDS-code-based decoding, the framework achieves robustness against both dropouts and adversarial behaviors, yielding accuracy gains of up to 20.65% and 10.74%, respectively. Overall, the proposed framework establishes a practical foundation for large-scale, low-latency, and information-theoretically secure aggregation in sign-based FL.

## 2. 论文提出的方法论

### 2.1 核心思想

论文的核心洞见是：**MV多项式具有独特的"单基结构"** ——所有单项式都是同一个聚合值 x = Σᵢ₌₁ⁿ xᵢ 的幂次，而非不同输入变量的乘积。这一结构使安全乘法可以大幅简化，从而在保持单轮在线通信的同时，将离线复杂度从指数级降至线性级。

### 2.2 关键技术一：逆形式指数缩减（Inverse-Form Exponent Reduction）

- 利用费马小定理：对于素数 p 和任意 x ≠ 0，有 x^(p-1) ≡ 1 (mod p)。
- 任何满足 j > (p-1)/2 的高次项 xʲ 可以等价改写为：**xʲ ≡ x^(−(p−1−j)) (mod p)**。
- 效果：MV多项式的有效最高次数从 p−2 降至 **N′ = (p−1)/2**，削减近一半的乘法深度和通信/计算成本。
- 举例（n=5, p=7）：F(x) = 3x⁵ + 2x³ + 3x ≡ 3x⁻¹ + 2x³ + 3x (mod 7)，其中 x⁻¹ 可用费马小定理 x^(p−2) 高效求逆。

### 2.3 关键技术二：单轮安全乘法（Single-Round Secure Multiplication）

论文提出两种互补方法：

**Method A（DN + 经典 N-BTE）——通用方法**：
- 采用两层结构（受ATLAS启发）：
  - **Layer 1（DN乘法）**：对每个二元乘法执行DN风格掩码打开，输出Beaver三元组友好形式 [w]ₜ = u − [a]ₜ（u为公开值）；
  - **Layer 2（N-BTE聚合）**：利用预计算的子集掩码乘积 {[a_I]ₜ}，通过二项式展开式在无额外打开的情况下聚合N个Layer 1输出。
- 复杂度：离线为 Θ(N·2^N) 次DN乘法和 O(2^N) 存储；在线需 N 次打开（单轮）。
- 该方法可处理任意N输入乘法，但指数级离线成本限制了其扩展性（N≤8~9）。

**Method B（单掩码幂共享，Single-Mask Power Sharing）——面向MV多项式的专用优化**：
- 核心观察：MV多项式的单项式都是 x 的幂，可仅用**单一随机掩码 a** 和二项式定理完成全部求幂：
  - xᵏ = (x̂ + a)ᵏ = Σᵣ₌₀ᵏ C(k,r) · x̂ʳ · aᵏ⁻ʳ
- **离线阶段**（输入无关，t < n/2 下进行 DN 降次）：采样掩码 [a]ₜ，计算 [aʲ]ₜ（j=2~N′），并预计算系数加权共享 [P_r]ₜ ← Σⱼ₌ᵣ^N′ cⱼ·C(j,r)·[a^{j−r}]ₜ。
- **在线阶段**（单次打开）：聚合共享 [x]ₜ = Σᵢ [sign(gᵢ)]ₜ → 掩码并打开 x̂ = x − a（唯一一次通信）→ 所有用户本地计算 [F(x)]ₜ = Σᵣ₌₀^N′ x̂ʳ · [P_r]ₜ。
- 复杂度：离线 O(N′) 次DN乘法、O(N′) 存储；在线仅**1次打开**、单轮完成，每用户仅传1个域元素。

### 2.4 FL框架整体流程（Algorithm 7）

1. **用户端**：计算局部梯度 → 量化1比特符号 xᵢ(τ) = sign(gᵢ(τ)) ∈ {−1,+1}^d → 通过 Method B（或A）生成 F(x(τ)) 的 t-共享 → 上传给服务器。
2. **服务器端**：MDS码解码恢复 F(x(τ)) → 广播全局方向 g̃(τ) = sign(x(τ))。
3. **用户更新**：θ(τ+1) ← θ(τ) − η·g̃(τ)。

### 2.5 安全性与鲁棒性保障

- **信息论安全**（诚实多数 t < n/2）：所有打开值均由均匀随机掩码一次性填充（one-time padded），与输入统计独立；通过模拟器范式证明端到端安全。
- **MDS码鲁棒性**：DN乘法的共享度翻倍后，以最小距离 d_min = n − 2t 的MDS码解码，当**2e + s ≤ n − 2t − 1**时（e为恶意错误数，s为掉线擦除数），可完全恢复正确聚合结果。

## 7. 优点

1. **安全性等级高**：信息论安全不依赖任何计算困难假设，即使敌手计算能力无限也无法破解——适合长期运行的FL系统，避免密钥管理等运维负担。
2. **理论洞见深刻**：识别MV多项式的"单基结构"并利用二项式定理将其转化为单掩码共享问题，将离线复杂度从指数级骤降至线性，是优雅的理论创新。
3. **结构简洁**：Method B采用单层架构（线性聚合→一次掩码打开→本地多项式求值），相较Method A的双层ATLAS式和Beaver三元组方法都更简单。
4. **天然鲁棒性**：无需额外机制，直接利用秘密共享的MDS码特性同时处理掉线（擦除）和恶意行为（错误），且可完全恢复（而非仅容忍）。

6. **诚实多数假设具有自洽性**：SIGN SGD-MV本身依赖多数用户的正确性——若 t ≥ n/2，多数投票本身就不再可靠，因此该假设与系统模型天然一致。

## 9. 综合评价与展望

从整体来看，该论文的**理论贡献具有高颗粒度的可计算性**——它将“信息论安全 + 单轮在线通信 + 对掉线与恶意敌手的全恢复能力”这三个在以往文献中往往需要取舍的维度，通过MDS码、DN秘密共享和单掩码幂共享的组合取得了统一。尤其是对MV多项式“单基结构”的观察，使保密多数投票从指数级离线准备变为线性级准备，理论上达成了“接近无隐私FL的在线成本”的安全聚合——这在FedAvg类大模型、数千级节点参与的物联网场景中具有明显的落地优势。

但论文仍有不容忽视的**应用间隙**：一方面，它未在真实异构硬件（如树莓派、Android手机）上验证功耗和内存占用，也未与现有libsecagg等工程实现进行实际延迟对比；另一方面，它在机器学习层面对抗鲁棒性的论证明显弱于密码学层面的容错论证。若希望将该框架推向真实FL平台，至少还需补充三方面工作：

- 在真实设备上验证通信带宽、端到端延迟和能耗分布；
- 结合差分隐私或鲁棒聚合规则，评估投毒攻击/后门攻击下的学习性能；
- 开发完整的掉线感知与位置恢复协议，明确擦除位置的物理层识别机制。

总体而言，这是一篇**理论型顶会文章**，其贡献集中于安全多方计算与联邦学习的交叉点上，具备较高的创新性和潜在影响力。该方法在“符号级、大规模、资源受限且用户半诚实的FL”中，提供了一个优雅且可操作的安全性基准方案。在诚实多数且异常率低于MDS码纠错能力的条件下，它是目前已知通信成本和安全性综合最优的符号联邦聚合协议之一。
